# Greek (el): glossary corrections from the style guide

Applied 2026-11-26 from `el/style.md` §14 ("Proposed glossary corrections").
All Greek entries were `proposed`, so no correction conflicted with an attested
entry. Status stays `proposed` throughout. Concepts the glossary lacks were not
added; they are listed as "new concept" for the coordinator.

| Concept | Before | After | Reason |
|---|---|---|---|
| patch (im2col / ViT patches) | none | τεμάχιο | new concept: one inflecting word that is not already a term; «περιοχή» is region, «ψηφίδα» reads as pixel, «τμήμα» is slice |
| image-patch | τμήμα εικόνας | τεμάχιο εικόνας | applied: follows patch, frees «τμήμα» for slice |
| patch-embedding | ενσωμάτωση τμήματος | ενσωμάτωση τεμαχίων | applied: follows patch |
| slice (note) | slicing = «τεμαχισμός» | slicing = «λήψη τμήματος» | applied (note only; preferred «τμήμα» unchanged): «τεμαχισμός» now means cutting into patches |
| multilayer-perceptron (note) | invariable «τα perceptron» | «τα perceptrons» | applied (note only): one plural rule for Latin-script common nouns (style §5.2) |
| sliding window | none | κυλιόμενο παράθυρο | new concept: the form Greek statistics uses (κυλιόμενος μέσος) |
| effective receptive field | none | ενεργό υποδεκτικό πεδίο | new concept: agrees with ενεργός ορίζοντας, ενεργό μέγεθος δείγματος |
| flipped kernel | none | ανακλασμένος πυρήνας | new concept: «ανεστραμμένος» is inverted dropout, «ανάστροφος» is transpose |
| trade-off | none | αντιστάθμιση | new concept: one term, also for bias–variance trade-off |
| flatten | none | ισοπεδώνω, ισοπέδωση, ισοπεδωμένος | new concept: all three test translators agreed |
| module (`nn.Module`) | none | module (το module, τα modules) | new concept: «μονάδα» is unit (κρυφή μονάδα) |
| derive, derivation | none | εξάγω, εξαγωγή | new concept: style §5.4; παράγω/παραγωγή collide with παράγωγος |
| panel of a figure | none | μέρος | new concept: «τμήμα» is slice, «πλαίσιο» is framework and box |
