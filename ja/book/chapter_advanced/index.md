# 発展

<!--en:05037863-->
「*基礎*」パートの締めくくりでは、H. G. Wells の『The Time Machine』を用いてリカレントニューラルネットワークを訓練した。「*The Time Traveller*」という言葉をプロンプトとして与えると、この小さなモデルは英語として認識できる単語や句読点こそ出力するものの、十数文字もすると文法的な一貫性が崩れてしまう。対照的に、今日の最前線にある基盤モデル（foundation model）は、パラメータ化された層、損失関数、自動微分（automatic differentiation）、勾配ベースのオプティマイザといったまったく同じ基本的な構成要素から築かれているにもかかわらず、立ち入った技術的な対話を長く続け、ソフトウェアを書いてデバッグし、競技数学の問題を解き、1 文のテキストから写実的な画像や動画を合成する。

<!--en:b538bca4-->
教室で作るプロトタイプと現代の最前線のシステムを分かつものは何か。その隔たりを越えるには、トイデータセット上の小さなモデルでは決して直面しない 4 つの根本的な課題を解決する必要がある。

<!--en:041dfe13-->
1. **最適化の安定性とスケーリング。**「*基礎*」パートでは、ミニバッチ確率的勾配降下法、学習率スケジュール、バッチサイズを主に便利なレシピとして扱ってきた。しかし、ネットワークが数百万から数十億個のパラメータへと大規模化するにつれ、幅の狭い層を滑らかに訓練できる学習率であっても、より幅広い、あるいはより深いネットワークでは瞬時に発散を引き起こすことがあり、悪条件の損失曲面によって数百万ステップにわたり進行が停滞することもある。

<!--en:85a6be45-->
2. **長距離の記憶と並列な系列処理。**古典的なリカレントネットワークは、どの細部が後から重要になるかわからないうちに、それまでに読み込んだすべてを固定幅の単一の隠れベクトルへと圧縮せざるを得ない。しかも、各タイムステップが直前のタイムステップの完了を待つため、再帰的な訓練では現代の GPU が備える大規模な並列性を活かせない。

<!--en:30f52b65-->
3. **ハードウェアのボトルネックと分散システム。**現代のアクセラレータは、オフチップメモリとオンチップレジスタの間、あるいは GPU 間のネットワークリンク越しにテンソルを移動させる速度よりも、はるかに高速に浮動小数点演算を実行する。大規模環境では、モデルの実環境における訓練速度や推論速度は、単純な演算回数と同程度に、メモリ帯域幅、数値精度、通信トポロジーによって左右される。

<!--en:27f18906-->
4. **静的なラベルを超えた学習。**教師ありの交差エントロピーは、すべての入力に一意な正解ラベルがある場合には機能する。しかし、環境内で行動する自律エージェントは、自身の方策（policy）が変化するにつれて分布がシフトする、遅延した疎なスカラー報酬から学習しなければならない。また、高解像度画像を合成する生成モデルには一致させるべき単一の目標ラベルが存在しないため、確率分布全体を比較する目的関数や、連続的な破壊過程を逆転させる目的関数が必要となる。

<!--en:7440d5de-->
PyTorch と JAX の両方で実装された本パートの 9 つの章では、これら 4 つの課題に体系的に取り組む。

<!--en:9612db8a-->
* **最適化とスケーリング（:numref:`chap_optimization`）。**まずは、悪条件の曲率、鞍点（saddle point）、ミニバッチ勾配のノイズといった要因によって高次元の非凸最適化（nonconvex optimization）がなぜ難しくなるのか、そして現代のオプティマイザがそれらの障壁をいかに克服するのかを検証する。確率的勾配降下法（stochastic gradient descent）からモメンタム、AdaGrad、RMSProp、Adam、分離型重み減衰（decoupled weight decay、AdamW）への発展を、ウォームアップやコサイン学習率スケジュールと組み合わせてたどり、最後に、臨界バッチサイズや最大更新パラメータ化（maximal update parametrization、$\mu$P）を通じてバッチサイズや幅の拡大に伴って学習率をどう変化させるべきかを明らかにし、完全な訓練プロトコルで締めくくる。

<!--en:e8ea8d07-->
* **アテンション機構と Transformer（:numref:`chap_attention` と :numref:`chap_transformers`）。** :numref:`chap_attention` では、キー、値、クエリに対する微分可能な内容参照型検索（content-addressable lookup）である*アテンション*を導入し、古典的な系列モデルにおける固定長ベクトルの記憶ボトルネックを打破する。Nadaraya–Watson カーネル回帰から出発し、加法アテンションとスケール化ドット積アテンション、系列対系列のアライメントのための Bahdanau アテンション、そしてマルチヘッド自己アテンションを構築する。続く :numref:`chap_transformers` では再帰構造を完全に排し、自己アテンション、位置ごとのフィードフォワードネットワーク、層正規化（layer normalization）、残差接続、および回転位置埋め込み（rotary position embedding、RoPE）を含む位置エンコーディングを組み合わせて、双方向エンコーダ（BERT）、因果的自己回帰デコーダ（GPT）、Vision Transformer（ViT）という 3 つの基本的な *Transformer* パラダイムへと統合する。あわせて、長文脈アテンションの計算上のボトルネック、生成時のキー・値キャッシュ（KV キャッシュ）、スパースな混合エキスパート（mixture of experts、MoE）層も掘り下げる。

<!--en:a4deae62-->
* **現代のリカレントネットワークと状態空間モデル（:numref:`chap_modern_rnn`）。**すべてのトークンが他のすべてのトークンに注意を向けなければならない場面では二次の自己アテンションが主流となるが、数十万トークンにわたって肥大化し続けるキー・値キャッシュを保持することは推論時に高コストとなる。そこで :numref:`chap_modern_rnn` では、「*推論時には固定サイズの状態を保ちながら、系列のすべての位置にわたって並列に訓練するにはどうすればよいか*」という新たな問いを携えて再帰構造へと立ち返る。状態の非線形な再帰を取り除くことで結合的な*スキャン*（associative scan）による厳密な並列評価が可能になることを示し、線形漸化式（linear recurrence）を連続時間の*状態空間モデル*（state space model、SSM）や HiPPO 多項式射影と結びつけ、さらに行列値の状態（線形アテンション）、入力依存の*選択的*（selective）状態空間モデル（Mamba）、誤り訂正型のデルタ則（DeltaNet）へと進む。

<!--en:100beb6f-->
* **計算性能（:numref:`chap_performance`）。** :numref:`chap_performance` では、訓練ステップの時間とメモリがどこに費やされるのかを問う。ルーフラインモデルによって算術演算に律速される演算とメモリトラフィックに律速される演算とを切り分け、さらに 3 つ目の制約である、すべての演算を発行するホスト側の処理によって、細かな演算がなぜ GPU をアイドル状態のまま遊ばせてしまうのかを説明する。そのうえで、コンパイル（`torch.compile` と `jax.jit`）、bf16 演算、より大きなミニバッチ、活性化チェックポイント（activation checkpointing）を組み合わせることで、1 基の GPU 上における GPT の訓練ステップのスループットを約 2 倍に高める。続いて複数の GPU へと拡張し、手書き実装と実用ライブラリの両方によるデータ並列（data parallelism）、allreduce とそのコストモデル、通信と逆伝播のオーバーラップ、そして単一のカードには収まらないモデルを訓練するための重み・勾配・オプティマイザ状態のシャーディング（ZeRO と FSDP）を扱う。

<!--en:665f490f-->
* **強化学習と深層強化学習（:numref:`chap_reinforcement_learning` と :numref:`chap_deep_rl`）。** :numref:`chap_reinforcement_learning` では、不確実性の下での意思決定に関する数学的・アルゴリズム的基礎を築く。具体的には、マルコフ決定過程（Markov decision process）、ベルマン最適方程式、価値反復法と方策反復法、モデルフリーの時間差分学習（Q 学習）、多腕バンディット問題における探索戦略、模倣学習、既知のダイナミクスの下での連続最適制御（倒立振子における LQR、iLQR、モデル予測制御）、REINFORCE と分散低減ベースラインによる直接的な方策最適化、およびニューラル方策勾配を扱う。続く :numref:`chap_deep_rl` では強化学習を深層関数近似へとスケールさせ、深層 Q ネットワーク（DQN）における経験再生とターゲットネットワークによって不安定性の「死の三要素」（deadly triad）に対処したうえで、一般化アドバンテージ推定（generalized advantage estimation、GAE）を備えたアクタークリティックのアーキテクチャ、近接方策最適化（proximal policy optimization、PPO）、最大エントロピーに基づくソフトアクタークリティック（soft actor-critic、SAC）、オフライン強化学習とモデルベース強化学習、KL 正則化制御、さらには自己回帰言語モデルのための強化学習（GRPO）を展開する。

<!--en:4ff6317d-->
* **敵対的生成ネットワークと拡散モデル（:numref:`chap_gans` と :numref:`chap_diffusion`）。**最後の 2 つの章では、現代の深層生成モデリングを発展させる。:numref:`chap_gans` では、生成サンプルと本物のサンプルを見分けるよう学習するクリティックと生成器との間のゲームとして生成を捉える。そこでは、各クリティックの損失がどのダイバージェンス（Jensen–Shannon、他の $f$ ダイバージェンス、MMD、$W_1$）を測っているのか、また本物から離れた生成器にもなお勾配が得られるのかを問い、本物と生成サンプルをペアでスコア付けするクリティックを比較するとともに、ゼロ中心の勾配ペナルティである $R_1$ と $R_2$ がなぜ勾配による訓練をデータ近傍へと収束させるのかを小さなゲーム上で示す。さらに、条件付きモデルを含めた画像生成器を構築してスコア付けし、今日なおボコーダ、画像オートエンコーダ、および拡散モデルから蒸留された 1 ステップ生成器の訓練に用いられている敵対的項で締めくくる。続く :numref:`chap_diffusion` では、今日の主力となる画像・音声・動画モデルの背後にある連続時間の生成パラダイムを展開する。信号対雑音比（signal-to-noise ratio）によってパラメータ化されたガウス確率経路に沿ってデータを破壊し、クリーンなデータ、ノイズ、スコア関数、あるいは*速度場*（velocity field）を予測するよう深層ノイズ除去器（denoiser）を訓練し、逆時間の確率微分方程式（stochastic differential equation、SDE）または確率フロー ODE を積分して新しいサンプルを生成する。その過程で、ノイズ除去拡散（DDPM/DDIM）と*フローマッチング*を統一し、分類器なしガイダンス（classifier-free guidance）を備えた U-Net および Diffusion Transformer（DiT）のバックボーンを構築し、一貫性（consistency）と平均速度（average velocity）の蒸留によってサンプリングをわずか数ステップへと高速化する。

<!--en:8a3ca36c-->
これらの章は、必ずしも先頭から順番どおりに読む必要はない。どの章がどの章を前提としているかは、まえがきの依存関係図（:numref:`fig_book_org`）に示されている。これらの章が一体となって、「*言語モデル*」パートおよび「*画像モデル*」パートが大規模な基盤モデルに応用するアーキテクチャ・数学・システム面のツールキットを提供する。
