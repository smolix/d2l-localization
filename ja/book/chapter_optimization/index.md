# 最適化アルゴリズム

<!--en:267e3a3d-->
前章までに登場したすべての深層ネットワークは、モメンタム $0.9$ のミニバッチ SGD や、線形ウォームアップとコサイン減衰を組み合わせた AdamW といった標準的なレシピで訓練してきた（:numref:`sec_training_recipes`）。訓練の実行中に値が `nan` へ発散すれば学習率を下げ、進行が停滞すればスケジュールやバッチサイズを調整する。本章ではオプティマイザのブラックボックスを開き、3 つの実践的な問いに答える。安全に使える最大の学習率とそれ未満での収束速度は何によって決まるのか、現代的な訓練レシピの各要素は更新ステップをどのように作り変えるのか、そしてモデルやバッチサイズが大きくなるにつれてそれらのハイパーパラメータをどのようにスケーリングしなければならないのか。

<!--en:a1cfb999-->
勾配降下法そのものは現代のコンピュータより古く、1847 年に Augustin-Louis Cauchy が惑星の軌道を計算するために提案し、1951 年には Herbert Robbins と Sutton Monro がノイズを含む観測のもとで減衰するステップサイズを用いた求根問題を解析した。古典的な設定と現代的な設定のいずれにおいても、勾配ベースのあらゆるオプティマイザは次の 2 つの根本的な障害によって制約される。

<!--en:20853ff6-->
1. **悪条件性（不均一な曲率）：**損失曲面がある方向には急激に曲がり、別の方向には緩やかに曲がっているとき、最も急な方向で安定を保てるほど小さい学習率を選ぶと、最も平坦な方向への進行が極端に遅くなる。

<!--en:6d77785d-->
2. **勾配ノイズ：**勾配はデータセット全体ではなく有限サイズのミニバッチから推定されるため、各更新にはサンプリング分散が伴い、一定のステップサイズでは反復点が最小点に落ち着かない。

<!--en:7f987165-->
![谷を横切る方向の曲率が谷に沿う方向の $20$ 倍大きい谷（$\kappa = 20$）における 2 つの障害。左：勾配降下法は急な方向をジグザグに行き来しつつ、平坦な方向には少しずつしか進まない。右：ノイズを含む勾配と一定のステップサイズのもとでは、反復点は最小点に到達するものの決して落ち着かず、ノイズ球（破線の楕円：2 標準偏差）の内部をさまよい続ける。](../img/mdl-opt-two-obstacles.svg)

<!--en:2eb95fef-->
:numref:`fig_opt_two_obstacles` は、同一の 2 次元の谷におけるこれら両方の障害を示している。現代のオプティマイザにおけるあらゆる設計上の選択は、次の 3 つの制御軸を通じてそのいずれかに対処する。

<!--en:02b01f48-->
* **ステップ方向：**モメンタム（:numref:`sec_momentum`）、Adam や AdamW のような座標ごとの適応的手法（:numref:`sec_adam`）、および Muon のような行列レベルで直交化する手法（:numref:`sec_muon`）は、生の勾配を前処理（preconditioning）や平滑化を施した方向に置き換えることで、悪条件（ill-conditioned）な谷に沿ってより速く進む。

<!--en:26068e71-->
* **ステップサイズスケジュール：**学習率のウォームアップ、コサイン減衰や線形減衰、およびウォームアップ・安定・減衰（warmup–stable–decay、WSD）スケジュール（:numref:`sec_scheduler`）は、序盤の速やかな移動と終盤の低いノイズとの間のトレードオフを調整する。

<!--en:52fc5741-->
* **ミニバッチサイズとスケーリング：**臨界バッチサイズ（critical batch size、:numref:`sec_batch_size`）は、ミニバッチを大きくしても最適化ステップ数がそれ以上減らなくなる境界を定める。一方、最大更新パラメータ化（maximal update parametrization、$\mu\text{P}$、:numref:`sec_scaling`）を用いると、小規模なプロキシモデルで調整した学習率をはるかに幅の広いネットワークへそのまま転移できる。

<!--en:30161f0b-->
本章では各手法を展開するにあたり、条件数（condition number）$\kappa = 20$ の 2 次元の二次関数の谷という解析モデルと、:numref:`sec_test_models` で導入する 2 つのニューラルネットワークベンチマーク（畳み込み分類器 `FashionCNN` とバイトレベルの Transformer 言語モデル `TinyLM`）での体系的な実証計測とを組み合わせる。最後に :numref:`sec_practice` では、勾配クリッピング、重み平均化、ハイパーパラメータのスケーリングを統合し、大規模な訓練の実行を設定・診断するためのエンドツーエンドのプロトコルを構築する。

<!--en:4583ac54-->
本章では、勾配、対称行列の固有値、および基本的なミニバッチ SGD（:numref:`subsec_linear-regression-minibatch-sgd`）に関する知識を前提とする。ハイパーパラメータの選択に直結する箇所では簡潔な導出を示し、より長い数学的証明は :numref:`chap_mdl-optimization` に譲る。教科書、論文、および実務者向けプレイブックに関する注釈付きの参考文献は :numref:`sec_optimization-further-reading` にまとめている。

<!--en:acc8203e-->
[中心的な問題]{.kicker}

<!--en:b9b351be-->
- **障害 1・悪条件性（$\kappa = \lambda_{\max}/\lambda_{\min} \gg 1$）：**
  - $f(\mathbf{x}) = 0.1x_1^2 + 2x_2^2$（$\lambda_1 = 0.2, \lambda_2 = 4, \kappa = 20$）では、$x_2$ 方向の安定性により $\eta < 2/\lambda_2 = 0.5$ に制限され、$x_1$ はステップあたり $<10\%$ しか縮小しない（$47$ ステップかけて誤差 $1\%$ に到達）

<!--en:550499f4-->
- **障害 2・ミニバッチ勾配ノイズ（$\operatorname{tr}(\boldsymbol{\Sigma})/b$）：**
  - $b$ 個の例をサンプリングすると、一定の学習率による反復点は分散 $\eta\sigma^2 / (2\lambda b)$ の定常な**ノイズ球**の内部に閉じ込められる

<!--en:26dd0777-->
- **本章の主眼：**現代のオプティマイザの各制御軸は、これら 2 つのボトルネックのいずれかに対処する

<!--en:bdab91cc-->
::: {.slide title="現代的な訓練レシピにおける 3 つの制御軸"}

<!--en:49387932-->
[構成の枠組み]{.kicker}

<!--en:80315afc-->
- **1. ステップ方向と前処理（§{sec_momentum}〜§{num:sec_muon}）：**
  - $-\nabla f(\mathbf{x})$ をモメンタム速度（$\mathbf{v}_t$）、座標ごとの RMS 正規化（AdamW）、またはスペクトル直交化（$\mathbf{U}\mathbf{V}^\top$、Muon）に置き換える

<!--en:d4d47dfd-->
- **2. ステップサイズスケジュール $\eta_t$（§{sec_scheduler}）：**
  - ウォームアップ中に $\eta_t$ を引き上げて $2/\eta_0$ 未満へ誘導し、高い移動バジェット $B_T = \sum_t \eta_t$ を維持したのち $\eta_T \to 0$ へ減衰させる

<!--en:347a23e7-->
- **3. バッチサイズ、幅スケーリング、安全策（§{sec_batch_size}〜§{num:sec_practice}）：**
  - $b$ を $b_{\text{noise}}$ に合わせ、$\mu\text{P}$（$\eta/m$）で異なる幅へ学習率を転移し、大域ノルムクリッピングと重み EMA で保護する

<!--en:be94bbbe-->
- **解析的な二次関数と線形データ（§{sec_gd}〜§{num:sec_sgd}）：**
  - 厳密な安定性の上限、$\sqrt{\kappa}$ の臨界減衰、および過剰損失 $\frac{\eta\operatorname{tr}\boldsymbol{\Sigma}}{4b}$ を、$\kappa=20$ の谷と NASA 翼型データセット（$n=1{,}500, d=6$）上で解く

<!--en:8cabdac7-->
- **相補的な 2 つのニューラルネットワーク（§{sec_test_models}〜§{num:sec_practice}）：**
  - **`FashionCNN`（$421\text{K}$ パラメータ）：**ホールドアウトのテスト正解率で評価する複数エポックの画像分類（$8.5$ エポックを $2{,}000$ ステップで訓練、$b = 256$）
  - **`TinyLM`（$471\text{K}$ / $3.3\text{M}$ パラメータ）：**WikiText-103 上のシングルパス・バイトレベル Transformer（層間の勾配スケールに $40\times$ の開き）

<!--en:6dc634f1-->
- **基礎とベンチマーク（§{sec_gd}〜§{num:sec_test_models}）：**
  - 安定条件 $\eta < 2/\lambda_{\max}$、安定性の縁 $\lambda_{\max} \approx 2/\eta$、ノイズ球 $\frac{\eta\sigma^2}{2\lambda b}$、カウントモデルの基準値、$3\times$ マルチシード閾値

<!--en:46a6adb8-->
- **前処理された更新方向（§{sec_momentum}〜§{num:sec_muon}）：**
  - モメンタム $\eta_{\text{eff}} = \frac{\eta}{1-\beta}$（$O(\sqrt{\kappa})$）、AdamW の時間スケール $\tau = \frac{1}{\eta\lambda}$、Muon の 5 ステップ Newton–Schulz 直交化 $-\eta\mathbf{U}\mathbf{V}^\top$

<!--en:4f271e46-->
- **スケジュール、スケーリング、実運用（§{sec_scheduler}〜§{num:sec_practice}）：**
  - ウォームアップ + WSD・コサインのバジェット $B_T$、臨界バッチサイズ $b_{\text{noise}} = \frac{\operatorname{tr}\boldsymbol{\Sigma}}{\|\nabla f\|^2}$、$\mu\text{P}$ の隠れ層学習率 $\eta/m$、クリッピング（$\theta=1$）、重み EMA
