# ベクトル、角度、射影

<!--en:5bc50d68-->
「基礎」パートの各章を通して、あらゆる入力をベクトルとして表してきた。画像はピクセル値の並びになり、単語は埋め込みになった。機械学習モデルがこれらのベクトルに対して行う操作は、突き詰めれば 3 つの幾何学的な操作に集約される。2 つの埋め込みが似ているかを測るときのようにベクトルを*比較*し、目的変数の組に最もよく当てはまる特徴量の組み合わせを求めるときのようにベクトルを*当てはめ*、分類器が入力を境界のどちら側に振り分けるかを決めるときのようにベクトルを*分離*する。2 次元平面では、これらの操作はいずれも長さ、角度、影からなるおなじみの図として描ける。しかし実際の入力は、誰にも図示できない何百、何千もの次元の空間に存在する。そのような高次元空間でも、こうした幾何学的なイメージはなお意味を持つのだろうか。

<!--en:7ee4d288-->
T シャツとズボンの見分けが具体的なテストになる。$28 \times 28$ の Fashion-MNIST 画像（:numref:`sec_fashion_mnist`）はそれぞれ $784$ 個のピクセル輝度の並びであり、$\mathbb{R}^{784}$ 内の 1 点である。考えうる最も単純な規則を試してみよう。平均的な T シャツと平均的なズボンを計算し、新しい各画像をより近いほうの平均に割り当てるのである。平面上なら「より近い」かどうかは目で見て確かめられるが、$\mathbb{R}^{784}$ では画像 1 枚あたり 1 回のドット積で済む計算になる。これら 2 つのクラスのテスト画像 $2{,}000$ 枚に対して、この規則は約 $92\%$ の割合で正しい判定を下す。これほど単純な規則がこれほどうまく機能するという事実から、2 つの点群は十分に離れて位置しており、目に見えない空間でも距離のような幾何学的概念が意味を保っていることがわかる。

<!--en:cbcdeee9-->
平面の幾何を任意の次元へと運ぶのはドット積である。長さはドット積の平方根であり、あるベクトルの別のベクトルへの影はドット積の比で表され、2 つのベクトルのなす角もドット積から直接定義される。本節では、この幾何学を 3 つの段階で展開する。第 1 に、1 組のベクトルを対象として、直線への射影、2 つのベクトルのなす角、およびコーシー・シュワルツの不等式を調べる。この不等式は :numref:`sec_linear-algebra` で代数的に証明したが、ここでは直角三角形から改めて証明する。第 2 に、本章の残りの部分で基盤となる部分空間の言葉（張る空間、線形独立性、基底、次元）を導入し、QR 分解を計算ツールとして最小二乗法を射影として解く。第 3 に、これらの考え方を高次元の画像へと持ち込み、$\mathbb{R}^d$ において無関係なベクトル同士がどれほど似ているかを問い、線形分類器を超平面として読み解く。

<!--en:0182e39c-->
なかでも特に重要な結果が 3 つある。射影の残差が射影先の直線や部分空間と直交し、それゆえに射影が最近接点になること、任意の次元で角度が矛盾なく定義されることを保証するコーシー・シュワルツの不等式、そして典型的なスケールが $1/\sqrt{d}$ となる $\mathbb{R}^d$ 内のランダムな方向の間のコサインである。データセットの読み込みを除けば、本節のコードはすべて素の NumPy で書かれており、どのフレームワークでも同一に動作する。

## ベクトルとその幾何学

<!--en:d7802703-->
### 点と方向

<!--en:cb61033d-->
ベクトルは、互いに補い合う 2 つの見方で捉えられる。*点*として見れば、$\mathbf{v} = (3, 2)$ は*原点*から右に $3$ 単位、上に $2$ 単位進んだ位置を表す。この見方に立つと、データセット全体が 1 つの点群になり、T シャツとズボンを見分けるような分類課題は 2 つの点群を分離する幾何学的な問題になる。一方、*方向*（または変位）として見れば、同じベクトルは右へ $3$ 歩、上へ $2$ 歩移動せよという指示になる。変位はどこを始点にしてもよいため、:numref:`fig_mdl-la-vectors` に描かれた平行な矢印はすべて同じベクトルを表している。

<!--en:95cb6fca-->
![ベクトルの 2 通りの読み方：座標 $(x, y)$ を持つ*点*として見るか（左）、どこからでも出発できる矢印としての*方向*と見るかであり、後者では図中のすべての矢印が同じベクトル $(3, 2)$ を表す（右）。](../img/mdl-la-vectors.svg)

<!--en:6427ec43-->
方向という見方をとれば、ベクトルの加算は直ちに理解できる。1 本目の矢印をたどり、その先端から 2 本目の矢印をたどればよい（:numref:`fig_mdl-la-vector-add`）。

<!--en:32984767-->
![先端と始点をつなぐベクトルの加算：1 本目の矢印をたどり、その終点から 2 本目の矢印をたどる。](../img/mdl-la-vector-add.svg)

<!--en:5e069ed1-->
減算も同様である。$\mathbf{u} = \mathbf{v} + (\mathbf{u}-\mathbf{v})$ が成り立つため、差 $\mathbf{u}-\mathbf{v}$ は点 $\mathbf{v}$ から点 $\mathbf{u}$ へと運ぶ変位の矢印にほかならない。

<!--en:63536ed4-->
本節のこれ以降の内容はすべて、:numref:`sec_linear-algebra` で導入した*ドット積*（dot product）というただ 1 つの演算から導かれる。2 つのベクトル $\mathbf{u}, \mathbf{v} \in \mathbb{R}^d$ に対し、対応する成分同士を掛けてその和をとる演算である。

<!--en:d4c9e49e-->
ドット積は $\mathbf{u}^\top\mathbf{v} = \mathbf{v}^\top\mathbf{u}$ と対称であるため、しばしば $\mathbf{u}\cdot\mathbf{v}$ と書く。2 本の矢印をイメージするときはドットを用い、行列の式の中に現れるときは転置を用いる。$\mathbf{u} = (1, 3)$ と $\mathbf{v} = (2, 1)$ に対しては $\mathbf{u}\cdot\mathbf{v} = 2 + 3 = 5$ であり、$\mathbf{u}$ の長さの二乗は $\mathbf{u}\cdot\mathbf{u} = 1 + 9 = 10$ となる。

<!--en:4f07e707-->
### 直線への射影

<!--en:fb98743b-->
ベクトル $\mathbf{v}$ のうち、別のベクトル $\mathbf{w}$ に沿った成分はどれだけあるだろうか。同じことだが、どのスカラー倍 $t\mathbf{w}$ が $\mathbf{v}$ に最も近くなるだろうか。これは線形代数における最も単純な当てはめ問題であり、単一の方向を使って $\mathbf{v}$ を近似し、最良の係数 $t$ を求めることにあたる。

<!--en:7fb2c9c3-->
先ほどの組 $\mathbf{v} = (1, 3)$ と $\mathbf{w} = (2, 1)$ で、$t$ にいくつか値を代入して試してみよう。$t = 1$ では、誤差 $\mathbf{v} - t\mathbf{w} = (-1, 2)$ の長さの二乗は $5$ である。$t = 0.5$ では誤差は $(0, 2.5)$ で長さの二乗は $6.25$ になり、$t = 1.5$ では $(-2, 1.5)$ でやはり長さの二乗は $6.25$ になる。最小値は $t = 1$ で達成され、最近接点は $(2, 1)$ となる。このとき残る誤差を*残差*（residual）と呼ぶ。ここでは残差は $\mathbf{r} = (-1, 2)$ であり、$\mathbf{w}$ とのドット積を計算すると $\mathbf{r}\cdot\mathbf{w} = -2 + 2 = 0$ となることに注目しよう。最短の誤差ベクトルは直線と直角に交わるのである。さらに都合のよいことに、長さの二乗の間には直角三角形の関係が成り立つ。すなわち $\|\mathbf{v}\|^2 = 10$ に対し、最近接点の長さの二乗は $5$、残差の長さの二乗も $5$ であり、$10 = 5 + 5$ となっている。

<!--en:78ef8837-->
この法則はすべての次元で成り立つ。

<!--en:f11f6e46-->
**命題（直交射影）。** *$\mathbf{w} \neq \mathbf{0}$ とする。$\mathbf{w}$ のスカラー倍のうち $\mathbf{v}$ に最も近いものは次で与えられる。*

<!--en:b4cb8a0e-->
*また、残差 $\mathbf{r} = \mathbf{v} - \operatorname{proj}_{\mathbf{w}}\mathbf{v}$ は $\mathbf{r}\cdot\mathbf{w} = 0$ を満たす。*

<!--en:7392742b-->
**証明。** 二乗誤差を $t$ の関数として最小化する。$\mathbf{v} - t\mathbf{w}$ 自身のドット積を展開すると、$t$ の二次関数が得られる。

<!--en:ad464355-->
最高次の係数 $\|\mathbf{w}\|^2$ は正であるため、$q(t)$ は導関数 $q'(t) = 2\|\mathbf{w}\|^2 t - 2\,\mathbf{v}\cdot\mathbf{w}$ がゼロになる点、すなわち $t^\star = (\mathbf{v}\cdot\mathbf{w}) / (\mathbf{w}\cdot\mathbf{w})$ で唯一の最小値をとる。$t^\star$ を代入すれば :eqref:`eq_mdl-projection` が得られる。残差を確認すると、$\mathbf{r}\cdot\mathbf{w} = \mathbf{v}\cdot\mathbf{w} - t^\star\,\mathbf{w}\cdot\mathbf{w} = 0$ となる。 $\blacksquare$

<!--en:64f6be81-->
先ほどの例では $q(t) = 5t^2 - 10t + 10$ となり、最小値 $5$ を $t^\star = 5/5 = 1$ でとるため、試行した値の結果が裏づけられる。$\operatorname{proj}_{\mathbf{w}}\mathbf{v}$ を、$\mathbf{v}$ の $\mathbf{w}$ への*射影*（projection）、あるいは*影*（shadow）と呼ぶ。射影は $\mathbf{v}$ のうち $\mathbf{w}$ に沿った成分を取り出し、残差はそれに直交する成分を取り出す。なぜ $\mathbf{w} \neq \mathbf{0}$ を仮定したかにも注意しよう。ゼロベクトルは方向を定めず、$\mathbf{w} = \mathbf{0}$ とおくとゼロ除算が生じるからである。

<!--en:3c8c7e7e-->
この直角のおかげで、長さの二乗がきれいに足し合わされる。2 つのベクトル $\mathbf{a}$ と $\mathbf{b}$ は、$\mathbf{a}\cdot\mathbf{b} = 0$ のとき*直交*（orthogonal）するという。このとき、和の長さの二乗を展開すると*ピタゴラスの定理*（Pythagoras' theorem）が得られる。

<!--en:17fcc80b-->
どの次元でも、直交する成分同士では交差項が消え、長さの二乗がそのまま足し合わされる。これを分解 $\mathbf{v} = \operatorname{proj}_{\mathbf{w}}\mathbf{v} + \mathbf{r}$ に適用すると $\|\mathbf{v}\|^2 = \|\operatorname{proj}_{\mathbf{w}}\mathbf{v}\|^2 + \|\mathbf{r}\|^2$ が得られ、先ほどの例ではこれが $10 = 5 + 5$ に対応する。

<!--en:6bd8ab0a-->
また、影が $\mathbf{w}$ と同じ向きか逆向きかを表す符号を含めた影の長さも必要になる。係数 $t^\star$ に $\|\mathbf{w}\|$ を掛けると、この*符号付き長さ*（signed length）が得られる。

<!--en:e2b6348d-->
先ほどの例では $5/\sqrt{5} = \sqrt{5}$ となり、$(2, 1)$ の長さに一致する。この符号付き長さは、本節の終盤で点から超平面までの符号付き距離として再び登場する。:numref:`fig_mdl-la-projection` にこの幾何学的な関係全体を示す。

<!--en:68c6ab69-->
![(a) $\mathbf{v}=(1, 3)$ の $\mathbf{w}=(2, 1)$ への射影（影）は $(2, 1)$ であり、残差 $(-1, 2)$ は $\mathbf{w}$ と直角に交わるため $\|\mathbf{v}\|^2 = 10 = 5 + 5$ が成り立つ。(b) コーシー・シュワルツの不等式の等号成立条件：$\mathbf{v}$ が $\mathbf{w}$ と共線であり、残差がゼロになる。](../img/mdl-la-projection.svg)

<!--en:5157fe18-->
### コーシー・シュワルツの不等式と角度

<!--en:5034ed7d-->
$784$ 次元の空間に分度器はない。それでも「2 枚の画像のなす角」に意味を持たせられるだろうか。意外なことに、その答えははるかに単純な問いから得られる。ベクトルの影が元のベクトル自身より長くなることはありうるだろうか。:numref:`fig_mdl-la-projection` のパネル (a) を見れば、答えは否である。影は $\mathbf{v}$ を斜辺とする直角三角形の 1 辺だからである。ピタゴラスの定理を使えば、この図をあらゆる次元で通用する証明へと変えられる。

<!--en:20fd32c9-->
**命題（コーシー・シュワルツの不等式）。** *すべてのベクトル $\mathbf{v}, \mathbf{w}$ に対して、次の不等式が成り立つ。*

<!--en:c2873e0f-->
*等号は $\mathbf{v}$ と $\mathbf{w}$ が共線（一方が他方のスカラー倍）のとき、かつそのときに限り成り立つ。*

<!--en:9c1f295e-->
**証明。** $\mathbf{w} = \mathbf{0}$ のときは両辺ともゼロになり、2 つのベクトルは共線（collinear）である。そうでないとき、$\mathbf{v}$ を $\mathbf{w}$ への射影とそれに直交する残差 $\mathbf{r}$ に分解する。ピタゴラスの定理 :eqref:`eq_mdl-pythagoras` より、次が成り立つ。

<!--en:cd096625-->
両辺に $\|\mathbf{w}\|^2$ を掛けて平方根をとれば、求める不等式が得られる。等号が成り立つのは $\mathbf{r} = \mathbf{0}$、すなわち $\mathbf{v} = t^\star\mathbf{w}$ のとき、かつそのときに限る。逆に $\mathbf{v} = t\mathbf{w}$ ならば、$|\mathbf{v}\cdot\mathbf{w}| = |t|\,\|\mathbf{w}\|^2 = \|\mathbf{v}\|\,\|\mathbf{w}\|$ となる。 $\blacksquare$

<!--en:fa7a1120-->
平たく言えば、ベクトルの影が元のベクトル自身より長くなることは決してなく、長さが一致するのは残差に何も残らない場合だけである。:numref:`sec_linear-algebra` ではコーシー・シュワルツの不等式を代数的に証明したが、ここではパネル (a)（:numref:`fig_mdl-la-projection`）から直ちに導かれ、パネル (b) が等号成立の場合を示している。

<!--en:ad1703e5-->
これで任意の次元において角度を定義できる。平面上では、余弦定理により $\mathbf{v}\cdot\mathbf{w} = \|\mathbf{v}\|\|\mathbf{w}\|\cos\theta$ が成り立つ（:numref:`sec_linear-algebra`）。$\mathbb{R}^d$ には実際に測定できる三角形がないため、この恒等式を定義へと転用する。ゼロでないベクトル $\mathbf{v}, \mathbf{w} \in \mathbb{R}^d$ に対し、そのなす*角度*を次で定義する。

<!--en:6d39c8db-->
$\arccos$ は $[-1, 1]$ 上でのみ定義されるため、この式が意味を持つのは比がその区間内に収まる場合に限られるが、コーシー・シュワルツの不等式によってそれは常に保証される。したがって角度はすべての次元で矛盾なく定義され、平面におけるドット積の公式が直ちに任意の次元で成り立つ。

<!--en:e027dd9b-->
コーシー・シュワルツの不等式における 2 つの等号成立条件は、$\theta = 0$（同じ向きを指すベクトル）と $\theta = \pi$（反対向きを指すベクトル）に対応する。

<!--en:fd46839c-->
ここで自然な疑問が生じる。この代数的な定義は、分度器で実際に測った角度と一致するのだろうか。結論から言えば一致する。任意の 2 つのベクトルは 1 つの平面内（共線であれば 1 つの直線上）に収まり、その平面内では通常の幾何学が成り立つ。射影を使えば、その平面に直交座標を入れられる。$\mathbf{q}_1 = \mathbf{w}/\|\mathbf{w}\|$ とおき、$\mathbf{r} \neq \mathbf{0}$ であれば $\mathbf{q}_2 = \mathbf{r}/\|\mathbf{r}\|$ とおく。これら 2 つのベクトルは単位長を持ち互いに直交するため、それらの線形結合のドット積は $\mathbb{R}^2$ におけるドット積とまったく同じように振る舞う。この座標系では $\mathbf{w} = (\|\mathbf{w}\|, 0)$、$\mathbf{v} = (\mathbf{v}\cdot\mathbf{w}/\|\mathbf{w}\|,\ \|\mathbf{r}\|)$ となる。平面上のこれら 2 本の矢印のなす角を分度器で測ると、そのコサインは $(\mathbf{v}\cdot\mathbf{w}/\|\mathbf{w}\|)/\|\mathbf{v}\|$ となり、:eqref:`eq_mdl-angle_formula` と一致する。先ほどの例 $\mathbf{v} = (1, 3)$ と $\mathbf{w} = (2, 1)$ では $\cos\theta = 5/(\sqrt{10}\sqrt{5}) = 1/\sqrt{2}$ となり、$\theta = 45^\circ$ が得られる。

<!--en:c37d00ee-->
ゼロでないベクトルに対して、直交とは $\theta = \pi/2$ を意味する。直交性を $\mathbf{v}\cdot\mathbf{w} = 0$ で定義しておくと、ゼロベクトルも含められるというちょっとした利点がある。ゼロベクトルに対して角度は定義されないが、すべてのベクトルと直交することになる。

<!--en:5ee71a04-->
:eqref:`eq_mdl-angle_formula` をコードにするには 2 行で足りるが、実用上注目すべき安全策が 1 つある。先ほどの例と、意図的に扱いを難しくした共線な組 $\mathbf{v} = (10^8 + 1, 3, 7)$ と $3\mathbf{v}$（真のコサインは $1$、真の角度は $0$）で試してみよう。共線な組については、生のコサインから $1$ を引いた値と、クリップ前の `arccos` も出力する。

<!--en:3f9251d9-->
最初の数値は $0.785 = \pi/4$ であり、先ほどの例の角度 $45^\circ$ と一致する。残りの 3 つの値は、なぜ `np.clip` が不可欠かを示している。厳密な演算では、コーシー・シュワルツの不等式によって比は $[-1, 1]$ の内部に保たれる。しかし浮動小数点演算では、丸めによって最終桁の 1 単位分だけ境界の外へはみ出すことがある。ここでは共線な組に対して $1 + 2.2 \times 10^{-16}$ が生じ、`np.arccos` が `nan` を返している。$[-1, 1]$ にクリップすることで、正しい答えである $0$ が復元される。

<!--en:7e89e81d-->
コーシー・シュワルツの不等式からは、和の長さが長さの和を決して超えないこともわかる。$\|\mathbf{v} + \mathbf{w}\|^2$ を展開し、交差項 $2\,\mathbf{v}\cdot\mathbf{w}$ を :eqref:`eq_mdl-cauchy-schwarz` によって $2\,\|\mathbf{v}\|\|\mathbf{w}\|$ で上から抑えると、:numref:`sec_linear-algebra` と同様に*三角不等式*（triangle inequality）$\|\mathbf{v} + \mathbf{w}\| \le \|\mathbf{v}\| + \|\mathbf{w}\|$ が得られる。

## 部分空間と最小二乗法

<!--en:d3495f0e-->
### 張る空間、基底、部分空間

<!--en:419d5f9e-->
ある量を時刻 $t = 0, 1, 2$ で 3 回測定し、データに最もよく当てはまる直線 $C + Dt$ を求めたいとしよう。測定値を並べてベクトル $\mathbf{y} \in \mathbb{R}^3$ とし、時刻を $\mathbf{t} = (0, 1, 2)$ にまとめ、$\mathbf{1} = (1, 1, 1)$ とおく。3 つの時刻で直線の値を評価すると、ベクトル $C\mathbf{1} + D\mathbf{t}$ が得られる。したがって最良の直線を見つけるとは、$C\mathbf{1} + D\mathbf{t}$ の形をしたベクトルのうち $\mathbf{y}$ に最も近いものを見つけることにほかならない。$C$ と $D$ がすべての実数を動くとき、これらの候補ベクトルは $\mathbb{R}^3$ 内で原点を通る平面を描き出す。直線への射影では単一の方向を扱ったが、平面やその高次元版を扱うには、基本的な用語をいくつか用意する必要がある。張る空間、基底、部分空間にすでに慣れている読者は、直線の当てはめを完了させる次の項へそのまま進んでかまわない。

<!--en:bef40482-->
重み付き和 $a_1\mathbf{v}_1 + \cdots + a_k\mathbf{v}_k$ を、$\mathbf{v}_1, \ldots, \mathbf{v}_k$ の*線形結合*（linear combination）と呼ぶ。そのような線形結合全体の集合が、それらの*張る空間*（span）である。

<!--en:a9e21417-->
$\mathbb{R}^2$ では（:numref:`fig_mdl-la-span`）、1 つのゼロでないベクトルが張る空間はその方向に沿って原点を通る直線であり、原点を通る同一の直線上にない 2 つのベクトルが張る空間は平面全体になる。先ほどの直線当てはめの問題では、候補となる当てはめ全体の集合は $\operatorname{span}(\mathbf{1}, \mathbf{t})$ である。

<!--en:e12cb16d-->
![左：1 つのゼロでないベクトル $\mathbf{v}$ が張る空間はそのスカラー倍全体の集合であり、原点を通る直線、すなわち 1 次元の部分空間をなす。右：原点を通る同一の直線上にない 2 つのベクトルは平面全体を張る。破線の平行四辺形は $\mathbf{x}$ を $2\mathbf{u} + \mathbf{w}$ と分解しており、$\mathbf{u}$ と $\mathbf{w}$ が線形独立であるため座標は一意に定まる。](../img/mdl-la-span.svg)

<!--en:b5eefee7-->
張る空間は、常に加算とスカラー倍について閉じていることに注目しよう。2 つの線形結合を足しても、あるいは 1 つの線形結合を実数倍しても、やはり線形結合になる。これら 2 つの閉包性を持つ空でないベクトルの集合を*部分空間*（subspace）と呼ぶ。すべての部分空間はゼロベクトル $\mathbf{0}$ を含まなければならない（任意の要素に $0$ を掛ければよい）。つまり、原点を通らない直線や平面は部分空間ではない。$\mathbb{R}^2$ の部分空間は、原点のみからなる集合、原点を通る直線、そして $\mathbb{R}^2$ 自身に限られる。$\mathbb{R}^3$ では、これに原点を通る平面が加わる。

<!--en:db1a9cbc-->
部分空間を張るベクトルの組には、冗長なものが含まれうる。あるベクトルが他のベクトルの張る空間にすでに含まれているなら、そのベクトルを取り除いても張る空間は縮まない。そのような冗長性が一切ないとき、ベクトルの組は*線形独立*（linearly independent）であるという。これは、線形結合 $a_1\mathbf{v}_1 + \cdots + a_k\mathbf{v}_k$ が $\mathbf{0}$ に等しくなるのが、すべての $a_i = 0$ とした自明な場合に限られることを意味する。先ほどのベクトル $\mathbf{1}$ と $\mathbf{t}$ は線形独立である。実際、$a_1\mathbf{1} + a_2\mathbf{t} = (a_1,\, a_1 + a_2,\, a_1 + 2a_2)$ がゼロになるのは $a_1 = a_2 = 0$ のときに限られる。

<!--en:67c38f91-->
部分空間の*基底*（basis）とは、その部分空間を張る線形独立なベクトルの組である。おなじみのベクトル $\mathbf{e}_1 = (1, 0)$ と $\mathbf{e}_2 = (0, 1)$ は $\mathbb{R}^2$ の*標準基底*（standard basis）をなすが、:numref:`fig_mdl-la-span` の傾いた 2 本の組も同様に立派な基底である。線形代数の基本定理（ここでは証明なしに用いる）によれば、与えられた部分空間のどの基底も同じ個数のベクトルからなり、その共通の個数を部分空間の*次元*と呼ぶ。これにより、「$d$ 次元空間」における $d$ に明確な意味が与えられる。すなわち、$\mathbb{R}^d$ の次元が $d$ であるのは、$\mathbf{e}_1, \ldots, \mathbf{e}_d$ が基底をなすからである。同様に、先ほどの直線当てはめの候補全体は $\mathbb{R}^3$ の 2 次元部分空間をなす。

<!--en:317ca8f8-->
部分空間内のすべての点に一意な座標を与えるのが線形独立性である。$\mathbf{v}_1, \ldots, \mathbf{v}_k$ が部分空間 $S$ の基底であれば、すべての $\mathbf{x} \in S$ は $\mathbf{x} = a_1\mathbf{v}_1 + \cdots + a_k\mathbf{v}_k$ とただ 1 通りに表せる。基底は $S$ を張るため、少なくとも 1 つの表示が存在する。もし係数 $a_i$ と $b_i$ を持つ 2 通りの表示が存在したとすれば、両者の差をとることで $\sum_i (a_i - b_i)\,\mathbf{v}_i = \mathbf{0}$ が得られ、線形独立性により $a_i = b_i$ がすべての $i$ に対して成り立つ。

<!--en:ad2b1e90-->
いったん基底を固定すれば、$k$ 次元の部分空間は $\mathbb{R}^k$ とまったく同じように振る舞い、各点は係数の組 $(a_1, \ldots, a_k)$ によって一意に指定される。直線の当てはめにおいては、その座標とは単に切片 $C$ と傾き $D$ のことである。

<!--en:629b53ef-->
### 部分空間への射影

<!--en:381ab7b6-->
具体的な測定値 $\mathbf{y} = (6, 0, 0)$ を用いて直線の当てはめに戻ろう。$C\mathbf{1} + D\mathbf{t}$ という形の平面 $\operatorname{span}(\mathbf{1}, \mathbf{t})$ 上の点のうち、$\mathbf{y}$ に最も近いものを求めたい。1 本の直線へ射影したときは、最近接点の残差はその直線と直交していた。平面への射影でも、残差は平面全体と直交し、したがって $\mathbf{1}$ と $\mathbf{t}$ の両方と直交するはずである（この事実はすぐ後で証明する）。両方のドット積をゼロとおくと、2 変数に関する 2 本の線形方程式が得られる。

<!--en:223d0bdd-->
第 2 式から第 1 式を引くと $2D = -6$ となるので、$D = -3$、$C = 5$ が得られる。最もよく当てはまる直線は $5 - 3t$ である。時刻 $t = 0, 1, 2$ における予測値は $(5, 2, -1)$ となり、残差は $\mathbf{r} = \mathbf{y} - (5, 2, -1) = (1, -2, 1)$ となる。直交性の確認も $\mathbf{r}\cdot\mathbf{1} = 1 - 2 + 1 = 0$ および $\mathbf{r}\cdot\mathbf{t} = 0 - 2 + 2 = 0$ と両方成り立っている。ピタゴラスの定理により、ここでも $\mathbf{y}$ の長さの二乗が $36 = 30 + 6$ ときれいに分解される。比較として、$\mathbf{y}$ を $\mathbf{1}$ のみに射影すると定数による当てはめ $\mathbf{y}\cdot\mathbf{1}/\mathbf{1}\cdot\mathbf{1} = 2$（標本平均）が得られ、その残差 $(4, -2, -2)$ の長さの二乗は $24$ になる。$\mathbf{t}$ に沿った傾きを許すことで、二乗誤差は $24$ から $6$ へと減少する。:numref:`fig_mdl-la-least-squares` に $\mathbb{R}^3$ におけるこの射影を示す。

<!--en:5881c1fd-->
![射影としての最小二乗法：測定値 $\mathbf{y}=(6, 0, 0)$ は候補直線 $C\mathbf{1}+D\mathbf{t}$ のなす平面の外にあり、平面内の最近接点は $(5, 2, -1)$（直線 $5-3t$）で、残差 $(1, -2, 1)$ は $\mathbf{1}$ と $\mathbf{t}$ の両方に垂直である。](../img/mdl-la-least-squares.svg)

<!--en:806b6db2-->
一般の結果を見通しよく述べ、証明するには、互いに直交し単位長を持つベクトルからなる基底を選ぶと都合がよい。ベクトル組 $\mathbf{q}_1, \ldots, \mathbf{q}_k$ がなす部分空間 $S \subseteq \mathbb{R}^n$ の基底は、すべてのベクトルが $\|\mathbf{q}_i\| = 1$ を満たし、異なるベクトル同士が $\mathbf{q}_i\cdot\mathbf{q}_j = 0$ を満たすとき*正規直交*（orthonormal）であるという。有限個のベクトルからなる任意の生成系からは、このような正規直交基底を作ることができる。:numref:`subsec_mdl-gram-schmidt` では、直線への射影だけを使って実際に構成する。これらの基底ベクトルを $n \times k$ 行列 $\mathbf{Q}$ の列として並べると、正規直交性は $\mathbf{Q}^\top\mathbf{Q} = \mathbf{I}_k$ という簡潔な形で表せる。なぜなら、成分 $(i, j)$（$\mathbf{Q}^\top\mathbf{Q}$ の各成分）は $\mathbf{q}_i\cdot\mathbf{q}_j$ に等しいからである。本章全体を通じて、文字 $\mathbf{Q}$ は正規直交列を持つ行列を表すために用いる。次の命題は、本章の残りの部分で最も頻繁に用いられる中核的な結果である。

<!--en:1065ae07-->
**命題（部分空間への射影）。** *$\mathbf{Q}$ が $S$ を張る正規直交列を持つとし、$\mathbf{P} = \mathbf{Q}\mathbf{Q}^\top$ とおく。このとき、すべての $\mathbf{x} \in \mathbb{R}^n$ に対して次が成り立つ。*
(i) *$\mathbf{P}\mathbf{x} \in S$ であり、残差 $\mathbf{x} - \mathbf{P}\mathbf{x}$ は $S$ のすべてのベクトルと直交する。*
(ii) *$\mathbf{P}\mathbf{x}$ は $S$ 内で $\mathbf{x}$ に最も近い唯一の点である。*
(iii) *$\mathbf{P}^2 = \mathbf{P}$ かつ $\mathbf{P}^\top = \mathbf{P}$ である。*

<!--en:ac543032-->
**証明。** (i) について、$\mathbf{P}\mathbf{x} = \mathbf{Q}(\mathbf{Q}^\top\mathbf{x})$ は $\mathbf{Q}$ の列の線形結合であるため $S$ に属する。残差に左から $\mathbf{Q}^\top$ を掛けると次が得られる。

<!--en:0d321c20-->
したがって残差はすべての列 $\mathbf{q}_i$ と直交し、ひいてはそれらの任意の線形結合とも直交する。(ii) について、任意の $\mathbf{s} \in S$ をとり、$\mathbf{x} - \mathbf{s} = (\mathbf{x} - \mathbf{P}\mathbf{x}) + (\mathbf{P}\mathbf{x} - \mathbf{s})$ と書く。$\mathbf{P}\mathbf{x} - \mathbf{s}$ は $S$ に属する一方、$\mathbf{x} - \mathbf{P}\mathbf{x}$ は $S$ と直交するため、ピタゴラスの定理 :eqref:`eq_mdl-pythagoras` より次が成り立つ。

<!--en:70de726d-->
ここで等号が成り立つのは $\mathbf{s} = \mathbf{P}\mathbf{x}$ のときに限られる。(iii) については、$\mathbf{P}^2 = \mathbf{Q}(\mathbf{Q}^\top\mathbf{Q})\mathbf{Q}^\top = \mathbf{Q}\mathbf{Q}^\top = \mathbf{P}$、および $\mathbf{P}^\top = (\mathbf{Q}^\top)^\top\mathbf{Q}^\top = \mathbf{P}$ である。 $\blacksquare$

<!--en:bbf24b27-->
逆に、(i) の直交条件は最近接点を一意に特徴づける。ある $\mathbf{s} \in S$ に対して残差 $\mathbf{x} - \mathbf{s}$ が $S$ と直交するならば、差 $\mathbf{P}\mathbf{x} - \mathbf{s} = (\mathbf{x} - \mathbf{s}) - (\mathbf{x} - \mathbf{P}\mathbf{x})$ は $S$ に属すると同時に $S$ と直交するため、自分自身と直交することになり、$\mathbf{s} = \mathbf{P}\mathbf{x}$ が導かれる。直線の当てはめで 2 本の直交方程式を解けば必ず最近接点が得られたのは、まさにこのためである。

<!--en:6b0a66d2-->
性質 (iii) の 2 つの式には、それぞれ明確な幾何学的意味がある。恒等式 $\mathbf{P}^2 = \mathbf{P}$ は、1 回目の射影ですでに $S$ 内に到達しているため、2 回目の射影を施しても何も変わらないことを表す。対称性 $\mathbf{P}^\top = \mathbf{P}$ こそが、この射影を*直交*射影たらしめている。対称性なしに $\mathbf{P}^2 = \mathbf{P}$ を満たす行列は*斜*射影行列（oblique projector）であり、ベクトルを斜めの方向に沿って列空間へ写すため、一般には最近接点から外れる（:exref:`ex_mdl-geometry-linear-algebraic-ops-projectors`）。1 次元の場合（$k = 1$）には、単一の単位列ベクトル $\mathbf{q} = \mathbf{w}/\|\mathbf{w}\|$ をとることで、$\mathbf{P} = \mathbf{q}\mathbf{q}^\top$ は先ほどの直線への射影 :eqref:`eq_mdl-projection` にそのまま帰着する。

<!--en:b116e9c4-->
先ほどの直線当てはめは、線形回帰の中核をなす最適化問題である*最小二乗法*（least squares）の 1 例である。行がデータ例、列が特徴量であるデータ行列を $\mathbf{A}$ とし、目的変数のベクトルを $\mathbf{y}$ とする。最小二乗法では、二乗誤差を最小化する係数ベクトル $\mathbf{x}$ を求める。

<!--en:2ea316d1-->
$\mathbf{x}$ がすべての係数ベクトルを動くとき、$\mathbf{A}\mathbf{x}$ は $\mathbf{A}$ の列が張る空間、すなわち*列空間*（column space）$\operatorname{col}(\mathbf{A})$ を描き出す。したがって最小二乗法とは、$\operatorname{col}(\mathbf{A})$ 内で $\mathbf{y}$ に最も近い点を求める問題である。先ほどの射影の命題により、その点は残差 $\mathbf{y} - \mathbf{A}\hat{\mathbf{x}}$ が $\mathbf{A}$ のすべての列と直交する点として定まる。この直交条件を $\mathbf{A}^\top(\mathbf{y} - \mathbf{A}\hat{\mathbf{x}}) = \mathbf{0}$ と書けば、次の*正規方程式*（normal equations）が得られる。

<!--en:24a0a268-->
これは手計算で解いた $2 \times 2$ 連立方程式の行列形式にほかならない。直線の当てはめでは、$\mathbf{A} = [\mathbf{1}\ \mathbf{t}]$ に対して $\mathbf{A}^\top\mathbf{A} = \left(\begin{smallmatrix}3&3\\3&5\end{smallmatrix}\right)$ および $\mathbf{A}^\top\mathbf{y} = (6, 0)$ となる。$\mathbf{A}$ の列が線形独立であれば、常に $\mathbf{A}^\top\mathbf{A}$ は可逆であり、最適な係数 $\hat{\mathbf{x}}$ は一意に定まる。列が線形従属である場合でも、当てはめベクトル $\mathbf{A}\hat{\mathbf{x}}$ は依然として $\operatorname{col}(\mathbf{A})$ 内の最近接点であるため一意のままだが、それを与える係数ベクトル $\hat{\mathbf{x}}$ は複数存在しうる。

<!--en:e863250c-->
したがってコード上では、当てはめ直線 $5 - 3t$ を計算する方法が 2 通りある。正規方程式を直接解くか、$\mathbf{P} = \mathbf{Q}\mathbf{Q}^\top$ を使って射影するかである。$\mathbf{Q}$ を得るには `np.linalg.qr` を呼び出す。この関数は、線形独立な列を持つ行列の列空間に対する正規直交基底を構築する（次の項ではこれを手計算で構成する）。

<!--en:9b7ccddf-->
どちらの方法でも、手計算と同じく係数 $C = 5$ と $D = -3$、射影された値 $(5, 2, -1)$、および残差 $(1, -2, 1)$ が復元される。2 行目にある確認用の 2 つのノルムは浮動小数点の丸め誤差の範囲でゼロになり、$\mathbf{P}^2 = \mathbf{P}$ と $\mathbf{Q}^\top\mathbf{r} = \mathbf{0}$ が裏づけられる。

<!--en:f30c7218-->
このように小さく性質のよい問題では、2 つの手法は完全に一致する。しかし $\mathbf{A}$ の列がほぼ線形従属である場合、$\mathbf{A}^\top\mathbf{A}$ を作ると問題の条件数（丸め誤差に対する感度）が二乗されてしまう（このことは :numref:`subsec_mdl-condition-number` で示す）。そのため、実用的な最小二乗ソルバは正規方程式を避け、代わりに列空間の正規直交基底を用いて計算する。

<!--en:1e921c1c-->
### グラム・シュミット法と QR 分解

<!--en:96f1ccae-->
実際にはどのようにして正規直交基底を構築するのだろうか。答えは射影の繰り返しである。2 つの線形独立なベクトルが与えられたとき、1 つ目のベクトルの方向はそのまま保ち、2 つ目のベクトルから 1 つ目の方向に沿った影を引き去る。射影の命題により、残った成分は 1 つ目のベクトルと直交する。

<!--en:792335e2-->
これを $\mathbf{a}_1 = (3, 4)$ と $\mathbf{a}_2 = (1, 0)$ に対して実行してみよう。$\mathbf{a}_1$ を正規化すると $\mathbf{q}_1 = \mathbf{a}_1/5 = (0.6, 0.8)$ となる。$\mathbf{a}_2$ の $\mathbf{q}_1$ への影は $(\mathbf{q}_1\cdot\mathbf{a}_2)\,\mathbf{q}_1 = 0.6\,(0.6, 0.8) = (0.36, 0.48)$ である。これを引くと $(1, 0) - (0.36, 0.48) = (0.64, -0.48)$ が残り、これは長さ $0.8$ のベクトルで、確かに $\mathbf{q}_1$ と直交している（$0.384 - 0.384 = 0$）。この残りを正規化すると $\mathbf{q}_2 = (0.8, -0.6)$ が得られる。以上の手順を逆にたどれば、元の各ベクトルを新しい正規直交基底で表すことができる。

<!--en:c1400eeb-->
行列記法で書けば、これは $\mathbf{A} = \mathbf{Q}\mathbf{R}$ である。ここで $\mathbf{A} = [\mathbf{a}_1\ \mathbf{a}_2]$、$\mathbf{Q} = [\mathbf{q}_1\ \mathbf{q}_2]$ であり、$\mathbf{R} = \left(\begin{smallmatrix}5&0.6\\0&0.8\end{smallmatrix}\right)$ はドット積 $\mathbf{q}_i\cdot\mathbf{a}_j$ を集めた行列である。なぜ $\mathbf{R}$ が上三角行列になるかにも注目しよう。構成法から、各 $\mathbf{a}_j$ は $\mathbf{q}_1, \ldots, \mathbf{q}_j$ のみに依存するからである。

<!--en:bf691021-->
この考え方を任意の線形独立なベクトル組 $\mathbf{a}_1, \ldots, \mathbf{a}_k$ へ拡張したものが*グラム・シュミットの直交化法*（Gram–Schmidt process）である。ベクトルを順に処理し、各 $\mathbf{a}_j$ から、すでに構成した単位ベクトル $\mathbf{q}_1, \ldots, \mathbf{q}_{j-1}$ への射影 :eqref:`eq_mdl-projection` を引き去り、残りを正規化して $\mathbf{q}_j$ を得る。その結果として、$\operatorname{span}(\mathbf{a}_1, \ldots, \mathbf{a}_k)$ の正規直交基底が得られると同時に、*QR 分解*（QR factorization）$\mathbf{A} = \mathbf{Q}\mathbf{R}$ も得られる。ここで $\mathbf{Q}$ は正規直交列を持ち、$\mathbf{R}$ は対角成分が正の上三角行列である。この分解には線形独立性が不可欠である。それ以前のベクトルが張る空間にすでに含まれているベクトルからは残りがゼロになり、正規化できないからである。張る空間の正規直交基底だけが必要なら、残りがゼロになったベクトルを単に飛ばして先へ進めばよい。したがって有限個のベクトルからなる任意の生成系から正規直交基底が得られ、先ほど用いた存在の主張が正当化される。

<!--en:9979f561-->
数値計算ライブラリは鏡映に基づく別のアルゴリズムで QR 分解を計算しており、浮動小数点演算においてはるかに良好に振る舞う。その出力は符号の違いを除いてグラム・シュミット法と一致する。$\mathbf{Q}$ のある列とそれに対応する $\mathbf{R}$ の行の符号を同時に反転させても、積 $\mathbf{Q}\mathbf{R}$ は変わらないからである。$\mathbf{A}$ の列が線形独立であれば、不定性はこの符号反転のみに限られる。2 ステップのグラム・シュミット計算を `np.linalg.qr` と比較し、符号を除いて同じ列が得られることを確かめてみよう。

<!--en:78f737a8-->
グラム・シュミット法は $(0.6, 0.8)$ と $(0.8, -0.6)$ を生成する一方、`np.linalg.qr` は両方の列の符号を反転させたものと、対角成分が $-5$ と $-0.8$ である $\mathbf{R}$ を返す。これは同じ基底であり、符号を除けば手計算で求めたドット積 $5$、$0.6$、$0.8$ とも一致している。浮動小数点演算では、引き算を実行する順序も重要になる。ほぼ線形従属な列に対しては、*古典的*（classical）グラム・シュミット法と呼ばれる上記の定式化は徐々に直交性を失っていく（:exref:`ex_mdl-geometry-linear-algebraic-ops-gram-schmidt`）。

## 高次元における類似度

<!--en:3e11721f-->
ここまでの結果には、すべて $\mathbb{R}^2$ や $\mathbb{R}^3$ の図が伴っていた。ここからは図を描くことのできない空間へと移り、実際の 2 枚の画像がどれほど似ているか、そして無関係なベクトル同士が純粋な偶然によってどの程度の類似度を持つかを考える。Fashion-MNIST データセット（:numref:`sec_fashion_mnist`）を `d2l.FashionMNIST` 経由で NumPy 配列として読み込み、各画像を $784$ ピクセルの行ベクトルへ平坦化し、$[0, 1]$ にスケーリングする。

<!--en:9a18cdc3-->
これら $70{,}000$ 枚の画像は、いまやそれぞれが $\mathbb{R}^{784}$ 内の 1 点である。

### コサイン類似度

<!--en:baaf30d4-->
:eqref:`eq_mdl-angle_formula` の内部にある比は、:numref:`sec_linear-algebra` で導入した*コサイン類似度*（cosine similarity）である。

<!--en:dd159002-->
コサイン類似度は長さを無視して方向だけを比較する。ある画像と、その明るさを $10\%$ に落としたコピーはユークリッド距離では大きく離れているが、コサイン類似度は依然として $1$ である。

<!--en:f92b2d05-->
このスケール不変性により、コサイン類似度は埋め込みに対する最近傍検索や、SimCLR :cite:`Chen.Kornblith.Norouzi.ea.2020` のような対照学習（contrastive learning）の目的関数における標準的な指標となっている。SimCLR では、同一画像の 2 つのビューから生成された埋め込みの方向を揃える。一方、元の Transformer のアテンション層は異なる選択をしており、$1/\sqrt{d}$ でスケーリングした*正規化なしの*ドット積を用いるため（その理由はまもなく導出する）、そこではベクトルの長さも情報を持つ。後発の多くのモデルでは、先にクエリとキーを正規化する（:numref:`subsec_qk-norm`）ことで、スコアを再びスケール付きコサインへと戻している。

<!--en:1aa17ceb-->
### ランダムな方向の概直交性

<!--en:301e8003-->
無関係な 2 枚の画像、あるいは無関係な 2 つの埋め込みを選んだとしよう。純粋な偶然によって、それらの間にどの程度のコサイン類似度が期待されるだろうか。比較の基準がなければ、観測されたコサインが意味のある大きさかどうかを判断できない。最も明快な基準は、空間のどの領域にも偏りを持たせず、単位球面上から一様ランダムに選んだ方向である。

<!--en:3b1a9ff9-->
**命題（概直交性）。** *単位ベクトル $\mathbf{u} \in \mathbb{R}^d$ を固定し、$\mathbf{v}$ を $\mathbb{R}^d$ の単位球面上の一様分布から抽出する。このとき $\cos\theta = \mathbf{u}\cdot\mathbf{v}$ は次を満たす。*

<!--en:fe1ec783-->
**証明。** 球面上の一様分布は回転に対して不変であるため、$\mathbf{u} = \mathbf{e}_1$ となるように座標系を回転させてよく、このとき $\cos\theta = v_1$ となる。この分布は符号反転 $\mathbf{v} \mapsto -\mathbf{v}$ によっても変わらないため、$\mathbb{E}[v_1] = 0$ である。対称性により、すべての座標は同じ二次モーメント $\mathbb{E}[v_i^2]$ を持つ。$\sum_{i=1}^d v_i^2 = \|\mathbf{v}\|^2 = 1$ であるから、期待値をとると $d\,\mathbb{E}[v_1^2] = \mathbb{E}\bigl[\sum_{i=1}^d v_i^2\bigr] = 1$ となり、したがって $\textrm{Var}(\cos\theta) = \mathbb{E}[v_1^2] = 1/d$ が得られる。裾の評価はチェビシェフの不等式 $\Pr(|X - \mathbb{E}[X]| \ge \varepsilon) \le \textrm{Var}(X)/\varepsilon^2$（:numref:`sec_prob`）から直ちに従う。 $\blacksquare$

<!--en:caf824ff-->
したがって、ランダムな 2 つの方向のなす角のコサインは典型的に $1/\sqrt{d}$ のオーダーになる。$d = 784$ では標準偏差が $1/28 \approx 0.036$ となり、画像空間内のランダムな 2 つの方向はほとんど常に直交から数度以内に収まる。チェビシェフの不等式は $|\cos\theta| \ge 0.1$ となる確率を $1/(784 \cdot 0.01) \approx 0.13$ 以下と評価するが、真の確率は $0.01$ 未満である。チェビシェフの不等式が緩いのは分散しか使っていないためであり、より鋭い指数型の上界は :numref:`sec_mdl-concentration-generalization` で扱う。

<!--en:9f0ccbbb-->
低次元での様相はまったく異なる（:numref:`fig_mdl-la-cosine-highd`）。平面（$d = 2$）では、固定した方向とランダムな方向のなす角は $[0, \pi]$ 上で一様であるため、直交から $0.1$ ラジアン以内に収まる確率と、共線から $0.1$ ラジアン以内に収まる確率は等しい（それぞれ約 $6\%$）。ところが*コサイン*は $\pm 1$ の近くに集中する。$\cos\theta$ が $\theta = 0$ と $\theta = \pi$ の近くで平坦になるためであり、$|\cos\theta| > 0.9$ となる確率が約 $0.29$ であるのに対し、わずか $0.06$ にすぎない（$|\cos\theta| < 0.1$ の場合）。$d = 3$ ではコサインは $[-1, 1]$ 上で一様になり、これは Archimedes にも知られていた古典的な結果である。$d = 4$ からは密度が $0$ でピークを持つようになり、$d = 10$ では幅 $1/\sqrt{10} \approx 0.32$ の釣鐘型をなし、$d = 1000$ に至ると幅が約 $0.03$ の鋭いスパイクへと収縮する。

<!--en:bacff0e4-->
![次元 $d = 2$、$10$、$1000$ における独立なランダム単位ベクトル間のコサインのヒストグラム。$d = 2$ では、角度は一様であるにもかかわらずコサインが $\pm 1$ 付近に集中する。$d = 10$ では $0$ の周りに釣鐘型をなし、$d = 1000$ では命題の通り幅 $\approx 1/\sqrt{d}$ の細いスパイクへと集中する。](../img/mdl-la-cosine-highd.svg)

<!--en:3d0eff3b-->
$d = 784$ におけるこの等方的な基準をシミュレーションで確かめてみよう。標準ガウスベクトルの分布は回転不変であるため、それを正規化すると一様ランダムな単位ベクトルが得られる。同じコードセル内で、すぐ後のアテンションの議論で必要になる分散、すなわち $\mathbf{q}\cdot\mathbf{k}$ の分散（$64$ 次元の独立な標準正規ベクトルの場合）もあわせて推定しておく。

<!--en:d5b6876d-->
経験標準偏差は $1/\sqrt{784} \approx 0.036$ と一致し、正規化なしのドット積の分散は次元である $64$ に近い値となる。

<!--en:a55c9d3d-->
しかし実データが等方的に見えることはめったにない。無関係な 2 枚の Fashion-MNIST 画像は、ほぼ直交するベクトルのように振る舞うだろうか。テスト画像からランダムなペアを $5{,}000$ 組サンプリングし、まず生のピクセルに対して、次に訓練画像の平均を引いた後でコサインを測ってみよう。

<!--en:bdc7c618-->
結果は似ても似つかない。生の画像の平均コサインは約 $0.6$、標準偏差は約 $0.18$ であり、$0 \pm 0.036$ とは程遠い。理由は単純で、ピクセル輝度は非負であるため、すべての画像が $\mathbb{R}^{784}$ の同じ正象限（positive orthant）に属しており、負のドット積が生じえないからである。平均画像を引くとコサインの中心は $0$ に移るが、その標準偏差は約 $0.34$ と依然として等方的な値のほぼ 10 倍もある。先ほどの命題によれば、$0.34$ という広がりはわずか 8〜9 次元におけるランダムな方向に相当する（$1/0.34^2$ は $8$ と $9$ の間にある）。コサインから判断する限り、中心化された画像群は $784$ 次元ではなく 10 次元未満の空間に収まる点群のように振る舞っており、これは :numref:`sec_mdl-svd-low-rank` で学ぶ低ランク構造の片鱗である。実用上、あるコサインが大きいと言えるのは、*同じ*データセットからとった無関係なペアの広がりよりも際立っている場合に限られる。関連するペアをその背景分布の上へと押し上げることこそが、埋め込みモデルを訓練する役割である。

<!--en:c078f0e2-->
### アテンションスコアのスケール

<!--en:aa1c0d22-->
ドット積アテンション（:numref:`sec_attention-scoring-functions`）は、クエリ $\mathbf{q} \in \mathbb{R}^d$ とキー $\mathbf{k}_1, \mathbf{k}_2, \ldots$ の適合度を $\mathbf{q}\cdot\mathbf{k}_j/\sqrt{d}$ によってスコア付けし、そのスコアをソフトマックスに通す :cite:`Vaswani.Shazeer.Parmar.ea.2017`。簡単な分散の計算から、$\sqrt{d}$ の由来が説明できる。全 $2d$ 個の成分（$\mathbf{q}$ と $\mathbf{k}$ の成分）が互いに独立で、平均 $0$、分散 $1$ を持つと仮定しよう。このとき各積 $q_i k_i$ は平均 $0$、分散 $\mathbb{E}[q_i^2]\,\mathbb{E}[k_i^2] = 1$ を持ち、異なる項同士は $\mathbb{E}[(q_i k_i)(q_j k_j)] = \mathbb{E}[q_i]\,\mathbb{E}[k_i]\,\mathbb{E}[q_j]\,\mathbb{E}[k_j] = 0$（$i \neq j$）より無相関である。したがって $d$ 個の項の分散はそのまま足し合わされる。

<!--en:b15a3f27-->
ゆえに生のドット積の標準偏差は $\sqrt{d}$ となってヘッド次元とともに増大するが、$\sqrt{d}$ で割れば単位分散に戻る。このスケーリングがないと、ソフトマックスは飽和してほぼワンホットに近い重みになってしまう。$d = 64$ の場合、生のスコアの標準偏差は $8$ であり、$8$ だけ離れた 2 つのスコアにはソフトマックス重み $0.9997$ と $0.0003$ が割り当てられる。$\sqrt{d} = 8$ で割ることで、重みは健全な $0.73$ と $0.27$ に戻る。幾何学からもまったく同じスケーリングが導かれる。各ベクトルの長さは約 $\sqrt{d}$ である一方、無関係な方向のなす角のコサインは約 $1/\sqrt{d}$ であるため、そのドット積の典型的な大きさは $\sqrt{d}\cdot\sqrt{d}\cdot (1/\sqrt{d}) = \sqrt{d}$ となる。

<!--en:4e03ff86-->
もっとも、無関係なキーが多数ある場合、概直交性があるからといってそれらを無視できるわけではない。無関係な個々のコサインのスケールは $1/\sqrt{d}$ であっても、独立な $n$ 個のキーの中での*最大の*コサインは主要項で $\sqrt{2\ln n / d}$ のように増大する。大規模な検索インデックスでは、このような背景ノイズによる最悪の一致度が $1/\sqrt{d}$ の数倍に達するため、真に関連するキーははるかに高い水準を超えなければならず、訓練によってまさにそれが実現される（:exref:`ex_mdl-geometry-linear-algebraic-ops-random-cosines` でこの効果を具体的な数値で確認する）。

<!--en:f9f996c7-->
## 超平面と決定境界

<!--en:09326fa0-->
線形分類器は、入力 $\mathbf{x}$ に対して 2 つの幾何学的な問いを投げかける。決定境界（decision boundary）のどちら側にあるか、そしてその境界からどれだけ離れているかである。本節を通して、この境界を $\mathbf{w}\cdot\mathbf{x} + b = 0$ と書く。

<!--en:267a7007-->
### 超平面と符号付き距離

<!--en:ded15950-->
平面上ではこの方程式は直線を定め、簡単な例から $\mathbf{w}$ と $b$ の役割がわかる。$\mathbf{w} = (2, 1)$、$b = -1$ としよう。$2x + y - 1 = 0$ を満たす点は直線 $y = 1 - 2x$ をなす。この直線上のすべての点 $\mathbf{x}$ は $\mathbf{w}\cdot\mathbf{x} = -b$ を満たすため、$\mathbf{w}$ への影はすべて同じ符号付き長さ :eqref:`eq_mdl-signed-length` を持つ。

<!--en:de579ee2-->
幾何学的には、この直線は $\mathbf{w}$ に垂直に走り、符号付き位置 $-b/\|\mathbf{w}\|$、すなわち原点からの距離 $|b|/\|\mathbf{w}\| = 1/\sqrt{5} \approx 0.45$ の位置でその方向を横切る。

<!--en:5b710d5e-->
高次元でも事情はまったく変わらない。$\mathbb{R}^d$ における*超平面*（hyperplane）とは、集合 $\{\mathbf{x} : \mathbf{w}\cdot\mathbf{x} + b = 0\}$（ただし $\mathbf{w} \neq \mathbf{0}$）のことであり、$\mathbf{w}$ をその*法線*（normal）ベクトル、$b$ をその*オフセット*と呼ぶ。これは部分空間 $\mathbf{w}\cdot\mathbf{x} = 0$ を平行移動させたものにすぎず、その次元は $d - 1$ である（:numref:`subsec_mdl-rank`）。すなわち、$\mathbb{R}^2$ では直線、$\mathbb{R}^3$ では平面、画像空間内では $783$ 次元の平坦な面となる。超平面は $\mathbb{R}^d$ を 2 つの*半空間*（half-space）$\mathbf{w}\cdot\mathbf{x} + b > 0$ と $\mathbf{w}\cdot\mathbf{x} + b < 0$ に分割する。$b$ を変化させると、超平面は傾きを変えずに $\mathbf{w}$ に沿って平行移動する。

<!--en:b183d8d7-->
任意の点 $\mathbf{x}$ は超平面からどれだけ離れているだろうか。超平面上の任意の点 $\mathbf{x}_0$ をとると、$\mathbf{w}\cdot\mathbf{x}_0 = -b$ が成り立つ。$\mathbf{x}$ から超平面までの距離は、変位 $\mathbf{x} - \mathbf{x}_0$ の法線 $\mathbf{w}$ への影の符号付き長さであり、次の*符号付き距離*（signed distance）を与える。

<!--en:6df46c96-->
$\mathbf{x}_0$ が完全に消えていることに注目しよう。符号付き距離は $\mathbf{x}$、$\mathbf{w}$、$b$ のみに依存する。その値は、$\mathbf{w}$ が向く側で正、反対側で負、超平面上ではゼロになる。先ほどの平面の例では、原点は符号付き距離 $-1/\sqrt{5}$ の位置にあり、点 $(1, 1)$ はスコア $\mathbf{w}\cdot\mathbf{x} + b = 2$ を持つため正の側の符号付き距離 $+2/\sqrt{5} \approx 0.89$ の位置にある。直線上でこの点に最も近い点は $(1, 1) - (2/5)(2, 1) = (0.2, 0.6)$ である。点 $(0, 1)$ のスコアは $0$ であり、ちょうど直線上に乗っている（:numref:`fig_mdl-la-hyperplane`）。

<!--en:9318899b-->
![超平面 $\mathbf{w}\cdot\mathbf{x}+b=0$（法線 $\mathbf{w}$）。左：$\mathbf{w}=(2, 1)$、$b=-1$ のとき、超平面は直線 $2x+y=1$（原点からの距離 $1/\sqrt{5}$）であり、点 $(1, 1)$ は符号付き距離 $2/\sqrt{5}$ の位置（$\mathbf{w}$ が向く側）にあり、色付きの半平面は $\mathbf{w}\cdot\mathbf{x}+b>0$ を表す。右：3 次元では同じ方程式が平面を定める。](../img/mdl-la-hyperplane.svg)

<!--en:07751cce-->
ラベル付きデータ例 $(\mathbf{x}, y)$（ただし $y \in \{-1, +1\}$）に対しては、それが*正しい*側にあるかどうかも知りたい。符号付き距離にラベルを掛けたものは*マージン* $y\,(\mathbf{w}\cdot\mathbf{x} + b)/\|\mathbf{w}\|$ を定め、分類が正しいときに正となり、点が本来の半空間の奥深くにあるほど大きくなる。$(\mathbf{w}, b) \to (c\mathbf{w}, cb)$（任意の $c > 0$）と再スケーリングしても超平面とマージンは変わらない一方、生のスコア $\mathbf{w}\cdot\mathbf{x} + b$ は $c$ 倍になる。したがって、生のスコアを最大化するような学習目的関数は、いずれも $\mathbf{w}$ のスケールに制約を課さなければならない。

<!--en:18cd2177-->
### 最近傍平均分類器

<!--en:894b69eb-->
2 つのクラスを分離するには、どの超平面を選ぶべきだろうか。最も単純な規則には反復的な訓練すら不要で、平均がより近いほうのクラスへ $\mathbf{x}$ を割り当てればよい。驚くべきことに、この規則自体がただ 1 つの超平面になる。2 つのクラス平均を $\bar{\mathbf{x}}_0$ と $\bar{\mathbf{x}}_1$ としよう。両方の距離の二乗を展開すると、二次項 $\|\mathbf{x}\|^2$ が両辺で相殺される。

<!--en:9317fa38-->
恒等式 $\|\mathbf{a}\|^2 - \|\mathbf{c}\|^2 = (\mathbf{a} - \mathbf{c})\cdot(\mathbf{a} + \mathbf{c})$ を使うと、最後の不等式は次の定義のもとで $\mathbf{w}\cdot\mathbf{x} + b > 0$ となる。

<!--en:3f565447-->
つまり「最近傍平均」とは垂直二等分超平面にほかならない。その法線は一方の平均から他方の平均へと向き、2 つの平均の中点をまっすぐ横切る。手動で調整すべきしきい値はなく、この規則はピクセルの一様な再スケーリングに対して不変である。すべてのピクセルに $c > 0$ を掛けると $\mathbf{w} \to c\mathbf{w}$、$b \to c^2 b$ となり、すべてのスコアが $c^2$ 倍されるだけで予測は 1 つも変わらない（:exref:`ex_mdl-geometry-linear-algebraic-ops-nearest-centroid` ではこの不変性を回転と平行移動へ拡張し、逆に予測を*変えてしまう*ピクセルごとの再スケーリングを構成する）。

<!--en:bed05b0b-->
この分類器を T シャツとズボンで試す前に、2 つのクラス平均を観察し、そのなす角を計算してみよう。

<!--en:caaa38a9-->
どちらの平均画像もぼやけてはいるが、ひと目で判別できる。両者のなす角は約 $33^\circ$（コサインにして $0.84$）にすぎず、直交からは程遠い。どちらの衣類も画像中央の明るい領域を占めているからである。2 つの平均の角度がこれほど近いと悲観的になるかもしれないが、最近傍平均分類器（nearest-mean classifier）は平均同士の直交性を必要とせず、両者の*差*のみに依拠する。T シャツとズボンのテスト画像全 $2{,}000$ 枚で評価してみよう。

<!--en:25abcf77-->
この規則はテスト画像の約 $92\%$ を正しく分類し、誤った側に振り分けられたのはわずか $169$ 枚（全 $2{,}000$ 枚中）である。各クラスの平均をとり、1 つの超平面のどちら側に各テスト画像が入るかを調べただけでこの結果が得られた。

<!--en:302a4735-->
残りの誤分類がどこから生じるかを理解するため、すべてのテスト画像を境界までの符号付き距離 :eqref:`eq_mdl-signed-distance` という 1 つの数値に圧縮し、クラスごとにヒストグラムを描いてみよう。

<!--en:ede3ffaa-->
2 つのクラスは明確に分かれた山をなすが、それぞれの裾が境界をまたいでいる。T シャツは $-4$ 付近を中心とする幅広い山をなす一方、ズボンは $+4$ 付近に鋭いピークを持ち、ゼロに向かって長い裾を引いている。平均的には、各クラスはその訓練平均の符号付き距離 $\mp\|\mathbf{w}\|/2 \approx \mp 3.2$ の近くに位置する。$\mathbf{w}$ に沿った各クラスの標準偏差を計算し、誤った側に入るデータ例の個数を数えて、この様子を定量化しよう。

<!--en:f7018da8-->
$\mathbf{w}$ に沿った標準偏差は T シャツが約 $2.4$、ズボンが約 $1.7$ であり、T シャツ $101$ 枚とズボン $68$ 枚が誤分類されている。各クラスの中心から境界までの距離が標準偏差の 2 倍未満であるため、数パーセントの誤り率が生じるのは当然の結果である。ここに中点規則の本質的な限界がある。2 つのクラス平均しか見ておらず、どちらの点群の大きさや形状も考慮する術を持たないのである。では、T シャツ対シャツやプルオーバー対コートのように、見た目がはるかに似通った難しいペアに適用するとどうなるだろうか。

<!--en:12d45569-->
正解率は急落し、T シャツ対シャツでは約 $79\%$、プルオーバー対コートでは約 $72\%$ まで落ち込む。残りの出力列がその理由を物語っている。各訓練平均は境界から距離 $\|\mathbf{w}\|/2$ の位置にあり、重なり具合を左右するのは、この距離を $\mathbf{w}$ に沿った各クラスの標準偏差を単位として測った値である。T シャツとズボンでは、その隔たりは標準偏差の $1.4$ 倍から $1.9$ 倍ある。ところが難しい 2 組のペアではわずか $0.6$ 倍から $1.0$ 倍に縮まるため、中点に置いた境界が両クラスの中心部をまっぷたつに横切ってしまう。その処方箋は、クラスのばらつきが大きい方向を避けるように $\mathbf{w}$ を傾けることであり、これがフィッシャーの線形判別（Fisher's linear discriminant、:exref:`ex_mdl-geometry-linear-algebraic-ops-fisher-direction`）の考え方である。ソフトマックス回帰はさらに一歩進めて傾きとオフセットの両方をデータから直接学習し、深層ネットワークは入力そのものを変換して、単一の超平面でクラスがほぼ分離可能になる表現を獲得する。

<!--en:9e773092-->
### 超平面の積層としての層

<!--en:dba2c88b-->
ニューラルネットワークの線形層は、多数の超平面判定を並列に実行している。第 $i$ 成分（行列・ベクトル積 $\mathbf{A}\mathbf{x}$ の成分）は、第 $i$ 行（$\mathbf{A}$ の行）と $\mathbf{x}$ のドット積、すなわちスコア $\mathbf{a}_i\cdot\mathbf{x}$（法線 $\mathbf{a}_i$ に対するスコア）であり、バイアスベクトルを加えると各成分が超平面スコアになる。たとえば、:numref:`sec_softmax` における Fashion-MNIST 上の 10 クラスソフトマックス層は、10 個の法線 $\mathbf{w}_1, \ldots, \mathbf{w}_{10}$ と 10 個のオフセットを保持している。スコアが最大のクラスを予測するため、クラス $i$ とクラス $j$ を分ける決定境界は、両者のスコアが並ぶ超平面 $(\mathbf{w}_i - \mathbf{w}_j)\cdot\mathbf{x} + (b_i - b_j) = 0$ となる。

<!--en:f52205a0-->
具体例として、本章で通しで用いる行列 $\mathbf{A} = \left(\begin{smallmatrix}1&2\\-1&3\end{smallmatrix}\right)$ と入力 $\mathbf{x} = (2, -1)$ をとろう。第 1 行からは $1\cdot 2 + 2\cdot(-1) = 0$ が得られ、$\mathbf{x}$ は原点を通る法線 $(1, 2)$ の超平面上にちょうど乗っていることがわかる。第 2 行からは $-2 - 3 = -5$ が得られ、$\mathbf{x}$ は法線 $(-1, 3)$ の超平面の負の側に符号付き距離 $-5/\sqrt{10} \approx -1.58$ だけ離れて位置する。両方の結果を並べれば $\mathbf{A}\mathbf{x} = (0, -5)$ となる。

<!--en:18123cee-->
$\mathbf{A}\mathbf{x}$ を行ごとに眺めれば線形層が超平面判定の積層であることがわかるが、2 つの本質的な問いが未解決のまま残る。この変換はどの入力をゼロに潰すのか、そしてその作用はいつ逆転できるのかという問いである。:numref:`sec_mdl-linear-maps` では、まったく同じ積を列ごとに読み解くことでこの両方の問いに答える。

<!--en:30ac03ff-->
## まとめ

<!--en:95f216a3-->
ドット積は、平面上の長さ、角度、射影をまったく同じ公式のまま任意の次元へと拡張する。直線や部分空間への射影は、射影先の空間と直交する残差によって特徴づけられる唯一の最近接点を与え、このただ 1 つの幾何学的事実からコーシー・シュワルツの不等式（高次元の角度を矛盾なく定義可能にする）と最小二乗法の正規方程式が導かれる。グラム・シュミットの直交化法は任意の生成系を正規直交基底へと変換し、QR 分解の因子 $\mathbf{Q}$ を与える。$\mathbb{R}^d$ におけるランダムな方向は典型的に $1/\sqrt{d}$ のオーダーのコサインを持ってほぼ直交する一方、実際の画像データセットは等方的とは程遠いため、観測されたコサインは同じ分布からとった無関係なペアと比較して初めて意味を持つ。最後に、最近傍平均分類器は 2 つのクラス平均を二等分する単一の超平面を定め、T シャツ対ズボンでは約 $92\%$ の正解率に達するが、境界の法線方向に沿ったクラスの広がりが効いてくる見た目の似たペアでは $72\%$〜$79\%$ に低下する。

[extended] **ほぼ直交する方向のパッキング。** ●● $\mathbb{R}^d$ には互いに直交する方向は高々 $d$ 個しか収まらないが、ペアごとのコサインを小さく保ったままなら、それよりはるかに多くの方向を詰め込むことができる。:citet:`Elhage.Hume.Olsson.ea.2022` はこの幾何学を用いて、幅 $d$ の層が $d$ 個を超える特徴量をほぼ直交する方向として*重ね合わせ*の形で表現できる仕組みを説明している。ここで扱われる特徴量は*疎*であり、各特徴量はごく一部の入力でしか活性化しないため、一度に読み出す必要があるのは少数にとどまる。$\mathbf{u}_1, \ldots, \mathbf{u}_n$ を $\mathbb{R}^d$ 内の単位ベクトルとし、それらを行として並べた行列を $\mathbf{U} \in \mathbb{R}^{n \times d}$ とし、ペア間の最悪の干渉を $\mu = \max_{i \neq j}|\mathbf{u}_i\cdot\mathbf{u}_j|$ とおく。
    1. $\sum_{i,j}(\mathbf{u}_i\cdot\mathbf{u}_j)^2$ を座標で展開し、これが $\sum_{k,l}\bigl(\sum_i u_{ik}u_{il}\bigr)^2$、すなわち $d \times d$ 行列 $\mathbf{U}^\top\mathbf{U}$ の各成分の二乗和に等しいことを示せ。$d$ 個の対角項と、$\sum_{k=1}^d a_k^2 \ge \bigl(\sum_k a_k\bigr)^2/d$ の形のコーシー・シュワルツの不等式を用い、$\sum_k (\mathbf{U}^\top\mathbf{U})_{kk} = n$ に注意してこの和を下から評価せよ。さらに元の和を上から $n + n(n-1)\mu^2$ で抑えることで、次の *Welch の下界* :cite:`Welch.1974` を導出せよ。

       $$
       \mu^2 \ge \frac{n - d}{d\,(n - 1)}.
       $$

       $d = 32$ のもとで $n = 64$ と $n = 512$ に対してこの下界の値を求めよ。
    1. すべてのペアにわたるユニオンバウンドにより、独立なランダム方向は $\mu \le \varepsilon$ を $n$ が $e^{d\varepsilon^2/4}$ のオーダーになるまで保つことが示される（:numref:`sec_mdl-concentration-generalization`）。$d = 32$、$n \in \{64, 128, 256, 512\}$ に対してランダム単位ベクトルの $\mu$ を計算し、Welch の下界と比較せよ。
    1. 最適化によって直接 $\mu$ を小さくせよ。すなわち、$\sum_{i \neq j}(\mathbf{u}_i\cdot\mathbf{u}_j)^{p}$ を $p = 10$ のような偶数のべきに対して、$\mathbf{U}$ 上の勾配ステップ（各ステップ後にすべての行を再正規化する）によって最小化せよ。$d \in \{16, 32, 48, 64\}$ と $n \in \{d, 2d, 4d, 8d, 16d\}$ に対し、ランダムなベクトル、最適化したベクトル、および Welch の下界について $\mu$ を $n$ に対してプロットせよ。
    1. これらの曲線を使って、各 $d$ に対して最大の $n$（最適化した方向が $\mu \le 0.2$ を保てる上限）を推定せよ。この容量は $d$ の増加に伴って、ランダム方向の増加率 $e^{d\varepsilon^2/4}$ と比べどのように増大するか。もし一部の特徴量が他より重要であったり、多くの特徴量が同時に活性化したりする場合、結論はどのように変わるか。

- **ユークリッド距離：**2 つのデータ点 $\mathbf{u}, \mathbf{v} \in \mathbb{R}^d$ 間の距離は、差の矢印の長さ $\|\mathbf{u} - \mathbf{v}\| = \sqrt{(\mathbf{u} - \mathbf{v})\cdot(\mathbf{u} - \mathbf{v})}$

<!--en:99d89c25-->
::: {.slide title="直線への射影：最も近いスカラー倍"}

<!--en:0b4c6a7e-->
[直交射影]{.kicker}

<!--en:51eb74eb-->
- **1 次元の当てはめ問題：**$\mathbf{v} = (1, 3)$ と方向 $\mathbf{w} = (2, 1)$ に対し、どのスカラー倍 $t\mathbf{w}$ が $\mathbf{v}$ に最も近いか

<!--en:7481d346-->
- **二次の誤差曲線：**二乗誤差を展開すると $t$ に関する凸な放物線になる
  $$q(t) = \|\mathbf{v} - t\mathbf{w}\|^2 = \|\mathbf{w}\|^2 t^2 - 2(\mathbf{v}\cdot\mathbf{w})t + \|\mathbf{v}\|^2$$

<!--en:eb149cb2-->
- **唯一の最小点（$q'(t^\star) = 0$）：**$2\|\mathbf{w}\|^2 t - 2(\mathbf{v}\cdot\mathbf{w}) = 0$ とおくと $t^\star = (\mathbf{v}\cdot\mathbf{w})/(\mathbf{w}\cdot\mathbf{w})$ となり、この組では $t^\star = 5/5 = 1$ から影 $(2, 1)$ と残差 $\mathbf{r} = (-1, 2)$ が得られる

<!--en:aa1da602-->
::: {.slide title="任意の次元における直交性とピタゴラスの定理"}

<!--en:0b4c6a7e-2-->
[直交射影]{.kicker}

<!--en:32adf452-->
- **直交射影の公式：**$\mathbf{w} \neq \mathbf{0}$ のスカラー倍のうち $\mathbf{v}$ に最も近いものは $\operatorname{proj}_{\mathbf{w}}\mathbf{v} = \frac{\mathbf{v}\cdot\mathbf{w}}{\mathbf{w}\cdot\mathbf{w}}\mathbf{w}$ であり、残差 $\mathbf{r} = \mathbf{v} - \operatorname{proj}_{\mathbf{w}}\mathbf{v} \perp \mathbf{w}$ を残す

<!--en:75c44c55-->
- **ピタゴラスの定理（$\mathbf{a}\cdot\mathbf{b} = 0$）：**交差項が消えるため $\|\mathbf{v}\|^2 = \|\operatorname{proj}_{\mathbf{w}}\mathbf{v}\|^2 + \|\mathbf{r}\|^2$（$10 = 5 + 5$）

<!--en:dd179828-->
- **影の符号付き長さ：**$t^\star$ に $\|\mathbf{w}\|$ を掛けると $(\mathbf{v}\cdot\mathbf{w})/\|\mathbf{w}\|$ となる

<!--en:e74383dd-->
::: {.slide title="直角三角形から導くコーシー・シュワルツの不等式"}

<!--en:3dda3eba-->
[高次元の角度]{.kicker}

<!--en:735768a9-->
- **コーシー・シュワルツの不等式：**すべての $\mathbf{v}, \mathbf{w} \in \mathbb{R}^d$ に対し $|\mathbf{v}\cdot\mathbf{w}| \le \|\mathbf{v}\|\,\|\mathbf{w}\|$ が成り立ち、等号は $\mathbf{v}$ と $\mathbf{w}$ が共線のとき、かつそのときに限る

<!--en:c9875454-->
- **1 行の証明：**ピタゴラスの定理から $\|\mathbf{r}\|^2 \ge 0$ を落とすと $\|\mathbf{v}\|^2 \ge \|\operatorname{proj}_{\mathbf{w}}\mathbf{v}\|^2 = (\mathbf{v}\cdot\mathbf{w})^2/\|\mathbf{w}\|^2$

<!--en:56b84b5e-->
- **三角不等式：**$2\mathbf{v}\cdot\mathbf{w} \le 2\|\mathbf{v}\|\|\mathbf{w}\|$ で上から抑えることで $\|\mathbf{v} + \mathbf{w}\| \le \|\mathbf{v}\| + \|\mathbf{w}\|$ を証明

<!--en:0ad26fec-->
::: {.slide title="角度の定義と丸め誤差への対策"}

<!--en:3dda3eba-2-->
[高次元の角度]{.kicker}

<!--en:b9cf4381-->
- **高次元の角度：**コーシー・シュワルツの不等式によりコサイン比が $[-1, 1]$ に収まり、$\theta = \arccos\!\left(\frac{\mathbf{v}\cdot\mathbf{w}}{\|\mathbf{v}\|\|\mathbf{w}\|}\right) \in [0, \pi]$ が定まる

<!--en:468639e4-->
- **浮動小数点の安全策：**共線なベクトルは丸めにより $1 + 2.2\times 10^{-16}$ になりうるため、比は常に `np.clip(cos, -1, 1)` で囲む

::: {.slide title="張る空間、線形独立、基底、次元"}

<!--en:7ad73785-->
[部分空間]{.kicker}

<!--en:9fdf5347-->
- **張る空間と部分空間：**すべての線形結合の集合 $\operatorname{span}(\mathbf{v}_1, \ldots, \mathbf{v}_k) = \{\sum_{i=1}^k a_i \mathbf{v}_i\}$ は加算とスカラー倍で閉じており、原点 $\mathbf{0}$ を通る*部分空間*をなす

<!--en:0d82d0cf-->
- **線形独立：**ベクトル $\mathbf{v}_1, \ldots, \mathbf{v}_k$ は、冗長なベクトルがないとき、すなわち $\sum_i a_i \mathbf{v}_i = \mathbf{0}$ を与える線形結合が $a_1 = \cdots = a_k = 0$ のみであるとき線形独立

<!--en:72814f4c-->
- **基底と一意な座標：**部分空間 $S$ の基底とは線形独立な生成系であり、そのベクトル数が*次元* $\dim S$ となって、すべての $\mathbf{x} \in S$ が一意な座標 $(a_1, \ldots, a_k)$ を持つ

<!--en:6a09de9d-->

<!--en:9d5ad7d6-->
[最小二乗法]{.kicker}

<!--en:acc27e82-->
- **$\mathbb{R}^3$ 内の候補部分空間：**$C + Dt$ を $\mathbf{y} = (6, 0, 0)$（時刻 $\mathbf{t} = (0, 1, 2)$）に当てはめる問題は、最近接ベクトル $C\mathbf{1} + D\mathbf{t}$ を 2 次元平面 $S = \operatorname{span}(\mathbf{1}, \mathbf{t})$ 内で探すこと

<!--en:a3266051-->
- **直交方程式：**残差 $\mathbf{r} = \mathbf{y} - C\mathbf{1} - D\mathbf{t}$ は平面 $S$ 全体と直交し、したがって両方の基底ベクトルとも直交する（$\mathbf{1}\cdot\mathbf{r} = 6 - 3C - 3D = 0$ かつ $\mathbf{t}\cdot\mathbf{r} = -3C - 5D = 0$）
  $$3C + 3D = 6 \implies C = 5, \; D = -3$$

<!--en:331334c2-->

<!--en:642e838f-->

<!--en:cac1d6b3-->
