# 制約付き最適化

<!--en:0e94fa30-->
ここまでに最適化したパラメータはすべて任意の実数値をとることができたため、最小点を見つけるとは勾配がゼロになる点を探すことであった。しかし、深層学習に現れる多くの量にはそのような自由度がない。アテンション重みは非負で和が 1 にならなければならず、勾配クリッピングは更新のノルムを閾値以下に抑え、ノルムバジェットは重みベクトルの大きさを制限し、サポートベクターマシンはすべての訓練マージンが少なくとも 1 であることを要求する。変数が実行可能領域（feasible set）の内部に留まらなければならないとき、最適点において勾配がゼロになることはめったになく、前節までのゼロ勾配による判定は破綻する。制約のもとにある最適点をどのように見分け、どのように計算すればよいのだろうか。

<!--en:40c9fac7-->
勾配クリッピングは最も単純な具体例を与える。ベクトル $\mathbf{y} = (3, 4)$ を、そのノルムが高々 $1$ になるようにクリップしたいとしよう。単位長に再スケーリングすると $(0.6, 0.8)$ が返り、これは単位円板上で $\mathbf{y}$ に最も近い点である。言い換えれば、$(0.6, 0.8)$ は二乗距離 $f(\mathbf{x}) = \tfrac12\|\mathbf{x} - \mathbf{y}\|^2$ を円板 $\|\mathbf{x}\| \le 1$ 上で最小化し、最適値 $f = 8$ を達成する。ところが、その点での勾配は $(-2.4, -3.2)$ であり、ゼロにはほど遠い。$(0.6, 0.8)$ を最適にしているのは、*許容される*いかなる方向も $f$ を減少させないという事実である。すなわち、$\|\mathbf{x}\| \le 1$ を保つあらゆる移動は、1 次の範囲で $f$ を増加させるか変化させないかのいずれかである。このような問題を扱うには、ゼロ勾配条件に代わる基準と、そのままでは実行可能領域の外へ飛び出してしまう素の勾配降下法に代わる手法の両方が必要になる。

<!--en:e2aca00f-->
「勾配がゼロである」に代わる条件では、制約ごとに*乗数*（multiplier）と呼ばれる 1 つのスカラーを導入し、最適点がその制約をどれほど強く押しているかを測る。点 $(0.6, 0.8)$ では、境界が外向き法線に沿って強さ $4$ で押し返すため、$(-2.4, -3.2) + 4\,(0.6, 0.8) = \mathbf{0}$ が成り立つ。乗数を用いると一階最適性条件（first-order optimality conditions）が得られる。すなわち、等式制約に対するラグランジュ条件と、不等式制約に対するカルーシュ・キューン・タッカー（KKT）条件である。一方、$(3, 4)$ を $(0.6, 0.8)$ へと写した射影（projection）からは、直接的なアルゴリズムが示唆される。通常の勾配ステップを進めたあと、最も近い実行可能点へ射影して戻せばよい。さらに、硬い境界が折れ目を持つペナルティ（たとえば Lasso が各重みに課す絶対値ペナルティ）に置き換わるとき、射影は*近接ステップ*（proximal step）へと一般化され、小さな重みを厳密なゼロへと送り込む。本節全体を通して、凸性（:numref:`sec_mdl-convexity`）こそがこれらの条件を大域的最適性の保証へと変え、アルゴリズムの収束を保証する鍵となる。

<!--en:c13c2743-->
本節を支える柱は 3 つある。KKT 条件とその凸問題における十分性、射影を特徴づける鈍角不等式（obtuse-angle inequality）、そしてソフト閾値処理（soft-thresholding）である。

## 等式制約とラグランジュ乗数

<!--en:4d911d1c-->
### 接条件とラグランジュ条件

<!--en:22daf9e8-->
等式制約は不等式制約よりも単純であるため、まずはクリッピングの例の中身の詰まった円板をその境界に置き換えるところから始めよう。すなわち、$f(\mathbf{x}) = \tfrac12\|\mathbf{x} - \mathbf{y}\|^2$（ただし $\mathbf{y} = (3, 4)$）を、$h(\mathbf{x}) = \tfrac12(\|\mathbf{x}\|^2 - 1) = 0$ と表される単位円上で最小化する。より一般に、微分可能な目的関数 $f : \mathbb{R}^n \to \mathbb{R}$ を 1 つの等式制約のもとで最小化する問題を考える。

<!--en:e4132a97-->
実行可能領域は全次元の領域ではなく曲面（2 次元では曲線）であるため、実行可能な移動はすべてその曲面上に留まらなければならない。

<!--en:2cdfffbb-->
:numref:`fig_mdl-opt-lagrange-tangency` に最適点の幾何学的な特徴を示す。いま、$f$ の等位集合（level set）が円と*交差する*実行可能点に立っているとしよう。このとき $\nabla f$ は円に沿った非ゼロの成分を持つため、その成分と逆向きに円に沿って滑るように動けば、実行可能領域から出ることなく $f$ を減らせる。したがって、そのような点は最適点ではあり得ない。最適点が現れうるのは等位集合が円に*接する*場所だけであり、そこでは円に沿ったどの移動も 1 次の範囲で $f$ を変化させない。互いに接する曲線は平行な法線ベクトルを共有するため、最適点において $\nabla f$ は $\nabla h$ のスカラー倍でなければならない。

<!--en:c119099e-->
![$f=\tfrac12\|\mathbf{x}-\mathbf{y}\|^2$（$\mathbf{y}=(3,4)$）の単位円 $h(\mathbf{x})=0$ 上での最小化。等位集合が円と交差する場所では、$\nabla f$ が制約に沿った成分を持ち、実行可能な降下方向を与える。$\mathbf{x}^\star=(0.6,0.8)$ では等位集合が円に接し、$\nabla f=-4\,\nabla h$ となる。対蹠点 $(-0.6,-0.8)$ も $\nu=-6$ で接条件を満たし、最大点となる。](../img/mdl-opt-lagrange-tangency.svg)

<!--en:00542f2e-->
**命題（ラグランジュ条件）** *$\mathbf{x}^\star$ を $f$ の $\{\mathbf{x} : h(\mathbf{x}) = 0\}$ 上における極小点とする。$f$ は $\mathbf{x}^\star$ で微分可能であり、$h$ は $\mathbf{x}^\star$ の近傍で連続微分可能であり、かつ $\nabla h(\mathbf{x}^\star) \neq \mathbf{0}$ であるとする。このとき、一意なスカラー $\nu^\star$（**ラグランジュ乗数**）が存在して次式を満たす。*

<!--en:a8e53cd0-->
言葉で言えば、目的関数の勾配は制約の法線ベクトルの定数倍と釣り合っている。これは :numref:`subsec_mdl-lagrange` で証明したラグランジュ条件と同じものであり、そこでは制約を $g(\mathbf{x}) = c$、条件を $\nabla f = \mu\,\nabla g$ と書いていた。$h = g - c$ および $\nu = -\mu$ とおけば 2 つの形式は一致する。ここでプラスの符号を用いるのは、次に導入するラグランジアンの符号と揃えるためである。

<!--en:8c81616a-->
接点 $(0.6, 0.8)$ を :numref:`fig_mdl-opt-lagrange-tangency` で確認すると、$\nabla f = \mathbf{x} - \mathbf{y} = (-2.4, -3.2)$ かつ $\nabla h = \mathbf{x} = (0.6, 0.8)$ である。この 2 つのベクトルは実際に平行で $\nabla f = -4\,\nabla h$ を満たしており、これから $\nu^\star = 4$ が得られる。

<!--en:45f64196-->
仮定 $\nabla h(\mathbf{x}^\star) \neq \mathbf{0}$ は**制約想定**（constraint qualification）の最初の例であり、単なる技術的な細目ではなく本質的な条件である。$f(\mathbf{x}) = x_1$ を制約 $h(\mathbf{x}) = x_1^2 + x_2^2 = 0$ のもとで最小化することを考えよう。実行可能領域は $\mathbf{0}$ のただ 1 点のみからなり、これが自動的に最小点となる。ところが $\nabla f(\mathbf{0}) = (1, 0)$ である一方 $\nabla h(\mathbf{0}) = \mathbf{0}$ であるため、いかなる乗数 $\nu^\star$ も :eqref:`eq_mdl-opt-lagrange-condition` を満たすことができない。実行可能領域が接線方向を持たない 1 点へと潰れてしまっているため、接条件の議論が足掛かりを失うのである。

<!--en:9cb507a0-->
### ラグランジアン

<!--en:075d0b3e-->
ここで、$\mathbf{x}$ と $\nu$ という 2 つの未知数と、勾配が平行であることおよび実行可能性という 2 つの要請があることに注目しよう。これら両方の要請は、$(\mathbf{x}, \nu)$ の 1 つの関数の停留性へとまとめることができる。この関数は**ラグランジアン**と呼ばれ、乗数で重み付けした制約を目的関数に加えたものである。

<!--en:d2e34577-->
$\mathcal{L}$ のすべての偏微分をゼロとおくと次式が得られる。

<!--en:0e95aa19-->
これにより、:eqref:`eq_mdl-opt-lagrange-condition` と等式制約が同時に復元される。このようにして、$\mathbf{x}$ に関する制約付き最適化問題は、$(\mathbf{x}, \nu)$ に関する制約なしの停留問題へと帰着する。

<!--en:150fe69f-->
ラグランジアンを使って単位円上の問題を解いてみよう。$\mathbf{x}$ に関する停留性から $\nabla_{\mathbf{x}}\mathcal{L} = (\mathbf{x} - \mathbf{y}) + \nu\mathbf{x} = \mathbf{0}$ となるため、$\mathbf{x} = \mathbf{y}/(1 + \nu)$ は原点と $\mathbf{y}$ を通る直線上になければならない。さらに実行可能性 $\|\mathbf{x}\| = 1$ を課すと $|1 + \nu| = \|\mathbf{y}\| = 5$ が必要となり、次の 2 つの解が得られる。

<!--en:ee3fa255-->
* $\nu = 4$：$\mathbf{x} = (0.6, 0.8)$ であり、距離 $4$ だけ $\mathbf{y}$ から離れ、$f = 8$ となる。

<!--en:8446d07f-->
* $\nu = -6$：$\mathbf{x} = (-0.6, -0.8)$ であり、距離 $6$ だけ $\mathbf{y}$ から離れ、$f = 18$ となる。

<!--en:d9631d07-->
2 番目の解は、円上で*最も遠い*点（$\mathbf{y}$ からの距離が最大となる点）である。ここから重要な注意点が浮かび上がる。ラグランジュ条件は必要条件であって十分条件ではない。というのも、曲面上の $f$ の極大点や鞍点を含むすべての停留点で成り立つからである。この例では、乗数の符号が最小点と最大点を区別している。次節で不等式制約へ進むと、KKT 条件がこの符号を一般的な規則へと昇華させる。

<!--en:6b4aea98-->
複数の等式制約 $h_j(\mathbf{x}) = 0$（$j = 1, \ldots, p$）がある場合は、各制約にそれぞれ乗数を割り当て、ラグランジアンは $\mathcal{L} = f + \sum_j \nu_j h_j$ となる。制約の勾配 $\nabla h_j(\mathbf{x}^\star)$ が線形独立である限り、同じ議論により $\nabla f(\mathbf{x}^\star)$ は制約の法線が*張る空間*（span）に属する。すなわち、目的関数の勾配は制約の勾配の線形結合と釣り合う。

<!--en:290942e6-->
### 超平面上の最近接点

<!--en:a7816eb9-->
線形制約を持つ最も単純な制約付き問題は、超平面上で原点に最も近い点を求める問題である。すなわち、$f(\mathbf{x}) = \tfrac12\|\mathbf{x}\|^2$ を制約 $h(\mathbf{x}) = \mathbf{a}^\top\mathbf{x} - b = 0$ のもとで最小化する。$\mathcal{L} = \tfrac12\|\mathbf{x}\|^2 + \nu(\mathbf{a}^\top\mathbf{x} - b)$ の勾配をゼロとおくと $\mathbf{x} + \nu\mathbf{a} = \mathbf{0}$ となるため、最近接点は法線ベクトル $\mathbf{a}$ の方向になければならない。$\mathbf{x} = -\nu\mathbf{a}$ を制約に代入すると $-\nu\|\mathbf{a}\|^2 = b$ となり、$\nu^\star = -b/\|\mathbf{a}\|^2$ と定まる。したがって、解と最適値は次のようになる。

<!--en:904be79b-->
幾何学的には、最近接点は距離 $b/\|\mathbf{a}\|$ だけ単位法線 $\mathbf{a}/\|\mathbf{a}\|$ に沿って進んだ位置にあり、:numref:`sec_mdl-geometry-linear-algebraic-ops` の射影の公式と一致する。

<!--en:d86f540d-->
$\mathbf{a} = (3, 4)$、$b = 5$ とすると、再び $(0.6, 0.8)$ に到達し、今度は $\nu^\star = -0.2$、$p^\star = \tfrac12$ となる。直線 $3x_1 + 4x_2 = 5$ は点 $(0.6, 0.8)$ で単位円に接している。ここで、乗数が単なる代数計算の補助にとどまらないことに注目しよう。$b$ を $5$ から $5.1$ へとわずかに動かして直線を原点から少し遠ざけると、最適値は約 $0.02 = -\nu^\star \cdot 0.1$ だけ増加する。:numref:`subsec_mdl-shadow-prices` で一般の場合について示すように、乗数が常に測っているのはまさにこの量、すなわち制約をずらしたときの最適値の感度である。

## 不等式制約と KKT 条件

<!--en:6d439bac-->
### 有効制約と非有効制約

<!--en:a58f414a-->
機械学習に現れる制約の大半は片側のみを制限するものである。たとえば、ノルムが高々 $r$ であること、確率が少なくとも $0$ であること、あるいはリソースバジェットを超えないことなどである。不等式制約は、次の標準形で書く。

<!--en:a2168a9b-->
このように書くと、各 $g_i$ は領域の真の内部で負、境界上でゼロとなる。解 $\mathbf{x}^\star$ において、すべての不等式は 2 つの状態のいずれかに分類される。$g_i(\mathbf{x}^\star) < 0$ ならば、その制約は**非有効**（inactive）である。解は領域の真の内部にあるため、局所的にはその制約は何の影響も及ぼさない。一方、$g_i(\mathbf{x}^\star) = 0$ ならば、その制約は**有効**（active）である。解はまさに境界上に位置し、そこで不等式は等式のように働く。

<!--en:a34f5462-->
勾配クリッピングは、この両方の状態を明快に示してくれる。ベクトル $\mathbf{y}$ を半径 $r$ のユークリッド球へ射影するため、$f(\mathbf{x}) = \tfrac12\|\mathbf{x} - \mathbf{y}\|^2$ を制約 $g(\mathbf{x}) = \tfrac12(\|\mathbf{x}\|^2 - r^2) \le 0$ のもとで最小化するとしよう。乗数 $\lambda$ を導入すると、$f + \lambda g$ の停留性から $(\mathbf{x} - \mathbf{y}) + \lambda\mathbf{x} = \mathbf{0}$ が得られるため、$\mathbf{x} = \mathbf{y}/(1 + \lambda)$ は常に $\mathbf{y}$ を動径方向に再スケーリングした点となる。どちらの状態になるかは $\|\mathbf{y}\|$ によって決まる。

<!--en:9c6e1853-->
* $\|\mathbf{y}\| \le r$ のとき、$\mathbf{y}$ はすでに実行可能であり、そのまま $f$ を最小化する。制約は非有効で、$\lambda^\star = 0$ かつ $\mathbf{x}^\star = \mathbf{y}$ となる。たとえば $\mathbf{y} = (0.3, 0.4)$ は $r = 1$ のときそのまま変化しない。

<!--en:4e5d4527-->
* $\|\mathbf{y}\| > r$ のとき、内点が最適になることはあり得ない。内点が最小点であるためには $f$ の制約なし最小点でなければならないが、唯一の制約なし最小点は実行不可能な点 $\mathbf{y}$ だからである。したがって制約は必ず有効となり、$\|\mathbf{x}^\star\| = r$ から $\lambda^\star = \|\mathbf{y}\|/r - 1 > 0$ が定まる。$\mathbf{y} = (3, 4)$、$r = 1$ のときは、$\lambda^\star = 4$、$\mathbf{x}^\star = (0.6, 0.8)$、および $p^\star = \tfrac12 \cdot 4^2 = 8$ が得られる。

<!--en:85e5d559-->
両方のケースは 1 つの式にまとまる。

<!--en:7b0983c6-->
この式は、短いベクトルはそのまま残し、長いベクトルはノルム $r$ に再スケーリングする。これを勾配ベクトルに適用したものが*勾配クリッピング*である :cite:`Pascanu.Mikolov.Bengio.2013`。コード上では、この場合分けは 1 回の `max` に集約でき、クリップされた点において $f$ の勾配が $\lambda^\star$ 倍の制約勾配 $\nabla g(\mathbf{x}) = \mathbf{x}$ によって打ち消されることを直接確認できる。

<!--en:84fda57e-->
$\nabla f$ がゼロからほど遠くても停留性は成り立っている。目的関数の勾配 $(-2.4, -3.2)$ と境界からの押し返し $(2.4, 3.2)$ の和がゼロになり、乗数 $\lambda^\star = 4$ が両者の長さの比を与えている。

<!--en:c8995615-->
乗数の符号が持つ幾何学的な意味に注目しよう。球の外へ出ると $g(\mathbf{x})$ は増加するため、その勾配 $\nabla g = \mathbf{x}$ は外向きを指す。停留性を $-\nabla f = \lambda\nabla g$（$\lambda > 0$）と書くと、下り方向 $-\nabla f$ が外向きに引っ張る一方で、境界の壁がそれを押し返していることがわかる。仮に $-\nabla f$ が内側を向いていたとすれば、球の内部へ踏み出すことで $f$ を下げられるため、その点は最適ではあり得ない。したがって負の乗数は排除される。実際、$\lambda = -6$ とすると円上の遠い側の点 $(-0.6, -0.8)$ が選ばれ、これは円板上での最小点ではなく最大点になる。等式制約とは異なり、不等式の壁は 1 つの方向にしか押し返さないのである。

<!--en:1430fa5b-->
### カルーシュ・キューン・タッカー条件

<!--en:3d991241-->
不等式制約と等式制約を組み合わせると、次の一般的な最適化問題が得られる。

<!--en:cd35ba8a-->
この問題の**ラグランジアン**は各制約に 1 つずつ乗数を割り当て、不等式制約の乗数には非負であることを課す。

<!--en:06da237d-->
制約想定（具体的にどの条件を用いるかは次項で述べる）が成り立つ任意の極小点 $\mathbf{x}^\star$ において、次の 4 つの**カルーシュ・キューン・タッカー（KKT）条件**を満たす乗数が存在する :cite:`Karush.1939,Kuhn.Tucker.1951`。

<!--en:abfae1b8-->
最初の 3 つの条件、すなわち勾配の釣り合い（停留性）、制約そのものの成立（主実行可能性）、不等式乗数に対する片方向の符号制限（双対実行可能性）は、これまでの例ですでに見てきたとおりである。4 つ目の**相補性条件**（complementary slackness）は、各 $i$ について $\lambda_i^\star$ と $g_i(\mathbf{x}^\star)$ の少なくとも一方がゼロになることを述べている。その結果、すべての非有効制約（$g_i(\mathbf{x}^\star) < 0$）は自動的に $\lambda_i^\star = 0$ となり、停留性の式から脱落する。ただし、微妙な非対称性に留意しておこう。乗数が正であればその制約は確実に有効であるが、逆に有効制約であっても、たまたま力を及ぼさずに $\mathbf{x}^\star$ に接しているだけならば $\lambda_i^\star = 0$ となりうる。球への射影の例では、相補性条件は手計算で行った場合分けをそのまま符号化しており、点 $(0.6, 0.8)$ では $\lambda^\star g(\mathbf{x}^\star) = 4 \cdot 0 = 0$ が成り立っている。

<!--en:bbd23a40-->
:numref:`fig_mdl-opt-kkt-active-set` は、停留性と双対実行可能性を合わせた幾何学的構造を示している。最適点において、降下方向 $-\nabla f$ は有効制約の外向き法線の非負線形結合でなければならない。言い換えれば、$-\nabla f$ はそれらの外向き法線が張る錐（*法線錐*（normal cone））の内部に含まれ、非有効制約は一切寄与しない。

<!--en:426e7ac3-->
![2 つの不等式制約で定義された実行可能領域における KKT 条件の幾何構造。(a) では、一方の制約が $\mathbf{x}^\star$ で有効、もう一方が非有効であり、$-\nabla f$ は $\lambda_1 > 0$ で有効な外向き法線と同じ向きに揃い、$\lambda_2 = 0$ となる。(b) では、角の点で両方の制約が有効となるため、$-\nabla f$ は両方の外向き法線が張る網掛けの法線錐の内部になければならない。オレンジ色の弧は、$f$ の制約なし最小点 (+) のまわりの等位集合を表す。](../img/mdl-opt-kkt-active-set.svg)

<!--en:98f28c69-->
ラグランジュ条件と同様、KKT 条件は一階条件であり、それ単独では十分条件にならない。$f(x) = -x^2$ を $[-1, 1]$ 上（すなわち $x - 1 \le 0$ かつ $-1 - x \le 0$）で最小化することを考えよう。$x = 0$ では勾配がゼロになり、両方の制約が非有効で、両方の乗数をゼロとおけば 4 つの KKT 条件すべてを満たすが、$x = 0$ は*最大点*である。真の最小点である $x = \pm 1$ も KKT 点であり、それぞれ有効な境界制約に対して乗数 $2$ を持つ。

<!--en:3ee3f851-->
### 制約想定と十分性

<!--en:7a5416b2-->
こうして、互いに補い合う 2 つの問いが残る。第 1 に、極小点が KKT 条件を満たすことが*保証される*のはいつか。第 2 に、KKT 点が最小点であることが*保証される*のはいつか。

<!--en:166c0f5e-->
1 つ目の問いに対する答えは、等式制約の場合と並行している。すなわち、制約想定が成り立つ限り、極小点は必ず KKT 条件を満たす。最もよく使われる一般的な条件は*線形独立制約想定*（linear independence constraint qualification、LICQ）である。$\mathbf{x}^\star$ を :eqref:`eq_mdl-opt-standard-problem`（ただし $f$、$g_i$、$h_j$ は連続微分可能）の極小点としよう。すべての有効な不等式制約の勾配とすべての等式制約の勾配を合わせた集合 $\{\nabla g_i(\mathbf{x}^\star) : g_i(\mathbf{x}^\star) = 0\} \cup \{\nabla h_j(\mathbf{x}^\star) : j = 1, \ldots, p\}$ が線形独立であれば、:eqref:`eq_mdl-opt-kkt` を満たす乗数の存在が保証される（:citet:`Nocedal.Wright.2006` 第 12 章）。LICQ は $\nabla h(\mathbf{x}^\star) \neq \mathbf{0}$ の直接的な一般化であり、これが破れたときに何が起きうるかは演習問題 :exref:`ex_mdl-constrained-degenerate-constraints` で確認する。

<!--en:98df1be5-->
凸問題に対しては、未知の解における勾配を調べる代わりに、1 つの実行可能点を見つけるだけで済むはるかに単純な判定条件がある。問題 :eqref:`eq_mdl-opt-standard-problem` は、$f$ とすべての $g_i$ が凸関数であり、すべての $h_j$ がアフィン関数であるとき*凸*であるという。凸問題において**スレーター条件**（Slater's condition）:cite:`Slater.1950` が成り立つとは、次を満たす点 $\bar{\mathbf{x}}$ が存在することをいう。

<!--en:4aad0c89-->
平たく言えば、$\bar{\mathbf{x}}$ は実行可能であり、かつ曲がったすべての不等式制約の真の内部になければならない。すべての制約がアフィンであれば、単に実行可能であるだけでスレーター条件は満たされる。（ここでは扱わないが、$f$ またはいずれかの $g_i$ が $\mathbb{R}^n$ の部分集合上でのみ定義されている場合は、$\bar{\mathbf{x}}$ はその定義域の相対的内部にも属していなければならない。）ユークリッド球の場合は、$\bar{\mathbf{x}} = \mathbf{0}$ とすれば $g(\mathbf{0}) = -r^2/2 < 0$ となるため直ちに条件を満たす。微分可能な $f$ と $g_i$ を持つ凸問題でスレーター条件が成り立つとき、すべての最小点は KKT 点となる :cite:`Boyd.Vandenberghe.2004`。その背後にあるより深い理由は強双対性（strong duality）であり、:numref:`subsec_mdl-strong-duality` ではまさに同じ条件からこれを導く。

<!--en:aa6929d5-->
凸性は 2 つ目の問いにも決着をつけ、本節で最も有用な結果をもたらす。

<!--en:e34b34f1-->
**命題（凸性のもとでの KKT 条件の十分性）** *問題 :eqref:`eq_mdl-opt-standard-problem` において、$f$ とすべての $g_i$ が凸かつ微分可能であり、すべての $h_j$ がアフィンであるとする。$(\mathbf{x}^\star, \boldsymbol{\lambda}^\star, \boldsymbol{\nu}^\star)$ が KKT 条件 :eqref:`eq_mdl-opt-kkt` を満たすならば、$\mathbf{x}^\star$ は大域的最小点である。*

<!--en:5342166d-->
**証明：**$\varphi(\mathbf{x}) = \mathcal{L}(\mathbf{x}, \boldsymbol{\lambda}^\star, \boldsymbol{\nu}^\star)$ とおく。$\lambda_i^\star \ge 0$ であるから、$\varphi$ は凸関数の非負結合にアフィン項を加えたものであり、したがって $\varphi$ は凸関数である。停留性より $\nabla\varphi(\mathbf{x}^\star) = \mathbf{0}$ であるから、$\mathbf{x}^\star$ は*大域的な*最小点（$\varphi$ の $\mathbb{R}^n$ 全体における最小点）となる。ここで任意の実行可能点 $\mathbf{x}$ をとる。$\lambda_i^\star \ge 0$、$g_i(\mathbf{x}) \le 0$、および $h_j(\mathbf{x}) = 0$ より、次式が成り立つ。

<!--en:9c7ce807-->
ここで最後の等号は、相補性条件（$\sum_i \lambda_i^\star g_i(\mathbf{x}^\star) = 0$）と主実行可能性（$h_j(\mathbf{x}^\star) = 0$）から従う。$\blacksquare$

<!--en:5fe45b2c-->
この短い証明の中に織り込まれている、より広い原理に注目しよう。*任意の*固定された乗数（$\boldsymbol{\lambda} \ge 0$）に対して、すべての実行可能点 $\mathbf{x}$ で最初の不等式が成り立つため、ラグランジアンを $\mathbf{x}$ に関して最小化すれば、常に制約付き最適値の下界が得られる。そして KKT 乗数においては、その下界は厳密に一致する。:numref:`sec_mdl-lagrangian-duality` では、この考察を出発点として双対性（duality）の理論全体を構築する。したがって凸問題においては、KKT 条件は常に十分条件であり、さらにスレーター条件のもとでは必要条件にもなって大域的最小点を完全に特徴づける。

<!--en:1763ee2b-->
## 射影と射影勾配降下法

<!--en:bf130831-->
KKT 条件は最適点を*見分ける*方法を教えてくれ、単純な制約であればそれを使って手計算で解くこともできる。より一般的に解を*計算する*には、勾配降下法を最近接の実行可能点を求める操作と組み合わせる。すなわち、通常の勾配ステップを進め、実行可能領域の外へ出るたびにそのまま内側へ射影して戻すのである。

<!--en:84098937-->
### 凸集合への射影

<!--en:8c34800f-->
空でない閉凸集合 $C \subseteq \mathbb{R}^n$ に対し、**射影**とは点 $\mathbf{y}$ を $C$ へ写す操作であり、$C$ 内で $\mathbf{y}$ に最も近い唯一の点として次式で定義される。

<!--en:a4eeda9a-->
なぜ唯一の最小点が常に存在するのだろうか。最適点を除外しないまま、$C$ と $\mathbf{y}$ を中心とする十分大きな閉球との共通部分をとることができるからである。この共通部分は有界閉集合（したがってコンパクト）となるため、連続な目的関数はそこで最小値を達成する。さらに二乗距離の狭義凸性（strict convexity）によって複数の点が同値で並ぶ可能性が排除され、$\Pi_C$ は一意に定まる写像となる。

<!--en:78c5d641-->
すでに超平面への射影（最近接点問題）と球への射影（クリッピングの公式）という 2 つの射影を閉形式で求めた。半空間（half-space）$\{\mathbf{x} : \mathbf{a}^\top\mathbf{x} \ge b\}$ への射影は、超平面の公式から直ちに従う。$\mathbf{y}$ がすでに不等式を満たしていればそのままにし、満たしていなければ $\mathbf{a}$ に沿って境界超平面上までまっすぐ移動する。

<!--en:a472c276-->
閉凸集合への射影は、きわめて明快な幾何学的特徴づけを満たす。$\hat{\mathbf{x}} = \Pi_C(\mathbf{y})$ を $\tfrac12\|\mathbf{x} - \mathbf{y}\|^2$ の $C$ 上での最小点としよう。他の任意の点 $\mathbf{x} \in C$ に対し、凸性により $\hat{\mathbf{x}}$ から $\mathbf{x}$ までの線分全体が $C$ の内部に収まる。したがって $\hat{\mathbf{x}}$ から $\mathbf{x}$ へ向かって動いても 1 次の範囲で目的関数は減少せず、方向微分は非負、すなわち $(\hat{\mathbf{x}} - \mathbf{y})^\top(\mathbf{x} - \hat{\mathbf{x}}) \ge 0$ となる。符号を反転させると、次の**鈍角不等式**（または変分不等式（variational inequality））が得られる。

<!--en:d655ce84-->
幾何学的には、*残差*ベクトル $\mathbf{y} - \Pi_C(\mathbf{y})$ は少なくとも $90^\circ$ の角を、$\Pi_C(\mathbf{y})$ から任意の点 $\mathbf{x} \in C$ へ向かうベクトルとの間になす（:numref:`fig_mdl-opt-projection-inequality` の (a)）。言い換えれば、$\Pi_C(\mathbf{y})$ を通り法線 $\mathbf{y} - \Pi_C(\mathbf{y})$ を持つ超平面は $C$ の*支持超平面*（supporting hyperplane）であり、集合 $C$ 全体をその反対側に保つ。

<!--en:d2333d33-->
![(a) 残差 $\mathbf{y}-\Pi_C(\mathbf{y})$ は少なくとも $90^\circ$ の角を $C$ の内部へ向かうあらゆる方向との間になすため、$C$ は $\Pi_C(\mathbf{y})$ を通る支持直線の反対側に完全に収まる。(b) 閉凸集合への射影は距離を決して増加させない（$\|\mathbf{u}-\mathbf{v}\|\le\|\mathbf{x}-\mathbf{x}'\|$）。](../img/mdl-opt-projection-inequality.svg)

<!--en:b44cc86a-->
本節の共通の例でこの不等式を確かめてみよう。単位円板へ射影される $\mathbf{y} = (3, 4)$ に対して、残差は $(2.4, 3.2) = 4\,(0.6, 0.8)$ となり、またしても乗数と外向き法線の積が現れる。任意の $\mathbf{x}$（$\|\mathbf{x}\| \le 1$）に対して、次式が成り立つ。

<!--en:9d0550fe-->
ここで最初の不等号にはコーシー・シュワルツの不等式 $\mathbf{u}^\top\mathbf{v} \le \|\mathbf{u}\|\,\|\mathbf{v}\|$ を用いた。ここでの支持直線は $3x_1 + 4x_2 = 5$ であり、まさに先ほどの最近接点の例に現れた超平面そのものである。

<!--en:e201122f-->
同様に重要なこととして、鈍角不等式は*十分条件*でもある。ある点 $\hat{\mathbf{x}} \in C$ が :eqref:`eq_mdl-opt-proj-variational` を満たすとし、$\varphi(\mathbf{x}) = \tfrac12\|\mathbf{x} - \mathbf{y}\|^2$ とおこう。その $\hat{\mathbf{x}}$ における勾配は $\hat{\mathbf{x}} - \mathbf{y}$ である。微分可能な凸関数は常にその接平面の上側にあるため（:numref:`sec_mdl-convexity`）、$\varphi(\mathbf{x}) \ge \varphi(\hat{\mathbf{x}}) + (\hat{\mathbf{x}} - \mathbf{y})^\top(\mathbf{x} - \hat{\mathbf{x}})$ が成り立つ。仮定により最後の項はすべての $\mathbf{x} \in C$ に対して非負であるから、$\varphi(\mathbf{x}) \ge \varphi(\hat{\mathbf{x}})$ が $C$ 全体で成り立ち、$\hat{\mathbf{x}} = \Pi_C(\mathbf{y})$ が証明される。したがって、:eqref:`eq_mdl-opt-proj-variational` は射影を*完全に特徴づける*。射影を用いたアルゴリズムに必要な性質はすべて、射影が決して距離を引き伸ばさないという事実をはじめとして、この不等式から直接導かれる。

<!--en:642a6c04-->
**命題（射影の非拡大性）** *空でない閉凸集合 $C$ とすべての $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$ に対して、次式が成り立つ。*

<!--en:2d947fd4-->
**証明：**$\mathbf{u} = \Pi_C(\mathbf{x})$ および $\mathbf{v} = \Pi_C(\mathbf{y})$ とおく。:eqref:`eq_mdl-opt-proj-variational` を 2 回、まず $\mathbf{x}$ に対して $\mathbf{v} \in C$ を用いて、次に $\mathbf{y}$ に対して $\mathbf{u} \in C$ を用いて適用すると、次式が得られる。

<!--en:f0a903c8-->
この 2 つの不等式を足し合わせると $(\mathbf{x} - \mathbf{y} - (\mathbf{u} - \mathbf{v}))^\top(\mathbf{v} - \mathbf{u}) \le 0$ となり、整理すると次式になる。

<!--en:13a2457c-->
ここで後半の不等号はコーシー・シュワルツの不等式による。両辺を $\|\mathbf{u} - \mathbf{v}\|$ で割れば証明が完了する（なお $\|\mathbf{u} - \mathbf{v}\| = 0$ のときは主張は自明である）。$\blacksquare$

<!--en:002a81d0-->
パネル (b)（:numref:`fig_mdl-opt-projection-inequality`）はこの性質を視覚的に表している。円板の外にある 2 点間の距離は、常にそれらの射影間の距離以上である。ここでは $C$ の凸性が本質的である。非凸な 2 点集合 $C = \{-1, 1\}$ をとると、$y = 0.01$ は $1$ へ射影される一方、$y = -0.01$ は $-1$ へ射影され、$0.02$ の入力の差が $2$ の出力の差へと拡大してしまう。さらに $y = 0$ では射影が一意ですらなくなる。非凸集合への射影は不連続にも多価にもなりうるのである。

<!--en:a93e0f23-->
### 射影勾配降下法

<!--en:6b02b539-->
**射影勾配降下法**（projected gradient descent、PGD）は、勾配ステップのたびに射影を施すことで、射影を反復ソルバへと仕立て上げる。

<!--en:5fab0a77-->
構成から明らかなように、すべての反復点は実行可能に保たれる。さらに都合のよいことに、PGD の不動点（fixed point）はまさに制約付き停留点と一致する。任意の微分可能な $f$、閉凸集合 $C$、およびステップサイズ $\eta > 0$ に対し、不動点方程式 $\mathbf{x}^\star = \Pi_C(\mathbf{x}^\star - \eta \nabla f(\mathbf{x}^\star))$ が成り立つのは、$\mathbf{x}^\star \in C$ が鈍角不等式 :eqref:`eq_mdl-opt-proj-variational` を $\mathbf{y} = \mathbf{x}^\star - \eta\nabla f(\mathbf{x}^\star)$ に対して満たすとき、かつそのときに限る。$\mathbf{x}^\star$ を相殺して $\eta > 0$ で割ると、この不等式は次の形になる。

<!--en:e01cc0fe-->
平たく言えば、実行可能な方向の中に降下方向は 1 つも存在しない。これは一般的な制約付き一階条件であり、$\nabla f(\mathbf{x}^\star) = \mathbf{0}$ へと $C = \mathbb{R}^n$ のときに帰着する。$f$ が凸であれば、接平面の不等式からこの条件は直ちに大域的最小点の十分条件となり、$f$ が非凸であれば停留性を保証する。さらに $C = \{\mathbf{x} : g_i(\mathbf{x}) \le 0\}$ がスレーター条件を満たす微分可能な凸関数 $g_i$ で定まるとき、この条件は KKT 条件と同値になる。

<!--en:8764d31a-->
余分な射影ステップによって勾配降下法は遅くなるのだろうか。驚くべきことに遅くはならず、非拡大性（nonexpansiveness）から 3 行の証明が得られる。

<!--en:7a541b5f-->
**命題（PGD は少なくとも GD と同じ速さで縮小する）** *$C$ を空でない閉凸集合とし、$f$ は 2 回連続微分可能で $\mu\mathbf{I} \preceq \nabla^2 f \preceq L\mathbf{I}$ がある $0 < \mu \le L$ に対して成り立つとし、$\mathbf{x}^\star$ を $f$ の $C$ 上での最小点とし、$\eta > 0$ とする。このとき、:eqref:`eq_mdl-opt-pgd` の反復列は次式を満たす。*

<!--en:203438c2-->
**証明：** (i) $\mathbf{x}^\star$ は PGD の不動点であるため、$\mathbf{x}^\star = \Pi_C(\mathbf{b})$（ただし $\mathbf{b} = \mathbf{x}^\star - \eta\nabla f(\mathbf{x}^\star)$）と書ける。(ii) この $\mathbf{b}$ の選び方が急所となるステップであり、非拡大性を $\mathbf{x}_k - \eta\nabla f(\mathbf{x}_k)$ と $\mathbf{b}$ に適用すると、射影がそっくり取り除かれる。

<!--en:ad13a624-->
(iii) $\mathbf{x}^\star$ と $\mathbf{x}_k$ を結ぶ線分に微分積分学の基本定理を適用すると、$\nabla f(\mathbf{x}_k) - \nabla f(\mathbf{x}^\star) = \bar{\mathbf{H}}(\mathbf{x}_k - \mathbf{x}^\star)$（ただし $\bar{\mathbf{H}} = \int_0^1 \nabla^2 f(\mathbf{x}^\star + t(\mathbf{x}_k - \mathbf{x}^\star))\,dt$）が得られる。この平均化されたヘッセ行列は対称ですべての固有値が $[\mu, L]$ に属するため、$\mathbf{I} - \eta\bar{\mathbf{H}}$ の各固有値は $1 - \eta h$（$h \in [\mu, L]$）の形をしており、その絶対値は高々 $\rho$ である。したがって右辺は高々 $\rho\,\|\mathbf{x}_k - \mathbf{x}^\star\|$ で抑えられる。$\blacksquare$

<!--en:79b0690d-->
ステップ (ii) で射影を取り除いてしまえば、あとに残るのは制約なし勾配降下法の縮小だけである。二次関数 $f = \tfrac12\mathbf{x}^\top\mathbf{A}\mathbf{x}$ に対しては $\bar{\mathbf{H}} = \mathbf{A}$ となり、ステップ (iii) はモードごとの厳密な縮小率 $|1 - \eta\lambda_i(\mathbf{A})|$（:numref:`sec_mdl-gradient-based-optimization`）を復元し、その値は $1$ より真に小さく保たれる（$0 < \eta < 2/L$ のとき）。強凸ではない凸かつ $L$ 滑らかな $f$ に対しても同様に、$\eta = 1/L$ とした PGD は勾配降下法の $O(1/k)$ の目的関数値の収束率をそのまま引き継ぐ :cite:`Nesterov.2018`。

<!--en:732dfb84-->
縮小率 $\rho$ が実際にどれほどタイトかを試してみよう。悪条件な二次関数 $f(\mathbf{x}) = \tfrac12(x_1^2 + 1000\,x_2^2)$（条件数 $\kappa = 10^3$）を、半空間 $x_1 + x_2 \ge 1$（すなわち $g(\mathbf{x}) = 1 - x_1 - x_2 \le 0$）上で最小化する。KKT 条件は手計算で解ける。制約なし最小点 $\mathbf{0}$ は実行不可能であるため、制約は有効でなければならない。停留性 $(x_1, 1000\,x_2) - \lambda(1, 1) = \mathbf{0}$ から $x_1 = \lambda$ および $x_2 = \lambda/1000$ が得られ、これらを $x_1 + x_2 = 1$ に代入すると、$\lambda^\star = 1000/1001 \approx 0.999$、$\mathbf{x}^\star = (1000/1001,\; 1/1001) \approx (0.999, 0.001)$、および $p^\star = 500/1001 \approx 0.4995$ が求まる。

<!--en:91a77350-->
ここで、ステップサイズ $\eta = 0.0015$（安定限界 $2/L = 0.002$ を十分に下回る値）で PGD を実行する。先ほどの命題から、1 ステップあたりの縮小率 $\rho = \max(1 - \eta,\ |1 - 1000\,\eta|) = 0.9985$ が保証される。$(3, 4)$（距離 $4.47$ だけ $\mathbf{x}^\star$ から離れた点）から出発すると、この上界からは最大 $\log(4.47 \times 10^6)/\log(1/\rho) \approx 10{,}200$ ステップを距離 $10^{-6}$ に達するまでに要すると予測される。以下のコードでは PGD を実行し、1 ステップでの最悪の縮小比、実際のステップ数、毎ステップ境界に当たり始める時点、境界に沿った縮小比、および最終的な勾配を調べる。

<!--en:c50285cf-->
1 ステップでの最大の比は $0.9977$ と $\rho = 0.9985$ に迫っており、1 ステップあたりの最悪ケース評価はほぼタイトである。ところが総ステップ数は嬉しい驚きをもたらす。$738$ ステップで済み、$10{,}200$ ステップには遠く及ばないのである。出力された診断情報からその理由がわかる。軌跡が 2 つの明確な段階に分かれて進むためである。第 1 段階では、最初のステップのあと制約は非有効のままであり、急峻な座標 $x_2$ は数十回の反復で潰れる一方、平坦な座標 $x_1$ は制約なし勾配降下法とまったく同様に毎ステップ $1 - \eta$ 倍ずつじわじわと内側へ這い進む。$x_1 = 3$ から境界線に到達するまでにおよそ $\log 3 / \eta \approx 730$ ステップかかる。ステップ $733$ 以降は、すべての更新が境界に当たって直線 $x_1 + x_2 = 1$ 上へ射影される。この直線に沿うと二次関数の曲率は $(1 + 1000)/2 = 500.5$ となるため、$\mathbf{x}^\star$ までの距離は毎ステップ $1 - 500.5\,\eta = 0.249$ 倍に縮まり（直線に沿った 1 次元勾配降下法の厳密な縮小率）、あとほんの数ステップで実行が完了する。$\rho$ は平面上のあらゆる場所における最悪の曲率に備えなければならないのに対し、いったん制約が有効になれば*境界に沿った*曲率だけが効いてくるのである。最後に、終了時点での勾配 $(0.999, 0.999) = \lambda^\star(1, 1) = -\lambda^\star\nabla g$ にも注目しよう。ゼロになるどころか、手計算で導いた乗数 $\lambda^\star = 1000/1001$ をそのまま返してくれる。

<!--en:1be411be-->
$\Pi_C$ が安価に計算できる場面では、PGD は主力となる手法である。非負制約では単に負の成分をゼロにするだけで非負象限（nonnegative orthant）へ射影でき、重み行列の各行に対する最大ノルム制約では更新のたびに各行を球面上へ再スケーリングすればよい。深層学習におけるおそらく最も有名な応用は、入力摂動 $\boldsymbol{\delta}$（$\|\boldsymbol{\delta}\|_\infty \le \epsilon$）に対する射影勾配上昇法によって敵対的サンプルを生成する手法であり、そこでの射影は単に各成分を $[-\epsilon, \epsilon]$ にクリップするだけである :cite:`Madry.Makelov.Schmidt.ea.2018`。なお、勾配クリッピングも球への射影を用いるが、射影するのはパラメータではなく*勾配ベクトル*であるため、重みに対するいかなる制約の PGD でもないことに注意しよう（演習問題 :exref:`ex_mdl-constrained-projected-fixed-points` でその違いを浮き彫りにする）。クリッピングが達成しているのは、勾配とともに曲率が増大する領域でもステップを安全に保つことである（:numref:`subsec_mdl-relaxed-smoothness`）。

<!--en:09ad72b6-->
### 単体への射影

<!--en:80593b7c-->
アテンション重みやクラス確率は**確率単体**（probability simplex）$\Delta = \{\mathbf{x} : \mathbf{x} \ge 0,\; \sum_i x_i = 1\}$ の上に乗っている。実数スコアのベクトル $\mathbf{y}$ が与えられたとき、$\Delta$ 上で最も近い点をどのように見つければよいだろうか。それには次の問題を考える。

<!--en:e2a099d1-->
これは小規模な**二次計画問題**（quadratic program、QP）、すなわちアフィン制約のもとで凸二次目的関数を最小化する問題であり、KKT 条件を使うと 1 つのスカラーを求める問題に帰着する。和の制約に対する乗数 $\tau$ と、乗数 $\lambda_i \ge 0$（非負制約 $-x_i \le 0$ に対するもの）を導入しよう。停留性から $x_i - y_i + \tau - \lambda_i = 0$ が得られ、相補性条件によって各座標は 2 つのグループに分かれる。$x_i > 0$ となる座標では $\lambda_i = 0$ でなければならず、したがって $x_i = y_i - \tau$ となる。一方 $x_i = 0$ となる座標では、停留性から $\lambda_i = \tau - y_i$ となり、双対実行可能性 $\lambda_i \ge 0$ から $y_i \le \tau$ が課される。両方のケースをまとめると次式が得られる。

<!--en:a7567159-->
言い換えれば、単体への射影とは、すべてのスコアから同じ閾値 $\tau$ を引き、負になった値をゼロにクリップするだけの操作である。注目すべきことに、この閾値の式は*任意の* $\tau$ に対して停留性、相補性条件、双対実行可能性、および非負性を自動的に満たしており、和が 1 であるという制約 $\sum_i x_i = 1$ だけが $\tau$ を一意に定める。左辺の $\varphi(\tau) = \sum_i \max(y_i - \tau, 0)$ は連続な区分線形関数であり、正の値をとる領域では狭義単調減少であるため、一意な $\tau$（$\varphi(\tau) = 1$ の解）が存在する。

<!--en:511c9c0a-->
簡単な手計算で $\tau$ の見つけ方を確認しよう。すでに降順に並んだベクトル $\mathbf{y} = (0.9, 0.5, -0.2)$ をとり、上位 $k$ 個のスコアがゼロより大きく生き残ると推測してみる。すると和の制約 $\sum_{j \le k}(y_j - \tau) = 1$ から閾値の候補 $\tau_k = (\sum_{j \le k} y_j - 1)/k$ が予測され、これが自己無撞着になるのは $k$ 番目のスコアが $\tau_k$ より真に大きく保たれる場合に限られる。

<!--en:4174c0d5-->
* $k = 1$：$\tau_1 = -0.1$ であり、$y_1 = 0.9 > \tau_1$ を満たす。

<!--en:458a2c11-->
* $k = 2$：$\tau_2 = 0.2$ であり、$y_2 = 0.5 > \tau_2$ を満たす。

<!--en:ab7ce4bb-->
* $k = 3$：$\tau_3 \approx 0.067$ であるが、$y_3 = -0.2 < \tau_3$ となる。

<!--en:caabe2a3-->
妥当な最大の選択は $k = 2$ であり、$\tau = 0.2$ および $\mathbf{x}^\star = (0.7, 0.3, 0)$ が得られる（:numref:`fig_mdl-opt-simplex-threshold`）。比較として、同じスコアにソフトマックスを適用すると $(0.50, 0.33, 0.17)$ となり、すべての成分が真に正に保たれる。

<!--en:88237bd5-->
![$\mathbf{y}=(0.9,0.5,-0.2)$ の確率単体への射影。(a) ではすべてのスコアが閾値 $\tau=0.2$ だけ引き下げられてゼロでクリップされ、$\tau$ は $\sum_i x_i=1$ によって一意に定まる。(b) の同じスコアに対するソフトマックスでは、すべての座標が真に正に保たれる。](../img/mdl-opt-simplex-threshold.svg)

<!--en:4054936f-->
2 つの単純な考察から、この手計算は一般的なアルゴリズムへと変わる。第 1 に、*サポート* $\{i : x_i^\star > 0\}$ は常に上位のスコアからなる。実際、$y_i > y_j$ かつ $x_j^\star > 0$ ならば $x_i^\star \ge y_i - \tau > y_j - \tau = x_j^\star > 0$ が成り立つ。（*有効な*符号制約は残りのゼロ座標である。）第 2 に、スコアを $u_1 \ge \cdots \ge u_n$ と降順にソートすると、判定条件 $u_k > \tau_k$ は真のサポートサイズ以下のすべての $k$ で成り立ち、それを超えると破綻する。実際、$u_k > \tau_k$ を変形すると $\sum_{j < k}(u_j - u_k) < 1$、すなわち $\varphi(u_k) < 1 = \varphi(\tau)$ となり、$\varphi$ が狭義単調減少であることから、これは $u_k > \tau$ と同値である。したがって、$\mathbf{y}$ をソートし、最大の $k$（$u_k > \tau_k$ を満たすもの）を選んで $\tau = \tau_k$ とおけばよく、計算時間は $O(n \log n)$ となる :cite:`Held.Wolfe.Crowder.1974,Duchi.Shalev-Shwartz.Singer.ea.2008`。

<!--en:460011a7-->
アテンションスコアに適用するとき、この単体射影はスコアの低い位置に厳密なゼロの重みを割り当てることから *sparsemax* と呼ばれる :cite:`Martins.Astudillo.2016`。ソフトマックスと sparsemax の違いは正則化項 1 つだけである。二乗距離を展開すると、sparsemax は $\mathbf{y}^\top\mathbf{x} - \tfrac12\|\mathbf{x}\|^2$ を $\Delta$ 上で最大化するのに対し、ソフトマックスは二次のペナルティをシャノンエントロピーに置き換えた $\mathbf{y}^\top\mathbf{x} + H(\mathbf{x})$ を最大化する（:numref:`sec_mdl-lagrangian-duality`）。

<!--en:8734eafe-->
射影を実装したら、その出力を検証するのがよい習慣である。最初に行う自然なテストは KKT 残差の確認であるが、どの条件が実際に誤りを識別できるかには注意が必要である。以下のセルでは、6 個のランダムなスコアに対して、計算された $\tau$ と摂動を加えた値 $\tau + 0.3$ の両方でテストし、さらに鈍角不等式 :eqref:`eq_mdl-opt-proj-variational` による最適性の証明書を確認する。:eqref:`eq_mdl-opt-proj-variational` の左辺は $\mathbf{x}$ に関してアフィンであるため、$\Delta$ 上での最大値は頂点で達成される。したがって、$n$ 個の標準基底ベクトル $\mathbf{e}_i$ を調べるだけで単体全体を検証するのに十分である。

<!--en:b2effafc-->
通常、6 個の座標のうち 3〜5 個が厳密なゼロに設定される。これらは有効な非負制約であり、それぞれ正の乗数 $\tau - y_i$ を伴う。ここで診断上の落とし穴に注目しよう。停留性、相補性条件、および双対実行可能性は、*両方*の値（正しい $\tau$ と誤った値）に対して丸め誤差の範囲内で通ってしまう。誤りを捉えるのは和の制約だけであり、したがってこれら 3 つの残差を調べるだけでは解の正しさを確認できない。一方、頂点による証明書は確実に機能する。丸め誤差の範囲内で $\max_i (\mathbf{y} - \mathbf{x}^\star)^\top(\mathbf{e}_i - \mathbf{x}^\star) \le 0$ であることを確かめれば、単体上のどの点もこれ以上 $\mathbf{y}$ に近づけないことが証明される。

<!--en:1529c3d8-->
## 近接作用素と座標降下法

<!--en:3f65a794-->
### ソフト閾値処理と近接作用素

<!--en:c18103f7-->
重みを抑制する方法は、硬い境界を設けることだけではない。**Lasso** :cite:`Tibshirani.1996` は、硬い壁の代わりに折れ目を持つ $\ell_1$ ペナルティを最小二乗損失に加える。

<!--en:3f97adc0-->
その最小点は、多くの座標を厳密なゼロに設定するのが特徴である。ここでペナルティの重みをあえて $\lambda$ と書いたのは、それがノルム制約 $\|\mathbf{w}\|_1 \le c$ に対するラグランジュ乗数のように働くからである。すなわち、$F$ のすべての最小点は、それが消費する $\ell_1$ バジェット $c$ のもとで最小二乗損失を最小化しており、逆に任意のバジェット $c > 0$ はあるペナルティ $\lambda$ に対応する。:numref:`subsec_mdl-weight-decay-duality` では、Lasso と $\ell_2$ 重み減衰（weight decay）の両方について、この双方向の対応を証明する。

<!--en:97537f1d-->
数値的に何が起きるかを見るため、5 個のゼロ座標を持つスパースなベクトル $\mathbf{w}$ を $\mathbb{R}^8$ 内に用意し、$n = 100$ 個のノイズを含む線形観測値を生成して $\lambda = 3$ と設定しよう。ステップサイズは $\eta = 1/L$ と選ぶ。ここで $L = \lambda_{\max}(\mathbf{A}^\top\mathbf{A})$ は $\mathbf{A}^\top\mathbf{A}$ の最大固有値であり、最小二乗項の滑らかさの定数である。

<!--en:06eb0212-->
ここで $L$ は通常 $130$〜$190$ の範囲に収まるのに対し、列の二乗ノルム $\|\mathbf{a}_j\|^2$（$\mathbf{A}$ の各列）は $100$ 前後になる。

<!--en:d8237e1b-->
試すべき最も素朴なアルゴリズムは劣勾配降下法（subgradient descent）である。:numref:`sec_mdl-convexity` で学んだとおり、$|w|$ の劣勾配（subgradient）は $\mathrm{sign}(w)$（$w \neq 0$ のとき）であり、折れ目では区間 $[-1, 1]$ 全体（$w = 0$ のとき）となる。各ステップで $\mathrm{sign}(\mathbf{w})$ を選ぶと、更新式 $\mathbf{w} \leftarrow \mathbf{w} - \eta\left(\mathbf{A}^\top(\mathbf{A}\mathbf{w} - \mathbf{b}) + \lambda\,\mathrm{sign}(\mathbf{w})\right)$ が得られる。これで 5 個のゼロを復元できるだろうか。

<!--en:bd403d4e-->
厳密なゼロを生成することには完全に失敗する。どの座標もゼロに着地せず、5 個の*ヌル*座標（あらかじめゼロに設定した座標）はほぼ毎回の反復で符号を反転させ、約 $\eta\lambda$ の振幅で行ったり来たり振動する。原因はゼロにある折れ目である。真の Lasso 解において、ヌル座標における滑らかな項の勾配は絶対値が $\lambda$ より真に小さい。そのためゼロの近くでは、ペナルティ項 $-\eta\lambda\,\mathrm{sign}(w_j)$ がステップを支配し、毎回およそ $\eta\lambda$ だけ座標をゼロの反対側へ蹴り出してしまう。劣勾配降下法は各ステップで区間 $[-\lambda, \lambda]$ からただ 1 つの傾きを選んで決め打ちするため、固定ステップサイズでは滑らかな項の勾配をちょうど打ち消す傾きに落ち着くことが決してできないのである。

<!--en:2a6d8839-->
解決策は単純であり、折れ目のあるペナルティを線形化する代わりに*厳密に*扱えばよい。まずは 1 次元から始め、$\lambda|x| + \tfrac12(x - z)^2$ を $x \in \mathbb{R}$ 上で最小化しよう。目的関数は凸であるため、$x$ が最適であるための必要十分条件は、$0$ がその劣勾配の集合に含まれることである。

<!--en:2b775dc5-->
* $x \neq 0$ のとき、目的関数は $x$ で微分可能であるため $\lambda\,\mathrm{sign}(x) + x - z = 0$ となる。$x > 0$ のときはこれから $x = z - \lambda$ が得られ、これには $z > \lambda$ が必要である。一方 $x < 0$ のときは $x = z + \lambda$ が得られ、これには $z < -\lambda$ が必要である。

<!--en:1e8a04c0-->
* $x = 0$ のとき、劣勾配は区間 $[-\lambda, \lambda] - z$ をなし、これが $0$ を含むための必要十分条件は $|z| \le \lambda$ である。

<!--en:88aca6e5-->
これら 2 つのケースは実数直線を分割し、1 つの式にまとめると**ソフト閾値処理**になる。

<!--en:4cb4e898-->
絶対値が高々 $\lambda$ の入力はすべて厳密なゼロへ吸い寄せられ、それより大きい入力はゼロに向かって $\lambda$ だけ縮小される。たとえば $\lambda = 0.7$ のとき、$z = 0.5$ は $0$ へ、$z = 2$ は $1.3$ へ、$z = -2$ は $-1.3$ へと写される（:numref:`fig_mdl-opt-soft-threshold`）。この不感帯（dead zone）$[-\lambda, \lambda]$ こそが、$\ell_1$ 正則化（regularization）が厳密なスパース性（sparsity）を生み出す仕組みであり、対照的に $\ell_2$ 正則化は重みをゼロに向かって縮小するだけで決してゼロにはしない。

<!--en:124f61ce-->
![ソフト閾値処理 $\mathrm{prox}_{\lambda|\cdot|}(z)$（$\lambda = 0.7$、実線）。不感帯 $[-\lambda, \lambda]$ 内の入力は $0$ へ写され（$z = 0.5$ など）、それ以外の入力はすべて $0$ に向かって $\lambda$ だけ移動する（$z = 2$ など）。破線は恒等写像を表す。点線は二乗ペナルティ $\tfrac12 x^2$ に対応する写像であり、すべての入力を半分にするが $z = 0$ 以外をゼロにすることはない。](../img/mdl-opt-soft-threshold.svg)

<!--en:ba42acd8-->
ソフト閾値処理は、はるかに一般的な操作の 1 つの例にすぎない。**近接作用素**（proximal operator）は、関数 $\psi$ に対して $\psi(\mathbf{x})$ を小さくすることと参照点 $\mathbf{z}$ の近くに留まることのトレードオフをとる。

<!--en:6ceb6e5b-->
この写像はすべての*真閉凸*（proper closed convex）関数 $\psi$、すなわち凸であり、$\mathbb{R} \cup \{+\infty\}$ に値をとり、少なくとも 1 点で有限値をとり、かつ閉じたエピグラフを持つ関数に対して一意に定まる。これらの条件のもとで、:eqref:`eq_mdl-opt-prox` の目的関数は $1$ 強凸となるため、一意な最小点を持つ :cite:`Parikh.Boyd.2014`。

<!--en:93a4d220-->
3 つの特別な場合を見ることで、近接作用素が既知の概念をいかに統一しているかがわかる。

<!--en:88cc9f1d-->
* $\psi = 0$ のとき、近接作用素は単なる恒等写像である。

<!--en:3c483480-->
* $\psi$ が閉凸集合 $C$ の*指示関数*（indicator）（値は $0$（$C$ 上）および $+\infty$（外部））であるとき、最小点は必ず $C$ に属さなければならないため、近接作用素はユークリッド射影 $\mathrm{prox}_\psi = \Pi_C$ に帰着する。近接作用素とは、集合から関数へと一般化された射影なのである。

<!--en:d11e8a0c-->
* $\psi = \lambda\|\cdot\|_1$ のとき、目的関数は座標ごとに完全に分離するため、近接作用素はソフト閾値処理 :eqref:`eq_mdl-opt-soft-threshold` を各座標に適用する操作となる。

<!--en:a61c63d7-->
演習問題 :exref:`ex_mdl-constrained-group-lasso-prox` では重みのブロック全体を一括でゼロにするユークリッドノルムの近接作用素を導出し、演習問題 :exref:`ex_mdl-convexity-moreau-decomposition` ではノルムの近接作用素とその双対球への射影の和が恒等写像になることを示す。

<!--en:62e1f35c-->
### 近接勾配降下法

<!--en:bdb3a728-->
Lasso の目的関数は合成形式 $F = s + \psi$ をしており、滑らかな損失 $s$ と、近接作用素を安価に計算できる非平滑なペナルティ $\psi$ を組み合わせたものである。いま、$s$ が $L$ リプシッツ連続な勾配を持つ凸関数であり、$\psi$ が真閉凸であり、$0 < \eta \le 1/L$ であるとする。降下補題（descent lemma）（:numref:`sec_mdl-gradient-based-optimization`、$1/\eta \ge L$ を使用）より、$s$ は二次モデル $s(\mathbf{x}_k) + \nabla s(\mathbf{x}_k)^\top(\mathbf{x} - \mathbf{x}_k) + \tfrac{1}{2\eta}\|\mathbf{x} - \mathbf{x}_k\|^2$ によって上から抑えられる。ここで $\psi$ まで線形化するのではなく、$s$ のこの二次上界に*厳密な* $\psi$ を加えたものを最小化する。平方完成すると、その最小点は次式で与えられる。

<!--en:35f13d69-->
これは滑らかな部分に対する通常の勾配ステップに続けて、折れ目のある部分に対する近接ステップを施す操作である。この更新を次のように反復する。

<!--en:e22965fb-->
こうして得られる手法が**近接勾配降下法**（proximal gradient descent）であり、特に **ISTA**（iterative shrinkage-thresholding algorithm、反復縮小閾値アルゴリズム）の名で $\psi = \lambda\|\cdot\|_1$ のときに知られている。この手法は射影勾配降下法（$\psi$ として $C$ の指示関数をとる）と通常の勾配降下法（$\psi = 0$ ととる）の両方を包含する。

<!--en:ede157e7-->
$F$ が微分可能でなくても、$\eta = 1/L$ とした近接勾配降下法は滑らかな勾配降下法と同じ $O(1/k)$ の収束率 $F(\mathbf{x}_k) - F^\star \le L\|\mathbf{x}_0 - \mathbf{x}^\star\|^2/(2k)$ を達成する（:citet:`Beck.Teboulle.2009` 定理 3.1）。さらに、$s$ が 2 回連続微分可能かつ $\mu$ 強凸（$\mu\mathbf{I} \preceq \nabla^2 s$）であれば、先ほどの PGD の縮小の証明が一字一句そのまま通用する。証明に必要なのは $\mathbf{x}^\star$ が不動点であることと、$\mathrm{prox}_{\eta\psi}$ が $\Pi_C$ と同様に非拡大であることだけだからである（演習問題 :exref:`ex_mdl-convexity-accelerated-proximal-gradient` でこれを証明する）。

<!--en:d427314f-->
Lasso の場合、近接ステップは閾値 $\eta\lambda$ のソフト閾値処理であり、ゼロから $\eta\lambda$ 以内にあるすべての座標を直接ゼロへと吸い寄せる。この閾値は劣勾配降下法が振動していた振幅とぴったり一致するため、ISTA はヌル座標をきれいにゼロに保てるはずである。実際に確かめてみよう。

<!--en:fce9cfda-->
劣勾配降下法と 1 ステップあたり同じ計算コストで同じ 50 回の反復を行うと、ISTA は真のサポートを正確に復元し、5 個のヌル座標すべてをゼロに設定して 3 個の有効な座標を非ゼロのまま残す。これら 3 個の成分は真の値から約 $0.05$ 以内に収まっている。これ以上真の値に大きく近づくことはないが、それは $\ell_1$ ペナルティによって真の Lasso 解自体がゼロに向かっておよそ $\lambda/\|\mathbf{a}_j\|^2 \approx 0.03$ だけ縮小されているためである。

### 座標降下法

<!--en:d78978af-->
初読時には本項を読み飛ばしてもよい。座標降下法（coordinate descent）は Lasso に対する標準的なソルバであるが、ニューラルネットワークの訓練に用いられる手法ではないからである。

<!--en:d357e652-->
Lasso において、他のすべての座標を固定したまま 1 つの座標 $w_j$ に沿って最小化する問題は、先ほど解いた 1 次元の問題そのものに帰着する。$\mathbf{r}_{-j} = \mathbf{b} - \sum_{i \neq j}\mathbf{a}_i w_i$ を座標 $j$ を除いて計算した残差としよう。$j$ 番目の部分問題 $\tfrac12\|\mathbf{a}_j w_j - \mathbf{r}_{-j}\|^2 + \lambda|w_j|$ は、定数項を除いて $\|\mathbf{a}_j\|^2\left(\tfrac12(w_j - c_j/\|\mathbf{a}_j\|^2)^2 + (\lambda/\|\mathbf{a}_j\|^2)|w_j|\right)$ に等しい（ただし $c_j = \mathbf{a}_j^\top\mathbf{r}_{-j}$）。したがって、閾値 $\lambda/\|\mathbf{a}_j\|^2$ のソフト閾値処理によって閉形式で解ける。

<!--en:c804bd73-->
ある特徴量と現在の残差との相関 $c_j$ の絶対値が高々 $\lambda$ であれば、その重みは直ちにゼロに設定される。この更新式で座標を順番に巡回する手法こそ、広く使われている `glmnet` パッケージの背後にあるアルゴリズムである :cite:`Friedman.Hastie.Tibshirani.2010`。座標を更新するたびに残差を差分更新すれば、全 $d$ 座標を 1 周するスイープのコストは 1 回の勾配計算と同じになる。

<!--en:e2cf5614-->
同じ原理は、任意の微分可能な目的関数 $f$ が座標ごとの滑らかさの定数 $L_j$ を持ち、次式を満たす場合にも適用できる。

<!--en:a3a5856d-->
この二次上界を $t$ に関して最小化すると、次の**座標降下法**の更新式が得られる。

<!--en:fef6bcd5-->
$L_j$ は 1 つの座標軸に沿った曲率を測るため、大域的な滑らかさの定数 $L$ より大幅に小さくなり得て、より大きなステップをとることができる。実際、先ほどの Lasso 問題では $L_j = \|\mathbf{a}_j\|^2 \approx 100$ であるのに対し、$L \in [130, 190]$ であった。正定値二次関数 $f(\mathbf x)=\tfrac12\mathbf x^\top\mathbf{A}\mathbf x-\mathbf b^\top\mathbf x$ に対しては、$L_j = A_{jj}$ で上界が厳密に一致し、次の更新式が得られる。

<!--en:af85d9c1-->
この更新は $f$ を座標 $j$ に沿って厳密に最小化する。すべての座標を巡回的にスイープすると、$\mathbf{A}\mathbf x = \mathbf b$ に対する古典的なガウス・ザイデル反復が復元される。

<!--en:3ac6ec87-->
1 回の座標スイープは、同じ計算コストの ISTA の 1 ステップよりどれほど速いだろうか。先ほどの Lasso 問題において、目的関数のギャップ $F(\mathbf{w}) - F^\star$ を $10^{-8}$ 未満に押し下げるまでに各手法がデータを何回走査するかを数えてみよう。

<!--en:a811257b-->
対数プロット上では、どちらの手法も直線を描いて減少する（線形収束）が、座標降下法のほうがはるかに急激に減少し、通常はギャップ $10^{-8}$ に 4〜6 回のスイープで到達するのに対し、ISTA では 12〜25 ステップを要する。本節で証明したどの結果からも、この正確な高速化倍率は予測できない。座標降下法に対する最もシャープな収束率はランダムに座標を選ぶ設定で証明されており :cite:`Nesterov.2012`、ここで用いたような巡回的スイープも保証された収束率で収束するものの、その定数はより弱いものになる :cite:`Beck.Tetruashvili.2013`。

<!--en:4bd45453-->
座標降下法には重要な制約もある。非平滑な折れ目が座標ごとに分離しない場合、座標降下法は最適点から遠く離れた場所で立ち往生しうる。たとえば $f(x, y) = \max(|x|, |y|)$ において点 $(1, 1)$ にいるとき、$x$ 単独または $y$ 単独に沿って動いても $f$ を減少させることはできないが、大域的最小値 $0$ は原点にある。座標降下法が Lasso でうまく機能するのは、その非平滑ペナルティ $\lambda\sum_j |w_j|$ が座標ごとに分離可能だからにほかならない :cite:`Tseng.2001`。スパース線形モデルやブロック交互最小化においては、座標降下法は今なお第一選択の手法である。しかし密なニューラルネットワークの訓練では出番がない。現代のアクセラレータは、逐次的なスカラー更新ではなく並列な行列積のために設計されているからである。

<!--en:7d63bb3a-->
本節で行ってきたことすべてを貫く 1 つのパターンに注目しよう。乗数を求めたいときは毎回、まず $\mathbf{x}$ について解いていた。:numref:`sec_mdl-lagrangian-duality` ではこの問いを裏返し、乗数を*直接*求める方法、そして任意の乗数の選択が「いかなる実行可能点も所定の下界を下回れない」ことを示す証明書をいかに与えるかを学ぶ。$\lambda^\star = 4$、$p^\star = 8$ であった先ほどのクリッピングの例が、その冒頭を飾ることになる。

## まとめ

<!--en:b098ac35-->
制約付き最適点では、勾配がゼロになる必要はなく、代わりにいかなる実行可能な方向も目的関数を減少させられないという条件が成り立つ。$\nabla h(\mathbf{x}^\star) \neq \mathbf{0}$ を満たす 1 つの等式制約に対しては、これは $\nabla f + \nu\nabla h = \mathbf{0}$ が、解が制約をどれほど強く押しているかを測るラグランジュ乗数 $\nu$ に対して成り立つことを意味する。不等式制約を加えると 4 つの KKT 条件が導かれ、そこでは双対実行可能性（$\lambda_i \ge 0$）が片方向の壁を表し、相補性条件（$\lambda_i g_i = 0$）がすべての非有効制約の乗数をゼロにする。凸問題においてはすべての KKT 点が大域的最小点であり、制約想定（LICQ やスレーター条件など）のもとではすべての最小点が KKT 点となる。

<!--en:6f2ced4d-->
制約付きの解を反復的に計算するため、射影勾配降下法は各勾配ステップに続けてユークリッド射影 $\Pi_C$ を適用する。閉凸集合への射影は一意であり、鈍角不等式によって特徴づけられ、かつ非拡大であるため、射影勾配降下法は制約なし勾配降下法の収束率をそのまま保つ。球、半空間、および確率単体への射影は、いずれも 1 つのスカラー乗数について解く問題に帰着する。最後に、近接作用素は射影を集合から非平滑な関数へと一般化する。ソフト閾値処理は $\lambda|\cdot|$ の近接作用素であり、ISTA と座標降下法はいずれもこれを用いることで、劣勾配降下法では到達できない厳密なゼロを伴う Lasso の解を求める。

## 演習問題

<!--en:f75c9832-->
1. **退化した制約。** ラグランジュ条件 :eqref:`eq_mdl-opt-lagrange-condition` と KKT 条件 :eqref:`eq_mdl-opt-kkt` は、制約想定のもとでのみ最小点において成り立つ。以下の各問題は、いずれかの制約想定に違反している。
    1. $f(\mathbf{x}) = x_1 + x_2^2$ を $\mathbb{R}^3$ 上で制約 $h_1(\mathbf{x}) = x_3 = 0$ および $h_2(\mathbf{x}) = x_3 - x_1^2 = 0$ のもとで最小化せよ。実行可能領域が直線であることを示し、最小点を求め、両方の制約勾配がいたるところで非ゼロであることを示せ。また、最小点においていかなる乗数 $\nu_1, \nu_2$ も $\nabla f + \nu_1 \nabla h_1 + \nu_2 \nabla h_2 = \mathbf{0}$ を満たさないことを示せ。さらに、乗数が存在するような別の 2 つの等式制約によって同じ直線を表せ。制約想定とは実行可能領域そのものの性質か、それともそれを記述する関数の性質か。
    1. $f(x) = x$ を $\mathbb{R}$ 上で制約 $x^2 \le 0$ のもとで最小化せよ。$p^\star$ を求め、最小点においていかなる $\lambda \ge 0$ も KKT 停留条件を満たさないことを示せ。LICQ とスレーター条件のうちどちらが破れているか。それぞれについて理由を説明せよ。
    1. $f(x) = x$ を $\mathbb{R}$ 上で、制約 $-x \le 0$ を $g_1(x) = g_2(x) = -x$ と 2 回課したもとで最小化せよ。LICQ が破れ、スレーター条件が成り立つことを示せ。最小点において KKT 条件を満たすすべての組 $(\lambda_1^\star, \lambda_2^\star)$ を求めよ。緩和した制約 $-x \le u_1$ および $-x \le u_2$ のもとで最適値 $p^\star(u_1, u_2)$ を計算し、すべての KKT 乗数の組が $p^\star(\mathbf{u}) \ge p^\star(\mathbf{0}) - \boldsymbol{\lambda}^{\star\top}\mathbf{u}$ をすべての $\mathbf{u}$ に対して満たすことを確かめよ。$p^\star$ は $\mathbf{0}$ で微分可能か。また、関係式 $\boldsymbol{\lambda}^\star = -\nabla p^\star(\mathbf{0})$ に取って代わるものは何か。
   :exlabel:`ex_mdl-constrained-degenerate-constraints`

<!--en:ad250440-->
1. **射影の不動点。** 閉凸集合 $C$ に対し、射影勾配降下法 :eqref:`eq_mdl-opt-pgd` の不動点は、ステップサイズ $\eta > 0$ の選び方にかかわらず制約付き停留点と一致する。
    1. $C = \{\mathbf{x} : \mathbf{x} \ge 0\}$ とする。$\mathbf{x}^\star$ が不動点であるための必要十分条件は、すべての座標 $i$ について、$\partial f / \partial x_i (\mathbf{x}^\star) = 0$ かつ $x_i^\star \ge 0$ であるか、または $\partial f / \partial x_i (\mathbf{x}^\star) > 0$ かつ $x_i^\star = 0$ であることだと示せ。さらに、これらの条件が制約 $-x_i \le 0$ に対する KKT 条件に一致することを示し、乗数を $\nabla f(\mathbf{x}^\star)$ を用いて表せ。
    1. 勾配クリッピングは $\mathbf{x}_{k+1} = \mathbf{x}_k - \eta\,\Pi_{B_c}(\nabla f(\mathbf{x}_k))$（ただし $B_c = \{\mathbf{z} : \|\mathbf{z}\| \le c\}$）と更新する。この更新式の不動点を求め、パラメータ球 $\{\mathbf{x} : \|\mathbf{x}\| \le r\}$ 上への射影勾配降下法の不動点と比較せよ。2 つの更新式のうち、制約付き問題を解いているのはどちらか。
    1. 二値重みはパラメータを非凸集合 $C = \{-1, 1\}$ に制限し、$C$ への射影は近いほうの要素へ丸める（同距離のときは $1$ とする）。$f(x) = \tfrac12 (x - a)^2$（$0 < a < 1$）とせよ。どのようなステップサイズのとき $x = 1$ が :eqref:`eq_mdl-opt-pgd` の不動点になり、どのようなステップサイズのとき $x = -1$ が不動点になるか。$\eta$ が両方の範囲を超えると反復列はどう振る舞うか。$f$ を $C$ 上で最小化するのはどちらの点か。また、どちらかの点は $f'(x^\star)(x - x^\star) \ge 0$ をすべての $x \in C$ に対して満たすか。この集合に対しては、不動点の議論のどのステップが破綻するか。
    1. 半空間上の PGD のセルを、$\eta = 2.2/1000$（$0.0015$ の代わり）で実行せよ。射影は非拡大であるにもかかわらず、実行が発散するのはなぜか。縮小に関する命題のどの因子が $1$ を超えているか。
   :exlabel:`ex_mdl-constrained-projected-fixed-points`

<!--en:96f784cf-->
1. [code] **Sparsemax と $\ell_1$ 球。** 関数 `project_simplex` は単体射影 :eqref:`eq_mdl-opt-simplex`、すなわち sparsemax を計算し、その第 1 出力が射影後のベクトルである。
    1. すべてのスコアに同じ定数を加えても射影が変わらないことを示せ。スコアを温度 $T > 0$ で割り、$u_1 > u_2$ を $\mathbf{y}$ の上位 2 つの成分とする。$\mathbf{y} / T$ の射影がワンホットになる必要十分条件が $T \le u_1 - u_2$ であることを示し、$T \to \infty$ としたときの極限を求めよ。10 個の標準正規分布に従うスコアについて、$\mathbf{y} / T$ の射影の非ゼロ成分の個数を $T$ に対してプロットせよ。
    1. $S$ を $\mathbf{x}^\star$ のサポートとし、どの $y_i$ も閾値 $\tau$ に等しくないと仮定する。ヤコビ行列 $\partial \mathbf{x}^\star / \partial \mathbf{y}$ を :eqref:`eq_mdl-opt-simplex` から導出し :cite:`Martins.Astudillo.2016`、中心有限差分と比較して確かめよ。sparsemax を通る逆伝播は、長さ $n$ の入力に対して何回の算術演算を必要とするか。
    1. $\ell_1$ 球 $\{\mathbf{x} : \|\mathbf{x}\|_1 \le z\}$ への射影が $\mathbf{y}$ の各成分の符号を保ち、$\|\mathbf{y}\|_1 > z$ のときには $\mathrm{sign}(\mathbf{y}) \odot z\,\Pi_\Delta(|\mathbf{y}| / z)$ に等しくなることを示せ :cite:`Duchi.Shalev-Shwartz.Singer.ea.2008`。これを `project_simplex` を用いて実装せよ。得られた結果を変分不等式 $(\mathbf{y} - \hat{\mathbf{x}})^\top(\mathbf{x} - \hat{\mathbf{x}}) \le 0$ を $2n$ 個の点 $\pm z\,\mathbf{e}_i$ で調べることで検証せよ。なぜこれらの点だけで十分なのか。

<!--en:4f2ce876-->
1. **球面上の二階条件。** ● ラグランジュ条件は一階条件であり、極小点と鞍点を区別できない。二階の判定法では制約の曲率を考慮に入れる必要がある。
    1. $f$ と $h$ を 2 回連続微分可能とし、$\mathbf{x}^\star$ が :eqref:`eq_mdl-opt-lagrange-condition` を乗数 $\nu^\star$ で満たすとする。任意の曲線 $\mathbf{x}(t)$ が $\{h = 0\}$ 上にあり、$\mathbf{x}(0) = \mathbf{x}^\star$ かつ $\dot{\mathbf{x}}(0) = \mathbf{v}$ を満たすとき、次式を示せ。

       $$\left.\frac{d^2}{dt^2} f(\mathbf{x}(t))\right|_{t=0} = \mathbf{v}^\top \nabla^2_{\mathbf{x}} \mathcal{L}(\mathbf{x}^\star, \nu^\star)\, \mathbf{v},$$

       ここでラグランジアンには :eqref:`eq_mdl-opt-lagrangian-eq` を用いる。これから、極小点では $\mathbf{v}^\top \nabla^2_{\mathbf{x}} \mathcal{L}\, \mathbf{v} \ge 0$ がすべての接線方向 $\mathbf{v}$ に対して成り立つと結論せよ。この判定に $f$ のヘッセ行列単独を用いるのが誤りであるのはなぜか。なお逆に、接空間上で正定値であれば狭義の極小点となる（:citet:`Nocedal.Wright.2006` 第 12 章）。
    1. $\mathbf{A}$ を相異なる固有値 $a_1 < a_2 < \cdots < a_n$ と単位固有ベクトル $\mathbf{q}_1, \ldots, \mathbf{q}_n$ を持つ対称行列とし、$f(\mathbf{x}) = \mathbf{x}^\top \mathbf{A} \mathbf{x}$ を制約 $\mathbf{x}^\top \mathbf{x} = 1$ のもとで最小化せよ。ラグランジュ条件を満たす点が $\pm \mathbf{q}_i$（乗数 $\nu^\star = -a_i$）であることを示し、$\nabla^2_{\mathbf{x}} \mathcal{L}$ の $\mathbf{q}_i$ における接空間上での固有値を求めよ。これらの点のうち、極小点、極大点、鞍点はそれぞれどれか。また、$\mathbf{q}_i$ は互いに独立な降下方向を何本持つか。
    1. 球面上への射影勾配降下法 $\mathbf{x} \leftarrow (\mathbf{x} - \eta \nabla f(\mathbf{x})) / \|\mathbf{x} - \eta \nabla f(\mathbf{x})\|$ は非凸集合への射影を行う。この $f$ に対して、この更新が $\mathbf{I} - 2\eta \mathbf{A}$ に対するべき乗法になっていることを示せ。$a_1 + a_n > 0$ と仮定する。ランダムな初期点から出発したとき、反復列 $\mathbf{x}_k$ と関数値 $f(\mathbf{x}_k)$ はどう振る舞うか。その答えは $\eta > 0$ にどう依存するか。

<!--en:d77d2b57-->
1. **ブロックソフト閾値処理（グループ Lasso）。** ベクトル全体に課すペナルティ $\lambda\|\mathbf{w}\|_2$ は $\mathbf{w} = \mathbf{0}$ でのみ折れ目を持つ。その劣勾配は、$\mathbf{w}/\|\mathbf{w}\|$（$\mathbf{w} \neq \mathbf{0}$ のとき）および単位球内のすべてのベクトル（$\mathbf{0}$ のとき）に $\lambda$ を掛けたものである。
    1. $\mathrm{prox}_{\lambda\|\cdot\|_2}(\mathbf{z}) = \max\left(0,\; 1 - \lambda/\|\mathbf{z}\|\right)\mathbf{z}$ を示せ。
    1. ゼロが生じるパターンを座標ごとのソフト閾値処理 :eqref:`eq_mdl-opt-soft-threshold` と比較せよ。ブロック近接作用素が厳密に $\mathbf{0}$ を返すのはいつか。また、ブロック内の 1 つの座標だけをゼロにすることはあり得るか。
    1. ペナルティ $\lambda\sum_u\|\mathbf{w}_u\|_2$（出力側の重みベクトル $\mathbf{w}_u$ をネットワークの隠れユニット $u$ にわたって足し合わせたもの）は、ネットワークにどのような作用をもたらすか。
    1. [code] (a) の結果を 2 次元グリッド上の総当たり最小化と比較して、$\mathbf{z} = (0.3, 0.4)$ および $\mathbf{z} = (3, 4)$（$\lambda = 1$）について検証せよ。答えはそれぞれ $\mathbf{0}$ と $(2.4, 3.2)$ になるが、$(2.4, 3.2)$ は本節のどこに現れたか。

1. **モロー分解。** ● *凸共役*とは、$\psi$ に対して $\psi^*(\mathbf{y}) = \sup_{\mathbf{x}}\left(\mathbf{y}^\top\mathbf{x} - \psi(\mathbf{x})\right)$ で定義される関数である。真閉凸な $\psi$ に対しては、2 つの事実がこれを近接作用素 :eqref:`eq_mdl-opt-prox` と結びつける。すなわち、$\mathbf{x} = \mathrm{prox}_\psi(\mathbf{z})$ が成り立つ必要十分条件は $\mathbf{z} - \mathbf{x} \in \partial \psi(\mathbf{x})$（劣勾配の集合）であり、かつ $\mathbf{y} \in \partial \psi(\mathbf{x})$ が成り立つ必要十分条件は $\mathbf{x} \in \partial \psi^*(\mathbf{y})$ である :cite:`Parikh.Boyd.2014`。
    1. モロー分解 $\mathbf{z} = \mathrm{prox}_\psi(\mathbf{z}) + \mathrm{prox}_{\psi^*}(\mathbf{z})$ を導出せよ。
    1. $\psi = \lambda\|\cdot\|_1$ の共役は直方体 $\{\mathbf{y} : \|\mathbf{y}\|_\infty \le \lambda\}$ の指示関数である。この分解により、ソフト閾値処理 :eqref:`eq_mdl-opt-soft-threshold` が $\mathbf{z}$ からクリップされた $\mathbf{z}$ のコピーを引いた形に書けることを示せ。

[不等式制約]{.kicker}

<!--en:1a5c79be-->
$\tfrac12\|\mathbf{x} - \mathbf{y}\|_2^2$ を閉球 $g(\mathbf{x}) = \tfrac12(\|\mathbf{x}\|_2^2 - r^2) \le 0$ 上で最小化する問題は、2 つの状態に分かれる。

<!--en:2b5a606c-->
- **非有効（$g(\mathbf{x}^\star) < 0$、$\|\mathbf{y}\| < r$）：**$\mathbf{x}^\star = \mathbf{y}$ は球の内部にあり、$\lambda^\star = 0$ となる

<!--en:46fd58d2-->
- **有効（$g(\mathbf{x}^\star) = 0$、$\|\mathbf{y}\| \ge r$）：**$\mathbf{x}^\star = r\mathbf{y}/\|\mathbf{y}\|$ は境界球面上にあり、$\lambda^\star \ge 0$ となる

<!--en:2ba6b73b-->
::: {.slide title="勾配クリッピングにおける力の釣り合いの検証"}

<!--en:337be85b-2-->
[不等式制約]{.kicker}

<!--en:4f206d35-->
$\mathbf{y} = (3, 4)$、半径 $r = 1$ のとき、有効制約の式から $\lambda^\star = 5/1 - 1 = 4$ および $\mathbf{x}^\star = (0.6, 0.8)$ が得られる。

<!--en:a3f667c5-->
**なぜ不等式乗数は非負（$\lambda^\star \ge 0$）でなければならないか：**$\nabla g(\mathbf{x}^\star)$ は*外向き*に実行可能領域 $\{g \le 0\}$ から出る方向を指すため、停留性 $-\nabla f(\mathbf{x}^\star) = \lambda^\star \nabla g(\mathbf{x}^\star)$ と $\lambda^\star \ge 0$ により、下り方向 $-\nabla f$ が外側の壁へ向かって引っ張ることが保証される。もし $\lambda^\star < 0$ ならば $-\nabla f$ は*内向き*を指すため、内部へ踏み出すと $f$ が下がってしまう。

<!--en:e2295582-->
::: {.slide title="4 つのカルーシュ・キューン・タッカー（KKT）条件"}

<!--en:03246263-->
[KKT 条件]{.kicker}

<!--en:5e79d6f2-->
$\min_{\mathbf{x}} f(\mathbf{x})$（制約 $g_i(\mathbf{x}) \le 0$、$h_j(\mathbf{x}) = 0$）に対し、$\mathcal{L}(\mathbf{x}, \boldsymbol{\lambda}, \boldsymbol{\nu}) = f(\mathbf{x}) + \sum_i \lambda_i g_i(\mathbf{x}) + \sum_j \nu_j h_j(\mathbf{x})$ を構成する。

<!--en:b2d6f59f-->
- **実行可能性：**主実行可能性（$g_i(\mathbf{x}^\star) \le 0, h_j(\mathbf{x}^\star) = 0$）と双対実行可能性（$\lambda_i^\star \ge 0$）

<!--en:93edc294-->
- **相補性条件：**$\lambda_i^\star g_i(\mathbf{x}^\star) = 0$ がすべての $i$ で成立（非有効な壁が及ぼす力はゼロ）

<!--en:88c8e0a1-->
::: {.slide title="有効制約の法線錐の幾何構造"}

<!--en:03246263-2-->
[KKT 条件]{.kicker}

<!--en:6148fd1d-->
相補性条件により、非有効制約（$g_i(\mathbf{x}^\star) < 0$）は $\lambda_i^\star = 0$ となって停留性の和から消える。有効制約集合を $\mathcal{A}(\mathbf{x}^\star) = \{i : g_i(\mathbf{x}^\star) = 0\}$（$\lambda_i^\star \ge 0$）とおくと次式が成り立つ。

<!--en:de7c92a7-->
- **法線錐：**最適点において、最急降下方向 $-\nabla f(\mathbf{x}^\star)$ は有効な壁の外向き法線 $\nabla g_i(\mathbf{x}^\star)$ が張る凸錐の内部になければならない

<!--en:0f8b3ad5-->
- **非凸での注意点：**$\min_{x \in [-1, 1]} -x^2$ では、内点 $x = 0$ が $\lambda_1 = \lambda_2 = 0$ で 4 つの KKT 条件すべてを満たすが、$x = 0$ は大域的*最大点*である

<!--en:00a52566-->
::: {.slide title="制約想定：LICQ とスレーター条件"}

<!--en:449fc0b5-->
[KKT の必要性と十分性]{.kicker}

<!--en:561d1d6d-->
2 つの正則性条件により、すべての極小点が KKT 点であることが保証される（制約勾配が退化する境界の尖点を防ぐ）。

<!--en:5ab442db-->
- **1. 線形独立制約想定（LICQ：一般の滑らかな問題）：**
  点 $\mathbf{x}^\star$ におけるすべての有効な不等式制約と等式制約の勾配
  $$\big\{\nabla g_i(\mathbf{x}^\star) : i \in \mathcal{A}(\mathbf{x}^\star)\big\} \cup \big\{\nabla h_j(\mathbf{x}^\star) : j = 1, \ldots, p\big\},$$
  が線形独立である

<!--en:3174f87d-->
- **2. スレーター条件（凸問題：$f, g_i$ が凸、$h_j$ がアフィン）：**
  次を満たす狭義実行可能点 $\bar{\mathbf{x}}$ が 1 つ存在する。
  $$g_i(\bar{\mathbf{x}}) < 0 \;\text{ (for all non-affine } g_i\text{)}, \qquad g_i(\bar{\mathbf{x}}) \le 0 \;\text{ (for affine } g_i\text{)}, \qquad h_j(\bar{\mathbf{x}}) = 0 \;\forall\,j$$
  スレーター条件の確認には、内点をただ 1 つ見つけるだけでよく（たとえば任意のノルム球では $\bar{\mathbf{x}} = \mathbf{0}$ が半径 $r > 0$ で成立）、あらかじめ $\mathbf{x}^\star$ を知る必要はない

<!--en:6d26d651-->
::: {.slide title="凸性のもとでの KKT 十分性の証明"}

<!--en:449fc0b5-2-->
[KKT の必要性と十分性]{.kicker}

<!--en:71287f67-->
凸問題（$f$ と $g_i$ が凸かつ微分可能、$h_j$ がアフィン）では、KKT 条件は大域的最適性に対して**常に十分**であり、制約想定は一切不要である。

<!--en:048fea72-->
- **命題：**凸問題において $(\mathbf{x}^\star, \boldsymbol{\lambda}^\star, \boldsymbol{\nu}^\star)$ が KKT 条件を満たすならば、$f(\mathbf{x}^\star) \le f(\mathbf{x})$ がすべての実行可能な $\mathbf{x}$ で成り立つ

<!--en:ea213e18-->
- **3 行の証明：**
  1. KKT 乗数を固定し、$\varphi(\mathbf{x}) = \mathcal{L}(\mathbf{x}, \boldsymbol{\lambda}^\star, \boldsymbol{\nu}^\star) = f(\mathbf{x}) + \sum_i \lambda_i^\star g_i(\mathbf{x}) + \sum_j \nu_j^\star h_j(\mathbf{x})$ を考える。$\lambda_i^\star \ge 0$ より、$\varphi(\mathbf{x})$ は凸関数の非負重み付き和にアフィン関数を加えたものなので、$\varphi$ は $\mathbb{R}^n$ 上で凸関数である。
  2. KKT 停留性より $\nabla\varphi(\mathbf{x}^\star) = \mathbf{0}$ であるから、$\mathbf{x}^\star$ は $\varphi$ の制約なし大域的最小点であり、$\varphi(\mathbf{x}) \ge \varphi(\mathbf{x}^\star)$ がすべての $\mathbf{x} \in \mathbb{R}^n$ で成り立つ。
  3. 任意の実行可能な $\mathbf{x}$（$g_i(\mathbf{x}) \le 0, h_j(\mathbf{x}) = 0$）に対し、相補性条件（$\lambda_i^\star g_i(\mathbf{x}^\star) = 0$）から次式を得る。
     $$f(\mathbf{x}) \ge f(\mathbf{x}) + \sum_{i=1}^m \lambda_i^\star g_i(\mathbf{x}) + \sum_{j=1}^p \nu_j^\star h_j(\mathbf{x}) = \varphi(\mathbf{x}) \ge \varphi(\mathbf{x}^\star) = f(\mathbf{x}^\star)$$

<!--en:c81b9aec-->
::: {.slide title="閉凸集合へのユークリッド射影"}

<!--en:ffb1cc92-->
[射影]{.kicker}

<!--en:db2b6ee0-->
任意の空でない閉凸集合 $C \subseteq \mathbb{R}^n$ に対し、**ユークリッド射影** $\Pi_C(\mathbf{y})$ は $\mathbf{y} \in \mathbb{R}^n$ を $C$ 内の唯一の最近接点へ写す。

<!--en:874ec675-->
- **存在と一意性：**$C$ と $\mathbf{y}$ のまわりの閉球との共通部分はコンパクト集合となり（連続性から存在を保証）、$1$ 強凸性を $\tfrac12\|\mathbf{x} - \mathbf{y}\|^2$ が持つことから一意性が保証される

<!--en:f497f485-->
- **基本的な射影の閉形式一覧：**
  - *ユークリッド球 $\{ \|\mathbf{x}\|_2 \le r \}$：*$\Pi_C(\mathbf{y}) = \frac{\mathbf{y}}{\max(1,\, \|\mathbf{y}\|_2 / r)}$
  - *軸に沿った直方体 $[a_i, b_i]$：*$\Pi_C(\mathbf{y})_i = \min\big(b_i, \max(a_i, y_i)\big)$（座標ごとのクリッピング）
  - *半空間 $\{ \mathbf{a}^\top\mathbf{x} \ge b \}$：*$\Pi_C(\mathbf{y}) = \mathbf{y} + \frac{\max(0,\, b - \mathbf{a}^\top\mathbf{y})}{\|\mathbf{a}\|_2^2}\,\mathbf{a}$

<!--en:ba489448-->
::: {.slide title="鈍角変分不等式"}

<!--en:ffb1cc92-2-->
[射影]{.kicker}

<!--en:9c649b53-->
点 $\hat{\mathbf{x}} \in C$ が射影 $\Pi_C(\mathbf{y})$ となるための必要十分条件は、残差ベクトル $\mathbf{y} - \hat{\mathbf{x}}$ が鈍角または直角（$\ge 90^\circ$）を、実行可能なすべての弦 $\mathbf{x} - \hat{\mathbf{x}}$（$C$ の内部へ向かう弦、$\forall\,\mathbf{x} \in C$）との間になすことである。

<!--en:48925e4e-->
- **必要性：**$(1-\theta)\hat{\mathbf{x}} + \theta\mathbf{x} \in C$ に沿って動いても $\varphi(\mathbf{x}) = \tfrac12\|\mathbf{x} - \mathbf{y}\|^2$ は下がらないため、$\nabla\varphi(\hat{\mathbf{x}})^\top(\mathbf{x} - \hat{\mathbf{x}}) = (\hat{\mathbf{x}} - \mathbf{y})^\top(\mathbf{x} - \hat{\mathbf{x}}) \ge 0$ となる

<!--en:5a320c57-->
- **十分性：**凸関数 $\varphi$ の接線による下界より、$\varphi(\mathbf{x}) \ge \varphi(\hat{\mathbf{x}}) + (\hat{\mathbf{x}} - \mathbf{y})^\top(\mathbf{x} - \hat{\mathbf{x}}) \ge \varphi(\hat{\mathbf{x}})$ が成り立つ

<!--en:19d25f80-->
::: {.slide title="射影の非拡大性の証明"}

<!--en:ffb1cc92-3-->
[射影]{.kicker}

<!--en:eafd7bae-->
2 点を閉凸集合 $C$ へ射影しても、両者のユークリッド距離が増えることはない。

<!--en:ba347460-->
- **3 行の証明：**鈍角不等式 $(\mathbf{x} - \mathbf{u})^\top(\mathbf{v} - \mathbf{u}) \le 0$ と $(\mathbf{y} - \mathbf{v})^\top(\mathbf{u} - \mathbf{v}) \le 0$（ただし $\mathbf{u} = \Pi_C(\mathbf{x}), \mathbf{v} = \Pi_C(\mathbf{y})$）を足し合わせて $\|\mathbf{u} - \mathbf{v}\|_2^2 \le (\mathbf{x} - \mathbf{y})^\top(\mathbf{u} - \mathbf{v})$ を得て、コーシー・シュワルツの不等式を適用する

<!--en:f7328b02-->
::: {.slide title="射影勾配降下法と不動点"}

<!--en:a5da397f-->
[射影勾配降下法]{.kicker}

<!--en:9457b46a-->
**射影勾配降下法（PGD）**は、勾配ステップと $C$ へのユークリッド射影を交互に繰り返す。

<!--en:aadb6a96-->
- **不動点による判定条件：**$\mathbf{x}^\star = \Pi_C(\mathbf{x}^\star - \eta\nabla f(\mathbf{x}^\star))$ が成り立つ必要十分条件は、$\nabla f(\mathbf{x}^\star)^\top(\mathbf{x} - \mathbf{x}^\star) \ge 0$ がすべての $\mathbf{x} \in C$ で成り立つことである（実行可能な降下方向が存在せず、$f$ が凸ならば大域的最適点）

<!--en:618d29f5-->
::: {.slide title="なぜ PGD は制約なし GD と同じ速さで縮小するのか"}

<!--en:a5da397f-2-->
[射影勾配降下法]{.kicker}

<!--en:407b2fae-->
勾配更新のたびに射影ステップを挟むと収束は遅くなるだろうか。$\mu$ 強凸かつ $L$ 滑らかな関数（$\mu\mathbf{I} \preceq \nabla^2 f(\mathbf{x}) \preceq L\mathbf{I}$）上では、非拡大性により、制約なし勾配降下法と*まったく同じ*最悪ケース縮小率 $\rho = \max(|1 - \eta\mu|, |1 - \eta L|)$ が保証される。

<!--en:8502c261-->
- **ステップ 1（$\mathbf{x}^\star$ を不動点として書く）：**$\mathbf{x}^\star = \Pi_C\big(\mathbf{x}^\star - \eta\nabla f(\mathbf{x}^\star)\big)$

<!--en:4e5e3f43-->
- **ステップ 2（非拡大性により $\Pi_C$ を外す）：**
  $$\|\mathbf{x}_{k+1} - \mathbf{x}^\star\| = \big\|\Pi_C(\mathbf{x}_k - \eta\nabla f(\mathbf{x}_k)) - \Pi_C(\mathbf{x}^\star - \eta\nabla f(\mathbf{x}^\star))\big\| \le \big\|(\mathbf{x}_k - \mathbf{x}^\star) - \eta\big(\nabla f(\mathbf{x}_k) - \nabla f(\mathbf{x}^\star)\big)\big\|$$

<!--en:52b8d0d8-->
- **ステップ 3（微分積分学の基本定理を適用する）：**$\bar{\mathbf{H}} = \int_0^1 \nabla^2 f(\mathbf{x}^\star + t(\mathbf{x}_k - \mathbf{x}^\star))\,dt$（$\mu\mathbf{I} \preceq \bar{\mathbf{H}} \preceq L\mathbf{I}$）とおくと
  $$\|\mathbf{x}_{k+1} - \mathbf{x}^\star\| \le \big\|(\mathbf{I} - \eta\bar{\mathbf{H}})(\mathbf{x}_k - \mathbf{x}^\star)\big\| \le \max\big(|1 - \eta\mu|,\, |1 - \eta L|\big)\,\|\mathbf{x}_k - \mathbf{x}^\star\|$$

<!--en:09fb2a26-->
::: {.slide title="κ = 1000 の谷における 2 段階の PGD ダイナミクス"}

<!--en:a5da397f-3-->
[射影勾配降下法]{.kicker}

<!--en:f3d08a2a-->
$f(\mathbf{x}) = \tfrac12(x_1^2 + 1000\,x_2^2)$ を半空間 $x_1 + x_2 \ge 1$（$\mathbf{x}^\star = (\frac{1000}{1001}, \frac{1}{1001})$、$\lambda^\star = \frac{1000}{1001}$）上で、$\eta = 1.5 \times 10^{-3}$ の PGD により初期点 $(3, 4)$ から最小化する。

<!--en:b2b5a5ad-->
- **なぜ $738$ ステップで済み $10{,}200$ ステップかからないのか：**射影された最初のステップのあと、反復点はステップ $732$ まで内部を遅いレート $1 - \eta = 0.9985$ でドリフトする。直線 $x_1 + x_2 = 1$ の境界にステップ $733$ で到達すると、直線上に制限された二次関数は曲率 $500.5$ を持ち、毎ステップ $1 - 500.5\eta = 0.249$ で縮小する

<!--en:8745beec-->
::: {.slide title="確率単体への射影（Sparsemax）"}

<!--en:8ffaa442-->
[単体射影]{.kicker}

<!--en:80f6d60d-->
スコアベクトル $\mathbf{y} \in \mathbb{R}^n$ を確率単体 $\Delta = \{\mathbf{x} \succeq \mathbf{0} : \mathbf{1}^\top\mathbf{x} = 1\}$ へ射影するには、$\min_{\mathbf{x} \in \Delta}\tfrac12\|\mathbf{x} - \mathbf{y}\|^2$ を解く。

<!--en:538d112d-->
- **KKT 停留性と相補性：**乗数 $\tau$（制約 $\sum_i x_i = 1$）と $\lambda_i \ge 0$（制約 $-x_i \le 0$）を用いると、停留性 $x_i - y_i + \tau - \lambda_i = 0$ と $\lambda_i x_i = 0$ は $x_i^\star = \max(y_i - \tau,\, 0)$ に帰着し、$\tau$ は和が 1 の制約から一意に定まる
  $$\sum_{i=1}^n \max(y_i - \tau,\, 0) = 1$$

<!--en:b39abe67-->
- **厳密な $O(n\log n)$ のソート・閾値法：**$u_1 \ge \cdots \ge u_n$ とソートし、$\tau_k = \frac{1}{k}\big(\sum_{j=1}^k u_j - 1\big)$ を計算して、最大の $k$（$u_k > \tau_k$ を満たすもの）を選ぶ

<!--en:b3b793df-->
::: {.slide title="頂点テストによる単体射影の検証"}

<!--en:8ffaa442-2-->
[単体射影]{.kicker}

<!--en:9338f552-->
$x_i(\tau) = \max(y_i - \tau, 0)$ と $\lambda_i(\tau) = \max(0, \tau - y_i)$ は*すべての*スカラー $\tau$ に対して停留性・双対実行可能性・相補性条件を満たすため、これら 3 つの KKT 残差だけを調べても誤った $\tau$ を見抜けない。

<!--en:a3bd6bd8-->
- 和が 1 の制約 $\sum_i x_i = 1$、および $n$ 個の単体の頂点 $\mathbf{e}_i$ で判定する鈍角証明書 $\max_{1 \le i \le n}(\mathbf{y} - \mathbf{x}^\star)^\top(\mathbf{e}_i - \mathbf{x}^\star) \le 0$ だけが、$\mathbf{x}^\star = \Pi_\Delta(\mathbf{y})$ を保証する

<!--en:a7174e79-->
::: {.slide title="なぜ劣勾配降下法はスパース性を生み出せないのか"}

<!--en:f48e9910-->
[近接作用素]{.kicker}

<!--en:b9c976c0-->
**Lasso** は $F(\mathbf{w}) = \tfrac12\|\mathbf{A}\mathbf{w} - \mathbf{b}\|_2^2 + \lambda\|\mathbf{w}\|_1$（$\mathbf{A} \in \mathbb{R}^{100 \times 8}$、真のゼロ重み $5$ 個、$\lambda = 3$）を最小化する。劣勾配降下法 $\mathbf{w}_{k+1} = \mathbf{w}_k - \eta\big(\mathbf{A}^\top(\mathbf{A}\mathbf{w}_k - \mathbf{b}) + \lambda\,\mathrm{sign}(\mathbf{w}_k)\big)$ を $\eta = 1/L$ で実行すると何が起きるか。

<!--en:a33a045c-->
**なぜ劣勾配ステップはゼロをまたいで振動するのか：**真の値がゼロの座標では滑らかな項の勾配の大きさが $< \lambda$ であるため、劣勾配のキック $\pm\eta\lambda$ がそれを上回ってほぼ毎ステップ座標の符号を反転させ、厳密なゼロは $0$ 個に終わる。

<!--en:f53f0da1-->
::: {.slide title="ソフト閾値処理と近接作用素"}

<!--en:f48e9910-2-->
[近接作用素]{.kicker}

<!--en:d30e774d-->
**近接作用素**は、非平滑な凸ペナルティ $\psi(\mathbf{x})$ と $\mathbf{z}$ への二次の引き戻し項との和を最小化する。

<!--en:ea1bbf69-->
- **1 次元ソフト閾値処理（$\psi(x) = \lambda|x|$）：**フェルマーの規則 $0 \in \lambda\partial|x| + (x - z)$ より $\mathrm{prox}_{\lambda|\cdot|}(z) = \mathrm{sign}(z)\max(|z| - \lambda, 0)$ となり、厳密なゼロとなる**不感帯**を $|z| \le \lambda$ に持つ

<!--en:e65d17ab-->
::: {.slide title="近接勾配降下法（ISTA）による厳密なゼロの復元"}

<!--en:f48e9910-3-->
[近接作用素]{.kicker}

<!--en:e94d170e-->
合成目的関数 $F(\mathbf{w}) = s(\mathbf{w}) + \psi(\mathbf{w})$（$s$ は凸かつ $L$ 滑らか、$\psi$ は真閉凸）に対し、**近接勾配降下法**は $L$ 滑らかさによる $s$ の二次上界と*厳密な*ペナルティ $\psi$ の和を最小化する。

<!--en:1e49517a-->
- $\psi(\mathbf{w}) = \lambda\|\mathbf{w}\|_1$ のとき、この更新は **ISTA**（Iterative Shrinkage-Thresholding Algorithm）となり、その不感帯 $[-\eta\lambda, \eta\lambda]$ が劣勾配降下法の振動振幅をちょうど吸収して $5$ 個の真のゼロすべてをきれいに復元する

<!--en:32fc2098-->
::: {.slide title="Lasso に対する巡回座標降下法"}

<!--en:07d2c9a4-->
[座標降下法]{.kicker}

<!--en:81f2c977-->
$\|\mathbf{w}\|_1 = \sum_{j=1}^d |w_j|$ は座標ごとに分離するため、Lasso を単一の重み $w_j$ に沿って最小化する問題（部分残差 $\mathbf{r}_{-j} = \mathbf{b} - \sum_{i \neq j}\mathbf{a}_i w_i$、相関 $c_j = \mathbf{a}_j^\top\mathbf{r}_{-j}$）は厳密な閉形式を持つ。

<!--en:a4b62c49-->
- **なぜ座標スイープは ISTA に勝るのか：**各座標ステップは単一列の曲率 $L_j = \|\mathbf{a}_j\|_2^2 \approx 100$ を用い、大域的な固有値の上限 $L = \lambda_{\max}(\mathbf{A}^\top\mathbf{A}) \approx 160$ に縛られないため、$10^{-8}$ に $4$〜$6$ パスで到達する（ISTA は $12$〜$25$ パス）

<!--en:6e44ef82-->
::: {.slide title="理解度チェック：KKT、単体射影、近接作用素"}

<!--en:26a317d8-->
[理解度チェック]{.kicker}

<!--en:e713842f-->
KKT 条件と近接作用素の規則を使って、次の 3 つの計算を行え。

<!--en:1b806048-->
1. $\mathbf{y}_1 = (1.5, 2.0)$ と $\mathbf{y}_2 = (0.3, 0.4)$ を単位円板 $g(\mathbf{x}) = \tfrac12(\|\mathbf{x}\|_2^2 - 1) \le 0$ へ射影する。それぞれの最適点 $\mathbf{x}^\star$ と KKT 乗数 $\lambda^\star$ は何か。

<!--en:9426e669-->
2. スコアベクトル $\mathbf{y} = (0.9, 0.5, -0.2)$ を確率単体 $\Delta$ へ射影する。生き残る座標数（$k$）、閾値 $\tau$、および $\Pi_\Delta(\mathbf{y})$ は何か。

<!--en:66611403-->
3. ソフト閾値作用素 $\mathrm{prox}_{\lambda|\cdot|}(z)$（$\lambda = 0.7$）を $z = 0.5$ および $z = -2.0$ で評価せよ。

<!--en:59d4060d-->
**解答：** **(1)** $\|\mathbf{y}_1\|_2 = 2.5 > 1$（有効）：$\lambda^\star = 2.5 - 1 = \mathbf{1.5}$、$\mathbf{x}^\star = \mathbf{y}_1 / 2.5 = \mathbf{(0.6, 0.8)}$。$\|\mathbf{y}_2\|_2 = 0.5 < 1$（非有効）：$\lambda^\star = \mathbf{0}$、$\mathbf{x}^\star = \mathbf{(0.3, 0.4)}$。**(2)** 閾値の候補 $\tau_k = (\sum_{j \le k} y_j - 1)/k$：$\tau_1 = -0.1 < 0.9$（適）、$\tau_2 = (1.4 - 1)/2 = 0.2 < 0.5$（適）、$\tau_3 = 0.2/3 \approx 0.067 \not< -0.2$（不適）。よって $k = 2$、$\tau = \mathbf{0.2}$、$\Pi_\Delta(\mathbf{y}) = \mathbf{(0.7, 0.3, 0.0)}$。**(3)** $z = 0.5$ では $|0.5| \le 0.7$ が不感帯に入るため $\mathrm{prox}_{0.7|\cdot|}(0.5) = \mathbf{0}$。$z = -2.0$ では $\mathrm{prox}_{0.7|\cdot|}(-2.0) = -(2.0 - 0.7) = \mathbf{-1.3}$。

<!--en:c5a222f8-->
[要点]{.kicker}

<!--en:fc612d2e-->
| 問題・手法 | 数学的条件・更新式 | 最適性・収束率の保証 | 深層学習・機械学習での役割 |

<!--en:f2b24e1f-->
| **等式ラグランジュ** | $\nabla f(\mathbf{x}^\star) + \sum_j \nu_j^\star \nabla h_j(\mathbf{x}^\star) = \mathbf{0}$、$h_j = 0$ | LICQ のもとで必要条件、$\nu_j^\star = -\partial p^\star/\partial b_j$ | 超平面への射影、正規化制約 |

<!--en:5747d380-->
| **不等式 KKT** | 停留性、主・双対実行可能性（$\lambda_i^\star \ge 0$）、$\lambda_i^\star g_i(\mathbf{x}^\star) = 0$ | 凸問題で十分条件、スレーター条件のもとで必要条件 | 勾配クリッピング、SVM、ノルムバジェット正則化 |

<!--en:82ba748b-->
| **ユークリッド射影 $\Pi_C$** | $(\mathbf{y} - \Pi_C(\mathbf{y}))^\top(\mathbf{x} - \Pi_C(\mathbf{y})) \le 0\;\forall\mathbf{x}\in C$ | 一意かつ非拡大（$\|\Pi_C(\mathbf{x}) - \Pi_C(\mathbf{y})\| \le \|\mathbf{x}-\mathbf{y}\|$） | PGD $\mathbf{x}_{k+1} = \Pi_C(\mathbf{x}_k - \eta\nabla f(\mathbf{x}_k))$ は少なくとも GD と同じ速さで縮小（同じ $\rho$） |

<!--en:950ef665-->
| **単体射影** | $x_i^\star = \max(y_i - \tau, 0)$、$\sum_i x_i^\star = 1$ | 厳密な $O(n\log n)$ のソート・閾値法 | 厳密なゼロ成分を持つ `sparsemax` アテンション重み |

<!--en:4db68f42-->
| **近接勾配法（ISTA）** | $\mathbf{w}_{k+1} = \mathrm{prox}_{\eta\psi}(\mathbf{w}_k - \eta\nabla s(\mathbf{w}_k))$ | 凸で $O(1/k)$、強凸で線形収束 $(1-\mu/L)^k$ | ソフト閾値処理 $\mathrm{prox}_{\lambda\|\cdot\|_1}$ が厳密な重みのスパース性を生成 |
