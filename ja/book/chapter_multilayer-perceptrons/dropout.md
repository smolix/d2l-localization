# ドロップアウト

<!--en:a0b2a3fa-->
過剰パラメータ化されたネットワークを希少なデータやノイズの多いデータで何エポックも訓練すると、やがて訓練データ特有の癖や破損したラベルまで暗記してしまう（:numref:`sec_generalization_deep`）。重み減衰（weight decay、:numref:`sec_weight_decay`）が大きな重みにペナルティを課し、早期停止（early stopping、:numref:`subsec_early_stopping`）が終盤の暗記が始まる前に訓練を打ち切るのに対し、*ドロップアウト*は訓練中に乗法的なノイズを隠れ層へ直接注入することでネットワークを正則化する :cite:`Hinton.Srivastava.Krizhevsky.ea.2012,Srivastava.Hinton.Krizhevsky.ea.2014`。すなわち、各順伝播において各隠れユニット（hidden unit）をそれぞれ独立に確率 $p$ でゼロにすることで、特定のパートナーユニットに頼る*共適応*（co-adaptation）を起こさず、どのユニットにも単独で確実に機能する特徴を学習させる。テスト時にはドロップアウトを無効にし、ネットワーク全体を決定論的に動作させる。

<!--en:5efc8186-->
本節では、逆ドロップアウト（inverted dropout）におけるマスク処理と再スケーリングを定式化し、Fashion-MNIST 上で隠れ層を 2 つ持つ MLP にゼロからの実装と簡潔な実装の両方を施す。さらに、ラベルを大幅に破損させたラベルノイズ実験を通じて、ドロップアウトがいかに暗記を遅らせ、検証正解率の低下をどれだけ食い止めるかを実証する。

<!--en:4d7e7e87-->
## 隠れ層におけるノイズ

<!--en:0f0f89be-->
### マスク処理と再スケーリング（逆ドロップアウト）

<!--en:45a6bf3d-->
訓練中に入力へランダムなノイズを注入すると、摂動に強く滑らかな関数が学習されやすくなる :cite:`Bishop.1995`。実際、二乗誤差（squared error）のもとでの線形モデル $\mathbf{w}^\top\mathbf{x} + b$ において、入力に平均 0・分散 $s^2$ の独立なノイズを加えると、期待損失には $s^2\|\mathbf{w}\|_2^2$ が加算される。これは $\ell_2$ 重み減衰にほかならない。ドロップアウトは、ランダムな二値マスクによってこのノイズ注入を隠れ層へと拡張する。

<!--en:975cc0ee-->
隠れ層の活性化値（activation）$h_j$ と*ドロップアウト確率* $p \in [0, 1)$ に対し、各訓練ステップで独立なベルヌーイマスク $\xi_j \in \{0, 1\}$（$P(\xi_j = 0) = p$、$P(\xi_j = 1) = 1 - p$）をサンプリングし、$h_j$ を次の式で置き換える。

<!--en:c01ee068-->
訓練中に生き残った活性化値を $1 - p$ で割ること（*逆ドロップアウト*）により、期待値は不偏に保たれる。

<!--en:0d43bfcb-->
訓練中に $\mathbb{E}[h_j'] = h_j$ が保たれるため、**推論時には重みの再スケーリングを一切せず、単にドロップアウトをオフにする（$h_j' = h_j$）だけでよい**。（なお、入力ドロップアウトを伴う線形回帰（linear regression）モデルでは、分散の式 $\mathrm{Var}[x_j'] = \frac{p}{1-p}x_j^2$ により、二乗損失（squared loss）に適応的なリッジペナルティ $\mathbb{E}[(\mathbf{w}^\top\mathbf{x}' + b - y)^2] = (\mathbf{w}^\top\mathbf{x} + b - y)^2 + \frac{p}{1-p}\sum_j x_j^2 w_j^2$ が加わる。一方、深い非線形ネットワークでは $\mathbb{E}[\mathrm{ReLU}(z)] \neq \mathrm{ReLU}(\mathbb{E}[z])$ であるため、テスト時の決定論的なネットワークは、間引かれた $2^h$ 個のサブネットワークからなるアンサンブルに対する実用的な近似となっている。演習問題 :exref:`ex_dropout-monte-carlo-dropout` および :exref:`ex_dropout-geometric-mean` を参照。）

<!--en:50c31334-->
## 実装

<!--en:3a469f20-->
### ドロップアウト層

<!--en:86fe8cc3-->
ゼロから実装する `dropout_layer(X, dropout)` は、区間 $[0, 1)$ の一様分布からテンソルをサンプリングし、値が $\geq$ `dropout` である要素を残して `1.0 - dropout` で割る（ただし `dropout == 1` のときはゼロのテンソルを返す）。

<!--en:fef4737c-->
`dropout_layer` を $2 \times 8$ のテンソルに対し、ドロップアウト確率 $0$、$0.5$、$1$ でテストしてみよう。また、100 万個の 1 からなるベクトルに $p = 0.2$ を適用し、標本平均と標本分散が理論値である $1$ および $p/(1 - p) = 0.25$ と一致することを確かめる。

<!--en:d4963cb5-->
### モデルのゼロからの定義と訓練

<!--en:2d29f689-->
各隠れ層の出力に対し、ReLU 活性化の直後にドロップアウトを適用する（:numref:`fig_dropout2`）。ただし、有効にするのは訓練中*のみ*である。以下では、He 初期化（He initialization）を施した隠れ層 2 層の分類器 `DropoutMLPScratch`（$784 \to 256 \to 256 \to 10$）を、層ごとに独立したドロップアウト確率 `dropout_1` と `dropout_2` を持たせて定義する。

<!--en:b5317627-->
![ドロップアウトは各訓練ステップにおいて、隠れユニットのランダムな部分集合（図では $h_2$ と $h_5$）およびそれらに接続する結合を無効化する。](../img/dropout2.svg)

<!--en:0cb00fbd-->
各層は `autograd.is_training()` を判定する。この関数は `autograd.record()` の内部でのみ真となる。

<!--en:ae0b4b2d-->
各層は `self.training` を判定する。トレーナの `model.eval()` はこれを `False` に設定する。

<!--en:04c950dd-->
各層は `self.training` を判定する。これは `Module.call` が、Keras から渡される `training` 引数をもとに設定する。

<!--en:ff8410a7-->
各層は `self.deterministic` を判定する。トレーナの評価用ビューはこれを `True` に設定する。

<!--en:a63aea76-->
ここで `DropoutMLPScratch` を、第 1 隠れ層の後に `dropout_1 = 0.2`、第 2 隠れ層の後に `dropout_2 = 0.5`、学習率（learning rate）に `lr = 0.1` を指定してインスタンス化し（後で再利用するためハイパーパラメータは `hparams` にまとめておく）、Fashion-MNIST 上で $20$ エポック訓練する。

<!--en:c0d81a71-->
最初の数エポックでは、訓練損失（training loss）が検証損失（validation loss）よりも*上*に位置していることがわかる。これは、訓練損失がノイズを伴うドロップアウトマスクを有効にした状態で評価されるのに対し、検証損失は決定論的なネットワーク全体を使って計算されるためである。

<!--en:41f09a2d-->
### 簡潔な実装

<!--en:8ff0824f-->
フレームワークのドロップアウト層 `Dropout` を `Sequential` の内部で用いれば、まったく同じ隠れ層 2 層のアーキテクチャを数行で記述できる。

## ラベルノイズ下におけるドロップアウトの効果

<!--en:f05f1e41-->
$60{,}000$ 枚の画像すべてを含む Fashion-MNIST データセット全体で 20 エポック訓練する程度では、正則化なしの MLP でもほとんど過学習（overfitting）しないため、ドロップアウトが真価を発揮する余地は小さい。深刻な暗記にドロップアウトがどう対抗するかを観察するため、:numref:`subsec_early_stopping` で用いた $1{,}000$ 枚の画像からなるラベルノイズ付きベンチマークに立ち返り、`d2l.corrupt` によって訓練ラベルの $40\%$ をランダムに破損させる（誤ラベルは全体の $\sim 36\%$ となり、ブールマスク `wrong = labels != y` で参照する）。

<!--en:f0109cff-->
ここで `DropoutMLP` を $200$ エポックにわたり `(X, labels)` 上で訓練し、両方の隠れ層のドロップアウト確率を `p = 0`（ドロップアウトなし）とした場合と `p = 0.5` とした場合を比較する。その際、`d2l.Tracker` を用いて、破損した訓練サブセット `X[wrong]` に対する正解率（accuracy）と、ホールドアウトされた `X_val` に対する検証正解率を記録する。

<!--en:ede111f2-->
2 つの軌跡を見てみよう。

<!--en:97b673e3-->
- **ドロップアウトなし（$p = 0$）：**100 エポック目までに MLP は破損した訓練ラベルを $100\%$ 暗記してしまい、検証正解率は序盤のピークから $\sim 10$ パーセントポイント低下する。

<!--en:47caeb0e-->
- **ドロップアウトあり（$p = 0.5$）：**誤ラベルの暗記が減速する。200 エポック目でも MLP が再現する誤ラベルはすべてではなく約 $70$〜$85\%$ にとどまり、最後の 10 エポックにおける検証正解率は正則化なしのネットワークより **3〜6 パーセントポイント高い**。もっとも、誤ラベルの正解率曲線はなお上昇を続けている。すなわち、ドロップアウトは悪影響を取り除くのではなく遅らせる手法であり、だからこそ早期停止と組み合わせて使われるのである。

<!--en:51962aae-->
実務上、ドロップアウトが最も威力を発揮するのは、パラメータ数（parameter count）がデータセットのサイズを圧倒的に上回り、かつ何エポックにもわたって訓練する場合である（:numref:`sec_alexnet` の AlexNet のような 2010 年代初頭の画像分類器がその典型である）。一方、データを 1 周のみ処理する基盤モデルの事前学習（pretraining）や、バッチ正規化（batch normalization）層の直前（:numref:`sec_batch_norm`、訓練時にドロップアウトが分散を $1/(1-p)$ 倍に膨張させることで訓練時とテスト時の間に分散のずれが生じる :cite:`Li.Chen.Hu.ea.2019`）では、通常ドロップアウトを弱めるか省略する。

<!--en:30ac03ff-->
## まとめ

<!--en:a75b41b0-->
逆ドロップアウトは、訓練中に各隠れ層の活性化値をそれぞれ独立に確率 $p$ でゼロにし、生き残った活性化値を $1/(1 - p)$ 倍に再スケーリングする。この再スケーリングは $\mathbb{E}[h_j'] = h_j$ を保ちつつ分散 $\frac{p}{1 - p}h_j^2$ を注入するため、テスト時には重みの再スケーリングを一切せずにマスクなしのネットワーク全体を決定論的に動作させられる。パラメータ数がサンプル数を大きく上回る小規模なデータセットやノイズの多いデータセットでは、ドロップアウトによって隠れユニット間の脆い共適応が抑えられ、破損したラベルの暗記が遅くなり、ホールドアウト正解率が数パーセントポイント向上する。ただし、ドロップアウトは最終的な暗記を防ぐのではなく遅らせるものであるため、早期停止や重み減衰と併用するときに最も効果を発揮する。

<!--en:3505f5e8-->
1. **テスト時のドロップアウト。** ● `dropout_1` を 0 に設定して第 2 隠れ層のみがマスクされるようにし、$\boldsymbol{\xi}$ がそのマスク全体を動くとする。$\mathbf{o}(\boldsymbol{\xi})$ と $\hat{\mathbf{y}}(\boldsymbol{\xi})$ を、マスク $\boldsymbol{\xi}$（確率 $P(\boldsymbol{\xi})$ で生じる）のもとでのロジットおよびソフトマックス出力とする。ネットワーク全体のロジットが $\sum_{\boldsymbol{\xi}} P(\boldsymbol{\xi})\, \mathbf{o}(\boldsymbol{\xi})$ に等しいことを示せ。さらに、そのソフトマックス出力が次の正規化された重み付き幾何平均に等しいことを示せ。

    $$\tilde{y}_j = \frac{\prod_{\boldsymbol{\xi}} \hat{y}_j(\boldsymbol{\xi})^{P(\boldsymbol{\xi})}}{\sum_k \prod_{\boldsymbol{\xi}} \hat{y}_k(\boldsymbol{\xi})^{P(\boldsymbol{\xi})}}.$$

    また、`dropout_1` が非ゼロになると、いずれの等式も一般には成り立たない理由を説明せよ。

<!--en:c85aadba-->
::: {.slide title="なぜ隠れユニットにランダムなノイズを注入するのか？"}

<!--en:fe8bdd90-->
[動機と共適応]{.kicker}

<!--en:17115cf4-->
- **相補的な 3 つの正則化手法：**重み減衰は大きな重みノルム $\|\mathbf{W}\|_{\textrm{F}}^2$ にペナルティを課し、早期停止は終盤のノイズ暗記が始まる前に訓練を止め、**ドロップアウト**（Srivastava et al., 2014）は各訓練ステップで各隠れユニットを確率 $p$ でランダムにゼロにする

<!--en:d367b0d1-->
- **隠れユニットの共適応の防止：**ユニットが常に同時に存在すると、複数のニューロンが結託して個別の訓練誤差を埋め合わせかねない。ランダムなマスク処理により、ランダムなパートナーの部分集合と組んでも有用な特徴を各ユニットに抽出させる

<!--en:a48c14f4-->
::: {.slide title="ウォームアップ：入力ノイズと L2 重み減衰の等価性"}

<!--en:677b1197-->
[正則化としてのノイズ]{.kicker}

<!--en:a4dc89de-->
- **Bishop の等価性（1995）：**入力を平均 0 のノイズ $\boldsymbol{\epsilon}$（分散 $s^2$）で摂動させると、交差項はゼロになり（$\mathbb{E}[\boldsymbol{\epsilon}] = \mathbf{0}$）、厳密な $\ell_2$ リッジペナルティ $s^2\|\mathbf{w}\|_2^2$ が加わる

<!--en:9b65913a-->
- **加法的ノイズから乗法的ノイズへ：**ドロップアウトはノイズ注入を、すべての隠れ層にわたる二値の乗法的なマスク処理へと拡張する

<!--en:1d5a6fda-->
::: {.slide title="逆ドロップアウト：マスク処理と 1/(1 − p) による再スケーリング"}

<!--en:6f14e397-->
[数学的定式化]{.kicker}

<!--en:feb83ec5-->
- **不偏な訓練時の期待値（$\mathbb{E}[h_j'] = h_j$）：**訓練中に生き残ったユニットを $1 - p$ で割ることで $\mathbb{E}[h_j'] = p \cdot 0 + (1 - p)\frac{h_j}{1 - p} = h_j$ が成り立つ

<!--en:c8f9ea6a-->
- **テスト時のオーバーヘッドはゼロ：**推論時には重みの再スケーリングは不要で、単にドロップアウトを無効にする（$h_j' = h_j$）

<!--en:d6d78254-->
::: {.slide title="逆ドロップアウトによる分散の膨張"}

<!--en:e608a2ca-->
[二次モーメントのスケーリング]{.kicker}

<!--en:79b09a6e-->
- **乗法的ノイズのスケール：**$p = 0.5$ では生き残ったユニットが 2 倍（$2\times$）になり、注入される標準偏差は $100\%$（すなわち $|h_j|$）となる。$p = 0.8$ では生き残ったユニットが $5\times$ にスケールされる（$\textrm{std} = 2|h_j|$）

<!--en:3a4d2ed7-->
- **二次モーメントのずれ：**訓練時に $\mathbb{E}[(h_j')^2]$ が $\frac{1}{1-p}$ 倍に膨張するため、BatchNorm の直前にドロップアウトを置くと訓練時と推論時の間で移動分散にずれが生じる

<!--en:2ab8cadc-->
::: {.slide title="適応的リッジペナルティと非線形なテスト時の不一致"}

<!--en:9e4ccb43-->
[線形での厳密性と ReLU での近似]{.kicker}

<!--en:ec10d4d7-->
テスト時の決定論的なネットワーク（$h_j' = h_j$）は、訓練中にサンプリングされる $2^h$ 個のランダムなサブネットワークとどのような関係にあるか。

<!--en:2c5c5429-->
**1. 線形層における厳密な適応的リッジペナルティ：**

<!--en:e6075348-->
- 各重み $w_j^2$ に対し、特徴量のエネルギー $x_j^2$ に比例したペナルティを課す（頻出する特徴量ほど強く正則化される）

<!--en:e19a6e3b-->
**2. 非線形性による期待値の不一致（$\mathbb{E}[\mathrm{ReLU}(z)] \neq \mathrm{ReLU}(\mathbb{E}[z])$）：**

<!--en:487e66ce-->
| $(h_1', h_2')$（$p = 0.5$ 時） | $(0, 0)$ | $(2, 0)$ | $(0, 2)$ | $(2, 2)$ |

<!--en:f2de7e52-->
| 活性化前の値 $z = h_1' - h_2'$ | $0$ | $+2$ | $-2$ | $0$ |

<!--en:75365b9c-->
- 間引かれた ReLU の平均は $\mathbb{E}[\mathrm{ReLU}(z)] = 0.5$ である一方、決定論的なテスト時のネットワークは $\mathrm{ReLU}(\mathbb{E}[z]) = \mathrm{ReLU}(0) = 0$ を出力する

<!--en:552dc9c0-->
::: {.slide title="3 行のコードによる逆ドロップアウトの実装"}

<!--en:e0151bb4-->
[ゼロからの層実装]{.kicker}

<!--en:9cfc761a-->
`dropout_layer(X, dropout)` は区間 $[0, 1)$ の一様乱数を生成し、値が $\ge p$ の要素を残して $1 / (1 - p)$ 倍に再スケーリングする。

<!--en:fedcb087-->
::: {.slide title="多層 MLP におけるドロップアウトの配置"}

<!--en:beee0837-->
[アーキテクチャとモード切り替え]{.kicker}

<!--en:75453b18-->
各隠れ層の ReLU 活性化の直後にドロップアウトを挿入する。**訓練中のみ**有効にし、検証・推論時にはバイパスする。

<!--en:f920b335-->
- **Fashion-MNIST 用の隠れ層 2 層の MLP：**$784 \to 256 \to 256 \to 10$（パラメータ数 $269{,}322$、He 初期化）

<!--en:4ee54bf3-->
- **層ごとのドロップアウト設定：**入力付近では元の特徴量信号を保つため弱め（`dropout_1 = 0.2`）にし、共適応のリスクが最も高い深い層では強め（`dropout_2 = 0.5`）にする

<!--en:3d66c908-->
- **逆伝播も自動的にマスク処理：**$h_j' = \frac{\xi_j}{1 - p}h_j$ であるため、自動微分はドロップされたユニットを通る勾配に $0$ を、生き残ったユニットを通る勾配に $\frac{1}{1 - p}$ を掛ける

<!--en:dc3fb122-->
::: {.slide title="DropoutMLPScratch の定義と訓練"}

<!--en:f6f46dbb-->
[ゼロからのモデル実装]{.kicker}

<!--en:9676c0e6-->
`DropoutMLPScratch` では、各 `dropout_layer` の呼び出しをフレームワークの訓練モードフラグで制御する。

<!--en:b32bb124-->
::: {.slide title="Fashion-MNIST 全体での 20 エポックの訓練曲線"}

<!--en:0b6411a5-->
[全データセットでのベンチマーク]{.kicker}

<!--en:af67f020-->
`DropoutMLPScratch` を $20$ エポックにわたり全 $60{,}000$ 枚の画像で訓練すると、検証正解率は $\sim 87\%$ に達する。

<!--en:0523388a-->
- **序盤に訓練損失が検証損失より*上*になる理由：**`train_loss` はノイズのある間引かれたネットワーク（$p_1 = 0.2, p_2 = 0.5$）で評価されるのに対し、`val_loss` はマスクなしのクリーンなアンサンブル近似を用いるため

<!--en:a6022661-->
- **クリーンな $60{,}000$ 枚の画像では過学習はわずか：**$20$ エポックでは正則化なしの MLP でもデータセット全体にほとんど過学習しない。ドロップアウトの真価を見るため、次にラベルノイズ下で検証する

<!--en:5262f50c-->
::: {.slide title="フレームワークのドロップアウト層による簡潔な実装"}

<!--en:05952cca-->
[高水準 API]{.kicker}

<!--en:2d4e70db-->
フレームワークの `Sequential` コンテナでは `Dropout(p)` モジュールを各 `ReLU` の後に挟み込み、`train` モードと `eval` モードに応じたマスクの切り替えを `Trainer` の内部で自動化する。

<!--en:0933aeea-->
::: {.slide title="40% のラベル破損下における暗記の抑制"}

<!--en:9c425cb9-->
[ラベルノイズによるストレステスト]{.kicker}

<!--en:b5b23e5d-->
$1{,}000$ 枚の画像からなるベンチマークでラベルの $40\%$ を引き直し（誤ラベル $\sim 36\%$）、`DropoutMLP` を $200$ エポックにわたり $p = 0$ と $p = 0.5$ で訓練する。

<!--en:ec5ac706-->
- **ドロップアウトなし（$p = 0$、青）：**誤ラベルの $100\%$ を 100 エポック目までに暗記し（`C0--`）、検証正解率（`C0-`）を序盤のピークから $\sim 10$ ポイント引き下げる

<!--en:fdefe227-->
- **ドロップアウトあり（$p = 0.5$、オレンジ）：**誤ラベルの暗記を遅らせ（`C1--`、200 エポック目で再現率 $70$〜$85\%$、なお上昇中）、検証正解率（`C1-`）は最終的に **3〜6 パーセントポイント高い**水準に達する

<!--en:0821d58e-->
::: {.slide title="ドロップアウトの相補的な 3 つの解釈"}

<!--en:2d703e6e-->
[理論的な視点]{.kicker}

<!--en:1ef0f1c3-->
- **適応的なノイズ正則化：**乗法的な分散 $\mathrm{Var}[h_j'] = \frac{p}{1-p}h_j^2$ を注入し、エネルギーの高い特徴量の重みに $\propto \frac{p}{1-p}x_j^2 w_j^2$ のペナルティを課す

<!--en:6901205e-->
- **共適応の抑制（Hinton et al.）：**任意のユニット対が同時に残る確率は $(1 - p)^2$（$25\%$、$p = 0.5$ 時）となり、ノイズ付きラベルに対する複数ユニットの脆い結託を打破する

<!--en:0bb787ad-->
- **暗黙的なサブネットワークのアンサンブル：**間引かれた $2^h$ 個のサブネットワーク間で重みを共有する（本節の 2 層 MLP では $2^{512} \approx 10^{154}$ 通りのマスク）

<!--en:1ed0b0a3-->
::: {.slide title="ドロップアウトを使うべきとき、避けるべきとき"}

<!--en:57bd6a5d-->
[現代の実践的ガイドライン]{.kicker}

<!--en:69ef322e-->
- **小規模・ノイズの多いデータ上の全結合層（$p \in [0.2, 0.5]$）：**高い $p/n$ 比のもとで多エポック訓練すると、共適応のリスクが高まる

<!--en:e85e86fe-->
- **多エポックの Transformer（$p \approx 0.1$）対 1 エポックの LLM（$p = 0.0$）：**数兆トークンを 1 周だけ処理する事前学習では毎ステップ新しいデータを見るため、エポックを重ねることによる暗記が蓄積しない

<!--en:f5039e95-->
- **BatchNorm の直前は避ける（$p = 0.0$）：**訓練時の二次モーメントの膨張 $\frac{1}{1-p}$ により、BatchNorm の移動統計量に訓練時とテスト時の間で分散のずれが生じる（Li et al., 2019）

<!--en:b7ce1573-->
::: {.slide title="理解度チェック：逆ドロップアウト・パートナー・分散"}

<!--en:ffcb46a8-->
[確認]{.kicker}

<!--en:79ad73f0-->
ドロップアウトの数理とシステム上の挙動を確認しよう。

<!--en:847acf37-->
1. **極端なドロップアウト（$p = 0.8$）：**隠れユニットの活性化値が $h_j = 1.0$ のとき、$p = 0.8$ の逆ドロップアウトを適用すると、生き残ったユニットはどの値をとるか。また $\mathbb{E}[h_j']$ と $\mathrm{Var}[h_j']$ はいくらか。

<!--en:31170022-->
2. **パートナー間の共適応確率：**256 ユニットの隠れ層で $p = 0.5$ のとき、データ例あたり平均して何個のユニットが生き残るか。また、特定の 3 つのパートナーユニット $(j_1, j_2, j_3)$ が*すべて*同時に活性化する訓練ステップの割合はいくらか。

<!--en:f60f0533-->
3. **テスト時のドロップアウト解除忘れ：**検証時に誤ってモデルを訓練モードのままにすると、どのような症状が現れるか。

<!--en:557b98b6-->
**解答：**

<!--en:fac36778-->
1. **$p = 0.8$ のとき：**生き残ったユニットは $1 / (1 - 0.8) = 5.0$ にスケールされる（発生割合は $20\%$）。平均は $\mathbb{E}[h_j'] = 0.2 \times 5.0 = 1.0$、分散は $\mathrm{Var}[h_j'] = \frac{0.8}{0.2}(1.0)^2 = 4.0$（標準偏差は $2.0 = 2|h_j|$）となる。

<!--en:a2538629-->
2. **パートナーの生存確率：**平均して $256 \times 0.5 = 128$ 個のユニットが生き残り、任意の 3 つ組 $(j_1, j_2, j_3)$ が同時に残るのは全ステップの $(1 - 0.5)^3 = 1/8 = 12.5\%$ にすぎない。

<!--en:de046b62-->
3. **テスト時のバグ：**検証時の予測が呼び出しのたびに非決定論的になり、1 回の順伝播での正解率が低下する（ただし $T \ge 20$ 回のモンテカルロ順伝播で平均する場合を除く）。

<!--en:fdbcfd4c-->
::: {.slide title="まとめ：ドロップアウト正則化"}

<!--en:c5a222f8-->
[要点]{.kicker}

<!--en:f2929934-->
- **不偏な逆ドロップアウトマスク：**$h_j' = \frac{\xi_j h_j}{1 - p}$ は訓練中に $\mathbb{E}[h_j'] = h_j$ を保つため、テスト時のネットワークは一切スケーリングなしで動作する（$h_j' = h_j$）

<!--en:dcaa35e8-->
- **適応的な正則化：**乗法的な分散 $\mathrm{Var}[h_j'] = \frac{p}{1-p}h_j^2$ を注入し、線形層に対してエネルギーで重み付けされた $\ell_2$ ペナルティとして働く

<!--en:13511773-->
- **実証的な効果：**ラベルを $40\%$ 破損させた Fashion-MNIST（$n = 1{,}000$）において、$p = 0.5$ は誤ラベルの暗記を遅らせ、検証正解率を $3$〜$6$ パーセントポイント向上させる
