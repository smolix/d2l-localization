# 多層パーセプトロン

<!--en:e2e253a5-->
本章では、最初の*深層*ニューラルネットワークを導入する。:numref:`chap_classification` では、ソフトマックス回帰が Fashion-MNIST の衣類画像を構成する 784 ピクセルそれぞれに固定の重みを割り当ててその根拠を合計していたため、周囲に何があるかにかかわらず、すべてのピクセルがクラスに対して同じ票を投じていた。しかし、明るいピクセルは袖、ハンドバッグのストラップ、襟のいずれにも属しうるため、そのどれであるかは近傍のピクセルを見なければわからない。4 つの二値点においてさえ、単一の線形層では 2 ビットの排他的論理和（exclusive-OR、XOR）を計算できない。これは Marvin Minsky と Seymour Papert が 1969 年に、Frank Rosenblatt の単層*パーセプトロン*について指摘した限界である。

<!--en:92bec8c6-->
*多層パーセプトロン*（multilayer perceptron、MLP）は、それぞれアフィン変換と非線形な活性化関数を組み合わせた全結合の*隠れ層*（hidden layer）を出力層の前に 1 つ以上積み重ね、すべての層を*誤差逆伝播法*（backpropagation）で同時に訓練することによって、この線形の壁を乗り越える :cite:`Rumelhart.Hinton.Williams.ea.1988`。まず、なぜ線形モデルが XOR のような特徴量の相互作用を扱えないのか、隠れ層が深さに応じて入力空間をどのように指数関数的に多くの線形領域へと折り畳むのか、そして代表的な活性化関数（ReLU、GELU、シグモイド、$\tanh$）が微分においてどのように振る舞うのかを示す（:numref:`sec_mlp`）。続いて、256 ユニットの ReLU MLP を Fashion-MNIST 上でゼロから、また簡潔に実装すると（:numref:`sec_mlp-implementation`）、ソフトマックス回帰の分類誤差が約 5 分の 1 削減され（正解率 $\sim 87\%$ 対 $\sim 84\%$）、GPU でのエポック時間はほぼ同じまま、ぼやけた衣類全体のテンプレートが局所的なコントラスト検出器に置き換わる。

<!--en:774825a8-->
隠れ層を追加すると、深層学習における 3 つの根本的な問いも生じる。これらが本章の残りの節の主題である。第 1 に、:numref:`sec_backprop` では MLP を通じたリバースモード微分の 3 つの行列微分則を導出し、自動微分（automatic differentiation）と機械精度まで一致することを検証したうえで、訓練時の活性化メモリと FLOP の所要量を明らかにする。第 2 に、:numref:`sec_numerical_stability` では $K$ 個の層にわたる信号と勾配の分散を追跡し、10 層の MLP における勾配消失と勾配爆発を防ぐ *Xavier* 初期化と *He* 初期化を導出するとともに、隠れユニットの対称性を破るためになぜランダムな重みが必要なのかを示す。第 3 に、:numref:`sec_generalization_deep` と :numref:`sec_dropout` では、大幅に過剰パラメータ化されたネットワークがなぜ汎化（generalization）するのかを検討し、ランダムラベルの記憶、二重降下（double descent）、勾配降下法の暗黙的バイアス（implicit bias）、早期停止、*ドロップアウト*による乗法的ノイズ正則化を扱う。そして最後に、:numref:`sec_kaggle_house` でこれら一連の手法を Kaggle の Ames Housing 回帰ベンチマークに適用する。

<!--en:acc8203e-->
[中心となる問題]{.kicker}

<!--en:ef9c3705-->
- **特徴量の相互作用の欠如（XOR）：**排他的論理和では入力ビット $x_1$ の反転に伴う出力の向きが $x_2$ 次第で逆転するため、単一の超平面では $\{0, 1\}^2$ の 4 頂点すべてを分離できない

<!--en:32fb9b82-->
- **文脈を見ないピクセル重み：**Fashion-MNIST では、近傍が襟・袖・ハンドバッグのストラップのどれを成していても明るいピクセルはクラスに全く同じ票を投じるため、線形モデルの正解率は $\sim 84\%$ で頭打ちになる

<!--en:ef3358bf-->
- **深層学習による解決策：**非線形な特徴量の組み合わせを出力分類器と同時に学習する隠れ層 $\mathbf{H} = \phi(\mathbf{X}\mathbf{W}^{(1)} + \mathbf{b}^{(1)})$ を挿入する（正解率 $\sim 87\%$）

<!--en:c494cd83-->
::: {.slide title="深層ネットワークにおける 3 つの根本的課題"}

<!--en:d70cdc74-->
[深さがもたらすもの]{.kicker}

<!--en:7a9116a5-->
1. **効率的な勾配計算：**有限差分ではステップあたり $203{,}530$ 回の順伝播が必要になるが、*誤差逆伝播法*は順伝播の活性化値を GPU RAM にキャッシュすることで 1 回の逆方向パスですべての勾配を計算する

<!--en:12095650-->
2. **深さにわたる数値安定性：**$K$ 個の層を通じ、信号と勾配は $K$ 個の重み行列と傾き行列の積を通過するため、分散保持の *Xavier* 初期化および *He* 初期化が必要になる

<!--en:e95fbf07-->
3. **補間を超えた汎化：**過剰パラメータ化された MLP はランダムノイズを記憶できるにもかかわらず、SGD の暗黙的バイアス、早期停止、*ドロップアウト*によって実データに対して汎化する

最初の節に入る前に、以降の節をつなぐ 2 つの基本的な問いで直感を試してみよう。

<!--en:0d9160f3-->
1. **線形崩壊：**10 層の幅 $256$ の全結合層を活性化関数なし（$\phi(z) = z$）で積み重ねた場合、このネットワークは単一の $784 \times 10$ 線形層よりも高い表現力を持つか。

<!--en:c3236889-->
2. **メモリ対パラメータ：**サイズ $n = 256$ のミニバッチで深層ネットワークを訓練するとき、すべての隠れ層が入力より狭い場合であっても、なぜ活性化メモリはパラメータのメモリを容易に上回りうるのか。

<!--en:557b98b6-->
**解答：**

<!--en:c9289f5b-->
1. **持たない：**$(\mathbf{X}\mathbf{W}^{(1)})\mathbf{W}^{(2)}\cdots\mathbf{W}^{(10)}$ を掛け合わせると単一の行列 $\mathbf{X}\mathbf{W}$ になり、そのランクは高々 $256$（出力では高々 $10$）にとどまる。代数的な崩壊を防ぐには非線形な活性化が不可欠である。

<!--en:58804622-->
2. **バッチによるスケーリング：**重み行列 $\mathbf{W}^{(k)} \in \mathbb{R}^{h \times h}$ が保持する浮動小数点数はバッチサイズによらず $h^2$ 個であるのに対し、キャッシュされる順伝播の活性化値 $\mathbf{H}^{(k)} \in \mathbb{R}^{n \times h}$ は 1 層あたり $nh$ 個の浮動小数点数を保持し、バッチサイズ $n$ と深さ $K$ の両方に比例して増加する
