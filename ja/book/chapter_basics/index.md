# 基礎

<!--en:8df36fc8-->
イントロダクションでは、機械学習が人手で書かれたルールを、データ例から直接学習するパラメータ化されたプログラムに置き換える仕組みを見た。ここで、衣類を写した小さなグレースケール写真を数万枚手渡され、それぞれの画像に写っているのが T シャツ、スニーカー、コート、ハンドバッグのどれかを識別するシステムを構築するよう求められたとする。生のピクセル強度を衣類のカテゴリへ確実に対応づける明示的な `if`-`else` ルールをどう書けばよいか、わかるプログラマはいない。しかし、本パートの最初の 3 章を終える頃には、まさにそれを実現する実用的な分類器を実際に構築し、訓練し終えているはずである。さらに本パートを終える頃には、複雑な視覚シーンを認識する深い畳み込みネットワークや、英語の散文をゼロから生成することを学習するリカレントネットワークにまで進んでいるだろう。

<!--en:3c3b4678-->
「基礎」パート全体を通じたアプローチは、シンプルな原則に基づいている。深層学習を真に理解するには、ブラックボックスのライブラリ呼び出しに頼る前に、その中核となる仕組みを自らの手で構築すべきだということである。これら 8 つの章を通して、基礎となるほぼすべてのモデル、層、損失関数、オプティマイザを 2 回ずつ実装する。最初は*ゼロから*、基本的なテンソル演算と自動微分（automatic differentiation）のみに頼り、すべての数学的演算がコード上で見える形で実装する。次に、現代の深層学習フレームワーク（PyTorch、JAX、TensorFlow、MXNet）の高水準な抽象化を用いて*簡潔に*実装する。各コンポーネントが土台からどのように動作するかを確認した後は、以降の章ではその簡潔なフレームワーク実装を構成要素として用いる。

<!--en:db60cbcd-->
本パートの 8 つの章は、次の 3 つの段階で展開される。

<!--en:cda57987-->
* **ツールキットと基本レシピ（:numref:`chap_preliminaries`〜:numref:`chap_classification`）：**まずは、完全に解析できるほどシンプルなモデルから始める。:numref:`chap_preliminaries` では、多次元配列（*テンソル*）へのデータの格納と操作、表形式データの前処理、コードによる線形代数と微分積分の適用、*autograd* による導関数の自動計算、そして確率を用いた不確実性の扱いといった、深層学習に不可欠な実用的ツールを身につける。続く :numref:`chap_regression` と :numref:`chap_classification` では、線形モデルを題材に機械学習の普遍的な訓練ループを導入する。:numref:`chap_regression` では、線形回帰、二乗誤差損失、ミニバッチ確率的勾配降下法を用いて連続値のターゲットにモデルを適合させ、統計学の中心的な課題である*汎化*（generalization）に向き合う。すなわち、訓練データに過度に適合させると過学習を招く理由と、重み減衰などの正則化手法がいかにモデルを健全に保つかを考察する。:numref:`chap_classification` では連続値から離散的なカテゴリへと対象を移し、ソフトマックス回帰と交差エントロピー損失を構築して Fashion-MNIST ベンチマーク上の衣類写真を分類する。あわせて、実世界のデータ分布が訓練セットからずれたときに、デプロイされた分類器がどのように振る舞うかも検証する。

<!--en:d69219ca-->
* **深層化とソフトウェアエンジンの習得（:numref:`chap_perceptrons`〜:numref:`chap_computation`）：**線形モデルに引けるのは、クラス間の平坦な決定境界だけである。:numref:`chap_perceptrons` では、非線形な活性化関数を備えたユニットの隠れ層を積み重ねて*多層パーセプトロン*（multilayer perceptron、MLP）を構築し、この限界を打破する。ここでは、誤差逆伝播法（backpropagation）によって深いネットワーク内を信号と勾配が順方向・逆方向に流れる仕組みをたどり、不用意に初期化すると深いネットワークが勾配消失や勾配爆発に陥る理由を探る。さらに、容量の大きいネットワークに対する強力な正則化手法として*ドロップアウト*を導入する。続く :numref:`chap_computation` では、現代の深層学習フレームワークのソフトウェアアーキテクチャを解き明かす。再利用可能なモジュール式のブロックから複雑なネットワークを組み立てる方法、パラメータの共有・検査・初期化、カスタム層と順伝播の定義、訓練済みの重みの保存と読み込み、そして GPU 上への計算の移行を扱う。

<!--en:9f5d64ae-->
* **ドメイン構造のアーキテクチャへの組み込み（:numref:`chap_cnn`〜:numref:`chap_rnn`）：**全結合ネットワークはすべての入力特徴量を対称に扱うため、入力が 2 次元の画像グリッド上に並んだピクセルなのか、文の中に順序よく並んだ単語なのかを区別しない。最後の 3 章では、データが本来持つ対称性をネットワークのアーキテクチャに直接組み込むことで、統計的効率と計算効率が劇的に向上することを示す。画像に対しては、:numref:`chap_cnn` で平行移動不変性と空間的局所性の原理から*畳み込みニューラルネットワーク*（convolutional neural network、CNN）を展開し、パディング、ストライド、複数の入力・出力チャネル、プーリングを導入して古典的な LeNet アーキテクチャを構築する。続く :numref:`chap_modern_cnn` では、コンピュータビジョンを現代へと押し上げたアーキテクチャ上のマイルストーンとして、AlexNet、繰り返し可能なブロック設計（VGG）、$1\times 1$ 畳み込み（NiN）、複数分岐の並列ブロック（GoogLeNet）、*バッチ正規化*（batch normalization）、ResNet の*残差接続*（residual connection）、DenseNet をたどり、原理に基づいたアーキテクチャ設計空間（AnyNet と RegNet）へと至る。最後に :numref:`chap_rnn` ではテキストや時系列などの系列データに目を向け、自己回帰言語モデリング、バイトレベル BPE トークン化、$n$-gram モデルとパープレキシティ、*リカレントニューラルネットワーク*（RNN）、通時的誤差逆伝播法（backpropagation through time）、デコーディングを構築し、H. G. Wells の『The Time Machine』風の新しい文章を生成する BPE レベルの言語モデルを訓練してこれらすべてを検証する。

<!--en:a6a52c6c-->
最初の 5 章（:numref:`chap_preliminaries`〜:numref:`chap_computation`）は一貫した背骨をなしており、順番どおりに読み進めるのが最もよい。これらを終えた後は、コンピュータビジョンの章（:numref:`chap_cnn` と :numref:`chap_modern_cnn`）と系列モデリングの章（:numref:`chap_rnn`）は互いに依存しないため、どちらの順序で学んでも構わない。これら全体を通じて、「発展」パートが土台とする概念的・工学的な習慣が築かれる。
