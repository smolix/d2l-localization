# 勾配ペナルティと収束

<!--en:a0dadcc0-->
:numref:`sec_basic_gan` の Fashion-MNIST 実験では、識別器損失も生成器損失も理論上の平衡値には落ち着かなかった。交互勾配降下法は収束が遅いだけなのか、それとも平衡点に到達することなくその周囲を際限なく周回しうるのだろうか。:numref:`sec_basic_gan` から :numref:`sec_gan_relativistic` までの母集団ダイバージェンスの解析では、クリティックが厳密な最適解 $D^\star$ にあるときのミニマックス目的関数を特徴づけた。しかし実際には、両方のネットワークが同時または交互に小さな勾配ステップを踏み、一方の更新がもう一方の目的関数を絶えず変化させる。

<!--en:f7e90f73-->
勾配訓練のダイナミクスを直接解析するため、:citet:`Mescheder.Geiger.Nowozin.2018` は点質量のデータ分布、点質量の生成器、および線形クリティックからなる最小限の 2 パラメータ問題である *Dirac-GAN* を導入した。このような 2 パラメータ系においてさえ、正則化なしの勾配降下法は収束しない。一方で、クリティックの入力勾配の二乗ノルムにペナルティ（$R_1$ と $R_2$）を課すと、平衡点は局所漸近安定（locally asymptotically stable）になる。これらのゼロ中心勾配ペナルティ（zero-centered gradient penalty）を :numref:`sec_gan_relativistic` の相対論的ペアリング目的関数と組み合わせることで、本章の残りの節で用いる R3GAN レシピが得られる :cite:`Huang.Gokaslan.Kuleshov.ea.2024`。

<!--en:e7fdb15b-->
## Dirac-GAN

<!--en:2ab44fb6-->
### 2 パラメータのミニマックス系

<!--en:81aac297-->
データ分布を原点における点質量 $p = \delta_0$ とし、生成器は $\theta \in \mathbb{R}$ に点質量を置く分布 $q_\theta = \delta_\theta$ とする（したがって $q_\theta = p$ となるのは $\theta = 0$ のとき、かつそのときに限る）。また、クリティックをバイアスなしの線形関数 $D_\psi(x) = \psi x$ とする。対称マージン目的関数 $V_\ell(D) = \mathbb{E}_{x \sim p}[\ell(D(x))] + \mathbb{E}_{x' \sim q}[\ell(-D(x'))]$（:numref:`sec_gan_objectives`）のもとでは、両方の期待値は単一の評価に帰着する。

<!--en:46617fa8-->
ここではロジスティック利得 $\ell(t) = \log \sigma(t)$ を用いる。この関数は $\ell'(t) = \sigma(-t) > 0$ および $\ell''(t) = -\sigma(t)\sigma(-t) < 0$ を満たし、$\ell'(0) = \tfrac12$、$\ell''(0) = -\tfrac14$ である。

<!--en:377554df-->
任意の $\theta \neq 0$ に対して、$p$ と $q_\theta$ の台（support）は互いに素である。そのため、$V(\theta, \psi)$ を $\psi$ について最大化すると $\psi\theta \to -\infty$ となり、定数 $\sup_\psi V(\theta, \psi) = \ell(0)$ がすべての $\theta \neq 0$ に対して得られる結果、$\theta$ に関する勾配はゼロになる。

<!--en:c37801fd-->
### 連続時間における非減衰振動

<!--en:38583078-->
勾配訓練では、$\sup_\psi V(\theta, \psi)$ を直接解く代わりに、現在の値から $\theta$ と $\psi$ を少しずつ更新する。:eqref:`eq_gan_dirac_value` の唯一の停留点（stationary point）は平衡点 $(\theta, \psi) = (0, 0)$ である。連続時間の同時勾配フロー（$\dot\theta = -\partial_\theta V$、$\dot\psi = +\partial_\psi V$）のもとでは、次式が成り立つ。

<!--en:7e7cf81a-->
速度ベクトル $\mathbf{u}(\theta, \psi) = \ell'(-\psi\theta)\,(\psi, -\theta)$ は至るところで状態ベクトル $(\theta, \psi)$ に直交するため、原点までの二乗距離は保存される。

<!--en:c1c55a43-->
あらゆる軌跡は、$(0, 0)$ を中心とする一定半径の閉じた円を描く（これは任意の狭義単調増加な利得 $\ell$ に対して成り立つ）。すなわち、生成器のパラメータ $\theta$ は決して収束することなく、$0$ をまたいで前後に振動し続ける。

<!--en:81fa7ba7-->
:eqref:`eq_gan_dirac_flow` を $(\theta, \psi) = (0, 0)$ の周りで線形化すると（:numref:`subsec_mdl-ode-linearization`）、ヤコビ行列と固有値は次のようになる。

<!--en:92dc98f3-->
純虚数の固有値は線形の*中心点*（center）に対応する（双線形鞍点問題 $\min_\theta \max_\psi \theta\psi$、:citet:`Daskalakis.Ilyas.Syrgkanis.ea.2018`）。なお、スカラー因子 $\ell'(-\psi\theta) = \sigma(D_\psi(\theta)) = w_{\textrm{sat}}$ は両成分に同時に掛かるため、円周上の角速度をリスケールするにすぎない。

<!--en:35fff7fe-->
### 離散時間における外向きスパイラルとリミットサイクル

<!--en:7ca86f7c-->
離散時間では、ステップサイズ $h > 0$ の同時勾配降下法は $(\theta, \psi) \mapsto (\theta, \psi) + h\,\mathbf{u}(\theta, \psi)$ と更新する。$\mathbf{u}(\theta, \psi) \perp (\theta, \psi)$ であるため、ピタゴラスの定理より次式が得られる。

<!--en:fa5b8075-->
したがって、任意の $h > 0$ に対して、離散時間の同時ステップは毎回、平衡点からの距離を厳密に*増加させ*、反復点は外向きに渦を巻いて発散する（演習問題 :exref:`ex_convergence-discrete-simultaneous-update-dirac`）。

<!--en:a8f0af25-->
交互勾配更新（まず $\psi$ を更新し、続いて $\theta$ を更新後の $\psi$ を用いて更新する手法）は、これよりわずかに良い挙動を示す。$(0, 0)$ の近傍では、各半ステップが面積保存の線形せん断となるため、合成されたヤコビ行列の行列式は $1$ である。$h\,\ell'(0) \leq 2$ のとき、両方の固有値は単位円上に乗るため :cite:`Mescheder.Geiger.Nowozin.2018`、交互更新の反復点は収束することなく原点の周りの有界な帯状領域内を周回する（演習問題 :exref:`ex_convergence-alternating-updates`）。非飽和生成器損失（原点で同じ線形化 $J$ を共有する）も、相対論的ペアリング損失（$\ell(D_\psi(0) - D_\psi(\theta)) = \ell(-\psi\theta)$ となり同一の勾配場を持つ）も、これらの局所固有値を変えない。

<!--en:b69554aa-->
## ゼロ中心勾配ペナルティ

<!--en:72d3a980-->
平衡点 $(\theta, \psi) = (0, 0)$ を局所漸近安定にするには、ヤコビ行列の固有値を虚軸上から開左半平面 $\operatorname{Re}(\nu) < 0$ へと移動させなければならない。平衡時のクリティックは平坦でなければならないため（$\nabla_x D^\star(x) = 0$ が $q = p$ のときに成り立つ）、クリティックの入力勾配の二乗ノルムにペナルティを課せば、平衡 $q = p$ をずらすことなくクリティックに減衰を加えられる。

<!--en:35f868a2-->
:citet:`Mescheder.Geiger.Nowozin.2018` は、2 つの*ゼロ中心勾配ペナルティ*として $R_1$（実データ $x \sim p$ 上で評価）と $R_2$（生成サンプル $x' \sim q$ 上で評価）を次のように定義している。

<!--en:2892305e-->
ここで $\gamma > 0$ はペナルティの重みである。クリティックは $V_\ell(D) - R_1 - R_2$ を最大化し、生成器の目的関数は変わらない。$m = (p + q)/2$ とおくと、両者の和は混合分布のもとでの二乗勾配ノルムの期待値となる。

<!--en:6ad8898e-->
### Dirac-GAN の減衰

<!--en:2d68e6af-->
線形クリティック $D_\psi(x) = \psi x$ に対しては、至るところで $\nabla_x D_\psi(x) = \psi$ であるため、$R_1 = R_2 = \tfrac{\gamma}{2}\psi^2$ となる。クリティックの目的関数から $\tfrac{\gamma}{2}\psi^2$ を引くと、線形減衰項 $-\gamma\psi$ が $\dot\psi$ に加わる（$-2\gamma\psi$ となるのは $R_1$ と $R_2$ の両方を含めた場合である）。

<!--en:c488a4cc-->
$(0, 0)$ におけるヤコビ行列とその固有値は次のようになる。

<!--en:0dffd9df-->
すべての $\gamma > 0$ に対して、両方の固有値は厳密に負の実部（$\operatorname{Re}(\nu_{1,2}) < 0$）を持つため、平衡点 $(0, 0)$ は局所指数安定（locally exponentially stable）である。特性多項式 $\nu^2 + \gamma\nu + \ell'(0)^2 = 0$ は減衰調和振動子（:numref:`subsec_mdl-ode-linearization`）のものと同一であり、次の 3 つのレジームを持つ。

<!--en:af678754-->
1. *不足減衰*（underdamped、$\gamma < 2\ell'(0)$）：実部 $-\gamma/2$ を持つ複素共役固有値となり、軌跡は内向きに渦を巻く（同時オイラーステップのもとでは $h < \gamma / \ell'(0)^2$ のときに収束する。演習問題 :exref:`ex_convergence-discrete-simultaneous-update-dirac`）。

<!--en:68937d32-->
2. *臨界減衰*（critically damped、$\gamma = 2\ell'(0)$、すなわちロジスティック損失では $\gamma = 1$）：重複実固有値 $\nu = -\ell'(0)$ を持ち、最も速い非振動的減衰をもたらす。

<!--en:2cc32bd2-->
3. *過減衰*（overdamped、$\gamma > 2\ell'(0)$）：2 つの負の実固有値を持ち、遅いモード $\nu \approx -\ell'(0)^2/\gamma$ は $\gamma$ が大きくなるほどゆっくりと減衰する。

<!--en:95e99743-->
すべての軌道は赤い点 $(\theta, \psi) = (1, 1)$（黒い十字で示す平衡点からの距離 $\sqrt 2 \approx 1.41$）から出発する。左のパネルは連続時間フローを示す。中央のパネルは、ステップサイズ $h = 0.2$ による 300 回の同時ステップと 2,000 回の交互ステップを示す。右のパネルは、ペナルティを加えた同じステップサイズによる 300 回の同時ステップを、不足減衰レジームの $\gamma = 0.3$ と臨界減衰の $\gamma = 1$ について示す。

<!--en:f405f265-->
相図から 4 つの予測すべてが確認できる。連続時間フロー（`RK4`）は半径 $1.41$ の円上を周回し、同時オイラーステップは 300 ステップ後に半径 $2.87$ まで外向きに渦を巻いて広がり、交互ステップは $[1.34, 1.42]$ の内部を周回する。そしてゼロ中心ペナルティを加えると、同時オイラーステップは原点へと直接収束する（半径 $6.5 \times 10^{-4}$ に不足減衰 $\gamma = 0.3$ で到達し、$7 \times 10^{-12}$ に臨界減衰 $\gamma = 1$ で到達する）。

### 一般のネットワークに対する局所収束とペナルティの比較

<!--en:ed725751-->
:citet:`Mescheder.Geiger.Nowozin.2018` は、この局所安定性解析を 2 パラメータの Dirac-GAN から一般のニューラルネットワークへと拡張した。すなわち、生成器がデータ分布 $p$ を表し、クリティックが $\operatorname{supp}(p)$ 上で平坦であるような平衡の近傍において、クリティックが生成器の一次摂動を検出するのに十分な局所表現能力を備えていれば、$R_1$ または $R_2$（および $\ell'(0) \neq 0, \ell''(0) < 0$ を満たす狭義凹損失）を用いた同時および交互勾配更新は、平衡多様体へ指数関数的に収束する（:citet:`Huang.Gokaslan.Kuleshov.ea.2024` は相対論的ペアリング目的関数に対しても同様の局所定理を確立している）。

<!--en:822c60b1-->
この解析から、実践上の 2 つの設計選択の理由も説明できる。

<!--en:48cc943c-->
- **ゼロ中心（$R_1, R_2$）対 1 中心（WGAN-GP）ペナルティ：**WGAN-GP は $(\|\nabla_x D\| - 1)^2$ にペナルティを課すため、$q = p$ のときでさえクリティックに傾き 1 を維持することを強制する。線形利得 $\ell(t) = t$ を持つ Dirac-GAN では、1 中心ペナルティによって $\theta = 0$ への収束が妨げられる。$\gamma \geq 2$ のときはワッサースタイン勾配とペナルティが釣り合う $|\theta| = \gamma$ に生成器を停留させ、それより小さい $\gamma$ では生成器がこの点をオーバーシュートして周期軌道を回り続ける（演習問題 :exref:`ex_convergence-one-centered-dynamics`）。

<!--en:83810c83-->
- **$R_1$ と $R_2$ の併用対 $R_1$ 単独の使用：**$q = p$ の近傍では、$R_1$ と $R_2$ は等価である。しかし平衡から離れた領域では、$R_1$ は実データ点 $x \sim p$ におけるクリティックの傾きにしかペナルティを課さず、生成点 $x' \sim q$ における傾きを制約しないままである（たとえば $D_c(x) = -cx^2$ は $p = \delta_0$ において傾きがゼロであるため $R_1 = 0$ となり、$c \to \infty$ が許容されて $x' = 1$ における生成器の勾配が爆発する。演習問題 :exref:`ex_convergence-one-sided-penalty`）。$R_2$ を加えることで、生成サンプルにおけるクリティックの勾配も有界に抑えられる。

<!--en:515a8d1f-->
## 勾配ペナルティが価値関数に及ぼす影響

<!--en:c04e957e-->
ゼロ中心ペナルティ $R_1 + R_2 = \gamma\,\mathbb{E}_m[\|\nabla_x D\|^2]$ は、平衡の近傍で生成器が最小化するダイバージェンスをどのように変化させるのだろうか。

<!--en:a0a8be0a-->
### 局所二次近似とガウス分布のシフト

<!--en:fcd9d021-->
$q = p$ の近傍では、最適なクリティック $D$ は小さい。$\ell(t) \approx \ell(0) + \ell'(0)t - \tfrac12|\ell''(0)|t^2$ により $D$ の 2 次まで $V_\ell(D)$ の内部を展開すると、次式が得られる。

<!--en:9622b18f-->
ここで $\langle p - q, D \rangle = \mathbb{E}_p[D] - \mathbb{E}_q[D]$ である。2 つの単位分散ガウス分布 $p = \mathcal{N}(0, 1)$ と $q = \mathcal{N}(\mu, 1)$（小さなシフト $\mu$ だけ離れている）および線形クリティック $D(x) = cx$ を考える。$\mu$ の主要項までとると、$\langle p - q, D \rangle = -c\mu$、$\int m\,D^2 \approx c^2$ であり、ペナルティは $\gamma\int m\,\|\nabla_x D\|^2 = \gamma c^2$ となる。凹二次関数 $-\ell'(0)\mu c - (|\ell''(0)| + \gamma)c^2$ を $c$ について最大化すると、最適な傾き $c^\star = -\frac{\ell'(0)\mu}{2(|\ell''(0)| + \gamma)}$ と次の値が得られる。

<!--en:5b4ac788-->
このように、ペナルティによってクリティックの傾きと局所的な値はともに $1 + 4\gamma$ 分の 1 に縮小する。$\gamma = 0$ では $\mu^2/4 \approx 2\,\mathrm{JS}(p, q)$ が復元され、大きい $\gamma$ では値は $\mu^2/(16\gamma) = \tfrac{\ell'(0)^2}{4\gamma} W_2(p, q)^2$ のようにスケールする。以下では、1 次元グリッド上でニュートン法により計算した厳密なペナルティ付き最適値と比較し、この閉形式近似を検証する。

<!--en:704835f9-->
シフトが小さい場合（$\mu = 0.2$）、二次近似式 $\mu^2/(4 + 16\gamma)$ はすべての $\gamma$ にわたって厳密な数値解と 1% 以内の誤差で一致する。

<!--en:f850962c-->
### 双対ソボレフノルムとローパスフィルタリング

<!--en:5490029c-->
平衡近傍にある一般の分布 $p$ と $q$ に対しては、部分積分を用いることで勾配ペナルティを $\int m\,\|\nabla_x D\|^2 = \langle D, \mathcal{L}_m D \rangle$ と書き換えられる。ここで $\mathcal{L}_m D = -\nabla \cdot (m \nabla D)$ は $m$ 重み付きラプラシアンである。局所二次近似をすべての関数 $D$ にわたって最大化すると、次式が得られる（演習問題 :exref:`ex_convergence-prove-eqref-eq-gan`）。

<!--en:ae769464-->
$\gamma \to 0$ のとき、この式は $\tfrac{\ell'(0)^2}{4|\ell''(0)|} \int (p - q)^2/m \approx 2\,\mathrm{JS}(p, q)$ に帰着する。一方、$\gamma \to \infty$ のときは、*双対ソボレフノルム*（dual Sobolev norm）$\dot H^{-1}(m)$ の二乗の定数倍に漸近する。

<!--en:43a22a09-->
$m$ がほぼ一様な領域では、$\mathcal{L}_m$ は波数 $\omega$ のフーリエモードに $m\omega^2$ を掛けるため、そのモードの重み付けは $(|\ell''(0)| + \gamma\omega^2)^{-1}$ となる（ペナルティなしの $|\ell''(0)|^{-1}$ に代わる）。したがって、$R_1 + R_2$ は $p - q$ に対する空間的な*ローパスフィルタ*として働き、そのカットオフ長さスケールは $\sqrt{\gamma / |\ell''(0)|}$（ロジスティック損失では $2\sqrt{\gamma}$）となる。$\nabla_x D$ は長さの逆数の単位を持つため、$\gamma$ は長さの二乗の単位を持ち、データの解像度やノルムに応じてスケールする。なお、$R_1 + R_2$ が $\nabla_x D$ にペナルティを課すのは $m = (p+q)/2$ の台の上のみである。互いに素な台の間に広がる空白領域をまたぐ勾配は、依然としてニューラルネットワークであるクリティックの滑らかさに依存する（演習問題 :exref:`ex_convergence-penalized-best-response`）。

<!--en:4eb8ea01-->
## R3GAN レシピ

<!--en:67f75286-->
R3GAN :cite:`Huang.Gokaslan.Kuleshov.ea.2024` は、相対論的ペアリング損失（`d2l.rpgan_loss_D` および `d2l.rpgan_loss_G`、:numref:`sec_gan_relativistic`）と両方のゼロ中心勾配ペナルティ $R_1$、$R_2$ を組み合わせた手法である。

<!--en:1e671c9a-->
### 損失とペナルティの実装

<!--en:ce74f528-->
比較のため、`gan_loss_D` と `gan_loss_G`（:numref:`sec_basic_gan` の古典的なロジスティック識別器損失と非飽和生成器損失）も同じ `(critic, real, fake)` シグネチャで実装し、保存しておく。

<!--en:afaabf95-->
ペナルティ関数は、係数 $\gamma/2$ を掛ける前の、両バッチにおけるサンプルごとの二乗入力勾配を返す。ここではクリティックのスコアの*和*を入力バッチに関して微分する。各スコアはそれぞれの行のみに依存するため、1 回の逆伝播ですべてのサンプルの入力勾配が求まる（行同士を混合するバッチ正規化を用いると、この性質は成り立たなくなる）。入力勾配は自動微分の計算グラフ内に保持されるため、オプティマイザはクリティックのパラメータに関してペナルティをさらに微分できる。このときサンプル自体は定数として固定する。2 回目の微分を伴うため、ペナルティ付きクリティックステップの計算コストはおよそ 2 回分の逆伝播に相当する。

<!--en:8699414f-->
`create_graph=True` によって 2 回目の微分のために計算グラフ内に入力勾配を保持し、`detach` によってサンプルを定数として扱う。

<!--en:a6741bf1-->
スコアの和に対する `jax.grad` によって入力勾配が得られ、クリティックに関してペナルティを微分するとその外側に 2 回目の勾配計算が入れ子になる。また、`jax.lax.stop_gradient` によってサンプルを定数として扱う。

<!--en:d053ca34-->
### 訓練ステップ

<!--en:589072f4-->
訓練ループでは、各プレイヤーのステップを 1 回ずつ交互に実行する。`critic_step` は生成バッチを固定した状態で、クリティック損失に両ペナルティの $\gamma/2$ 倍を加えた目的関数に対してオプティマイザを 1 ステップ進め、損失ならびに実サンプルと生成サンプルにおける二乗入力勾配のバッチ平均（$R_1$ と $R_2$ の $\gamma/2$ を掛ける前の値）を返す。これにより、訓練ループ内でクリティックの急峻さを記録できる。続いて `generator_step` が、更新後のクリティックに対する生成器損失について 1 ステップ進める。オプションのラベル `y` は、:numref:`sec_gan_conditional` の条件付きクリティックで用いる。

<!--en:240cf81a-->
損失関数はコンパイルされるステップ関数の静的引数であるため、損失のペアごとに 1 回だけコンパイルされる。一方、$\gamma$ はトレースされるため、再コンパイルなしに変更できる。

<!--en:871700d8-->
### 25 ガウスグリッドにおけるモード被覆

<!--en:bf6d0766-->
ニューラルネットワークにおけるモード被覆（mode coverage）に $R_1 + R_2$ とペアワイズランキングがどう影響するかを検証するため、2 次元ガウス分布の $5 \times 5$ グリッド（間隔 $2.0$、標準偏差 $\sigma = 0.05$）上で、3 層の MLP 生成器（64 次元の潜在変数、256 個の ReLU ユニットからなる 2 つの隠れ層）と 3 層の Leaky ReLU MLP クリティックを訓練する。生成された 10,000 個のサンプルを次の 4 つの評価指標で評価する。

<!--en:71d36f1a-->
1. *被覆モード数*（covered modes）：モード上サンプルのうち、少なくとも $1/5$ 倍（均等配分 $1/25$ に対する比率）を受け取ったモードの数。

<!--en:d8335a76-->
2. *モード上サンプル比率*（on-mode fraction）：最近傍のモード中心から $3\sigma = 0.15$ 以内に入るサンプルの割合（真の分布では $98.9\%$）。

<!--en:a3a2a7d4-->
3. 最近傍の中心までの*平均距離*（真の分布では $\approx 0.06$）。

<!--en:3fa0bf75-->
4. 生成サンプルにおける*クリティックの急峻さ*（critic steepness）$\mathbb{E}_q[\|\nabla_x D(x')\|^2]$。

<!--en:5a3e0c32-->
生成された点群をグリッドの `centers` に照らして評価するため、`mode_stats` は各サンプルを最近傍のモード中心に割り当て、被覆モード数、$3\sigma$ 以内のサンプル比率、および最近傍中心までの平均距離を返す。

<!--en:e66879ba-->
`train_grid` は `critic_step` と `generator_step` を 10,000 ステップ（バッチサイズ 1,024）交互に実行する。オプティマイザには $\beta_1 = 0$ の Adam（回転ベクトル場において正の一次モーメントのモメンタムは安定領域を狭めうるため、R3GAN に倣う）を用い、$2 \times 10^{-3}$ から $2 \times 10^{-4}$ へのコサイン学習率減衰を適用する。

<!--en:50f73ea8-->
ここでは $2 \times 2$ の要因実験として、2 つの目的関数（古典的な非飽和型 `NS` と `pairing`）に $\gamma = 0$（ペナルティなし）および $\gamma = 1$（$R_1 + R_2$）を掛け合わせた各条件を 3 シードずつ実行し、さらに過減衰の実行（$\gamma = 10$）を 1 つ加える。

<!--en:a4879047-->
各実行から生成された 10,000 個のサンプルに対する `mode_stats` の結果を、クリティックの最終的な二乗勾配ノルム $\mathbb{E}_q[\|\nabla_x D(x')\|^2]$ と並べて表にまとめる。

<!--en:0056605a-->
主要な 4 つの実験アームそれぞれの最初の実行から生成された 3,000 個のサンプルを、25 個のモード中心（`grid`）と重ねてプロットすると、モード被覆の違いが直接見て取れる。

<!--en:5ab7920e-->
この結果から、勾配ペナルティとペアリング損失それぞれの役割が明確に分離される。

<!--en:cd9d7eeb-->
- **勾配ペナルティがモード被覆をもたらす：**ペナルティなし（$\gamma = 0$）では、クリティックの勾配は急峻なままであり（$\mathbb{E}_q\|\nabla_x D\|^2 \in [0.7, 17]$）、モード被覆は不安定になる（シードによって 12〜25 モードに落ち込む）。$R_1 + R_2$ を $\gamma = 1$ で課すと、クリティックの勾配は 3 桁減衰し（$\sim 10^{-3}$）、`NS` と `pairing` の双方ですべての実行が全 25 モードを被覆する。

<!--en:93c0b679-->
- **大きい $\gamma$ における過減衰：**$\gamma$ を $10$ に増やすとクリティックが過度に平坦化され（$\sim 10^{-4}$）、収束が遅くなって 10,000 ステップ後でも 20〜30% のサンプルしかモードの $3\sigma$ 以内に収まらない。

<!--en:7b9081cb-->
最後に、チェックポイントのトレースを調べると、落ち着いたクリティック損失曲線の解釈になぜ注意が必要かがわかる。

<!--en:d6fa9238-->
ペナルティ付きの実行では、クリティック損失は最初のチェックポイントから平衡値（`NS` では $2\log 2 \approx 1.39$、`pairing` では $\log 2 \approx 0.69$）の付近に留まる。これは生成サンプルのわずか 1〜3% しかモード上に乗っていない段階でさえ生じる現象であり、勾配ペナルティが至るところで $D(x)$ を小さく保つからである。クリティック損失が平衡値にあることはクリティックが平坦であることを示すにすぎず、必ずしも生成器が収束したことを意味しない。

## まとめ

<!--en:f3db6f33-->
2 パラメータの Dirac-GAN（$p = \delta_0, q_\theta = \delta_\theta, D_\psi(x) = \psi x$）では、連続時間勾配フローは一定半径の円周上を周回し、離散時間の同時ステップは外向きに渦を巻いて発散し、離散時間の交互ステップは有界な帯状領域に閉じ込められる。ゼロ中心勾配ペナルティ $R_1 = \frac{\gamma}{2}\mathbb{E}_p[\|\nabla_x D(x)\|^2]$ および $R_2 = \frac{\gamma}{2}\mathbb{E}_q[\|\nabla_{x'} D(x')\|^2]$ を差し引くと、ヤコビ行列の固有値が開左半平面（$\operatorname{Re}(\nu_{1,2}) < 0$）へとすべての $\gamma > 0$ に対して移動し、平衡点は局所指数安定となる。平衡の近傍では、$R_1 + R_2$ は $p - q$ に対する空間ローパスフィルタ（ロジスティック損失のもとでのカットオフ長さスケールは $2\sqrt{\gamma}$）として働き、大きなスケールでの $2\,\mathrm{JS}(p, q)$ と細かなスケールでの二乗双対ソボレフノルム $\|p - q\|_{\dot H^{-1}(m)}^2$ の間を補間する。実験的にも、25 ガウスグリッドにおいて $R_1 + R_2$（$\gamma = 1$）はクリティックの急峻さを 3 桁減衰させ、古典的なロジスティック目的関数と相対論的ペアリング目的関数の双方で完全なモード被覆を達成した。

<!--en:cccd6a7a-->
- **ゼロ中心（$R_1, R_2$）対 1 中心（WGAN-GP）：**WGAN-GP は $\|\nabla_x D\| = 1$ の傾き 1 を $q = p$ でも強制するため、Dirac-GAN は原点に到達せず、$|\theta| = \gamma$ に停留（$\gamma \geq 2$）するか周期軌道を回る（より小さい $\gamma$）

<!--en:8103b8de-->
- **なぜ $R_1 + R_2$ が $R_1$ 単独に勝るか：**平衡から離れた状態（$p = \delta_0, q = \delta_1$）では、二次クリティック $D_c(x) = -cx^2$ は $R_1 = 0$（$x = 0$ にて）となるため $c \to \infty$ を許すが、$R_2$ を加えると $c^\star < 1/(8\gamma)$ に抑えられる

<!--en:d901e143-->
::: {.slide title="局所的な価値関数に対するペナルティの影響"}

<!--en:fc6c1469-->
[二次展開とガウス分布のシフト]{.kicker}

<!--en:11c219c6-->
$R_1 + R_2 = \gamma\int m\,\|\nabla_x D\|^2$ を差し引くと、平衡近傍のダイバージェンスはどう変化するか。$\ell(t) \approx \ell(0) + \ell'(0)t - \frac{1}{2}|\ell''(0)|t^2$ を $D$ の 2 次まで展開すると次式を得る。

<!--en:29ea9840-->
- **1 次元ガウス分布のシフト（$p = \mathcal{N}(0, 1)$、$q = \mathcal{N}(\mu, 1)$、線形クリティック $D(x) = cx$）：**小さい $\mu$ に対し、$-\ell'(0)\mu c - (|\ell''(0)| + \gamma)c^2$ をロジスティック損失（$\ell'(0) = \frac{1}{2}, |\ell''(0)| = \frac{1}{4}$）のもとで最大化すると、最適な傾きと局所的な値はともに $1 + 4\gamma$ 分の 1 に縮小する。
  $$c^\star = -\frac{\mu}{1 + 4\gamma}, \qquad V_\gamma(D^\star) - 2\ell(0) \approx \frac{\mu^2}{4 + 16\gamma}$$

<!--en:3ca8effe-->
::: {.slide title="局所的な価値関数に対するペナルティの影響（検証）" layout="tall-output"}

<!--en:fc6c1469-2-->
[二次展開とガウス分布のシフト]{.kicker}

<!--en:b26d963c-->
グリッド上でペナルティ付きゲームを厳密に解き（$D$ に関するニュートン上昇法）、局所近似値 $\mu^2/(4 + 16\gamma)$ および大きい $\gamma$ での漸近値 $\mu^2/(16\gamma)$ と比較する。

<!--en:51723cc2-->
::: {.slide title="双対ソボレフノルムと空間ローパスフィルタリング"}

<!--en:593d3556-->
[マルチスケール解釈]{.kicker}

<!--en:97b8be21-->
- **JS ダイバージェンスと双対ソボレフノルムの補間：**$\mathcal{L}_m D = -\nabla \cdot (m\nabla D)$ を用いると、局所的な値は $2\,\mathrm{JS}(p, q)$（$\gamma \to 0$）から $\frac{\ell'(0)^2}{4\gamma}\|p - q\|_{\dot{H}^{-1}(m)}^2$（$\gamma \to \infty$）へと遷移する

<!--en:882511bf-->
- **空間ローパスフィルタ：**フーリエ波数 $\omega$ を $(|\ell''(0)| + \gamma\omega^2)^{-1}$ 倍に減衰させ、カットオフ長さスケール $2\sqrt{\gamma}$ 未満の細部を抑える（$\gamma$ は**長さの二乗**の単位を持つ）

<!--en:d7a3e679-->
::: {.slide title="微分可能な R₁ + R₂ ペナルティの実装"}

<!--en:ee7e92be-->
[高階自動微分]{.kicker}

<!--en:068e79da-->
各サンプルのクリティックスコア $D(x_i)$ は行 $x_i$ のみに依存するため（バッチ正規化を除いた場合）、総和 $\sum_i D(x_i)$ を入力バッチ $x$ に関して微分すれば、1 回の逆伝播ですべてのサンプルの入力勾配 $\nabla_{x_i} D(x_i)$ が求まる。

<!--en:725e9360-->
**計算コスト：**オプティマイザが $\|\nabla_x D(x)\|^2$ をクリティックのパラメータに関して微分できるよう入力勾配を自動微分グラフ内に保持するため、ペナルティ付きクリティック更新のコストはおよそ **2 回分の逆伝播**になる。

[モニタリングの注意点]{.kicker}

<!--en:e6a19a5a-->

**平衡値のクリティック損失が収束を保証しない理由：**すべてのペナルティ付き実行において、クリティック損失は厳密な平衡値（`NS` では $2\log 2 \approx 1.39$、`pairing` では $\log 2 \approx 0.69$）にステップ $1{,}250$ の最初のチェックポイントから張り付いているが、この時点では生成サンプルのわずか **$1\text{--}3\%$** しかモード上に乗っていない。$R_1 + R_2$ が $D(x)$ を至るところでほぼ平坦に保つため、平衡値のクリティック損失はクリティックが減衰していることを示すだけであり、決して $q$ が $p$ に一致したことを保証するものではない。

::: {.slide title="理解度チェック：ミニマックスのダイナミクスとペナルティ"}

<!--en:929b7671-->
[理解度の確認]{.kicker}

<!--en:5cfed2a1-->
ミニマックスの回転ダイナミクスとゼロ中心勾配ペナルティの理解度を確認しよう。

<!--en:c1fb0c56-->
1. **離散オイラー法の安定性しきい値：**ロジスティック損失（$\ell'(0) = \frac{1}{2}$）を用いたペナルティ付き Dirac-GAN では、連続時間のヤコビ行列固有値は $\nu_{1,2} = -\frac{\gamma}{2} \pm i\sqrt{\ell'(0)^2 - \gamma^2/4}$（不足減衰レジーム $\gamma < 1$）である。ステップサイズ $h$ について同時離散オイラーステップが収束（$|1 + h\nu_{1,2}| < 1$）する上限は何か。また、$\gamma = 0.3$ におけるその数値はいくらか。

<!--en:28d5853c-->
2. **ペナルティ付きガウスシフト：**ロジスティック損失のもとで小さなシフトを持つ $p = \mathcal{N}(0, 1)$ と $q = \mathcal{N}(\mu, 1)$（$\mu = 0.2$）に対し、$\gamma = 1$ にすると最適な線形クリティックの傾き $c^\star$ は $\gamma = 0$ に比べて何分の 1 に縮小するか。

<!--en:557b98b6-->
**解答：**

<!--en:dc114740-->
1. $\nu_1 \nu_2 = |\nu|^2 = \ell'(0)^2$ かつ $2\operatorname{Re}(\nu) = -\gamma$ より、$|1 + h\nu|^2 = 1 - h\gamma + h^2\ell'(0)^2 < 1$ $\iff$ $h < \frac{\gamma}{\ell'(0)^2} = \mathbf{4\gamma}$ である。$\gamma = 0.3$ では、同時オイラーステップは **$h < 1.2$** で収束する。

<!--en:17ba2658-->
2. $c^\star = -\frac{\mu}{1 + 4\gamma}$ より、$\gamma = 1$ とするとクリティックの傾きと局所二次近似値 $\frac{\mu^2}{4 + 16\gamma}$ はともに $1 + 4(1) = \mathbf{5\times}$ の比率（5 分の 1）に縮小する。

<!--en:3923d6bc-->

<!--en:929b7671-2-->
[理解度の確認]{.kicker}

<!--en:56978812-->
3. **Dirac-GAN におけるペアリング：**単一サンプルのロジスティック損失を相対論的ペアリング損失 $\ell(D_\psi(0) - D_\psi(\theta))$ に置き換えると、ペナルティなしの Dirac-GAN のベクトル場は変化するか。

<!--en:23db34b8-->
**解答：**

<!--en:4a9026d1-->
3. **変化しない。**$D_\psi(0) = 0$ であるため、ペアリング目的関数 $\ell(D_\psi(0) - D_\psi(\theta)) = \ell(-\psi\theta)$ は単一サンプルの目的関数 $\ell(0) + \ell(-\psi\theta)$ と定数 $\ell(0)$ しか違わず、全く同じ回転ベクトル場を生じる。
