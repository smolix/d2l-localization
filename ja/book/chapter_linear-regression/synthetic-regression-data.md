# 合成データ

<!--en:c9dd53f3-->
実世界のデータセットは雑多であり、さらに厄介なことに「解答集」が付属していない。実際の住宅データで新しいアルゴリズムを訓練して重みベクトル $\hat{\mathbf{w}}$ を得たとしても、真のデータ生成パラメータ $\mathbf{w}^*$ や削減不能なノイズフロアを知る術はない。熟練した研究者は、実装を実データに投入する前に、まず正解（ground truth）が既知のモデルから生成した*合成データ*（synthetic data）でテストする。

<!--en:007751a8-->
合成データセットでは、特徴量の分布、真の重み $\mathbf{w}^*$ とバイアス $b^*$、標本サイズ $n$、およびノイズレベル $\sigma$ を自由に制御できる。これにより、コードを直接検証する 2 つの手段が得られる。学習されたパラメータ $(\hat{\mathbf{w}}, \hat{b})$ が $(\mathbf{w}^*, b^*)$ に近づくかどうかをテストでき、また最終的な損失を理論上のノイズフロア $\frac{1}{2}\sigma^2$ と比較できる。本節では、続く 3 つの節を通して使用する合成データセットを構築し、その散布図を観察したうえで、基準となるベンチマークとして最小二乗法による当てはめを計算する。

<!--en:ad7b0083-->
## データの生成

<!--en:ef4135b1-->
手軽に可視化できるようにしつつ、複数の特徴量を扱う行列演算も実践するため、$n = 1{,}000$ 個の訓練例を $d = 2$ 個の特徴量で生成する。計画行列（design matrix）$\mathbf{X} \in \mathbb{R}^{1000 \times 2}$ は各要素を独立な標準正規分布 $X_{ij} \sim \mathcal{N}(0, 1)$ からサンプリングし、次の線形モデルからラベルを生成する。

<!--en:ceffe8eb-->
ここで、正解パラメータには次の値を用いる。

<!--en:ddd6fb7a-->
さらに、加法的なガウスノイズ $\epsilon^{(i)} \sim \mathcal{N}(0, \sigma^2)$ を標準偏差 $\sigma = 0.01$ で加える。信号 $(\mathbf{X}\mathbf{w}^* + b^*)$ が数単位のスケールで変動するのに対し、ノイズ $\sigma = 0.01$ はその数百分の 1 の大きさしかない。したがって、正常に動作するオプティマイザであれば、$\mathbf{w}^*$ と $b^*$ を数千分の 1 以内の誤差で復元できるはずである。

<!--en:11e04bc9-->
JAX は明示的な関数型の擬似乱数キーを用いるため（:numref:`sec_ndarray`）、このデータ生成器は追加の引数 `key` を 1 つ受け取り、その値は状態を持つキー補助関数 `d2l.get_key` から取得する。

<!--en:0f375d73-->
$2{,}000$ 個の例を、$\mathbf{w}^* = (2, -3.4)$、$b^* = 4.2$、$\sigma = 0.01$ を用いて生成しよう。最初の $1{,}000$ 個は訓練用に確保し、残りの $1{,}000$ 個は検証用に残しておく。検証例は訓練例とまったく同じ分布から得られるが、モデルの当てはめ中には一切使用しない。そのため、検証例で損失を評価すれば、モデルが未知のデータをどれほど正確に予測できるかがわかる。この区別については :numref:`sec_generalization_basics` で詳しく検討する。

<!--en:5245bfbb-->
`X` の各行には 2 次元の特徴ベクトルが格納され、`y` の各行には対応するスカラーのラベルが格納されている。最初のデータ例を調べ、そのノイズ $\epsilon^{(1)} = y^{(1)} - (\mathbf{w}^{*\top}\mathbf{x}^{(1)} + b^*)$ を逆算してみることで、データが正しく生成されているかを手早く確認できる。

<!--en:3ad23f9c-->
最初の例について手計算で確かめてみると、$2 x_1^{(1)} - 3.4 x_2^{(1)} + 4.2$ は $y^{(1)}$ と、微小な $\mathcal{N}(0, 0.01^2)$ の摂動の範囲内で一致する。

<!--en:27181f46-->
## データの観察

<!--en:f9f75fac-->
モデルを当てはめる前に、ラベル $y$ を各特徴量 $x_1$、$x_2$ に対して個別にプロットしてみよう。

<!--en:91fc7890-->
どちらの散布図にも、予想どおりの符号を持つ明確な線形トレンドが現れている。$y$ は $x_1$ に伴って上昇し（傾き $+2$）、$x_2$ に伴ってより急激に下降する（傾き $-3.4$）。$\sigma = 0.01$ はこれほど小さいのに、なぜ各 2D 散布図はかみそりの刃のように細い直線ではなく、太い帯のように見えるのだろうか。それは、$y$ を $x_2$ だけに対してプロットすると、各点における $x_1$ の変動が無視されるからである。プロットされていない項 $2 x_1$ は標準偏差 $2$ を持つため、点の縦方向の位置が数単位の幅を持つ帯状に広がるのである。多変数の関係を周辺化した 2D 射影として観察すると、プロットされていない座標の変動が常に見かけ上の縦方向のばらつきとして折り畳まれる。

<!--en:afe3cea8-->
## パラメータの復元

<!--en:956882f2-->
:numref:`subsec_linear-regression-analytic-solution` で閉じた形の正規方程式を導出したので、1,000 個の例に対する最小二乗法による厳密解 $(\hat{\mathbf{w}}, \hat{b})$ を、`lstsq` を拡大計画行列 $[\mathbf{X}, \mathbf{1}]$ に適用して早速計算してみよう。これにより、:numref:`sec_linear_scratch` のミニバッチ SGD が一致を目指す基準（有限標本における理想的な当てはめ）が得られる。

<!--en:7c381e18-->
ここで、実際の推定誤差を、理論的に予測される標準誤差 $\sigma / \sqrt{n}$ と並べて出力する。

<!--en:fd42669e-->
`lstsq` で経験損失を機械精度まで解いたとしても、$(\hat{\mathbf{w}}, \hat{b})$ は真の値 $(2, -3.4, 4.2)$ と小数第 4 位で異なる。このわずかなずれは数値誤差ではなく、*統計的推定誤差*（statistical estimation error）である。1,000 個のノイズの実現値 $\boldsymbol{\epsilon}$ がたまたま $\mathbf{X}$ の各列とわずかに相関し、最小二乗平面を $\sigma / \sqrt{n} = 0.01 / \sqrt{1000} \approx 3 \times 10^{-4}$ 程度の大きさだけ傾けるのである（演習問題 :exref:`ex_synthetic-regression-data-recovery-under-noise`）。これはソルバではなくデータの限界である。1 回の実行で偶然より近い値になることはあっても、ノイズを含むこれら 1,000 個の点から計算されるいかなる不偏推定量（unbiased estimator）も、これより小さい期待二乗誤差は達成できない（*クラメール・ラオの下界*、Cramér–Rao bound）。また、演習問題 :exref:`ex_synthetic-regression-data-misspecified` で調べるように、真のデータ生成関数が非線形である場合、最小二乗法は特徴量の分布上でその関数に対する最良の線形近似を求める。

<!--en:30ac03ff-->
## まとめ

<!--en:80072e72-->
既知の線形モデル $\mathbf{y} = \mathbf{X}\mathbf{w}^* + b^* + \boldsymbol{\epsilon}$ から、$\mathbf{w}^* = (2, -3.4)^\top$、$b^* = 4.2$、$\sigma = 0.01$ を用いて合成データを生成すると、実データにはない 2 つの定量的検証手段が得られる。すなわち、$\frac{1}{2}\sigma^2 = 5 \times 10^{-5}$ という削減不能な損失の下限と、既知の正解パラメータである。$y$ を単一の座標 $x_j$ に対してプロットすると、プロットされていない特徴量の変動が縦方向の広がりに折り畳まれ、ほぼノイズのない平面が幅広い 2D の帯に変わる。最小二乗法の厳密ソルバであっても、$(\mathbf{w}^*, b^*)$ からオーダー $\sigma/\sqrt{n}$（$\approx 3 \times 10^{-4}$、$n = 1{,}000$ の場合）の統計的推定誤差だけずれるため、これが次節における反復的な最適化の精度目標となる。

    1. $n$ のうち、計測値が $\sigma/\sqrt{n}$ と 10% 以内で一致する最小の値を求め、それより少ない例数ではこの予測の背後にあるどの近似が破綻するかを述べよ。
    1. $\tilde{\mathbf{X}} = [\mathbf{X}, \mathbf{1}]$、$\tilde{\mathbf{w}}^* = (\mathbf{w}^*, b^*)$、$\hat{\tilde{\mathbf{w}}} = (\hat{\mathbf{w}}, \hat{b})$ とおく。正規方程式から $\hat{\tilde{\mathbf{w}}} - \tilde{\mathbf{w}}^* = (\tilde{\mathbf{X}}^\top\tilde{\mathbf{X}})^{-1}\tilde{\mathbf{X}}^\top\boldsymbol{\epsilon}$ を示し、そこから $\textrm{Cov}(\hat{\tilde{\mathbf{w}}}) = \sigma^2(\tilde{\mathbf{X}}^\top\tilde{\mathbf{X}})^{-1}$ を導出せよ。次に、相関を持つ特徴量 $x_2 = \rho x_1 + \sqrt{1 - \rho^2}\, z$（ただし $x_1$ と $z$ は独立な標準正規分布に従う）を $\rho \in \{0, 0.9, 0.99\}$ に対して生成せよ。この式から $\hat{w}_1$ の標準誤差を予測して数値的に確認し、重みが不正確であるにもかかわらず、同じ分布から得られた新しい例に対する予測 $\hat{\tilde{\mathbf{w}}}^\top \tilde{\mathbf{x}}$（ただし $\tilde{\mathbf{x}} = (\mathbf{x}, 1)$）が正確であり続ける理由を説明せよ。

<!--en:7fb8973a-->
1. [code] **適合しないモデル。** ● すべてのラベルに項 $c\,x_1^2$（$c = 0.5$）を加えてラベルが特徴量の線形関数に従わないようにし、本節と同様に最小二乗法で線形モデルを当てはめよ。
    1. $\mathbb{E}[x_1^2] = 1$ および $\mathbb{E}[x_1^3] = 0$ を用いて、$\hat{w}_1$、$\hat{w}_2$、$\hat{b}$ のうちどれが真の値から離れるか、またどの程度離れるかを予測せよ。

    1. 標準誤差の約 3 倍にあたる $10^{-3}$ を超えるパラメータ誤差を検出するテストは、本節のデータ上では正しい実装を合格と判定する。このデータ上では、正しい実装に欠陥があると判定するだろうか。モデルがデータに適合していないとき、このようなテストの合否から何がわかるかを説明せよ。

<!--en:b667324b-->
1. **損失の下限とその変動。** 次節では、1,000 個の検証例にわたる $\frac{1}{2}(\hat{y} - y)^2$ の平均である検証損失によって訓練の実行結果を評価する。

- **標本サイズに対する平方根スケーリング：**推定誤差を $10\times$ 縮小するには $100\times$ 多くの訓練例（$n = 100{,}000$）が必要になる一方、$\sigma$ を $10\times$ 縮小すれば誤差も直ちに $10\times$ 縮小する

<!--en:ba157fba-->
- **厳密な共分散：**$\operatorname{Cov}(\hat{\tilde{\mathbf{w}}} \mid \tilde{\mathbf{X}}) = \sigma^2 (\tilde{\mathbf{X}}^\top\tilde{\mathbf{X}})^{-1}$ は特徴量が多重共線性を持つときに増大する

<!--en:3cc55571-->
::: {.slide title="コードによる最小二乗法の基準解の検証"}

<!--en:bad5a28e-->
[基準となるベンチマーク]{.kicker}

<!--en:a6d08a77-->
$n = 1{,}000$ 個の訓練例に対して `lstsq` で正規方程式を解き、実際のパラメータ誤差を $\sigma / \sqrt{n} \approx 3 \times 10^{-4}$ と比較する。

<!--en:a571df4e-->
- **合否の許容誤差：**本章で収束した反復オプティマイザはすべて、$\sim 10^{-3}$（$\approx 3\text{ SE}$）の範囲内で $(\mathbf{w}^*, b^*)$ に到達しなければならない

<!--en:c26d20c4-->
::: {.slide title="理解度チェック：損失の下限・標本サイズ・多重共線性"}

<!--en:929b7671-->
[理解度の確認]{.kicker}

<!--en:a53f3b8a-->
この合成ベンチマークに以下の変更を加えたときの定量的な影響を予測してみよう。

<!--en:bf23bb97-->
1. **標本サイズ対ノイズ：**$\hat{w}_1$ の標準誤差は、(a) $n = 100, \sigma = 0.01$ のとき、および (b) $n = 1{,}000, \sigma = 0.1$ のとき、それぞれいくらか。

<!--en:8c48b484-->
2. **定式化から漏れた二次項：**真のラベルが $y = 2x_1 - 3.4x_2 + 4.2 + 0.5x_1^2 + \epsilon$（ただし $x_1, x_2 \sim \mathcal{N}(0, 1)$）で生成され、線形モデル $\hat{y} = w_1 x_1 + w_2 x_2 + b$ を当てはめるとする。モデル化されていない項 $0.5x_1^2$ は、$n \to \infty$ のときどのパラメータに吸収されるか。

<!--en:628ea3a3-->
3. **相関する特徴量：**$x_2 = 0.99 x_1 + \sqrt{1 - 0.99^2}\,z$ のとき、個々の重みの誤差 $|\hat{w}_j - w_j^*|$ は $\sim 7\times$ に膨れ上がるのに、同じ分布からの新しいテスト点に対する予測 $\hat{\mathbf{w}}^\top\mathbf{x}$ が正確であり続けるのはなぜか。

<!--en:557b98b6-->
**解答：**

<!--en:ca2b99de-->
1. (a) $\sigma / \sqrt{n} = 0.01 / \sqrt{100} = 10^{-3}$、(b) $0.1 / \sqrt{1000} \approx 3.16 \times 10^{-3}$。

<!--en:b068f1be-->
2. $\mathbb{E}[x_1^2] = 1$ かつ $\mathbb{E}[x_1 \cdot x_1^2] = \mathbb{E}[x_1^3] = 0$ より、二次項 $0.5x_1^2$ は $x_1$ および $x_2$ と直交するがラベルの平均を $+0.5$ だけ移動させるため、$\hat{b} \to 4.2 + 0.5 = 4.7$ となる一方、$\hat{\mathbf{w}} \to (2, -3.4)^\top$ となる。

<!--en:b38b5dce-->
3. $x_1 \approx x_2$ のとき、差の方向 $x_1 - x_2$ の分散は微小（$1 - \rho = 0.01$）となり $\operatorname{Var}(\hat{w}_1 - \hat{w}_2)$ を増大させるが、同じ分布からの新しいテスト点でも $x_1 \approx x_2$ が成り立つため、精度よく定まる和 $\hat{w}_1 + \hat{w}_2$ の方向しか参照されない。
