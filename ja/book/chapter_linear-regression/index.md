# 線形回帰

<!--en:6c9e1436-->
*回帰*（regression）は、床面積と築年数からの住宅販売価格の推定、バイタルサインからの患者の入院期間の予測、次の四半期の電力需要の予測のように、対象が離散的なカテゴリではなく意味のある数値であるあらゆる場面で、定量的な予測の主力となる。また、深層学習にとっても理想的な検証の場である。ニューラルネットワークの訓練を構成する要素、すなわちパラメータ化された順伝播、最尤法に基づく損失関数、ミニバッチ確率的勾配降下法、再利用可能な訓練ハーネス、汎化の診断、そして重みノルムによる正則化のほぼすべてが、*線形回帰*（linear regression）において最も単純で見通しのよい形で、すでに現れている。

<!--en:6749e303-->
まず :numref:`sec_linear_regression` では、アフィンモデルと二乗誤差損失を定式化し、直交射影による閉形式の解法とミニバッチ確率的勾配降下法（SGD）による反復的な解法の両方でこの問題を解いたうえで、二乗損失をガウス分布の下での最尤法と結びつける。実データを扱う前に、:numref:`sec_synthetic-regression-data` では既知の正解パラメータ $(\mathbf{w}^*, b^*)$ とノイズレベル $\sigma$ をもつ合成データのベンチマークを構築し、コードを検証するための厳密な基準を用意する。続く 3 つの節では、訓練パイプラインを段階的に構築していく。まず生のテンソルと自動微分（automatic differentiation）のみから実装し（:numref:`sec_linear_scratch`）、次に本書の以降の章を支える再利用可能な `Module`、`DataModule`、`Trainer` クラスへと整理し（:numref:`sec_oo-design`）、最後にフレームワークの高水準な層とオプティマイザを用いてわずか数行で表現する（:numref:`sec_linear_concise`）。

<!--en:210521c9-->
訓練データへの当てはめは、問題の半分にすぎない。:numref:`sec_generalization_basics` では多項式曲線フィッティングを題材に、訓練誤差と汎化誤差（generalization error）を切り分け、期待テスト誤差を統計的バイアスの二乗、分散、ノイズへと分解したうえで、テストデータを覗き見ることなく検証データへの分割や $K$ 分割交差検証（cross-validation）によってモデルの複雑さを選択する方法を示す。最後に :numref:`sec_weight_decay` では、二乗 $\ell_2$ ペナルティを加えることで高次元における過学習（overfitting）を抑え、重み減衰（weight decay）が訓練入力からは十分に定まらない方向を選択的に縮小させる仕組みを明らかにする。

- **パラメータ化された順伝播と損失：**予測は $\hat{y} = \mathbf{w}^\top \mathbf{x} + b$ で計算し、ガウス分布の下での最尤法に基づく $L(\mathbf{w}, b) = \frac{1}{2n}\|\mathbf{X}\mathbf{w} + b - \mathbf{y}\|_2^2$ で当てはまりの悪さを評価する

<!--en:ade204c0-->
- **厳密な閉形式とスケーラブルな反復法：**正規方程式 $\mathbf{X}^\top\mathbf{X}\mathbf{w}^* = \mathbf{X}^\top\mathbf{y}$ は $\mathbf{y}$ を $O(nd^2 + d^3)$ で直交射影するのに対し、ミニバッチ SGD はステップごとに $O(|\mathcal{B}|d)$ で更新する

<!--en:03fa90b0-->
- **繰り返し現れる 2 つの失敗モード：**エラーを出さない形状バグ（$(32,) - (32, 1) \to 32 \times 32$）があっても損失は下がり、ノイズを含む 20 点を補間する高次多項式は新しいデータで破綻する

- **理論と合成オラクル：**アフィンモデル、二乗損失、正規方程式、ミニバッチ SGD を定式化し、既知の正解 $(\mathbf{w}^*, b^*)$ とノイズフロア $\sigma^2/2$ に照らして検証する

<!--en:ecdd1c6c-->

<!--en:6686eb27-->
- **汎化と重み減衰：**バイアス・分散と $K$ 分割交差検証により学習不足と過学習を診断し、$\ell_2$ リッジ縮小で共線性によるノイズを抑える

<!--en:acad204f-->
- **射影と合成テストベッド：**3 点 $(0,1),(1,1),(2,0)$ への直線当てはめでは $\hat{\mathbf{w}} = (7/6, -1/2)^\top$ かつ $\mathbf{X}^\top\mathbf{r} = \mathbf{0}$ となり、$n = 1{,}000$ 個の例（$\mathbf{w}^* = (2, -3.4)^\top, b^* = 4.2, \sigma = 0.01$）では損失が $16.6$ から $\sigma^2/2 = 5 \times 10^{-5}$ まで減少する

<!--en:f8c01af4-->
- **多項式曲線フィッティング（$n = 20$）：**三次関数のノイズ付きサンプル（$\sigma = 0.1$）に対し、次数 $1$ は学習不足になり、次数 $3$ は $\sigma^2 = 0.01$ に達し、次数 $19$ は爆発する

<!--en:7d373300-->
- **高次元リッジ回帰（$d = 200, n = 300$）：**事前分布に基づくペナルティ $\lambda = \sigma^2/(n\tau^2) = 1/3$ により、有効パラメータ数は $\operatorname{df} \approx 127$ に縮小する

多層パーセプトロンから Transformer に至るまで、本書の以降の章で扱うすべてのモデルは、本章で構築するパイプラインをそのまま再利用する。

<!--en:9797c31e-->
- **順伝播と損失（`Module`）：**ミニバッチ入力 $\mathbf{X} \in \mathbb{R}^{|\mathcal{B}| \times d}$ を予測 $\hat{\mathbf{y}}$ へ写像し、ペナルティ付き経験損失 $L_{\mathcal{B}}(\mathbf{w}, b) + \frac{\lambda}{2}\|\mathbf{w}\|_2^2$ を評価する

<!--en:b3aa3992-->
- **逆伝播と更新（`Trainer`）：**リバースモード自動微分で $L_{\mathcal{B}}$ を微分し、$(\mathbf{w}, b) \leftarrow (\mathbf{w}, b) - \eta \nabla L_{\mathcal{B}}$ によりパラメータを更新する

<!--en:40a2f71b-->
- **検証と選択（`DataModule`）：**エポックごとにホールドアウトリスクを追跡し、テストデータをリークさせることなくハイパーパラメータ $(\eta, |\mathcal{B}|, \lambda)$ を調整する

<!--en:462821b0-->
ニューラルネットワークとして見れば、線形回帰は $d$ 個の入力と $1$ 個の線形出力ニューロンをもつ単一の全結合層である。
