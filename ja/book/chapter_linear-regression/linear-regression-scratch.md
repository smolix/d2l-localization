# 線形回帰のスクラッチ実装

<!--en:6c096796-->
線形回帰の理論（:numref:`sec_linear_regression`）と、既知の正解パラメータを持つ合成データセット（:numref:`sec_synthetic-regression-data`）が揃ったところで、いよいよこの両方をコードに落とし込んでいこう。本節では、基本的なテンソル演算と自動微分（automatic differentiation）のみに頼り、パラメータの初期化、線形の順伝播、二乗損失、自動微分、ミニバッチのイテレータ、SGD の更新ループといった訓練パイプラインのすべての構成要素をスクラッチで構築する。各ステップを手書きすることでブラックボックス化された仕組みが取り払われ、勾配がどのように流れ、学習率などのハイパーパラメータが収束をどのように左右するかが明確に見えてくる。全体の仕組みが明らかになった後、:numref:`sec_oo-design` ではこれらの構成要素を再利用可能なクラス（`Module`、`DataModule`、`Trainer`）へと整理し、さらに :numref:`sec_linear_concise` ではフレームワークの層、組み込みの損失関数、オプティマイザを用いて同じモデルをわずか数行で書き直す。

<!--en:1396cf9a-->
## モデル、損失、勾配

<!--en:ddf0cb95-->
まず、$2{,}000$ 個の合成データ例（訓練用に $1{,}000$ 個、検証用に $1{,}000$ 個）を、真のパラメータ $\mathbf{w}^* = (2, -3.4)^\top$、$b^* = 4.2$、ノイズ $\sigma = 0.01$ で生成しよう。

<!--en:4eeafb8a-->
### パラメータ

<!--en:0c91ca15-->
このモデルは、重みベクトル $\mathbf{w} \in \mathbb{R}^2$ とスカラーのバイアス $b \in \mathbb{R}$ を持つ。重みは $\mathcal{N}(0, 0.01^2)$ からの小さな乱数で初期化し、バイアスは $0$ に設定する（線形回帰ではすべて 0 から始めても同様に機能するが、これについては演習問題 :exref:`ex_linear-regression-scratch-initialization` を参照のこと。ただし、:numref:`chap_perceptrons` で隠れ層を積み重ねるようになると、ランダムな重みで対称性を破ることが不可欠になる）。

<!--en:18f3ed98-->
両方のテンソルに `requires_grad=True` を設定し、これらに関わるすべての演算を PyTorch の autograd エンジンが記録するようにする。

<!--en:b9d0e3cc-->
両方のパラメータに対して `attach_grad()` を呼び出して勾配バッファを確保し、`autograd.record()` 内の演算を追跡するよう MXNet に指示する。

<!--en:e4c67612-->
両方のテンソルを `tf.Variable` でラップする。これにより、TensorFlow の `GradientTape` がそれらを自動的に監視するようになる。

<!--en:4e829160-->
JAX の配列はイミュータブルな値である。`jax.grad` は配列上のフラグを書き換えることなく、純粋関数をその引数に関して直接微分する。

<!--en:9a7f0043-->
### 順伝播

<!--en:ac1c3252-->
ミニバッチの計画行列（design matrix）$\mathbf{X} \in \mathbb{R}^{|\mathcal{B}| \times d}$、パラメータ $\mathbf{w} \in \mathbb{R}^{d \times 1}$、およびスカラーのバイアス $b$ が与えられたとき、線形予測 $\hat{\mathbf{y}} = \mathbf{X}\mathbf{w} + b$ は 1 回の行列とベクトルの積にブロードキャストによる加算を足し合わせたものになる。

<!--en:762f27d1-->
### 損失

<!--en:348530b5-->
次に、平均二乗誤差（mean squared error）$L(\mathbf{w}, b) = \frac{1}{2|\mathcal{B}|}\sum_{i \in \mathcal{B}} (\hat{y}^{(i)} - y^{(i)})^2$ を実装する。`y` を列ベクトル `(-1, 1)` に変形して `y_hat` の形状に揃える。もし一方のテンソルの形状が `(n, 1)` で他方が `(n,)` だった場合、両者を減算すると暗黙のうちにブロードキャストされ、すべてのペアごとの差からなる `(n, n)` 行列になってしまう。このバグが厄介なのは、訓練自体はエラーにならずに進んでしまう点である。$n^2$ 個すべての二乗差の平均は、すべての予測がラベルの平均に等しいときに最小となるため、SGD は $\mathbf{w}$ を $\mathbf{0}$ へ、$b$ を $\bar{y}$ へと向かわせ、損失はラベルの分散の半分（このデータでは $\frac{1}{2}(2^2 + 3.4^2) \approx 7.8$）まで滑らかに減少する。したがって、損失曲線が下がっているだけでは、コードが正しいことの弱い証拠にしかならない。本節の後半では、損失が到達すべき値に達しているか、またパラメータが真の値と一致しているかを検証する。

<!--en:699278a4-->
### 勾配

<!--en:7ced92d2-->
自動微分に処理を任せる前に、32 個の例からなる 1 つのミニバッチを用いて、自動微分が :numref:`subsec_linear-regression-minibatch-sgd` で手計算により導出した次の式と同じ勾配を算出することを確認しておこう。

<!--en:a0c1cb57-->
最初の 32 個の訓練例 `(Xb, yb)` をスライスして取り出し、解析的な勾配と自動微分による勾配を比較してみよう。

<!--en:be03f928-->
要素ごとの最大の差は 0（高々 $\sim 10^{-7}$、すなわち `float32` の丸め精度）であり、autograd が期待どおりのミニバッチ勾配を計算していることが確認できる。ここからは、順伝播と損失の微分をフレームワークに自動で任せることにする。

<!--en:d5d9a066-->
## スクラッチからの訓練

<!--en:0a21023b-->
### 更新

<!--en:03d148cf-->
各ステップでは、$(\mathbf{w}, b) \leftarrow (\mathbf{w}, b) - \eta\,(\nabla_{\mathbf{w}} L, \nabla_b L)$ のようにパラメータをその勾配と逆方向に更新する。このとき、パラメータ更新そのものを計算グラフ（computational graph）に記録しないよう注意する。

<!--en:5573628b-->
### ミニバッチ

<!--en:6b6d15f0-->
データセット全体をサイズ $|\mathcal{B}|$ のランダムなミニバッチで一巡するため、ジェネレータ `minibatches` は各エポックの開始時にインデックス $0, \ldots, n - 1$ の新しいランダムな順列を生成し、サイズ `batch_size` の連続するスライスを順に返す（演習問題 :exref:`ex_linear-regression-scratch-why-reshuffle`）。

<!--en:d3378927-->
$1{,}000$ 個の訓練例と `batch_size=32` の場合、1 エポックで $\lceil 1000 / 32 \rceil = 32$ 個のミニバッチが得られる。内訳は、フルサイズのバッチが $31$ 個（各 $32$ 例）と、端数のバッチが 1 個（$8$ 例）である。このジェネレータを 1 回走査して中身を確認し、誤って*同じ*ジェネレータを 2 回目に反復処理するとどうなるか見てみよう。

<!--en:99101c97-->
返される各ペア `(Xb, yb)` の形状は `(32, 2)` と `(32, 1)` である。1 回目の走査（1 *エポック*）では期待どおり $32$ 個すべてのミニバッチが返されるが、2 回目の走査では 0 個になる。Python のジェネレータは使い切りであり、一度消費されると何も警告を出さずに空になる。訓練ループで各エポックの開始時に毎回新しく `minibatches(...)` を呼び出すのはこのためである。

<!--en:b53114de-->
### 訓練ループ

<!--en:002ca26c-->
ここで、完全な訓練ループを `train(lr, num_epochs, batch_size)` として組み立てよう。各エポックでは `minibatches(X, y, batch_size)` を反復処理し、ミニバッチの損失を計算して `w` と `b` に関して微分し、SGD のステップを適用する。

<!--en:ce25bb1f-->
PyTorch は新しい勾配を保存済みの勾配に上書きせず加算するため（:numref:`sec_autograd`）、ループの最後で各勾配をクリアする。

<!--en:23eb57f1-->
中核となる訓練ループはわずか 12 行ほどのコードにすぎず、この同じ 4 つのステップ（順伝播 $\rightarrow$ 損失 $\rightarrow$ 逆伝播 $\rightarrow$ パラメータ更新、:numref:`fig_linreg_sgd_cycle` に図示）が、本書の残りの章で扱うあらゆる深層ネットワークを訓練する。

<!--en:eea94d0a-->
![ミニバッチ SGD の 1 ステップ。順伝播でミニバッチに対する予測を計算し、損失でそれを 1 つの数値に集約し、逆伝播でその数値をパラメータに関して微分し、更新ステップでパラメータを勾配と逆方向に動かす。その後、次のミニバッチでこのサイクルを繰り返す。](../img/mdl-linreg-sgd-cycle.svg)

## 実装の検証

<!--en:c974d439-->
### 損失の期待値

<!--en:8504ecd2-->
訓練が成功したとき、損失はどこまで小さくなるべきだろうか。真のパラメータ $(\mathbf{w}^*, b^*)$ においてさえ、残差はガウスノイズ $\hat{y}^{(i)} - y^{(i)} = -\epsilon^{(i)} \sim \mathcal{N}(0, \sigma^2)$ に等しいため、損失の期待値は次の*削減不能なノイズフロア*（irreducible noise floor）となる。

<!--en:bac96f95-->
対照的に、初期化時点（$\mathbf{w} \approx \mathbf{0}, b = 0$）での残差は $-y = -(\mathbf{x}^\top\mathbf{w}^* + b^* + \epsilon)$ であり、その平均は $-b^* = -4.2$、分散は $\|\mathbf{w}^*\|_2^2 + \sigma^2 = 2^2 + (-3.4)^2 + 0.01^2 = 15.5601$ である。したがって、初期損失の期待値は次のようになる。

<!--en:151e1dda-->
したがって、訓練を通じて損失は約 $16.6$ からノイズフロアの $0.00005$ まで、5 桁にわたって急落すると予想される。

<!--en:6b0922c6-->
同じ計算から、損失がどのくらい*速く*減少するかも予測できる。任意のパラメータにおいて、残差は $r = \mathbf{x}^\top(\mathbf{w} - \mathbf{w}^*) + (b - b^*) - \epsilon$ となる。2 つの特徴量は互いに独立に標準正規分布に従い、ノイズもその両方と独立であるため、すべての交差項の期待値は 0 となり、次式が成り立つ。

<!--en:7de38882-->
この損失の期待値の $(\mathbf{w}, b)$ に関する勾配は、単に*パラメータ誤差*（parameter error）$(\mathbf{w} - \mathbf{w}^*, b - b^*)$ となる。そのため、サイズ $\eta$ の勾配ステップによってパラメータ誤差は $1 - \eta$ 倍に縮小し、ノイズフロアを上回る*過剰損失*（excess loss）は $(1 - \eta)^2$ 倍に縮小する。ミニバッチ勾配が期待勾配と一致するのは平均的な意味においてのみであるため、これは厳密な恒等式ではなく近似的な軌跡を与える。$\eta = 0.03$ のとき、$32$ 回のミニバッチ更新からなる 1 エポックで、過剰損失は約 $1 / (1 - 0.03)^{64} \approx 7$ 分の 1 に減少するはずである。

<!--en:cd477beb-->
### 訓練の実行

<!--en:b042a525-->
`train` を 10 エポックにわたり学習率 $\eta = 0.03$、ミニバッチサイズ $|\mathcal{B}| = 32$ で実行し、各エポック後の検証損失を対数スケールでプロットしてみよう。

<!--en:4c17ff8c-->
予想どおり、検証損失は直線に沿って急落し、エポックごとに約 $7\times$ の割合で減少した後、7〜8 エポック目あたりで予測された下限である $5 \times 10^{-5}$ 付近に収まって横ばいになる。最初の 7 エポックにわたり、実測された過剰損失を閉形式による予測とエポックごとに比較してみよう。

<!--en:079d514b-->
実測された過剰損失と予測された過剰損失は、序盤のエポックでは緊密に一致して推移し、その後少しずつ離れていくものの、7 エポック目でも高々 3〜4 倍程度の控えめな差にとどまる。なぜこのようなわずかなドリフトが生じるのだろうか。ここでの理想化した予測では、標本共分散行列（sample covariance matrix）$\mathbf{H} = \frac{1}{n}\sum_i \tilde{\mathbf{x}}^{(i)}(\tilde{\mathbf{x}}^{(i)})^\top$（演習問題 :exref:`ex_linear-regression-scratch-stability` を参照）が厳密に単位行列に等しいと仮定していた。$1{,}000$ 個の例からなる有限標本では、その固有値はおよそ $10\%$ の範囲内で $1$ の近くに収まっており、数エポックにわたってこの小さなずれが積み重なることで、実際の訓練は理想化した予測よりわずかに先行したり遅れたりするのである。減衰率とノイズフロアはいずれも理論と一致している。

<!--en:4312a4f3-->
### 復元されたパラメータ

<!--en:f9d55cac-->
このデータセットは合成データであるため、学習された $(\mathbf{w}, b)$ を真のパラメータ $\mathbf{w}^* = (2, -3.4)^\top$ および $b^* = 4.2$ と直接比較することもできる。

<!--en:6ec9bfe6-->
重みとバイアスはいずれも 1,000 分の 1 以内の誤差で復元されており、これは統計的推定の下限 $\sigma / \sqrt{n} \approx 3 \times 10^{-4}$（:numref:`sec_synthetic-regression-data` で最小二乗法のソルバを用いて確認した値）と一致している。

<!--en:f319e23f-->
### 学習率

<!--en:0236cbb5-->
学習率の選び方が適切でなかった場合はどうなるだろうか。まったく同じ 10 エポックのループを、3 桁にわたる 4 つの学習率 $\eta \in \{0.003, 0.03, 0.3, 3\}$ で実行し、それぞれの最終的な検証損失を表示してみよう（演習問題 :exref:`ex_linear-regression-scratch-stability`）。

<!--en:1ad5d5bb-->
結果はすべてのケースで理論と一致している。$\eta = 0.003$ では、誤差が 1 ステップあたり $0.997$ 倍にしかならないため、10 エポック後の損失は $2$ から $3$ 付近にとどまる（$16.6 \times 0.997^{640} \approx 2.4$ のすぐ近くである）。$\eta = 0.3$ では、最初の 1 エポックのうちにモデルが一気にノイズフロアまで到達する。そして $\eta = 3$ では、更新のたびに誤差が符号を反転させながら約 2 倍に膨れ上がり、たちまちオーバーフローして `nan` になる。なお、安定性の上限である $2$ という値は SGD の普遍的な定数ではなく、ここでの*データのスケーリング*に由来する性質であることに注意したい。これは、特徴量の分散が 1 であることから生じている。ある特徴量を $s > 1$ 倍にスケーリングすると、対応する重み方向の損失の曲率は $s^2$ 倍になり、安定な最大学習率は約 $2 / s^2$ まで縮小する。これが、訓練前に入力特徴量を標準化する実用上の大きな理由の 1 つである（:numref:`sec_pandas`）。

<!--en:d1b55dc8-->
続く :numref:`sec_oo-design` では、今構築した訓練の仕組みを再利用可能なオブジェクト指向のクラス（`Module`、`DataModule`、`Trainer`）にまとめ、:numref:`sec_linear_concise` では手書きのテンソル、損失、更新処理をフレームワークの既製コンポーネントに置き換える方法を示す。

<!--en:30ac03ff-->
## まとめ

<!--en:b48c5d36-->
完全な訓練ループに必要な基本要素は、パラメータ化された順伝播 $\hat{\mathbf{y}} = \mathbf{X}\mathbf{w} + b$、スカラーの損失 $\frac{1}{2|\mathcal{B}|}\|\hat{\mathbf{y}} - \mathbf{y}\|_2^2$、リバースモード自動微分（reverse-mode automatic differentiation）、そして勾配の記録対象外で実行するミニバッチ SGD の更新という 4 つだけである。損失曲線が下がっているだけではコードにバグがないことの証明にはならないため（暗黙の形状の不一致があっても、損失はラベルの分散の半分に向かって下がりうる）、合成データを用いて実装を定量的に検証した。すなわち、検証損失は予測されたエポックあたり $(1 - \eta)^{64}$ の割合でノイズフロア $\frac{1}{2}\sigma^2 = 5 \times 10^{-5}$ まで指数関数的に減衰し、学習されたパラメータは $(\mathbf{w}^*, b^*)$ と $O(\sigma/\sqrt{n})$ の範囲内で一致する。学習率を変えると、小さなステップサイズでは進行が遅く、適度なステップサイズでは素早くノイズフロアに到達し、$2/\mu_{\max}$ を超えるステップサイズでは二次関数の谷を飛び越えて発散する。

    1. フルバッチの勾配降下法において、各ステップがパラメータと最小二乗法による解との差に行列 $\mathbf{I} - \eta \mathbf{H}$ を掛けることを示せ。ここで $\mathbf{H}$ は、訓練セット全体での $\tilde{\mathbf{x}}\tilde{\mathbf{x}}^\top$ の平均である。$\mathbf{H}$ の固有値を計算し、安定な最大学習率を予測せよ。
    1. サイズ 1,000、32、1 のミニバッチで訓練し、各実行の更新回数を同じ値（たとえば 320 回）に揃えよ。各ミニバッチサイズについて、任意に選んだグリッド上で最終的な訓練損失が $10^{-3}$ 未満となる最大の学習率を求めよ。
    1. 単一の例に対する 1 ステップが、パラメータ誤差の $\tilde{\mathbf{x}}$ 方向の成分を $1 - \eta \|\tilde{\mathbf{x}}\|^2$ 倍にすることを示し、$\mathbb{E}\|\tilde{\mathbf{x}}\|^2 = 3$ を用いてサイズ 1 のミニバッチで見られた限界を説明せよ。
   :exlabel:`ex_linear-regression-scratch-stability`

<!--en:74705400-->
1. **なぜ再シャッフルするのか。**`minibatches` は毎エポック新しいランダムな順序を生成する。これによってミニバッチ勾配のどの性質が保たれるかを説明せよ。次に、ラベル順のソートなど、再シャッフルなしのミニバッチ SGD が異なる振る舞いを示す訓練セットの固定順序を 1 つ構成し、1 エポック内および複数エポックにわたる $(\mathbf{w}, b)$ の軌跡を記述せよ。
   :exlabel:`ex_linear-regression-scratch-why-reshuffle`

<!--en:7ff3e9e9-->
1. [code] **ロバストな損失。** ● `squared_loss` を平均絶対誤差 `d2l.reduce_mean(d2l.abs(y_hat - d2l.reshape(y, (-1, 1))))` に置き換えよ。
    1. 合成データ上で訓練し、復元されたパラメータおよび損失曲線を二乗損失の場合と比較せよ。
    1. :numref:`subsec_linear-regression-loss-function` で用いた外れ値と同じく 1 つの訓練ラベルを $y^{(5)} = 10{,}000$ に設定し、両方の損失で訓練せよ。ミニバッチ更新ごとに $b$ を記録して両方の実行について反復回数に対してプロットし、最終的な値を決める要因を含めて二乗損失の曲線のパターンを説明せよ。
    1. 外れ値を含むデータに対して、損失を次のフーバー損失のミニバッチ平均に置き換えよ。

        $$l_\delta(y, y') = \begin{cases}\frac{1}{2}(y-y')^2 & \textrm{ if } |y-y'| \leq \delta \\ \delta \left(|y-y'| - \frac{\delta}{2}\right) & \textrm{ otherwise,}\end{cases}$$

        この二次関数の部分は、本節の二乗損失と一致している。$\delta \in \{1, 10, 10^2, 10^3, 10^4\}$ に対して訓練し、学習されたバイアスと真のバイアスとの距離 $|\hat{b} - b^*|$（ここで $b^* = 4.2$ はデータ生成時のバイアス）を $\delta$ に対して両対数軸でプロットせよ。$l_\delta$ の $y'$ に関する導関数から曲線の形状を説明し、その結果を :numref:`fig_linreg-loss-menu` のペナルティ曲線と関連づけよ。

- **暗黙のブロードキャストのバグ：**1 次元のラベルテンソル `y`（形状 `(32,)`）を `y_hat`（形状 `(32, 1)`）から減算すると、全 $1{,}024$ 通りのペアごとの差を持つ `(32, 32)` 行列へブロードキャストされる

<!--en:f92390c6-->

<!--en:53c48109-->
- **二重の検証：**検証損失の下限（$\frac{1}{2}\sigma^2 = 5 \times 10^{-5}$）とパラメータの復元（$\|\hat{\mathbf{w}} - \mathbf{w}^*\|_\infty \lesssim 10^{-3}$）の両方を必ず確認する

- **厳密な一致：**リバースモードの `autograd` を $\nabla_{\mathbf{w}} L_{\mathcal{B}} = \frac{1}{|\mathcal{B}|}\mathbf{X}^\top\mathbf{r}$ および $\partial_b L_{\mathcal{B}} = \frac{1}{|\mathcal{B}|}\mathbf{1}^\top\mathbf{r}$ と比較し、`float32` のマシンイプシロン（$\sim 10^{-7}$）の精度で一致することを確認する

<!--en:4ab5cc17-->

[確率的サンプリングの不変条件]{.kicker}

<!--en:35b439d3-->
- **不偏性にはランダムサンプリングが必要：**一様にサンプリングされたミニバッチは $\mathbb{E}[\nabla L_{\mathcal{B}}] = \nabla L$ を満たし、バッチ平均 $\bar{y}_{\mathcal{B}} \approx 4.2 \pm 0.7$ によって $b$ は $b^* = 4.2$ へ向かって着実に上昇する

<!--en:4a84ee4c-->
- **ソート済みデータの弊害：**例がラベル順にソートされていると、バッチ 1 が最も負に大きい 32 個のラベル（$\bar{y}_{\mathcal{B}} \approx -4.6$）を占めるため、$b$ を下向きに押し下げて $4.2$ から*遠ざけ*、パラメータが毎エポック激しく振動する

- **初期の過剰損失：**$(\mathbf{0}, 0)$ 付近から始めると初期損失は $\frac{1}{2}(2^2 + (-3.4)^2 + 4.2^2) \approx 16.6$ であり、これは $5$ 桁以上もノイズフロア $\frac{1}{2}\sigma^2 = 5 \times 10^{-5}$ より大きい

<!--en:ea4970a5-->
- **エポックあたりの縮小率（$32$ ステップ、$\eta = 0.03$）：**各ステップでパラメータ誤差は $(1 - \eta) = 0.97$ 倍、過剰損失は $0.97^2$ 倍になるため、1 エポックで過剰損失は $0.97^{64} \approx 1/7$ 倍に縮小する（**エポックあたり $7\times$**）

<!--en:b6bfb9ed-->

<!--en:8e013550-->

次の 3 つのシナリオで、訓練ループの仕組みに関する理解を確認しよう。

<!--en:5e4cecdf-->
1. **`zero_grad()` の書き忘れ：**訓練ループ内で `param.grad.zero_()` を省略すると、ステップ $t$ では `param` からどのベクトルが減算され、二次関数の谷（ボウル）上で反復列はどのように振る舞うか。

<!--en:eed58c33-->
2. **和の損失と平均の損失：**損失関数が、*和* $\sum_{i \in \mathcal{B}} (\hat{y}^{(i)} - y^{(i)})^2$ をサイズ $|\mathcal{B}| = 32$ のミニバッチ上で（$2|\mathcal{B}|$ で割らずに）計算するとする。どの学習率 $\eta$ を選べば、$\eta_{\textrm{scratch}} = 0.03$ でのスクラッチ実装のステップを再現できるか。

<!--en:ce98df1a-->
3. **再スケーリングした特徴量の安定性：**特徴量 $x_1$ を $10$ 倍すると（分散が $100$ になり、元の $1$ から変化する）、安定な最大学習率 $\eta_{\max}$ はどうなるか。

<!--en:557b98b6-->
**解答：**

<!--en:9f78f5fc-->
1. 勾配をクリアしないと、ステップ $t$ では $\eta \sum_{s=1}^t \mathbf{g}_s$（過去のすべての勾配の累積和）が減算され、減衰のないモメンタムのように振る舞って最小値を通り越し、収束せずに振動する。

<!--en:7e0d5430-->
2. 和の損失はここでのスクラッチ実装の損失より $2|\mathcal{B}| = 64$ 倍大きいため、その勾配は $64\mathbf{g}$ となる。したがって学習率を $64$ で割り、$\eta = 0.03 / 64 \approx 4.69 \times 10^{-4}$ にする必要がある。

<!--en:0e672b88-->
3. $x_1$ を $10$ 倍にスケーリングすると、ヘッセ行列 $\mathbf{H} = \frac{1}{n}\mathbf{X}^\top\mathbf{X}$ の最大固有値が $10^2 = 100$ 倍になり、安定性の上限 $\eta_{\max} = 2 / \mu_{\max}$ は $100\times$ 縮小する（$\approx 2$ から $\approx 0.02$ へ下がる）。
