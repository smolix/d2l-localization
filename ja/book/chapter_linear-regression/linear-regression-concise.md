# 線形回帰の簡潔な実装

<!--en:3cb13709-->
:numref:`sec_linear_scratch` では、パラメータの確保、アフィン順伝播、二乗損失、リバースモード微分、ミニバッチジェネレータ、SGD の更新ステップといった線形回帰のあらゆる構成要素を生のテンソルから構築した。続く :numref:`sec_oo-design` では、それらの構成要素を再利用可能な基底クラス（`d2l.Module`、`d2l.DataModule`、`d2l.Trainer`）へと整理し、`LinearRegressionScratch` を `trainer.fit(model, data)` で訓練することで、ベンチマーク結果が再現されることを確認した。

<!--en:491c2121-->
生のパラメータテンソルや更新規則を手書きしてテストするのは、パラメータが 3 個の線形モデルであれば簡単であった。しかし、ResNet-50（:numref:`sec_resnet`）や GPT（:numref:`sec_gpt`）のような現代のアーキテクチャは、数十の層にわたって数百万〜数十億個のパラメータを管理し、状態を持つ適応的オプティマイザを用いて訓練する。そのため、PyTorch :cite:`Paszke.Gross.Massa.ea.2019`、JAX :cite:`Frostig.Johnson.Leary.2018`（Flax と Optax を併用）、TensorFlow :cite:`Abadi.Barham.Chen.ea.2016`、MXNet :cite:`Chen.Li.Li.ea.2015` といった深層学習フレームワークは、ハードウェア向けに最適化された層、数値的に検証済みの損失プリミティブ、標準的なオプティマイザを標準で提供している。本節では、こうした高水準の構成要素を `d2l.Module` と `d2l.Trainer` に組み込むことで、線形回帰をいかに簡潔に記述できるかを見ていく。

<!--en:4d13c0fd-->
## 全結合層

<!--en:64f7f409-->
この簡潔な実装では、サブクラス `LinearRegression(d2l.Module)` が出力ユニット数 1 の組み込みの全結合層（fully connected layer）を 1 つラップし、重みを $\mathcal{N}(0, 0.01^2)$ から、バイアスを 0 に初期化する。

<!--en:a8c98ebc-->
PyTorch の `nn.LazyLinear(1)` は構築時には出力次元のみを必要とし、入力特徴量の数 $d$ は最初の順伝播時に自動的に決まる。

<!--en:e7a2cb3c-->
Gluon の `nn.Dense(1)` も同様に、最初のミニバッチが通過した時点で入力次元を遅延決定する。

<!--en:39b2baee-->
Keras の `layers.Dense(1)` も、最初の呼び出し時に入力幅を遅延決定する。

<!--en:510d8f4e-->
Flax NNX の層は構築時にパラメータを即座に確保するため、`nnx.Linear` は入力次元（`num_inputs`、ここでは `2` に設定）と出力次元（`1`）の両方を受け取る。

<!--en:0877220c-->
なお、`LinearRegression` では `forward` を定義する必要すらなく、`Module.forward` を :numref:`sec_oo-design` から継承してそのまま `self.net(X)` に処理を委譲する。

<!--en:6f5e4337-->
## 損失関数

<!--en:94bd9db2-->
$(\hat{y} - y)^2 / 2$ を手書きする代わりに、`loss` はフレームワーク組み込みの平均二乗誤差（mean squared error、MSE）プリミティブに委譲する。標準的な平均二乗誤差はスクラッチ実装の損失にあった係数 $\frac{1}{2}$ を省くため、値はスクラッチ実装の 2 倍になり、$\sigma^2 = 10^{-4}$ で頭打ちになる（$\sigma^2 / 2$ ではない）。

<!--en:0d66f2a1-->
MXNet の `gluon.loss.L2Loss` にはあらかじめ係数 $\frac{1}{2}$ が含まれているため、標準的な平均二乗誤差に合わせるには $2$ を掛ける。

<!--en:8aa0af9a-->
## オプティマイザ

<!--en:73e27925-->
同様に、`configure_optimizers` はモジュールの登録済みパラメータと学習率 `self.lr` を接続した、フレームワーク組み込みのミニバッチ SGD オプティマイザを返す。

<!--en:ae027837-->
## フレームワークの構成要素を用いた訓練

<!--en:a5c1ad1c-->
`LinearRegression` を定義すれば、訓練はデータモジュール、モデル（学習率は $\eta = 0.015$ とし、MSE の勾配が 2 倍になる分を相殺するためスクラッチ実装の $\eta = 0.03$ から半減させる）、および `d2l.Trainer(max_epochs=10)` をインスタンス化し、`trainer.fit(model, data)` を呼び出すだけで済む。

<!--en:0e49b824-->
最終的な検証損失は約 $3\%$ 以内の差で理論的なノイズフロア $\sigma^2 = 10^{-4}$ に収まり、スクラッチ実装の結果と一致する。ここで小さなヘルパーメソッド `get_w_b` を追加し、学習された重みテンソルとバイアスをフレームワークの層から取り出して $(\mathbf{w}^*, b^*)$ と比較してみよう。

<!--en:89073002-->
今回も $\hat{\mathbf{w}}$ と $\hat{b}$ の誤差は 1,000 分の 1 程度に収まり、スクラッチ実装での実行結果と一致する。支配的な誤差要因（$1{,}000$ 個の例にわたるラベルノイズと、$10$ エポック後に残る距離）は、誰が層を実装したかにかかわらず同一だからである。

<!--en:632d52e1-->
ここまでの 3 つの節で確認してきた内容はすべて、正解（ground truth）のパラメータが既知であることに依拠していたが、これは現実のデータセットでは決して望めない贅沢である。続く :numref:`sec_generalization_basics` では、ホールドアウトデータのみからモデルを評価する方法に取り組む。

<!--en:30ac03ff-->
## まとめ

<!--en:5350d0e0-->
高水準のフレームワーク API を用いれば、線形回帰は `d2l.Module` のサブクラス内に 1 つの全結合層を置き、`loss` を組み込みの平均二乗誤差に、`configure_optimizers` を組み込みの SGD に委譲するだけで実装できる。標準的な平均二乗誤差はスクラッチ実装の目的関数にあった係数 $\frac{1}{2}$ を省くため、損失（$\sigma^2 = 10^{-4}$ で頭打ちになる）とその勾配がいずれも 2 倍になる。したがって、学習率を $\eta = 0.015$ へと半減させることで、スクラッチ実装と同じパラメータ更新が再現される。また、`LinearRegression` は `d2l.Module` の規約を満たしているため、データパイプラインや訓練ループを一切変更せずに `d2l.Trainer` で訓練できる。

[理解度の確認]{.kicker}

<!--en:8a6cd163-->
以下の 3 つの問いで、フレームワークの層と損失関数の規約に関する理解を確認しよう。

<!--en:8873dcbc-->
1. **簡潔な実装で損失の収束値が 2 倍になる理由：**まったく同じ合成データ生成器を用いているのに、簡潔な実装では $10^{-4}$ 付近で頭打ちになり、スクラッチ実装では $5 \times 10^{-5}$ 付近で頭打ちになったのはなぜか。

<!--en:3086bcab-->
2. **バイアスの省略（`bias=False`）：**`LinearRegression` のバイアスを無効にしてこのデータセット（$b^* = 4.2$、平均 0 の特徴量 $\mathbf{x} \sim \mathcal{N}(\mathbf{0}, \mathbf{I}_2)$）で訓練すると、検証 MSE はどの値で頭打ちになるか。

<!--en:4fd74cfa-->
3. **2 出力での MSE のスケーリング：**`LinearRegression` で $2$ 個の出力を予測する場合（$1$ 個ではなく）、フレームワークの MSE は残差行列の全 $2|\mathcal{B}|$ 要素で平均をとる。これにより各出力の勾配と等価な学習率はどう変化するか。

<!--en:557b98b6-->
**解答：**

<!--en:468759fe-->
1. フレームワークの MSE は $\frac{1}{|\mathcal{B}|}\|\hat{\mathbf{y}} - \mathbf{y}\|_2^2$ を係数 $\frac{1}{2}$ なしで計算するため、真のパラメータにおける期待値は $\mathbb{E}[\epsilon^2] = \sigma^2 = (0.01)^2 = 10^{-4}$ になる（$\frac{1}{2}\sigma^2 = 5 \times 10^{-5}$ ではない）。

<!--en:11312eaf-->
2. $\mathbb{E}[\mathbf{x}] = \mathbf{0}$ であるため重みは依然として $\mathbf{w}^* = (2, -3.4)^\top$ 付近に収束するが、モデル化されていない切片 $b^* = 4.2$ がすべての残差に残るため、MSE の下限は $(b^*)^2 + \sigma^2 = 4.2^2 + 10^{-4} \approx 17.64$ に上昇する。

<!--en:83067e78-->
3. $2|\mathcal{B}|$ で割ること（$|\mathcal{B}|$ ではなく）により各出力のパラメータに関する勾配が半分になるため、学習率を $\eta = 0.03$ に倍増させれば単一出力のステップサイズに戻る。
