# 深層学習のためのツール

<!--en:8b1ec08f-->
ノートパソコン上で動作するノートブックも、モデル、バッチ、あるいはコンテキストが大きくなった途端に失敗することがある。次に下すべき判断は、公称スループットが最も高いアクセラレータを無条件に購入することではない。まずは、ワークロードがメモリに収まるか、計算とデータ移動のどちらが律速しているか、そして実験を完遂するのにどれだけのコストがかかるかを見極める必要がある。さらに、訓練とサービングとでは課される制約が異なる。分散訓練ではアクセラレータ間の通信コストが発生するのに対し、サービングではモデルとキャッシュの永続的な状態を保持しつつ、レイテンシとスループットの目標も満たさなければならない。

<!--en:4bf478ec-->
