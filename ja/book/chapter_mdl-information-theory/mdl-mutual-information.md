# 相互情報量

<!--en:e42daee2-->
ここまでの節では、データ分布とモデルのように、同じ変数上の 2 つの分布を比較してきた。これに対し、深層学習における多くの問いは変数の対を扱う。画像とそのキャプション、同じ写真から切り出した 2 つの領域、あるいは文とその翻訳などである。一方の変数は、もう一方の変数についてどれだけの情報を与えてくれるのだろうか。

<!--en:0443e33a-->
従属性の標準的な尺度である相関係数は、線形な関係しか検出できない。$X\sim\mathcal N(0,1)$ とし、$Y=X^2+0.3\,\epsilon$ とおく。ここで $\epsilon\sim\mathcal N(0,1)$ は独立なノイズである。$X^3$ は 0 の周りで対称であるため $\textrm{Cov}(X,Y)=\mathbb{E}[X^3]=0$ となり、$X$ と $Y$ の相関は 0 である。しかし実際には、$X$ は $Y$ をほぼ決定している。$X$ がわかれば、$Y$ は標準偏差 $0.3$ のノイズの分しか変動しないのに対し、単体での $Y$ はおよそ $0$ から $9$ まで広がる。本節で定義する量は、この従属性を難なく捉える。実際、この対には相関 $0.9$ の 2 変量ガウス分布よりも多くの共有情報量が割り当てられる。

<!--en:c98899c8-->
求めているのは、2 つの変数が独立であるとき、かつそのときに限り 0 となり、従属性が強まるにつれて大きくなり、さらにどちらの変数を別の座標で表し直しても変化しない尺度である。これを構築するための道具はすでに揃っている。KL ダイバージェンス $D_{\textrm{KL}}(P\|Q)$（:numref:`sec_mdl-information_theory`）である。ギブスの不等式により、この量は常に非負であり、$P=Q$ の場合にのみ 0 になる。$P$ を対の真の同時分布とし、$Q$ を各成分が独立であった場合に従う積分布とすれば、*相互情報量*（mutual information）$I(X;Y)$ が得られる。

<!--en:3d10eb95-->
相互情報量の定義自体は単純であり、その真価はそこから導かれる帰結にある。本節では 3 つの基本的な結果を確立する。第 1 に、変数を処理しても他の何らかの対象との相互情報量は増加しないため、ニューラルネットワークのどの層も、その直下の層より多くの入力情報をもつことはない。第 2 に、分類器がある誤り率を達成するには、入力がラベルについて最低限の情報量をもっていなければならない。第 3 に、任意の確率モデルのテスト損失は、その情報量に対する下界を直接保証する。続いて、Shannon の 2 つの根源的な問い（雑音通信路はどれだけの情報を運べるか、非可逆な圧縮器はどれだけ少ない情報の保持で済むか）と、圧縮から発展した第 3 の問い（学習された表現は何を保持すべきか）へと進む。本節を通じて背後の分布は既知であると仮定する。サンプルのみから相互情報量を推定するのはより難しい問題であり、:numref:`sec_mdl-mi-estimation` で扱う。

<!--en:b2cdb548-->
これまでと同様、単位には nat を用いる。ここで $1$ ビット $=\ln 2\approx0.693$ nat である。対数はすべて自然対数とし、一般の式では $\log$、数値を評価する際には $\ln$ と書く。また 2 値エントロピーを $H_b(p)=-p\log p-(1-p)\log(1-p)$ で表す。

<!--en:fe0861fb-->
## 従属性の尺度

<!--en:5668d440-->
すべての定義を具体的に理解するため、まず 1 つの $2 \times 2$ 確率表の上でそれぞれの量を計算する。この確率表は、本節を通じて通し例として繰り返し登場する。

<!--en:5c4e12c1-->
### 結合エントロピーと条件付きエントロピー

<!--en:eeb1e15c-->
$X$ を公平なビットとし、$Y$ を $X$ が確率 $\delta=0.1$ で反転したコピーとする。$X$ をノイズのある回線で送られたビット、$Y$ を受信されたビットと読むこともできるし、$Y$ を 2 値ラベル、$X$ を $90\%$ の確率でそれに一致するノイズ付き特徴量と読むこともできる。表は対称であるため、以下の議論はどちらの解釈を選んでも変わらない。行を $x\in\{0,1\}$、列を $y\in\{0,1\}$ に対応させると、同時分布は次のようになる。

<!--en:984850c3-->
行と列の和をとると、周辺分布 $p_X=p_Y=(\tfrac12,\tfrac12)$ が得られる。この対を*反転ビット*（flipped bit）と呼ぶ。以下では、添字によって分布の変数名を表し、条件付き分布 $p(y\mid x)$ のように引数から分布が明らかな場合には添字を省略する。

<!--en:09415ac1-->
個々のエントロピー $H(X)$ と $H(Y)$ に加え、確率変数の対には :numref:`subsec_mdl-joint-conditional-entropy` で導入した 2 つの自然なエントロピーがある。*結合エントロピー*（joint entropy）は、対を単一の確率変数（ここでは 4 つの結果をもつ変数）とみなしたときのエントロピーである。

<!--en:a08f5161-->
この表では、$H(X,Y)=-2(0.45\ln0.45)-2(0.05\ln0.05)=1.018$ nat となる。これは 1 つの公平なビットがもつ $0.693$ nat よりは大きいが、独立な 2 つの公平なビットがもつ $1.386$ nat よりは小さい。

<!--en:b22fd943-->
*条件付きエントロピー*（conditional entropy）は、$Y$ について $X$ が既知となった後に残る驚きを測る量であり、条件付き分布の各行 $p(y\mid x)=p_{X,Y}(x,y)/p_X(x)$ のエントロピーの平均で与えられる。

<!--en:6e1c3fb8-->
反転ビットでは、2 つの行は $(0.9,0.1)$ と $(0.1,0.9)$ であり、それぞれのエントロピーは $H_b(0.1)=0.325$ nat であるから、$H(Y\mid X)=0.325$ nat となる。$X$ を観測した後でも、$Y$ は $0.325$ nat の驚きを（元の $0.693$ nat のうち）依然として保持している。

<!--en:cd05760f-->
これら 3 つの数値が $1.018=0.693+0.325$ を満たしていることに注目しよう。これは連鎖律 $H(X,Y)=H(X)+H(Y\mid X)$（:numref:`subsec_mdl-joint-conditional-entropy`）にほかならない。すなわち、対がもつ驚きは、$X$ の驚きに、$Y$ の追加的な驚き（$X$ が既知となった後のもの）を加えたものに等しい。

<!--en:7dc55780-->
### 相互情報量

<!--en:6b7f5b0a-->
条件付きエントロピーは、$Y$ の驚きのうち $X$ では説明できない部分を捉える。いま求めたいのは、2 つの変数が共有する部分である。もし $X$ と $Y$ が独立であれば、その同時分布は周辺分布の積 $P_X \otimes P_Y$ となり、すべてのセルに $p_X(x)\,p_Y(y)$ が入る。*相互情報量*とは、実際の同時分布からこの独立な積分布への KL ダイバージェンスである。

<!--en:e68b25e0-->
反転ビットでは、周辺分布の積はすべてのセルに $0.25$ を置く。したがって、独立な積に対する同時確率の比は、対角成分では $0.45/0.25=1.8$（$X$ と $Y$ が一致する場合）となり、非対角成分では $0.05/0.25=0.2$（不一致の場合）となる。この対数比を同時分布のもとで平均すると次を得る。

<!--en:245c58e4-->
一致は独立性が予測する頻度の $1.8$ 倍起こり、不一致は 1/5 の頻度しか起こらない。相互情報量とは、単にこの倍率の対数の期待値である。KL ダイバージェンスは誤ったモデルを用いた際に生じる余分な符号長も測るため（:numref:`sec_mdl-coding-compression`）、$I(X;Y)$ は $X$ と $Y$ を独立として扱う符号が 1 対あたりに浪費する nat 数でもある。:numref:`sec_diffusion-discrete` では、ネットワークが 2 つのマスクトークンを独立に予測する際に、まさにこのペナルティが現れる。

<!--en:98c5546c-->
:eqref:`eq_mdl-mut_ent_def` は表を 1 行ずつ読むこともできる。分子と分母を $p_X(x)$ で割ると比は $p(y\mid x)/p_Y(y)$ となり、対に関する期待値は、条件付き分布と周辺分布の間の KL ダイバージェンスを $x$ に関して平均した形に書き直せる（対象は $Y$ の分布である）。

<!--en:e9d68ba3-->
この形式では、相互情報量は $x$ を観測することで $Y$ の分布がその周辺分布から平均してどれだけ変化するかを測る。反転ビットでは、各条件付き行 $(0.9,0.1)$ および $(0.1,0.9)$ は、それぞれ $0.9\ln1.8+0.1\ln0.2=0.368$ nat だけ周辺分布 $(0.5,0.5)$ から離れている。この非対称な見方は、入力とノイズ付きエンコーダの出力のように 2 つの変数が異なる役割を担う場合に特に自然であり、:numref:`sec_mdl-information-bottleneck` で再び立ち返る。

<!--en:48512817-->
**命題（相互情報量の性質）。** *任意の対 $(X,Y)$ に対して $I(X;Y)=I(Y;X)\ge0$ が成り立ち、等号は $X$ と $Y$ が独立であるとき、かつそのときに限り成り立つ。関係する各エントロピーが有限であるとき、次が成り立つ。*

<!--en:b650beb7-->
**証明。**$X$ と $Y$ を入れ替えても :eqref:`eq_mdl-mut_ent_def` の比は変わらないため、対称性が従う。非負性と等号成立条件は、$P_{X,Y}$ と $P_X \otimes P_Y$ にギブスの不等式を適用すれば直ちに従う。すなわち KL ダイバージェンスは非負であり、すべての点で $p_{X,Y}(x,y) = p_X(x)\,p_Y(y)$ となるとき、かつそのときに限り 0 になるが、これは独立性の定義そのものである。エントロピーの恒等式を得るには、比の対数を 3 つの項に分解して期待値をとればよい。

<!--en:cebdd00f-->
2 通りの順序による連鎖律 $H(X,Y) = H(Y) + H(X \mid Y)=H(X)+H(Y\mid X)$ を代入すれば、残りの 2 つの形式が得られる。$\blacksquare$

<!--en:40bc1030-->
したがって、$X$ が $Y$ について語る情報量は、$Y$ が $X$ について語る情報量と正確に一致する。最後の恒等式は相互情報量を不確実性の減少として解釈するものであり、$X$ を観測すると $Y$ の驚きは $H(Y)$ から $H(Y\mid X)$ へと低下する（反転ビットでは $0.693$ nat から $0.325$ nat へ下がる）。また非負性から劣加法性の上界 $H(X,Y)\le H(X)+H(Y)$ が導かれ、等号は独立性が成り立つときにのみ成立する。すなわち、変数の対がもつ驚きは、各成分を別々に考えたときの驚きの和を決して超えない。:numref:`fig_mdl-mi-overlap` はこれらの関係を視覚的に表したものであり、命題の各恒等式は重なり部分の面積の異なる読み取り方にすぎない。

<!--en:23273e6a-->
![相互情報量 $I(X;Y)$ をエントロピー $H(X)$ と $H(Y)$ の重なりとして表した図。三日月形の部分は条件付きエントロピー $H(X\mid Y)$ と $H(Y\mid X)$、和集合は結合エントロピー $H(X,Y)$ であり、$I(X;Y)$ の 3 つの等価な表現は面積を読み取ることで得られる。](../img/mdl-it-mi-overlap.svg)

<!--en:59ef5d84-->
以下の関数 `mutual_information` は任意の離散同時確率表に対してダイバージェンス形式を実装したものであり、本節全体で再利用する。またこのセルでは、各行のエントロピーを平均することで恒等式 $I(X;Y) = H(Y) - H(Y\mid X)$ も確認している。

<!--en:28d26b1e-->
どちらの式も $0.3681$ nat、すなわち $0.531$ ビットを返す。10 回に 1 回反転するコピーであっても、元のビットについて半ビット強の情報を伝えているのである。

### ガウス対

<!--en:5e9063de-->
ここまでは離散的な確率表を扱ってきたが、深層学習における大半の変数（活性化値、勾配、埋め込みなど）は連続である。連続な場合の中で、手計算で完全に求められるケースが 1 つある。2 変量ガウス分布である。これは 2 つ目の通し例として、本節後半のレート・歪み曲線および情報ボトルネック（information bottleneck）の双方の土台となる。連続密度に対しては、離散エントロピーは微分エントロピー $h$（:numref:`subsec_mdl-differential-entropy`）に置き換わる。微分エントロピーは負になり得るうえ測定単位に依存するが、KL ダイバージェンスによる相互情報量の定義にはそのどちらの欠点もない。連鎖律の代数変形は離散性を用いていないため、各量が有限である限り $I(X;Y)=h(X)+h(Y)-h(X,Y)=h(Y)-h(Y\mid X)$ が成り立つ。ここで $h(Y\mid X)$ は条件付き密度 $p(y\mid x)$ の微分エントロピーを $x$ に関して平均した量を表す。

<!--en:e8e3b1c9-->
**命題（ガウス分布の相互情報量）。** *$(X, Y)$ が分散 $\sigma_X^2,\sigma_Y^2>0$、相関係数 $\rho$（ただし $\rho^2<1$）の 2 変量ガウス分布に従うならば、次が成り立つ。*

<!--en:66c57ba9-->
**証明。**$I(X;Y)=h(Y)-h(Y\mid X)$ を用いる。分散 $\sigma^2$ のガウス変数は微分エントロピー $\tfrac12\log(2\pi e\sigma^2)$（:numref:`subsec_mdl-gaussian-max-entropy`）をもつため、$h(Y)=\tfrac12\log(2\pi e\sigma_Y^2)$ である。$X=x$ で条件付けると、$Y$ は引き続きガウス分布に従い、その分散は $\sigma_Y^2(1-\rho^2)$ となって $x$ に依存しない。これは $Y$ の最良線形予測（$X$ に基づく予測）を差し引いた残差の分散であり、2 変量ガウス分布ではこの残差は $X$ と独立である（:numref:`subsec_mdl-mvn-conditioning`）。したがって $h(Y\mid X)=\tfrac12\log\big(2\pi e\sigma_Y^2(1-\rho^2)\big)$ となり、差をとれば $-\tfrac12\log(1-\rho^2)$ が得られる。$\blacksquare$

<!--en:dcab4b28-->
この結果は $1-\rho^2$、すなわち $Y$ の分散のうち $X$ によって説明されずに残る割合のみに依存する。$Y$ の単位が相殺されていることに注目されたい。これは :numref:`sec_mdl-mi-nonlinear-correlation` で証明する座標不変性の最初の現れである。

<!--en:0c118726-->
$\rho = 0$ のとき変数は独立であり、$I(X;Y) = 0$ となる。$\rho \to \pm 1$ の極限では同時密度が直線上に退化し、$I(X;Y) \to \infty$ となる。これら両極端の間では、$\rho = 0.5$ で $0.144$ nat、$\rho = 0.9$ で $0.830$ nat、$\rho = 0.99$ で $1.959$ nat となる。周辺分布が標準正規分布で $\rho=0.9$ である 2 変量ガウス分布は本節を通じて繰り返し登場するため、これを *$\rho=0.9$ のガウス対*と呼ぶ。

<!--en:4b21b2dd-->
極限 $\rho \to \pm 1$ が示すように、相互情報量は実際に無限大になり得る。この現象は後ほど、ニューラルネットワークの決定論的な層と情報ボトルネックのエンコーダという 2 つの場面で再び登場する。連続確率変数 $X$ に対して $Y=X$ であれば、$X$ を知ることは $Y$ を小数点以下無限桁まで特定することを意味する。$Y$ が $X$ の決定論的な関数であり、どの単一の値も正の確率をもたない場合にも同様のことが成り立つ。対照的に、$Y$ が有限のエントロピーをもつ離散変数である場合には、相互情報量が無限大になることはあり得ない。このとき $I(X;Y)=H(Y)-H(Y\mid X)\le H(Y)$ が $X$ によらず成り立つ（ここで $H(Y\mid X)$ は $p(\cdot\mid x)$ のエントロピーを $x$ について平均した量である）。たとえば標準正規分布に従う $X$ に対し、$X$ の符号はちょうど $\ln 2$ nat の情報量をもつ。この同じ上限によって、:numref:`sec_basic_gan` のイェンセン・シャノン・ダイバージェンスも $\ln 2$ 以下に抑えられる。そこで示したとおり、この量はサンプルとその生成元を識別する 2 値ラベルの間の相互情報量に等しいからである。

### 自己相互情報量

<!--en:5f9e5e7b-->
相互情報量はすべての結果の対にわたって平均をとるため、どの特定の対が従属性を生み出しているかは見えなくなる。しかし実際には、特定の 1 対に関心があることも多い。たとえば単語 *new* を見たとき、次の単語が *york* になる確率は偶然よりはるかに高くなるだろうか。:eqref:`eq_mdl-mut_ent_def` の和の中にある被加数は、この問いに直接答えるものであり、*自己相互情報量*（pointwise mutual information）と呼ばれる。

<!--en:197f55d6-->
この量は、特定の対 $(x, y)$ が実際に生じる頻度を、$X$ と $Y$ が独立であった場合に生じる頻度と比較する。正の pmi は 2 つの結果が引き合う（偶然の予測より高い頻度で共起する）ことを示し、負の pmi は反発し合うことを示す。そして $I(X;Y) = \mathbb{E}_{(x,y) \sim P_{X,Y}}[\textrm{pmi}(x,y)]$ はその平均的な引力である。反転ビットでは、一致する 2 つのセルで pmi は $\ln1.8=+0.588$、不一致の 2 つのセルで $\ln0.2=-1.609$ となり、先ほど平均をとった対数と正確に一致する。

<!--en:cf3a3aaf-->
自己相互情報量は自然言語処理における古典的な道具であり :cite:`Church.Hanks.1990`、本来結びつきの強い単語対である*連語*（collocation）を、単に両方とも頻出語であるために共起する単語対から切り分ける。小さなコーパスで連続する単語対（バイグラム）を数え上げ、*new*、*machine*、*the* のそれぞれの直後に *york*、*learning*、*day* が何回現れるかを集計したとしよう。

生の出現回数はここでは誤解を招く。「the day」が群を抜いて最多の対となっている（出現回数は $168$ 回であるのに対し、「new york」は $38$ 回）のは、単に *the* と *day* がともに高頻度語だからである。以下のコードは、各同時頻度を 2 つの周辺単語頻度の積で割り、4 つの対に対する pmi を出力するとともに、表全体の相互情報量を求める。

<!--en:57ef1162-->
周辺頻度で補正すると、真の連語が上位に浮上する。「new york」のスコアは $1.52$ nat、「machine learning」は $1.37$ であるのに対し、高頻度対「the day」は $0.34$ にとどまる。一方、「the york」は $-1.11$ nat と負になり、独立性が予測する頻度の約 1/3 しか現れない。表全体の相互情報量である $0.41$ nat は、1 語目が 2 語目を平均してどれだけ強く制約しているかを要約している。これと同じ周辺頻度の補正は、学習された単語埋め込み（:numref:`sec_lm_word_embeddings`）にも再び現れる。隣接語の観測対を $K$ 個のランダムな対から識別するよう skip-gram モデルを訓練することは、シフトされた自己相互情報量 $\textrm{pmi}(x,y)-\log K$ を成分とする行列を暗黙のうちに行列分解することに相当する :cite:`Levy.Goldberg.2014`（演習問題 :exref:`ex_mdl-mutual-information-negative-sampling-pmi`（:numref:`sec_mdl-mi-estimation`）で導出する）。

<!--en:84bb4f3c-->
### 相互情報量と相関

<!--en:0e5d3d2c-->
相関係数 $\rho(X,Y)=\textrm{Cov}(X,Y)/(\sigma_X\sigma_Y)$（:numref:`sec_mdl-joint-distributions`）は線形な従属性しか検出できず、$\rho(X,Y)=0$ は独立性を意味しない。対照的に、相互情報量は変数が独立であるとき、かつそのときに限り 0 になる。冒頭の例に戻ると、この違いが具体的になる。

<!--en:a3b51e4e-->
$X \sim \mathcal{N}(0, 1)$ とし、独立なノイズを用いて $Y = X^2 + 0.3\,\epsilon$（ただし $\epsilon \sim \mathcal{N}(0,1)$）とおく。この対の相関は $\rho=0$ である。$I(X;Y)=h(Y)-h(Y\mid X)$ と書けば、1 次元積分を用いて相互情報量を評価できる。$X=x$ で条件付けると、$Y$ に残るランダム性は加法的ノイズのみであり、分布を既知の定数 $x^2$ だけ平行移動しても微分エントロピーは変わらないため、$h(Y\mid X)=h(0.3\,\epsilon)=\tfrac12\ln(2\pi e\cdot0.09)=0.215$ nat となる。$h(Y)$ を数値計算する前に、解析的な上界を求めておこう。$Y$ の分散は $\textrm{Var}(X^2)+0.09=2.09$ であり、与えられた分散をもつすべての密度の中で微分エントロピーを最大化するのはガウス分布であるから（:numref:`subsec_mdl-gaussian-max-entropy`）、$h(Y)\le\tfrac12\ln(2\pi e\cdot2.09)=1.79$ nat、したがって $I(X;Y)\le1.79-0.215=1.57$ nat が得られる。$Y$ の周辺密度は $x$ にわたる連続混合分布 $p_Y(y)=\int\mathcal N(x;0,1)\,\mathcal N(y;x^2,0.09)\,dx$ であって閉形式をもたないため、数値積分によって $h(Y)$ を求める。

<!--en:52ac87e2-->
この対は $1.141$ nat を共有している。これがガウス分布による上界 $1.57$ nat を大きく下回るのは、$Y$ の密度（0 付近に集中し右に長い裾をもつ）がガウス分布から大きく外れているためである。それでいて、線形相関が 0 であるにもかかわらず、この値は $0.830$ nat（$\rho=0.9$ のガウス対）を上回っている。:numref:`fig_mdl-mi-corr-vs-mi` に 3 つのケースを並べて比較する。

<!--en:a69280fc-->
![相関と相互情報量による 3 つの対の比較。(a) 相関 $0.9$ のガウス対。(b) $Y=X^2+0.3\epsilon$。$X$ が $Y$ をほぼ決定しているにもかかわらず対称性により相関は 0 になる（(b) では縦軸のスケールが異なることに注意）。(c) 独立な対。相関は (b) と (c) を区別できないが、相互情報量は (b) を (a) より上位に置く。](../img/mdl-it-mi-corr-vs-mi.svg)

<!--en:190ed4d7-->
相関と相互情報量には、もう 1 つ根本的な違いがある。座標変換に対する振る舞いである。気温を摂氏ではなく華氏で測ったり、価格を対数スケールで記録したりしても、その変数が他の対象についてどれだけの情報をもつかはまったく変わらない。したがって、原理に基づいた従属性の尺度はこうした変換のもとで不変であるべきである。

<!--en:c93a9b4c-->
**命題（再パラメータ化不変性）。** *$\phi$ と $\psi$ をそれぞれ $X$ の値と $Y$ の値に対する可逆写像とする。このとき $I(\phi(X);\psi(Y))=I(X;Y)$ が成り立つ。*

<!--en:23df772b-->
**証明。**離散変数の場合、可逆写像は結果のラベルを付け替えるだけであり、$(\phi(X), \psi(Y))$ の同時分布は付け替え後の結果に対して $(X, Y)$ の同時分布と同じ確率を割り当てるため、:eqref:`eq_mdl-mut_ent_def` の和は変化しない。連続変数の場合、ここでは仕組みを示すために滑らかな場合を証明し、滑らかさの仮定は :numref:`subsec_mdl-dpi` で取り除く。$\phi$ と $\psi$ が連続微分可能かつ連続微分可能な逆写像をもつとし、$(x, y) \mapsto (\phi(x), \psi(y))$ によって変数変換する。変換後の対の $(\phi(x),\psi(y))$ における同時密度は $p_{X,Y}(x,y)\,|\det D\phi(x)|^{-1}|\det D\psi(y)|^{-1}$ となる一方、2 つの周辺密度にも因子 $|\det D\phi(x)|^{-1}$ と $|\det D\psi(y)|^{-1}$ が掛かる。これらのヤコビ行列の行列式因子は密度比の中で相殺されるため、:eqref:`eq_mdl-mut_ent_def` の被積分関数は対応する点で同じ値をとり、その期待値も変わらない。$x\mapsto x^3$ における原点のような確率 0 の例外点の集合は積分に寄与しない。$\blacksquare$

<!--en:94da0b0b-->
微分エントロピーがこの不変性（再パラメータ化不変性（reparameterization invariance））をもたないのは、ヤコビ行列の行列式因子を打ち消す相手が存在しないためであり、それゆえ $h$ は単位に依存する。また相関は（符号を除けば）アフィン変換のもとでしか保存されない。たとえば可逆写像 $x\mapsto x^3$ を $\rho=0.9$ のガウス対の第 1 座標に適用しても、相互情報量は $0.830$ nat のままであるが、相関は $0.9$ から $3\rho/\sqrt{15}=0.697$ へと低下する（$\mathbb{E}[X^3Y]=3\rho$ かつ $\textrm{Var}(X^3)=15$ が標準正規分布に従う $X$ に対して成り立つため）。相互情報量が問うているのは、2 つの変数が*何らかの*座標系において互いについての情報をもつかであって、たまたま直線上に並んでいるかではない。

## データ処理と予測

<!--en:c38ba4fc-->
ここで、冒頭で予告した 3 つの結果を導出しよう。最初の 2 つは根本的な限界を表すものである。すなわち、データを処理しても情報は生み出せず、正確な予測には最低限の情報量が不可欠である。どちらも相互情報量の連鎖律という単一の恒等式から従う。3 つ目の結果は、任意の確率モデルの交差エントロピー損失を、入力が保持する情報量の下界へと直接変換するものである。

<!--en:f53934d2-->
### 条件付き相互情報量と連鎖律

<!--en:5397a8eb-->
反転ビットの例をもう 1 段階拡張してみよう。$Z$ が、$Y$ をさらに独立に確率 $0.2$ で反転させることで生成されるとする。これは公平なビットを直列につながれた 2 本のノイズ回線で送る状況、あるいはラベルに続いてノイズ付き特徴量とそのノイズ付きコピーが得られる状況に相当する（:numref:`fig_mdl-it-bsc-chain`）。直列の 2 回反転は単一の反転として振る舞う。ビットが反転して届くのは 2 本の回線のうちちょうど一方だけが反転させるとき、かつそのときに限り、その確率は $0.1\cdot0.8+0.9\cdot0.2=0.26$ である。したがって対 $(X,Z)$ は $\delta=0.26$ の反転ビットであり、$I(X;Z)=\ln2-H_b(0.26)=0.120$ nat となる。2 本目のノイズ回線によって、$0.368$ nat あった $Y$ の情報量の 2/3 が失われたことになる。

<!--en:22e280fd-->
![直列の 2 回反転。公平なビット $X$ が確率 $0.1$ で反転して $Y$ となり、$Y$ が確率 $0.2$ で反転して $Z$ となる。2 回の反転は合成すると確率 $0.26$ の単一の反転になる。2 回目の反転で情報量の 2/3 が失われ、$I(X;Z\mid Y)=0$ は、$Z$ が $X$ について、$Y$ がすでに知っている以上の情報を何ももたないことを表す。](../img/mdl-it-bsc-chain.svg)

<!--en:d1a95bb9-->
変数が 3 つになると、新たな問いが生じる。$X$ と $Y$ は、$Z$ がすでに既知であるときにどれだけの情報を共有するだろうか。エントロピーに条件付き版があるのと同様に、相互情報量にも条件付き相互情報量（conditional mutual information）がある。

<!--en:873d43c4-->
ここで $H(X\mid Y,Z)$ は、$X$ の対 $(Y,Z)$ が与えられたもとでの条件付きエントロピーである。各条件付きエントロピーを期待値として書いて対数をまとめると、ダイバージェンス形式 $I(X; Y \mid Z) = \mathbb{E}_{z}\big[D_{\textrm{KL}}(P_{X,Y \mid z}\,\|\, P_{X \mid z} \otimes P_{Y \mid z})\big]$ が得られる。これは各 $z$ の値に対する条件付き分布の上で通常の相互情報量を計算し、平均をとったものにほかならない。KL ダイバージェンスの期待値であるため、$I(X; Y \mid Z)$ は常に非負であり、$X$ と $Y$ が $Z$ を与えたもとで条件付き独立であるとき、かつそのときに限り 0 となる。

<!--en:852dd854-->
この定義により、対 $(Y,Z)$ が $X$ について保持する情報量を 2 つの部分に分解できる。$H(X\mid Z)$ を $I(X;Y,Z)=H(X)-H(X\mid Y,Z)$ の中で引いて足すと、次式を得る。

<!--en:4e9e1e79-->
この恒等式は*相互情報量の連鎖律*（chain rule for mutual information）であり、各項を KL 形式で書けば完全な一般性のもとで成り立つ。言葉で述べれば、$(Y,Z)$ が $X$ について教えてくれる情報量は、$Z$ が教えてくれる情報量に、$Y$ が $Z$ の既知のもとでつけ加える情報量を足したものに等しい。まったく同様に、先に $Y$ で条件付けてもよい。直列の 2 回反転では、2 通りの順序によって同じ合計が 2 通りに分解される。$Z$ は $Y$ と独立なノイズから生成されるため、$Y$ が既知となれば、$Z$ は $X$ についてそれ以上の情報を何も加えない。すなわち $I(X;Z\mid Y)=0$ であり、$Y$ を先に置くと $I(X;Y,Z)=I(X;Y)+0=0.368$ nat となる。一方、$Z$ を先に置くと、同じ $0.368$ nat が $I(X;Z)+I(X;Y\mid Z)=0.120+I(X;Y\mid Z)$ と分割され、$I(X;Y\mid Z)=0.248$ nat が残る。ここでは、$Z$ で条件付けることで、$Y$ が $X$ について明かす情報量が減少した。$Z$ がすでにその情報の一部を保持しているからである。しかし次項で見るように、条件付けによって相互情報量が*増加*することもある。

### データ処理不等式

<!--en:3f8a6e7a-->
ニューラルネットワークでは、各隠れ層はその直下の層から計算され、さらにその層も入力から計算される。このような処理によって、前の層に含まれていなかった入力についての情報を新たに生み出すことはできるだろうか。2 本のノイズ回線では答えは否であったが、その理由はビットという特殊な設定とは無関係である。

<!--en:c14ceaab-->
3 つの確率変数 $X, Y, Z$ が*マルコフ連鎖*（$X \to Y \to Z$ と書く）をなすとは、$Z$ が $(X, Y)$ に $Y$ を通じてのみ依存すること、すなわち $p(z \mid x, y) = p(z \mid y)$ が成り立つことである。これは逐次処理の構造をそのまま捉えている。まず $Y$ が $X$ から生成され（観測値、特徴マップ、あるいは隠れ層）、続いて $Z$ が（場合によっては新たなランダム性を伴って）$Y$ のみから計算される。同値な言い方をすれば、$X$ と $Z$ は $Y$ が与えられたもとで条件付き独立であり、$I(X; Z \mid Y) = 0$ が成り立つ。

<!--en:0280bcdf-->
**命題（データ処理不等式）。** *$X \to Y \to Z$ がマルコフ連鎖であり、関係する各エントロピーが有限であるならば、次が成り立つ。*

<!--en:62d792b6-->
*等号が成り立つのは $I(X; Y \mid Z) = 0$ のとき、すなわち $X \to Z \to Y$ もマルコフ連鎖であるとき、かつそのときに限る* :cite:`Cover.Thomas.1999`。

<!--en:29c52487-->
**証明。**$I(X; Y, Z)$ を連鎖律により両方の順序で展開する。

<!--en:cbde2c4e-->
マルコフ性より最後の項は 0 となり、条件付き相互情報量の非負性から $I(X; Z) = I(X; Y) - I(X; Y \mid Z) \leq I(X; Y)$ が得られる。等号は $I(X; Y \mid Z) = 0$ のとき、かつそのときに限り成り立つ。$\blacksquare$

<!--en:77a85d9d-->
決定論的であれランダム化されていようと、$Y$ に対するいかなる処理も、$X$ について保持する情報量を増やすことはできない。直列の 2 回反転では、この不等式は単に $0.120 \le 0.368$ と表される。

<!--en:16d0730e-->
この不等式（データ処理不等式（data-processing inequality））はマルコフ連鎖の構造に厳密に依拠しており、条件付け一般の性質ではないことに注意されたい。マルコフ連鎖の外では、条件付けによって本来存在しなかった従属性が生じることがある。$X$ と $Y$ を独立な公平なビットとし、$Z = X \oplus Y$ をその排他的論理和とする。周辺分布では $X$ と $Y$ が共有する情報量は 0 であるが、いったん $Z$ が明かされると、$Y$ は $X$ を完全に決定する。以下のコードは、直列の 2 回反転とこの XOR の 3 つ組の双方について相互情報量を計算する。

<!--en:c543dbf4-->
2 回反転では、$I(X; Z \mid Y) = 0$ によってマルコフ性が数値的に確認でき、$I(X; Y, Z)$ の 2 通りの連鎖律分解はいずれも $0.3681$ nat を与える。排他的論理和では、$Z$ で条件付けることにより、$X$ と $Y$ の相互情報量は $0$ から 1 ビット分の全情報量である $\ln2=0.693$ nat へと跳ね上がる。

<!--en:e556ae03-->
処理によって情報がまったく失われないのはどのような場合だろうか。命題より、等号が成り立つのは $X\to Z\to Y$ もマルコフ連鎖であるとき、かつそのときに限る。すなわち $Z$ が、$Y$ から得られる $X$ についての情報をすべて保持している場合である。可逆変換 $Z=g(Y)$ は明らかにこれを達成する。$Y$ を $Z$ から復元できるからである。しかし写像が $Y$ の一部を捨てたとしても、$X$ についての情報を失わないことがある。捨てる部分が $X$ と無関係でありさえすればよい。たとえばコイン投げの系列における表の合計回数は、その系列がコインの偏りについて語る情報をすべて保存している。出た順序はコインの偏りについて何の情報ももたないからである。この性質をもつ任意の要約量 $T(Y)$（すなわち $p(x \mid y)$ が $y$ に $T(y)$ を通じてのみ依存し、したがって $I(X;T(Y))=I(X;Y)$ となるもの）を*十分統計量*（sufficient statistic）と呼ぶ。指数分布族（:numref:`sec_mdl-exponential-family`）の十分統計量はまさにこの種の要約量であり、そこでは $Y$ がデータの役割を、$X$ がパラメータ $\theta$（$I(\theta;Y)$ が適切に定義されるよう事前分布を備えたもの）の役割を果たす。

<!--en:68b7cba0-->
データ処理不等式そのものには、エントロピーの有限性も確率密度の存在も必要ない。相互情報量は KL ダイバージェンスであり、ランダムであれ決定論的であれデータのいかなる写像も KL ダイバージェンスを増加させないため（可算集合については :numref:`subsec_mdl-f-div-data-processing` で証明しており、完全な一般性のもとで成り立つ）、演習問題 :exref:`ex_mdl-mutual-information-dpi-from-f-divergence` ではこの事実からデータ処理不等式の一般的な証明を導く。さらに、この不等式を可逆写像とその逆写像に 1 回ずつ適用すれば、滑らかさを仮定することなく :numref:`sec_mdl-mi-nonlinear-correlation` の再パラメータ化不変性も得られる。

<!--en:2e54e127-->
深層ネットワークにデータ処理不等式を適用する際には、誤解が生じやすい。ネットワークの各層はマルコフ連鎖 $X \to Z_1 \to Z_2 \to \cdots$ をなすため、$I(X; Z_\ell)$ は深さ $\ell$ とともに増加することはない。ここから本節の終わりまでは、$Y$ を連鎖の中間変数ではなく予測対象のラベルを表すものとする。ネットワークがラベルについて知り得ることはすべて入力を経由しなければならないため、$Y \to X \to Z_1 \to Z_2 \to \cdots$ もマルコフ連鎖となり、$I(Y; Z_\ell)$ もまた $\ell$ とともに増加し得ない。いかなるアーキテクチャも入力に存在しなかったラベル情報を無から生み出すことはできず、前の層が捨てた情報を後の層が取り戻すこともできない。

<!--en:d40c7a80-->
これは、深さが役に立たないという意味では*ない*。隠れ層はラベルについての情報を増やすのではなく、単純な最終層で読み取れるように既存の情報を再編成するのである。ラベル $Y$ を公平なビットとし、入力 $X \in \mathbb{R}^2$ は半径 $1$ の円周上の一様分布（$Y=0$ のとき）または半径 $2$ の円周上の一様分布（$Y=1$ のとき）に従うとする。入力はラベルを完全に決定するため $I(Y;X)=\ln2$ であるが、2 つの同心円を分離できる直線は存在しない。最良の線形分類器は決定境界を内側の円に接するように置き、内側の円全体と、直線の外側に位置する外側の円の 1/3 を正しく分類して、正解率 $2/3$ を達成する。ここで単一の非線形特徴量 $Z=\|X\|^2$ を適用すると、その値は $1$ と $4$ の 2 通りしかとらない。両者の間に単純な閾値を設ければすべての点を完璧に分類できるが、$I(Y;Z)=\ln2$ は $I(Y;X)$ より大きくなったわけではない。この変換は情報を一切増やさなかったが、すべての情報を線形に読み取れる形へと変えたのである。演習問題 :exref:`ex_mdl-mutual-information-usable-information` では、制限された分類器の族が抽出できる分だけを数える利用可能情報量（usable information）の概念を定式化する。

<!--en:1ad93300-->
入力側の連鎖 $X \to Z_1 \to Z_2 \to \cdots$ については、最後に 1 つ注意点がある。決定論的な層では $H(Z_\ell\mid X)=0$ である。表現が離散化または量子化されていれば $I(X;Z_\ell)$ は単にエントロピー $H(Z_\ell)$ に帰着し、連続であれば $I(X;Z_\ell)$ は通常無限大になる（:numref:`subsec_mdl-mi-gaussian`）。したがって、層が入力についてどれだけ保持しているかの尺度として $I(X;Z_\ell)$ が意味をもつのは、層がノイズを注入するか離散出力を生成する場合に限られる。

<!--en:4968dd42-->
### ファノの不等式

<!--en:91fffbba-->
正確な予測には相互情報量が不可欠である。誤り率 $5\%$ を $1{,}000$ クラス分類で達成する分類器は、ラベルのエントロピーの大半を含む入力を受け取っていなければならず、ファノの不等式はその必要量を正確に教えてくれる。

<!--en:cefdef4c-->
**命題（ファノの不等式）。** *$Y$ が $k$ 個の要素からなる集合に値をとるとし、$\hat Y=g(X)$ を $Y$ に対する $X$ から計算された同じ集合上の任意の推定値とし、$P_e=P(\hat Y\ne Y)$ をその誤り確率とする。このとき次が成り立つ。*

<!--en:37450ab4-->
左辺には、推定値 $\hat Y$ を修復するコストとしての明快な符号化解釈がある。まず $H_b(P_e)$ nat を使って $\hat Y$ が誤っているかどうかを指定し、誤っている場合（確率 $P_e$）には高々 $\log(k-1)$ nat を使って残りの $k-1$ 個のラベルのどれが正解かを指定する。推定値と修復情報の両方をもっていれば $Y$ が正確にわかるため、修復のコストは $Y$ について $\hat Y$ が残す不確実性を下回ることはない。そしてデータ処理不等式により、その不確実性は少なくとも $X$ が残す不確実性以上である。

<!--en:2448cdd3-->
証明では、誤りが生じたかどうかを表す指示変数というただ 1 つの道具を使って、この直観を厳密な不等式へと仕立てる。残りは連鎖律だけである。

<!--en:116d0fb8-->
**証明。**$W = \mathbf{1}\{\hat Y \neq Y\}$ を誤りの指示変数とする。推定値が与えられたもとでの誤りの有無と真のラベルの双方に関する残りの不確実性 $H(W, Y \mid \hat Y)$ を 2 通りに展開する。第 1 に、$W$ は $(Y,\hat Y)$ によって完全に定まるためエントロピーを増やさず、$H(W, Y \mid \hat Y) = H(Y \mid \hat Y)$ となる。第 2 に、連鎖律より $H(W, Y \mid \hat Y) = H(W \mid \hat Y) + H(Y \mid W, \hat Y)$ が得られ、各項を個別に上から抑える。

<!--en:a03058b1-->
* $H(W)-H(W\mid\hat Y)=I(W;\hat Y)\ge0$ であるから、条件付けによってエントロピーは増加しない。したがって $H(W \mid \hat Y) \leq H(W) = H_b(P_e)$ である。

<!--en:b4727a8a-->
* $W=0$ のときラベルは $\hat Y$ に等しく、不確実性は 0 である。$W=1$ のとき（確率 $P_e$ で生じる）、ラベルは $k-1$ 個ある $\hat Y$ 以外の値のいずれかであるため、そのエントロピーは高々 $\log(k-1)$ である。$W$ について平均をとると $H(Y \mid W, \hat Y) \leq P_e \log(k-1)$ が得られる。

<!--en:87d032b9-->
両方の上界を合わせると $H(Y\mid\hat Y)\le H_b(P_e)+P_e\log(k-1)$ が得られる。最後に、$\hat Y$ は $X$ のみから計算されるため 3 つ組 $Y \to X \to \hat Y$ はマルコフ連鎖をなし、データ処理不等式より $I(Y; \hat Y) \leq I(Y; X)$、すなわち同値な形として $H(Y \mid \hat Y) \geq H(Y \mid X)$ が従う。$\blacksquare$

<!--en:f278d399-->
第 2 段階における残りのラベル数 $k-1$ は、$\hat Y$ が同じラベル集合の中に値をとることに依拠している点に注意しよう。もし分類器に「棄権」という回答を許せば、$\log k$ で $\log(k-1)$ を置き換えなければならず、上の不等式は成り立たなくなる。実際、公平なビット $Y$ が $X$ と独立であり、分類器が常に棄権するとすれば、$P_e=1$ となって左辺は $H_b(1)+\ln1=0$ となり、$H(Y\mid X)=\ln2$ を下回ってしまう。

<!--en:9b230c79-->
最も単純な場合では、ファノの不等式は等号で成り立つ。反転ビットにおいて推定値を $\hat Y=X$ とすると、$P_e=0.1$ かつ $k=2$ であるから、左辺は $H_b(0.1)+0.1\ln1=0.325$ となり、$H(Y\mid X)$ と厳密に一致する。

<!--en:1b828271-->
アーキテクチャや訓練手順がいかなるものであろうと、ファノの限界を超える分類器は存在しない。均衡した $1{,}000$ クラスでは $H(Y)=\ln1000=6.91$ nat であり、:eqref:`eq_mdl-fano` を $I(X;Y)$ について整理すると、各目標誤り率を達成するのに必要な最小の相互情報量がわかる。

<!--en:a594b16d-->
誤り率 $5\%$ に到達するには少なくとも $6.36$ nat（ラベルエントロピー $6.91$ nat の $92\%$）が必要であり、半分の確率で誤る分類器でさえ $2.76$ nat、すなわち全体の 2/5 を必要とする。

<!--en:eee66f95-->
### 損失による保証

<!--en:44130fe4-->
ファノの不等式は分類誤り率を相互情報量の下界へと変換する。しかし言語モデルはハードな誤り率では評価されない。最尤法で訓練されるほぼすべてのモデルと同様、交差エントロピー損失を報告するのである。この損失からも相互情報量の下界が得られ、その証明はわずか 3 行で済む。

<!--en:e01c2f93-->
**命題（損失は情報量を保証する）。** *$q(y\mid x)$ を入力に対するラベルの任意のモデルとし、交差エントロピー損失を $L=\mathbb{E}[-\log q(Y\mid X)]$（$P_{X,Y}$ のもとでの期待値）とする。このとき次が成り立つ。*

<!--en:00387ed3-->
*さらに、均衡した $k$ クラスに対しては $I(X;Y)\ge\log k-L$ が成り立つ。*

<!--en:7d2fe50e-->
**証明。**定義より $I(X;Y)=H(Y)-H(Y\mid X)$ である。各 $x$ に対し、$q(\cdot\mid x)$ の $p(\cdot\mid x)$ のもとでの交差エントロピーは、$p(\cdot\mid x)$ の真の条件付きエントロピーを $D_{\textrm{KL}}(p(\cdot\mid x)\,\|\,q(\cdot\mid x))\ge0$ だけ上回る（:numref:`sec_mdl-information_theory`）。$x$ について平均をとれば $H(Y\mid X)\le L$ が得られ、これを $H(Y)$ から引けば証明が完了する。$\blacksquare$

<!--en:407f8237-->
ホールドアウトしたテスト損失は $L$ を推定するため、任意の分類器や言語モデルのテスト損失は、入力がもつ情報量の下界を直接保証する。たとえば均衡したラベルに対する $10$ クラス分類器のテスト損失が $0.3$ nat であれば、入力は少なくとも $\ln10-0.3=2.0$ nat（ラベルの $2.30$ nat のうち）を保持していることが保証される。この下界はモデルの較正が不十分であったり訓練が不出来であったりしても成り立ち、弱いモデルは単に小さな下界を保証するにすぎない。これは分類器をデコーダとして用いた :citet:`Barber.Agakov.2003` の変分下界であり、:numref:`sec_mdl-mi-variational-bounds` ではこれをより広い相互情報量推定量の族へと発展させる。

<!--en:fddc9ba5-->
この保証がタイトになるのは、$q(y\mid x)$ が真の条件付き分布 $p(y\mid x)$ に一致するとき、かつそのときに限る。反転ビットにおいて $\hat Y=X$ を確信度 $c$ で予測するモデルの期待損失は $L=-0.9\log c-0.1\log(1-c)$ であり、以下ではこれを 4 つの確信度について評価する。

<!--en:b5bf877e-->
較正されたモデル（$c=0.9$）だけが全情報量である $0.368$ nat を保証する。過信したモデル（$c=0.99$）は誤るたびに大きなペナルティを支払い $0.22$ nat しか保証できず、自信不足のモデル（$c=0.6$）は $0.14$ nat にとどまる。しかし 4 つのモデルはすべて同一のハード予測を出力し $10\%$ の確率で誤るため、誤り率しか見ないファノの不等式はどのモデルに対しても $0.368$ nat すべてを保証する。交差エントロピー損失は予測確率まで見ているため、較正のずれにペナルティを科すのである。どちらの結果も同じ条件付きエントロピー $H(Y\mid X)$ を上から抑え（ファノの不等式は誤り率により、損失による保証は損失により）、それぞれの上界を $I(X;Y)$ の下界へと変換している。実は両者の結びつきは見た目以上に深い。演習問題 :exref:`ex_mdl-mutual-information-certificate-and-fano` で示すように、ファノの下界自体がある特定のモデルに対する損失による保証にほかならず、自身がいつ不確かであるかを把握している適切に較正された分類器は、それより真に多くの情報量を保証できる。

<!--en:a19060e9-->
## 通信と圧縮

<!--en:dfe25c75-->
Shannon は 2 つの根源的な工学的問いを立てたが、その答えは相互情報量の最大値と最小値に帰着する。雑音通信路はどれだけの情報を確実に運べるか、そして非可逆な圧縮器はどれだけ少ない情報の保持で済むか、という問いである。表現学習に関心がある読者は初読時には通信路容量（channel capacity）を流し読みしても構わないが、レート・歪み理論（rate–distortion theory）は本節の最後のパートが直接その上に構築されるため不可欠である。

<!--en:0efd7e03-->
### 通信路容量

<!--en:8a9e12e9-->
各ビットを独立に確率 $\delta$ で反転させる通信回線を、どれだけの情報が生き残れるだろうか。無記憶*通信路*（channel）は、各入力記号に独立に適用される条件付き分布 $p(y\mid x)$ によって規定され、送信される記号 1 つを通信路の 1 回の使用と数える。通し例の反転ビットは、入力 $X$ と出力 $Y$ をもつまさにそのような通信路である。通信路のノイズは固定されているが、送信者は入力分布 $p(x)$ を自由に選ぶことができる。通信路の*容量*（capacity）とは、入力分布のあらゆる選び方にわたって達成可能な最大の相互情報量であり、1 回の使用あたりの nat 数で測られる。

<!--en:56bb54e2-->
ほとんど 0 ばかりを送る送信者は、そもそも入力自体のエントロピーが小さいため、通信路を十分に活用できていない。シャノンの通信路符号化定理は、この量に操作的な意味を与える。符号の*レート*を通信路の 1 回の使用あたりに伝達するメッセージの nat 数と定義したとき、Shannon は、記号の長いブロックをまとめて符号化することで、$C$ 未満の任意のレートにおいて誤り確率をいくらでも小さく抑えた高信頼な通信が可能である一方、$C$ を超えるいかなるレートでも高信頼な通信は不可能であることを示した :cite:`Shannon.1948,Cover.Thomas.1999`。この定理は証明なしで認めることとする。

<!--en:6cbd7c60-->
*2 元対称通信路*（binary symmetric channel）として知られるビット反転通信路では、容量は 1 行で計算できる。$I(X;Y)=H(Y)-H(Y\mid X)$ と書く。$p(y\mid x)$ のどの行も順序を除けば $(1-\delta,\delta)$ であるから、入力分布によらず $H(Y\mid X)=H_b(\delta)$ となる。一方、$H(Y)\le\ln2$ であり、等号は $Y$ が一様分布であるとき、かつそのときに限り成り立つ。$P(Y=1)=\delta+P(X=1)(1-2\delta)$ より、$\delta\ne\tfrac12$ である限り、出力が一様になるのは入力が一様であるとき、かつそのときに限る。したがって次式を得る。

<!--en:1625d486-->
この最大値は一様な入力によって達成される。$\delta=0.1$ では、（入力が最初から一様であった）反転ビットの $0.368$ nat が復元され、直列の 2 本の回線（$\delta=0.26$）では容量は $0.120$ nat へと低下する。$\delta=\tfrac12$ では出力は入力と独立になり、容量は 0 になる。$\delta=1$ では容量は全情報量である $\ln2$ nat に戻る。すべてのビットが反転していると知っている受信者は単にそれを反転し直せばよいからである。ノイズが情報を破壊するのは、受信者がそれを予測できない範囲に限られる。以下のコードでは、まず $\delta=0.1$ の通信路に対して入力分布を動かし、続いて一様入力のもとで反転確率 $\delta$ を動かす。

<!--en:fd72b7d0-->
$1$ を $10\%$ の割合でしか送らない入力は、そもそも $H_b(0.1)=0.325$ nat しかもっておらず、そのうち通信路を通過できるのは $0.146$ nat、すなわち一様入力が達成する量の 2/5 にすぎない。:numref:`fig_mdl-it-capacity-rd` の左パネルに、容量を $\delta$ の関数として描く。ニューラルネットワークの内部にも独自の通信路が存在する。ドロップアウトは特徴量を確率 $\alpha$ で消去し、それ以外の場合には通過させるが、演習問題 :exref:`ex_mdl-information-theory-binary-channels` では 2 値の特徴量がこの通信路を通して高々 $(1-\alpha)\ln2$ nat しか送れないことを示す。

<!--en:f3270016-->
![nat 単位で表した Shannon の 2 つの操作曲線。左：2 元対称通信路の容量 $C=\ln2-H_b(\delta)$。反転ビット（$\delta=0.1$）と直列の 2 回反転（$\delta=0.26$）に印をつけてある。確率 $1/2$ で反転する通信路は何も運べない一方、常に反転する通信路は $\ln2$ すべてを運ぶ。右：分散 $\sigma_X^2=1$ の情報源に対するガウス分布のレート・歪み関数。レートは $D\to0$ で発散し、$D$ が情報源の分散に達すると 0 になる。](../img/mdl-it-capacity-rd.svg)

<!--en:f485ea58-->
### レート・歪み

<!--en:e0a42511-->
可逆圧縮には 1 記号あたり $H(X)$ nat が必要であり（:numref:`sec_mdl-coding-compression`）、連続情報源を厳密に可逆符号化しようとすれば無限に多くの nat が必要になる。しかし実用上は、近似的な再構成で十分なことがほとんどである。画像コーデックはピクセルをわずかに変化させてもよいし、学習された表現は無関係な細部を意図的に捨ててもよい。非負の*歪み*（distortion）尺度 $d(x,\hat x)\ge0$ を選んで $\hat x$ が $x$ をどれだけうまく再構成しているかを測り、平均歪みを高々 $D$ まで許容するとしよう。1 サンプルあたりどれだけ少ない nat 数で済むだろうか。*レート・歪み関数*（rate–distortion function）は、歪みの許容範囲内に収めるためにエンコーダ $p(\hat x\mid x)$ が保持しなければならない最小の相互情報量としてこの問いに答える。

<!--en:7d71cff4-->
許容歪みを厳しくするほど、より多くの情報量が求められる。シャノンのレート・歪み定理は通信路符号化定理と対をなしており、ここでのレートは符号が情報源の 1 サンプルあたりに費やす nat 数を測る。すなわち、$R(D)$ を上回る任意のレートで動作するブロック符号は平均歪み $D$ を達成できる一方、$R(D)$ 未満のいかなる符号もそれを達成できない :cite:`Shannon.1959`。

<!--en:ebfc90b1-->
実際には、ハードな歪み制約をペナルティに置き換え、$I(X;\hat X)+\lambda\,\mathbb{E}[d(X,\hat X)]$ を乗数 $\lambda>0$ のもとですべてのエンコーダにわたって最小化するほうが扱いやすいことが多い。各エンコーダは歪み・レート平面において曲線 $R(D)$ 上またはその上方の 1 点に対応し、ペナルティ付き目的関数は傾き $-\lambda$ の直線上で一定となる。$R(D)$ は凸関数であるため、最小値は傾き $-\lambda$ の直線が曲線に下から接する点で達成される。$\lambda$ を大きくするほど、より高いレートでより小さい歪みが選ばれる。:numref:`sec_mdl-information-bottleneck` の情報ボトルネックは、まさにこのラグランジアン形式で定式化される。

<!--en:db6dcac7-->
**命題（ガウス情報源のレート・歪み）。** *情報源 $X\sim\mathcal N(0,\sigma_X^2)$ と二乗誤差 $d(x,\hat x)=(x-\hat x)^2$ のもとで、次が成り立つ。*

<!--en:32b03cfb-->
この式を歪みについて解くと $D=\sigma_X^2 e^{-2R}$ となる。レートを 1 ビット（$\ln2$ nat）増やすごとに、二乗誤差は 1/4 に減少する。

<!--en:babea475-->
**証明。**主たるステップは下界の導出であり、:numref:`subsec_mdl-gaussian-max-entropy` のただ 1 つの事実に依拠する。すなわち、分散 $s^2$ をもつすべての密度の中で微分エントロピーを最大化するのはガウス分布であり、その最大値 $\tfrac12\log(2\pi e s^2)$ は $s^2$ とともに単調に増加する。$\mathbb{E}[(X-\hat X)^2]\le D$ を満たす任意のエンコーダをとると、次が成り立つ。

<!--en:3fa9d5f6-->
2 つ目の等号は、既知の値 $\hat X$ を引いても条件付き密度が平行移動するだけでエントロピーは変わらないことから従う。1 つ目の不等号は条件付けがエントロピーを増加させないという事実を用い、2 つ目の不等号は再構成誤差 $X-\hat X$ の分散が高々 $\mathbb{E}[(X-\hat X)^2]\le D$ であることからガウス分布の最大エントロピー上界を適用している。$D\ge\sigma_X^2$ のときは、何も送信せず常に平均 $0$ を出力する定数エンコーダがすでに許容歪みを満たすため、$R(D)=0$ となる。

<!--en:54a2851c-->
残るは $D<\sigma_X^2$ に対してこの下界を達成するエンコーダの構成である。$\sigma_X^2=1$ とおき、独立なガウスノイズを加えて $Z=X+\sigma\epsilon$（ただし $\epsilon\sim\mathcal N(0,1)$、$\sigma>0$）とする。このとき $\textrm{Cov}(X,Z)=1$ かつ $\textrm{Var}(Z)=1+\sigma^2$ であるから、二乗相関は $\rho_{XZ}^2=1/(1+\sigma^2)$ となる。:eqref:`eq_mdl-gaussian_mi` を適用すると、このエンコーダが保持する相互情報量は次で与えられる。

<!--en:930c035d-->
ここで $X$ を条件付き平均 $\hat X=\mathbb{E}[X\mid Z]=Z/(1+\sigma^2)$ によって再構成する。これは $X$ の $Z$ に対する傾き $\textrm{Cov}(X,Z)/\textrm{Var}(Z)$ の最適な線形回帰である。その平均二乗誤差は条件付き分散 $D=1-1/(1+\sigma^2)=\sigma^2/(1+\sigma^2)$ であり、開区間 $(0,1)$ 全体を $\sigma$ の変化に伴って動く。$\hat X$ は $Z$ の可逆な定数倍であるため、$I(X;\hat X)=\tfrac12\log(1+\sigma^{-2})=\tfrac12\log(1/D)$ が成り立つ。一般の分散 $\sigma_X^2$ に対しては、単に $X$ と $\hat X$ を定数倍すればよい。$\blacksquare$

<!--en:b7a7aa6a-->
この証明で用いたエンコーダ（独立なガウスノイズで汚された信号）は、信号対雑音比（signal-to-noise ratio）$\sigma^{-2}$ の*ガウス通信路*（Gaussian channel）として知られ、:eqref:`eq_mdl-gaussian-channel` はその容量である（演習問題 :exref:`ex_mdl-mutual-information-gaussian-channel`）。拡散モデル（:numref:`chap_diffusion`）の順方向ノイズ付加過程はまさにこの通信路にほかならない。データ分布がいかなるものであっても、信号対雑音比 $s$ までノイズを加えられた座標は、元のクリーンな値について高々 $\tfrac12\log(1+s)$ nat しか保持しない。以下のコードは、100 万個のサンプル上でこのエンコーダを $\sigma^2=1/9$、$1$、$3$（それぞれ $D=0.1$、$0.5$、$0.75$ に対応）においてシミュレーションし、二乗誤差を検証する。

<!--en:e0c725cf-->
経験二乗誤差は小数第 3 位の数単位以内で $D$ と一致する。$D=0.1$ の歪みには 1 サンプルあたり $1.15$ nat、$D=0.5$ には $0.35$ nat（半ビット）、$D=0.75$ には $0.14$ nat のコストがかかる。

<!--en:5defefa6-->
このノイズ付きエンコーダが $R(D)$ を達成しているのは相互情報量としてであり、まだ実際のファイルサイズとしてではないことに留意されたい。実用的な符号はサンプルを離散的なビット列へと写像しなければならず、サンプルの長いブロックをまとめて符号化することで初めてレート・歪み曲線に漸近する。1 度に 1 サンプルずつ量子化するいかなるスカラー符号も、曲線より真に上にとどまる。最も単純な例は $X$ の符号のみを保持するもので、$\ln2=0.693$ nat を費やして $\pm\sqrt{2/\pi}$（$|X|$ の平均）を再構成し、二乗誤差 $1-2/\pi=0.363$ を生じるが、レート・歪み曲線がその歪みに対して要求するのはわずか $0.506$ nat である。

<!--en:2bc2a9e3-->
:numref:`fig_mdl-it-capacity-rd` の右パネルに曲線全体を示す。$D\to0$ につれて必要レートは限りなく上昇し（連続変数の厳密なコピーがもつ無限の情報量を反映している）、$0$ まで落ちるのは $D$ が $\sigma_X^2$ に達したときである。$D=0$ 付近でのこの急激な立ち上がりは、現代の画像生成器がモデル化の前に画像を圧縮する理由を説明している。知覚できないほど微細なピクセルの細部がビットの大半を消費してしまうため、:numref:`sec_diffusion-latent` ではそうした細部をオートエンコーダに委ねるのである。

## 情報ボトルネック

<!--en:2a9ea7e5-->
優れた表現は、ラベルの予測に役立つものを残し、それ以外を捨てるべきである。一見すると、何かを捨てることは逆効果に思えるかもしれない。データ処理不等式によれば、情報を捨ててもベイズ最適な予測器が改善することは決してないからである。しかし実際には、無関係な細部には現実のコストが伴う。犬の写真には、照明や芝生、さらにはフレーム内のどこにたまたま犬が立っているかまでもが符号化されている。そうした細かな違いをすべて保存するには余分な nat がかかり、有限枚の画像で訓練された分類器はそれらをラベルへの真の手がかりと容易に取り違えてしまう。情報ボトルネックは、このトレードオフを 2 つの相互情報量によって定式化する。それはラベル自体が歪みを定義するレート・歪み問題にほかならない。

<!--en:d301883b-->
### ボトルネック目的関数

<!--en:edcfbabd-->
$Z$ を入力 $X$ から確率的エンコーダ $p(z\mid x)$ によって生成される表現とし、$Y$ を目的ラベルとする。$Z$ が連続であるとき、エンコーダは確率的でなければならない。決定論的な写像では通常 $I(X;Z)=\infty$ となってしまうからである（:numref:`subsec_mdl-mi-gaussian`）。*情報ボトルネック* :cite:`Tishby.Pereira.Bialek.1999` は、表現 $Z$ が $X$ の情報をできる限り削ぎ落としつつ、$Y$ についての情報をできる限り多く保持することを目指す。

<!--en:0b1b220c-->
ここで $I(X;Z)$ はレート（表現が入力について保持する情報量）であり、$I(Y;Z)$（重み $\beta>0$ を掛ける）は表現がラベルについて保持する情報量である。エンコーダは $X$ しか参照しないため、変数はマルコフ連鎖 $Y\to X\to Z$ をなし、データ処理不等式により $I(Y; Z) \leq \min\{I(X; Y),\, I(X; Z)\}$ という制約が課される。表現は入力以上にラベルを知ることは決してできず、また入力情報を保持せずにうまく予測することもできない。

<!--en:634e091e-->
乗数 $\beta$ がこのトレードオフを制御しており、その両極端は容易に理解できる。$\beta\le1$ である限り、何も保持しないことが最適である。実際、上の不等式から $I(X;Z)-\beta I(Y;Z)\ge(1-\beta)\,I(X;Z)\ge0$ であり、$X$ を完全に無視する定数エンコーダが $I(X;Z)=I(Y;Z)=0$ を達成する。定数エンコーダが最適になるとき、ボトルネックは*崩壊*（collapse）するという。逆に $\beta$ が大きくなるとラベルの項が支配的になり、エンコーダは $Y$ の予測に役立つあらゆる情報を保持するようになる。その極限では $I(Y;Z)$ は上限 $I(X;Y)$ に近づき、表現は*最小十分統計量*（minimal sufficient statistic）、すなわち $X$ の要約のうち $Y$ を $X$ 自身と同等の精度で予測できる最も粗いものへと近づく。もちろん、あらゆるニューラルネットワークがそうであるようにエンコーダがパラメトリックな族に制限されている場合には、その上限の手前で頭打ちになることがある。

<!--en:b183f06e-->
**命題（レート・歪み問題としてのボトルネック）。** *$Y\to X\to Z$ がマルコフ連鎖であるならば、次が成り立つ。*

<!--en:7ed4580c-->
**証明。**$I(Y;X,Z)$ を連鎖律により両方の順序で展開すると $I(Y;Z)+I(Y;X\mid Z)=I(Y;X)+I(Y;Z\mid X)$ となる。マルコフ性より $I(Y;Z\mid X)=0$ である。残った条件付き相互情報量を KL 形式で書くと $I(Y;X\mid Z)=\mathbb{E}_{(x,z)}\big[D_{\textrm{KL}}(p(y\mid x,z)\,\|\,p(y\mid z))\big]$ となり、マルコフ性により $p(y\mid x,z)$ は $p(y\mid x)$ に簡約される。$\blacksquare$

<!--en:0870d5ca-->
:eqref:`eq_mdl-ib-as-rd` を目的関数に代入すると、:eqref:`eq_mdl-ib_lagrangian` は $I(X;Z)+\beta\,\mathbb{E}[d(X,Z)]-\beta I(X;Y)$ へと書き換わる（ただし歪みは $d(x,z)=D_{\textrm{KL}}(p(y\mid x)\,\|\,p(y\mid z))$ である）。最後の項 $\beta I(X;Y)$ はエンコーダに依存しないため、情報ボトルネックはまさにレート・歪み問題のラグランジアン形式である。設計者が手作業で歪み尺度を作る代わりに、ラベルがそれを自動的に与えてくれる。符号 $z$ は、$x$ に対する忠実な表現であるのは、それが $Y$ を $x$ と同じ精度で予測するときなのである。ただし通常のレート・歪み問題とは異なり、この歪みは $p(y\mid z)$ を通じてエンコーダ自身に依存するため、最適化は格段に難しくなる。

<!--en:208ec15c-->
### ガウス情報ボトルネック

<!--en:246ec7e3-->
ある特別な設定では、情報ボトルネックのすべての量を閉形式で解くことができる :cite:`Chechik.Globerson.Tishby.ea.2005`。$(X, Y)$ を $\rho = 0.9$ のガウス対（$I(X; Y) = 0.830$ nat）とし、:numref:`subsec_mdl-rate-distortion` の加法的ノイズエンコーダを用いる。

<!--en:65f444da-->
このエンコーダはノイズのスケール $\sigma$ のみでパラメータ化される。レート $I(X;Z)$ はすでに :eqref:`eq_mdl-gaussian-channel` で与えられている。ラベルについては $\textrm{Cov}(Y,Z)=\textrm{Cov}(Y,X)=\rho$ かつ $\textrm{Var}(Z)=1+\sigma^2$ であるから、$\rho_{YZ}^2=\rho^2/(1+\sigma^2)$ となる。:eqref:`eq_mdl-gaussian_mi` を適用すると、両方の相互情報量が求まる。

<!--en:0e917b0d-->
$\sigma$ が $\infty$ から $0$ へ減少するにつれて、表現は $X$ について何も知らない状態から $X$ を完全に知る状態へと滑らかに移行し、ラベル情報量は $0$ からデータ処理不等式の上限である $0.830$ nat まで上昇する。

<!--en:0e17b955-->
このトレードオフを直接可視化するため、レートを $u=I(X;Z)$ と書く（$R$ はレート・歪み関数 $R(D)$ のために取っておく）。:eqref:`eq_mdl-gaussian-ib-info` を逆に解くと $\sigma^{-2}=e^{2u}-1$、ゆえに $1/(1+\sigma^2)=1-e^{-2u}$ となり、ラベル情報量をレートの関数として直接表せる。

<!--en:dec7cfba-->
導関数は $\rho^2$（$u=0$ における値）から $0$ に向かって単調に減少するため、この曲線は狭義凹関数である。原点を傾き $\rho^2=0.81$ で出発するため、最初の 1 nat の入力情報から得られるラベル情報は高々 $0.81$ nat であり、その後に続く 1 nat ごとの増分は $I(Y;Z)$ が $I(X;Y)$ に近づくにつれて逓減していく。:citet:`Chechik.Globerson.Tishby.ea.2005` は、ガウス対に対して線形・非線形を問わずいかなるエンコーダもこの曲線を上回れないことを証明しており、これが厳密な最適フロンティアとなる（この結果は証明なしで用いる）。任意の $\beta$ を選ぶと、ラグランジアンの最小点はこのフロンティア上のただ 1 つの*動作点*（operating point）を選び出す。

<!--en:4390507e-->
**命題（動作点と崩壊）。** *$\rho^2<1$ のガウス情報ボトルネックにおいて、ラグランジアン $u-\beta\,I(Y;Z)$ は $u$ に関して凸であり、その導関数は $1-\beta\rho^2$（$u=0$ における値）となる。$\beta\le1/\rho^2$ では最小点は $u=0$（定数エンコーダ）である。$\beta>1/\rho^2$ では、最小点とそのラベル情報量は次で与えられる。*

<!--en:bb9b312d-->
**証明。**$I(Y;Z)$ は $u$ に関して凹であるため、ラグランジアン $u-\beta I(Y;Z)$ は凸であり、導関数は $1-\beta\rho^2/(\rho^2+(1-\rho^2)e^{2u})$ である。$u=0$ ではこの導関数は $1-\beta\rho^2$ に等しい。$\beta\rho^2\le1$ のときは常に、導関数は $u=0$ で非負かつ狭義単調増加であるため、$u\ge0$ における最小値は $u=0$ で達成される。そうでない場合、導関数を 0 とおくと $\rho^2+(1-\rho^2)e^{2u}=\beta\rho^2$、すなわち $e^{2u}=\rho^2(\beta-1)/(1-\rho^2)$ が得られる。$\rho^2e^{-2u}=(1-\rho^2)/(\beta-1)$ を $I(Y;Z)=-\tfrac12\log(1-\rho^2+\rho^2e^{-2u})$ に代入すれば 2 つ目の式が得られる。$\blacksquare$

<!--en:1ba7e94f-->
先ほどは一般のデータ処理不等式の議論から $\beta\le1$ での崩壊が保証された。しかし $\rho=0.9$ のガウス対では、実際には崩壊が $\beta\le1/\rho^2=1.235$ に至るまで続く。この閾値以下では、レートを 1 nat 増やすごとに目的関数に $1$ が加わる一方で減少量は高々 $\beta\rho^2\le1$ にとどまる。フロンティアの傾きがその初期値 $\rho^2$ を決して超えないからである。閾値を超えると、$\beta$ の増加に伴って動作点はフロンティアに沿って上限へと滑り上がっていく。$\beta=2$ ではレート $u^*=\tfrac12\ln(0.81/0.19)=0.725$ nat とラベル情報量 $0.484$ nat が得られ、$\beta=16$ ではそれぞれ $2.079$ nat と $0.798$ nat に達する。:numref:`fig_mdl-ib-tradeoff` は、横軸にレート $I(X;Z)$、縦軸にラベル情報量 $I(Y;Z)$ をとった*情報平面*（information plane）上に、このフロンティアと各動作点を描いたものである。

<!--en:1dd2c63d-->
![$\rho = 0.9$ のガウス情報ボトルネックの情報平面。凹フロンティアは達成可能な最大の $I(Y;Z)$ を各レート $I(X;Z)$ に対してたどり、その上方の網掛け領域は実行不可能である。破線の上限はデータ処理不等式の限界 $I(X;Y) = -\tfrac{1}{2}\log(1-\rho^2) \approx 0.830$ nat を表す。フロンティアは原点を傾き $\rho^2$ で出発し、乗数は傾きが $1/\beta$ に等しくなる点を選択する。$\beta\le1/\rho^2\approx1.23$ ではその点は原点へと崩壊する。](../img/mdl-it-ib-tradeoff.svg)

<!--en:f205f04a-->
これほど鋭い相転移は数値的にも確かめておく価値がある。命題によれば、最適エンコーダは $\beta=1.2$ では何も保持しないが、$\beta=1.25$ では情報を保持するはずである。以下では閉形式解を用いずに、$4{,}001$ 個のノイズスケールからなるグリッド上でラグランジアンを直接最小化する。

<!--en:2d026be7-->
グリッド探索と閉形式解は 0.001 nat の精度で一致し、命題が予測したとおりの位置に崩壊の閾値があることが確認できる。$\beta=1.2$ では定数エンコーダが最適であるのに対し、$\beta=1.25$ ではエンコーダはすでに $0.032$ nat を保持している。ノイズスケール $\sigma$ をもつまったく同じこのエンコーダが、二乗誤差に対するレート・歪み曲線 $R(D)$ も $D=\sigma^2/(1+\sigma^2)$ において達成していることに注目しよう。レート・歪み理論はエンコーダが $X$ をどれだけうまく再構成するかで評価するのに対し、情報ボトルネックは $Y$ をどれだけうまく予測するかで評価するのである。

<!--en:d8c7a5d0-->
### 変分情報ボトルネック

<!--en:0bfdcea0-->
ガウス対に対しては、ボトルネック目的関数に含まれる 2 つの相互情報量をどちらも解析的に計算できた。しかし実データでは真の同時分布が未知であるため、どちらも計算できない。観測できるのはサンプル $(x,y)$ と、設計者が選んだエンコーダ $p(z\mid x)$ のみである。*変分情報ボトルネック*（variational information bottleneck）は、各相互情報量をサンプルから推定できる扱いやすい上下界に置き換えることで、この目的関数を訓練可能にする :cite:`Alemi.Fischer.Dillon.ea.2017`。

<!--en:c3497264-->
ラベルの項については、必要な下界がすでに手元にある。デコーダ $q(y\mid z)$（表現からラベルを予測する分類器）を導入し、その交差エントロピー損失を $L_Z=\mathbb{E}[-\log q(Y\mid Z)]$ とする。損失による保証 :eqref:`eq_mdl-info-certificate` を対 $(Z,Y)$ に適用すれば、直ちに $I(Y;Z)\ge H(Y)-L_Z$ が得られる。

<!--en:48219d90-->
一方、レート $I(X;Z)$ は*最小化*したい量であるため、今度は上界が必要になる。レートを条件付き形式 :eqref:`eq_mdl-mi-conditional-form`、すなわち $I(X;Z)=\mathbb{E}_x\big[D_{\textrm{KL}}(p(z\mid x)\,\|\,p(z))\big]$ で書こう。エンコーダ $p(z\mid x)$ は既知であるが、集約された周辺分布 $p(z)$ は $p(z\mid x)$ を未知のデータ分布で平均したものであるため未知である。そこで $p(z)$ を、標準正規分布などの任意に選んだ固定の事前密度 $r(z)$ に置き換える。恒等式 $\log\frac{p(z\mid x)}{r(z)}=\log\frac{p(z\mid x)}{p(z)}+\log\frac{p(z)}{r(z)}$ を用いて $x$ と $z$ について期待値をとると、次式を得る。

<!--en:3b2c638d-->
選んだ事前分布 $r$ と真の周辺分布 $p(z)$ の間にずれがあると、レートの上界は膨らむ方向にしか動かない。演習問題 :exref:`ex_mdl-mutual-information-vae-rate` では、ガウスエンコーダに対してこのギャップを明示的に計算する。両方の上下界を組み合わせると、:eqref:`eq_mdl-vib-rate-bound` の左辺にある KL 項に $\beta L_Z$ を加えたものが、ボトルネック目的関数 :eqref:`eq_mdl-ib_lagrangian` の上界を（定数 $\beta H(Y)$ の差を除いて）与えることがわかる。どちらの項も訓練例に関する単純な期待値であるため、ニューラルネットワークは確率的勾配降下法（stochastic gradient descent）によってこの上界を直接最小化できる。

<!--en:17f259a8-->
変分オートエンコーダ（variational autoencoder）を訓練したことがあれば、:eqref:`eq_mdl-vib-rate-bound` の左辺にはすぐ見覚えがあるだろう。変分オートエンコーダ（:numref:`sec_diffusion-latent`）とは、入力自身をラベルとしたまったく同じ構成にほかならない。すなわち、エンコーダ $p(z\mid x)$、固定の事前分布 $r(z)$、そして別のクラスラベルを予測する代わりに $x$ を $z$ から再構成するデコーダからなる。その訓練損失は、再構成誤差に重み付きの KL ペナルティを加えたものである。本節の視点から見れば、その KL ペナルティはレートの上界であり、潜在コードが入力について蓄えられる nat 数を制限する一方、再構成誤差が歪みの役割を担っている。異なるのはトレードオフの重みを置く位置だけである。:eqref:`eq_mdl-ib_lagrangian` が保持される情報量に $\beta$ を掛けるのに対し、変分オートエンコーダは KL レート項に重みを置くため、あちらでの大きな KL 重みはこちらでの小さな $\beta$ に対応する。

<!--en:951b1d19-->
デコーダの交差エントロピー損失と事前分布への KL ダイバージェンスは、本節の中でサンプルのみから評価できる唯一の量であり、一方の相互情報量には下界を、もう一方には上界を与えた。それ以外に計算してきた数値はすべて同時分布が既知であることに頼っていたが、実際の画像やテキストでは同時分布など決して手に入らない。:numref:`sec_mdl-mi-estimation` では、サンプルのみから相互情報量についてどこまで推定できるかを問う。

## まとめ

<!--en:4fd3ebe5-->
相互情報量は、同時分布とその周辺分布の積との間の KL ダイバージェンス $I(X;Y)=D_{\textrm{KL}}(P_{X,Y}\,\|\,P_X\otimes P_Y)$ であり、$X$ と $Y$ が独立であるとき、かつそのときに限り 0 となり、いずれの変数の可逆な再パラメータ化のもとでも不変である。線形相関とは異なり非線形な従属性を検出でき、相関が 0 であるにもかかわらず $1.14$ nat を $X$ と $Y=X^2+0.3\epsilon$ に割り当てる。データ処理不等式により、逐次処理は情報を生み出すことはできないが、ニューラルネットワークの層は分類器が読み取りやすいように既存の情報を並べ替えることができる。ファノの不等式は任意の目標誤り率を相互情報量の最小要件へと変換し、任意の確率モデルの交差エントロピー損失 $L$ は $I(X;Y)\ge H(Y)-L$ を保証する。Shannon の通信路容量とレート・歪み関数は、それぞれ入力に関する相互情報量の最大値と、非可逆エンコーダに関する最小値として現れる。最後に、情報ボトルネック $\min I(X;Z)-\beta I(Y;Z)$ は表現学習をラベルによって歪みが与えられるレート・歪み問題として定式化する。ガウス対に対しては $\beta$ が $1/\rho^2$ を超えるまで崩壊し、変分形式においてはそのレートペナルティが変分オートエンコーダでおなじみの KL 正則化項となる。

[基本定義]{.kicker}

<!--en:3c47a1ee-->
$X$ と $Y$ が独立なら、同時分布は周辺分布の積 $P_X \otimes P_Y$ になる。**相互情報量**は、真の同時分布からこの独立な積分布への KL ダイバージェンスである

<!--en:0275e927-->
- **反転ビット（$\delta = 0.1$）での計算：**独立な積は全セルに $0.25$ を置くため、$p_{X,Y}/(p_X p_Y)$ は一致する対角成分で $0.45/0.25 = 1.8$（重み $0.9$）、非対角成分で $0.05/0.25 = 0.2$（重み $0.1$）となる
  $$I(X; Y) = 0.9\ln 1.8 + 0.1\ln 0.2 = 0.529 - 0.161 = 0.368\text{ nats} \approx 0.531\text{ bits}$$

<!--en:c24932c4-->
- **条件付き KL の視点（行ごと）：**$\frac{p_{X,Y}(x, y)}{p_X(x)p_Y(y)} = \frac{p(y \mid x)}{p_Y(y)}$ より、$I(X; Y) = \mathbb{E}_{x \sim P_X}\big[D_{\textrm{KL}}(p(y \mid x) \,\|\, p_Y(y))\big]$ は $x$ の観測によって $Y$ が周辺事前分布 $p_Y$ からどれだけ変化するかを測る

<!--en:874ca09c-->
相互情報量は、個別・結合・条件付きエントロピーとどのように結びつくか。

- **非負性と独立性：**ギブスの不等式より $I(X; Y) = I(Y; X) \ge 0$ であり、$I(X; Y) = 0 \iff P_{X,Y} = P_X \otimes P_Y$（$X$ と $Y$ は独立）

  $$I(X; Y) = H(X) - H(X \mid Y) = H(Y) - H(Y \mid X)$$

2 変量ガウス対 $(X, Y)$（相関 $\rho \in (-1, 1)$）では、$X$ で条件付けると $Y$ の分散が $\sigma_Y^2$ から $\sigma_Y^2(1 - \rho^2)$ へ減少する

[1 次元数値求積とガウス上界]{.kicker}

$X \sim \mathcal{N}(0, 1)$ と $Y = X^2 + 0.3\epsilon$（$\rho = 0$）では、$X = x$ で条件付けると加法的ガウスノイズ $0.3\epsilon$ のみが残るため $h(Y \mid X) = \tfrac12\ln(2\pi e \cdot 0.09) = 0.215\text{ nats}$ となり、1 次元数値求積を $p_Y(y)$ に適用すると $h(Y) = 1.356\text{ nats}$、$I(X; Y) = 1.141\text{ nats}$ が得られる

<!--en:dd051826-->
::: {.slide title="全単射のもとでの再パラメータ化不変性"}

<!--en:d70da6fe-->
[座標系からの独立性]{.kicker}

<!--en:c80c449c-->
微分エントロピー $h(X)$（単位によってずれる）や線形相関 $\rho(X, Y)$（非線形な伸縮で変化する）とは異なり、相互情報量は変数のあらゆる可逆変換のもとで不変である

<!--en:f3dc5902-->
- **ヤコビ行列の因子が相殺される理由：**滑らかな全単射 $\tilde{x} = \phi(x)$ と $\tilde{y} = \psi(y)$ に対し、同時密度は $p_{\tilde{X},\tilde{Y}}(\tilde{x}, \tilde{y}) = p_{X,Y}(x, y)|\det D\phi(x)|^{-1}|\det D\psi(y)|^{-1}$ と変換され、周辺密度の積 $p_{\tilde{X}}(\tilde{x})p_{\tilde{Y}}(\tilde{y})$ にもまったく同じ 2 つのヤコビ行列の行列式因子が掛かるため、比 $\frac{p_{\tilde{X},\tilde{Y}}}{p_{\tilde{X}}p_{\tilde{Y}}}$ で打ち消し合う

<!--en:94cb1038-->
- **$\rho = 0.9$ のガウス対での具体例：**3 乗の全単射 $X \mapsto X^3$ を適用しても $I(X^3; Y) = I(X; Y) = 0.830\text{ nats}$ はまったく変わらないが、線形相関は $\rho = 0.900$ から $\frac{\mathbb{E}[X^3 Y]}{\sqrt{\textrm{Var}(X^3)\textrm{Var}(Y)}} = \frac{3\rho}{\sqrt{15}} = 0.697$ へと低下する

<!--en:8b20a5b6-->
::: {.slide title="条件付き相互情報量と連鎖律"}

<!--en:000b53ac-->
[3 変数の分解]{.kicker}

<!--en:606a4192-->
$X$ と $Y$ は、第 3 の変数 $Z$ が観測された後にどれだけの情報を共有するか。

<!--en:a9802757-->
- **条件付き相互情報量：**
  $$I(X; Y \mid Z) = H(X \mid Z) - H(X \mid Y, Z) \ge 0$$
  これは $\mathbb{E}_z[D_{\textrm{KL}}(P_{X,Y\mid z} \| P_{X\mid z}\otimes P_{Y\mid z})]$ に等しく、$X \perp Y \mid Z$ のとき、かつそのときに限り 0 になる

<!--en:59e2e25b-->
- **相互情報量の連鎖律：**
  $$I(X; Y, Z) = I(X; Z) + I(X; Y \mid Z) = I(X; Y) + I(X; Z \mid Y)$$

<!--en:9400d48e-->
- **直列の 2 回反転（$\delta_1 = 0.1, \delta_2 = 0.2 \implies \delta = 0.26$）：**$I(X; Y, Z) = 0.368 = 0.120 + 0.248\text{ nats}$

<!--en:8f4cb2a6-->
::: {.slide title="データ処理不等式（DPI）"}

<!--en:16ea4e4a-->
[逐次処理は情報を生み出せない]{.kicker}

<!--en:c11f3f68-->
3 変数が**マルコフ連鎖** $X \to Y \to Z$ をなすとは、$Z$ が $(X, Y)$ に $Y$ を通じてのみ依存することである（$p(z \mid x, y) = p(z \mid y)$、あるいは同値な条件として $I(X; Z \mid Y) = 0$）。

<!--en:82a7d2dc-->
**定理（データ処理不等式）：**$X \to Y \to Z$ がマルコフ連鎖ならば
$$I(X; Z) \le I(X; Y)$$
が成り立ち、等号成立は $I(X; Y \mid Z) = 0$ のとき、かつそのときに限る（すなわち $X \to Z \to Y$ もマルコフ連鎖となる）。

<!--en:d7df146b-->
- **連鎖律からの 2 行の証明：**$I(X; Y, Z)$ を両方の順序で展開する
  $$\begin{aligned} I(X; Z) + I(X; Y \mid Z) &= I(X; Y, Z) = I(X; Y) + \underbrace{I(X; Z \mid Y)}_{= 0 \text{ (Markov)}} \\ \implies I(X; Z) &= I(X; Y) - \underbrace{I(X; Y \mid Z)}_{\ge 0} \le I(X; Y) \quad \blacksquare \end{aligned}$$

<!--en:53c747b4-->
- **十分統計量：**等号 $I(X; T(Y)) = I(X; Y)$ は、$T(Y)$ が $Y$ に含まれる $X$ の情報をすべて保持するとき、かつそのときに限り成り立つ（$p(x \mid y) = p(x \mid T(y))$。例：コインの偏りに対する表の合計回数）

<!--en:1c9ffe2f-->
::: {.slide title="条件付けはデータ処理ではない：XOR のシナジー"}

<!--en:af0f3f9e-->
[条件付けが相互情報量を増やすとき]{.kicker}

<!--en:8905644d-->
不等式 $I(X; Y \mid Z) \le I(X; Y)$ はマルコフ連鎖 $X \to Y \to Z$ の内部では成り立つが、一般には成り立た*ない*。$X, Y$ が独立な公平なビットで $Z = X \oplus Y$ のとき、$Z$ を観測すると共有情報量は $0$ から $\ln 2 = 0.693\text{ nats}$ へ跳ね上がる

<!--en:fefa4e5b-->
::: {.slide title="深層ネットワークの層が担う役割：利用可能情報量"}

<!--en:478ba0ba-->
[深層学習における DPI の解釈]{.kicker}

<!--en:cc3a9c8e-->
フィードフォワードネットワーク $Y \to X \to Z_1 \to Z_2 \to \cdots$ に沿って、データ処理不等式は次を保証する

<!--en:7c81ec36-->
- **深さが有効な理由：**隠れ層は新たな Shannon 情報量を生み出せないが、同心状の多様体を解きほぐす（例：$Z_1 = \|X\|_2^2 \in \{1, 4\}$）ことで、制限された線形読み出し族 $\mathcal{V}$ が $\ln 2$ nat すべてを抽出できるようにする（**利用可能情報量**）

<!--en:40185af0-->
::: {.slide title="ファノの不等式：予測には情報量が必要"}

<!--en:bdb5f4d8-->
[分類誤差の下界]{.kicker}

<!--en:a3abf1c7-->
相互情報量 $I(X; Y)$ を入力 $X$ が $k$ クラスラベル $Y$ についてどれだけ保持していれば、*任意の*分類器 $\hat{Y} = g(X) \in \{1, \ldots, k\}$ が誤り確率 $P_e = \Pr(\hat{Y} \neq Y)$ を達成できるか。

<!--en:d5cf21ad-->
**定理（ファノの不等式）：**任意の $k$ クラス目的変数 $Y$ と、誤り率を伴う任意の推定器 $\hat{Y} = g(X) \in \{1, \ldots, k\}$（誤り率 $P_e = \Pr(\hat{Y} \neq Y)$）に対し、
$$H_b(P_e) + P_e \log(k - 1) \ge H(Y \mid X) = H(Y) - I(X; Y)$$

<!--en:f6fe6a32-->
- **符号化の直観（$\hat{Y}$ の修復）：**$Y$ を $\hat{Y}$ から復元するには、$H_b(P_e)$ nat で $\hat{Y}$ が誤ったかを伝え、誤ったときには高々 $\log(k-1)$ nat で残り $k-1$ クラスのどれが生じたかを伝えればよい（確率 $P_e$）

<!--en:8942ac01-->
::: {.slide title="ファノの不等式の 3 ステップ証明"}

<!--en:b5050e3a-->
[誤り指示変数と連鎖律]{.kicker}

<!--en:a5cd4e08-->
$W = \mathbf{1}\{\hat{Y} \neq Y\} \in \{0, 1\}$ を 2 値の誤り指示変数（$P(W = 1) = P_e$）とし、条件付きエントロピー $H(W, Y \mid \hat{Y})$ を 2 通りに展開する

<!--en:72f63103-->
- **ステップ 1（$W$ は $Y$ と $\hat{Y}$ の決定論的関数）：**
  $$H(W, Y \mid \hat{Y}) = H(Y \mid \hat{Y}) + \underbrace{H(W \mid Y, \hat{Y})}_{= 0} = H(Y \mid \hat{Y})$$

<!--en:f3a8d82e-->
- **ステップ 2（$W$ を先に展開し両項を上から抑える）：**
  $$H(W, Y \mid \hat{Y}) = \underbrace{H(W \mid \hat{Y})}_{\le H(W) = H_b(P_e)} + \underbrace{H(Y \mid W, \hat{Y})}_{= (1-P_e)\cdot 0 + P_e H(Y \mid W=1, \hat{Y}) \le P_e \log(k-1)}$$

<!--en:1d01ebcc-->
- **ステップ 3（$Y \to X \to \hat{Y}$ にデータ処理不等式を適用）：**$I(Y; \hat{Y}) \le I(Y; X)$ より、$H(Y \mid X) \le H(Y \mid \hat{Y}) \le H_b(P_e) + P_e \log(k - 1)$ を得る。$\blacksquare$

<!--en:1adb090d-->
::: {.slide title="テスト損失による保証：I(X; Y) ≥ H(Y) − L"}

<!--en:8ea1d6d6-->
[Barber–Agakov 変分保証]{.kicker}

<!--en:9a1ac2c9-->
ファノの不等式がハードな誤り率 $P_e$ を用いるのに対し、任意の確率的予測器 $q(y \mid x)$ のホールドアウト交差エントロピー損失 $L = \mathbb{E}_{(x,y) \sim P_{X,Y}}[-\log q(y \mid x)]$ は $I(X; Y)$ の下界を直接保証する

<!--en:2e08dc2e-->
::: {.slide title="Shannon の 2 つの曲線：容量とレート・歪み"}

<!--en:ca5d986f-->
[相互情報量の極値問題]{.kicker}

<!--en:3200c44b-->
通信と非可逆圧縮における Shannon の 2 つの根本的な操作限界は、相互情報量に関する双対な極値問題である

<!--en:dbde9b07-->
- **通信路容量（左）：**雑音通信路 $p(y \mid x)$ を固定し、送信者の入力分布に関して*最大化*する：$C = \max_{p(x)} I(X; Y)$

<!--en:6371804c-->
- **レート・歪み（右）：**情報源 $p(x)$ を固定し、非可逆エンコーダ $p(\hat{x} \mid x)$ に関して歪み許容値 $D$ のもとで*最小化*する：$R(D) = \inf_{p(\hat{x} \mid x): \mathbb{E}[d(X, \hat{X})] \le D} I(X; \hat{X})$

<!--en:59c37705-->
::: {.slide title="2 元対称通信路の容量"}

<!--en:bdc88c69-->
[入力分布に関する最大化]{.kicker}

<!--en:4417ed13-->
送信ビットをそれぞれ独立に確率 $\delta \in [0, 1]$ で反転させる 2 元対称通信路では、$p(y \mid x)$ の各行のエントロピーが $H_b(\delta)$ であるため、$I(X; Y) = H(Y) - H_b(\delta)$ は $Y$（したがって $X$）が一様分布（$\tfrac12, \tfrac12$）のときに最大化される

<!--en:3e0b5023-->
::: {.slide title="ガウス情報源のレート・歪み：1 ビットで RMS 誤差が半減"}

<!--en:ff022d96-->
[非可逆エンコーダに関する最小化]{.kicker}

<!--en:8a735c16-->
ガウス情報源 $X \sim \mathcal{N}(0, \sigma_X^2)$ と二乗誤差歪み $\mathbb{E}[(X - \hat{X})^2] \le D < \sigma_X^2$ のもとでのレート・歪み関数は次のとおりである

<!--en:a6b4c083-->
- **下界の証明：**
  $$\begin{aligned} I(X; \hat{X}) &= h(X) - h(X - \hat{X} \mid \hat{X}) \ge h(X) - h(X - \hat{X}) \\ &\ge \tfrac12\log(2\pi e\sigma_X^2) - \tfrac12\log(2\pi e D) = \tfrac12\log(\sigma_X^2/D). \end{aligned}$$

<!--en:dacee9a1-->
- **加法的ガウス通信路による下界の達成：**$Z = X + \sigma\epsilon$ と符号化し、事後平均 $\hat{X} = \mathbb{E}[X \mid Z] = \frac{\sigma_X^2}{\sigma_X^2 + \sigma^2}Z$ で再構成する

<!--en:25032209-->
::: {.slide title="レート・歪みとしての情報ボトルネック"}

<!--en:7785b855-->
[タスクに関連する表現学習]{.kicker}

<!--en:775cbdfe-->
$Y \to X \to Z$ に沿って、**情報ボトルネック**（Tishby et al., 1999）は圧縮レートと保持されるラベル情報量のトレードオフをとる

<!--en:fe9e26ce-->
- **レート・歪み恒等式：**$I(Y; Z) = I(X; Y) - \mathbb{E}[D_{\textrm{KL}}(p(y \mid x) \| p(y \mid z))]$ が成り立ち、エンコーダは崩壊（$I(X; Z) = 0$）を $\beta \le 1$ で常に起こす

<!--en:18d47a00-->
::: {.slide title="ガウス情報ボトルネックの閉形式解"}

<!--en:f3999d7e-->
[凹フロンティアと相転移]{.kicker}

<!--en:58bd9e8f-->
2 変量ガウス対 $(X, Y)$（相関 $\rho = 0.9$、$I(X; Y) = 0.830\text{ nats}$）と加法的エンコーダ $Z = X + \sigma\epsilon$ に対し、レートを $u = I(X; Z) = \tfrac12\log(1 + \sigma^{-2})$ とおくと厳密な最適フロンティアが得られる

<!--en:d5cf71e6-->
- **情報平面上の凹曲線：**
  $$I(Y; Z) = -\frac{1}{2}\log\Big(1 - \rho^2\big(1 - e^{-2u}\big)\Big)$$

<!--en:eaafdacf-->
- **$\beta_c = 1/\rho^2$ における相転移：**フロンティアは $(0, 0)$ を傾き $\frac{dI(Y;Z)}{du}\big|_{u=0} = \rho^2 = 0.81$ で出発し、すべての $\beta \le 1/\rho^2 \approx 1.235$ で最適エンコーダは**崩壊**する（$u^* = 0$）

<!--en:da41a32d-->
- **$\beta > 1/\rho^2$ における動作点：**
  $$u^* = \frac{1}{2}\log\frac{\rho^2(\beta - 1)}{1 - \rho^2}$$

<!--en:a5abeba0-->
::: {.slide title="ボトルネックの相転移の検証と VIB"}

<!--en:bb361bb0-->
[グリッド探索と変分オートエンコーダ]{.kicker}

<!--en:3a09721b-->
$4{,}001$ 個のノイズスケール $\sigma$ にわたるグリッド探索により、$\beta = 1.20$ での崩壊と $\beta = 1.25$ での立ち上がりが確認できる

<!--en:a03ce4b3-->
- **変分情報ボトルネック（VIB）と VAE：**$p(z)$ が未知のとき、事前分布 $r(z) = \mathcal{N}(0, I)$ に置き換えると $\mathbb{E}_x[D_{\textrm{KL}}(p(z \mid x) \| r(z))] = I(X; Z) + D_{\textrm{KL}}(p(z) \| r(z)) \ge I(X; Z)$ によりレートが上から抑えられる。これは変分オートエンコーダの KL 正則化項そのものである

<!--en:ec8af6e0-->
::: {.slide title="概念チェック：縦続通信路・容量・IB"}

<!--en:929b7671-->
[理解度の確認]{.kicker}

<!--en:e140a4fa-->
以下の 3 つの問題に取り組んでみよう

<!--en:90ca82e6-->
1. **直列の 2 本のノイズ回線：**公平なビット $X$ が $\delta_1 = 0.1$ の反転通信路を通って $Y$ を生じ、$Y$ が独立な $\delta_2 = 0.2$ の反転通信路を通って $Z$ を生じるとき、$I(X; Y)$、$I(X; Z)$、$I(X; Z \mid Y)$、$I(X; Y \mid Z)$ はいくらか。

<!--en:10a664c4-->
2. **2 元対称通信路の容量：**反転確率 $\delta = 1.0$ の BSC が無雑音通信路（$\delta = 0$）と同じ容量（$\ln 2\text{ nats}$）をもつのに対し、$\delta = 0.5$ では容量が $0$ になるのはなぜか。

<!--en:82db2a1b-->
3. **ガウス情報ボトルネックの動作点：**$\rho = 0.9$（$\rho^2 = 0.81$）のガウス対に対し、最適レート $u^* = I(X; Z)^*$ と保持されるラベル情報量 $I(Y; Z)^*$ をトレードオフ乗数 $\beta = 2$ で計算せよ。

<!--en:29b5f4fc-->
::: {.slide title="概念チェック：縦続通信路・容量・IB（続き）"}

<!--en:929b7671-2-->
[理解度の確認]{.kicker}

<!--en:557b98b6-->
**解答：**

<!--en:61ccedf4-->
1. **縦続反転：**$I(X; Y) = \ln 2 - H_b(0.1) = 0.368\text{ nats}$。合成反転確率は $0.1(0.8) + 0.9(0.2) = 0.26$ なので $I(X; Z) = \ln 2 - H_b(0.26) = 0.120\text{ nats}$。マルコフ連鎖 $X \to Y \to Z$ より $I(X; Z \mid Y) = 0$ であり、連鎖律から $I(X; Y \mid Z) = 0.368 - 0.120 = 0.248\text{ nats}$

<!--en:1c996b23-->
2. **BSC の容量：**$C(\delta) = \ln 2 - H_b(\delta)$。$\delta = 1$ では全ビットが決定論的に反転し（$H_b(1) = 0$）、受信者が反転し直せばよい。$\delta = 0.5$ では出力が入力と独立な公平なコインとなる（$H_b(0.5) = \ln 2 \implies C = 0$）

<!--en:7fa4c5a5-->
3. **$\beta = 2$ でのガウス IB：**$\beta = 2 > 1/0.81 = 1.235$ より、$u^* = \tfrac12\ln\frac{0.81(1)}{0.19} = 0.725\text{ nats}$、また $I(Y; Z)^* = \tfrac12\ln\frac{1}{2(0.19)} = 0.484\text{ nats}$
